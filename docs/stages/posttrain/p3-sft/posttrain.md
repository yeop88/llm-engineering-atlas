# 후학습 — 데이터 · 선별 · LoRA SFT · DPO · 병합 · 학습 전후 평가 · GGUF · 실측 (P1~P7)

화면은 `/posttrain/data`(학습 데이터 · 선별) · `/posttrain/train`(SFT · DPO · 병합) · `/posttrain/eval`(학습 전후 평가 · GGUF), 코드는 `app/stages/posttrain/` 입니다. 학습한 모델은 응용 모델 표(`kind=llm_adapter · llm_merged`)에, 가중치는 `data/posttrain/models/<번호>` 에 둡니다.

```
증류 데이터(7a) · 플라이휠 학습 데이터(FW4) · 합성 거절 ─┐
선호 쌍(8b) ────────────────────────────────────────┴─ 선별(형식 → 중복 → 평가 누수) ─ JSONL
   → LoRA SFT(답 부분 손실) / DPO(기준 = 어댑터를 끈 같은 모델) → 어댑터 · 병합(가중 합 · TIES · 기본 모델에)
   → 앱 안 OpenAI 호환 끝점(pt-base · pt-번호) → LLM 비교(7b) + 레드팀(G7) 같은 조건 → GGUF · 양자화 → llama-server
```

## 설계

- **작은 모델로 실제로 돈다.** 이 PC 는 CPU · 내장 GPU 라 큰 LLM 학습은 못 하지만, 학습 · 평가의 흐름 자체(데이터 → 학습 → 같은 조건 비교 → 배포 형식)는 작은 모델(`POSTTRAIN_BASE_MODEL`, 기본 Qwen3-0.6B)로 끝까지 돌릴 수 있습니다. GPU 가 있으면 같은 화면에서 기본 모델만 바꿉니다.
- **거절 예시를 섞는다.** 답 있는 예시만 학습하면 모델이 근거가 없어도 그럴듯하게 답하는 쪽으로 기웁니다(법률 실측에서 답 없는 질문 거절은 13개 중 1개). 평가 세트의 '답 없는 질문'을 실제 검색 근거와 함께 '근거에서 찾을 수 없습니다'로 만듭니다. 플라이휠 학습 데이터는 정답 문서의 근거를 붙여 넣고, 근거가 없는 예시는 뺍니다 — '근거 없이 답하기'를 가르치지 않게.
- **선별은 단계별로.** 형식 오류 → 거의 같은 예시(질문 바이그램 겹침 0.9 이상) → 평가 세트 누수(평가 질문과 0.8 이상). 단계마다 남은 건수 · 출처별 수 · 누수로 뺀 예를 남겨, 데이터가 왜 줄었는지 설명할 수 있게 합니다. 누수 검사에 쓰는 세트는 학습 전후 비교에 쓸 세트입니다.
- **TRL 없이 직접.** 필요한 손실이 두 개뿐이고(답 부분의 다음 글자 손실, DPO 손실) 작은 모델 몇십~몇백 걸음을 도는 데 트레이너 계층은 설정을 숨깁니다. transformers + peft(LoRA, q · k · v · o)로 걸음마다 손실을 작업 진행에 남기고, 취소하면 멈춥니다. fp16 은 쓰지 않습니다(bf16 지원 GPU 가 아니면 fp32 — 저장소 규칙과 같은 이유).
- **SFT 는 답 부분에만 손실.** 시스템 · 근거 · 질문까지 맞히게 하면 근거를 '외우는' 쪽으로 학습해, 답 형식 · 인용 습관이라는 목적과 어긋납니다. 길면 근거 앞부분을 잘라 답을 남깁니다(답이 잘리면 배울 것이 없음). Qwen3 의 생각 블록은 끕니다.
- **DPO 기준 모델은 어댑터를 끈 같은 모델.** 메모리에 모델 둘을 올리지 않으려고(`disable_adapter`). SFT 어댑터 위에서 이어 학습할 수 있습니다(흔한 순서: SFT → DPO). 걸음마다 선호 맞힘 비율(정책이 좋은 답에 더 높은 상대 확률을 주는 비율)을 남깁니다.
- **평가는 같은 주소 모양으로.** 학습한 모델을 앱 안의 OpenAI 호환 끝점(`/api/posttrain/v1`)으로 올리면, LLM 비교(7b) · 레드팀(G7) · 연결 비교가 받는 'LLM 설정'과 같은 모양이라 새 평가를 만들지 않고 같은 질문 · 같은 근거 · 같은 채점 · 같은 공격으로 학습 전후를 비교합니다. 첫 모델이 기준(짝 비교)이고, 품질이 올라도 안전성(공격 방어 · 정상 통과)이 떨어지면 쓰지 않습니다.
- **배포 형식.** 기본 모델에 합친 모델 → GGUF(llama.cpp 의 `convert_hf_to_gguf.py`, `LLAMA_CONVERT_SCRIPT`) → `llama-quantize` → llama-server. 변환 스크립트는 실행 파일 묶음에 없어, 없으면 실행할 명령을 그대로 보입니다. 변환 뒤에는 서빙 실측(S5) · LLM 비교로 학습 효과가 양자화 뒤에도 남았는지 다시 잽니다.
