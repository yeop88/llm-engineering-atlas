# P1 · 합성 데이터 생성 (Synthetic data)

**상태: 🟡 기초 있음** — 큰 모델 · 규칙으로 질문 · 답 · 거절 예시를 만들어 학습 데이터를 늘린다

## 원리

합성 데이터는 지문에서 질문을 만들고 교사 모델이 근거를 인용해 답한 쌍, 규칙으로 만든 거절 예시 등입니다. 다양성(질문 유형)과 정확성(검증 통과)을 함께 봅니다.

## 왜 하는가

사람이 만든 학습 데이터는 비싸고 적습니다. 평가 질문 생성 · LLM 증류 데이터를 이미 만들고 있어 확장이 쉽습니다.

## 어떻게 (이 앱에서)

- (있음) 평가 질문 7유형 생성, LLM 증류 데이터(교사 답 → 검증 통과만 JSONL)
- (예정) 거절 · 되묻기 예시 합성, 유형별 균형

## 화면
