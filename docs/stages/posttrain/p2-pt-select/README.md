# P2 · 선별 · 누수 방지 (Filtering & decontamination)

**상태: 🟡 기초 있음** — 검증을 통과한 좋은 예시만 남기고, 평가 세트의 근거가 학습에 섞이지 않게 한다

## 원리

선별은 근거 일치 · 질문 관련성 · 형식 검사를 통과한 예시만 남기는 것이고, 누수 방지는 평가 세트의 근거 지문이 학습 데이터에 들어가지 않게 빼는 것입니다.

## 왜 하는가

나쁜 예시를 배우면 나쁜 습관을 배웁니다(LLM 증류 데이터는 검증으로 1/3 만 남음). 누수가 있으면 평가가 부풀려집니다.

## 어떻게 (이 앱에서)

- (있음) 검증 기반 선별(근거 일치 · 질문 관련성), 평가 근거 지문 제외(여러 근거 모두)
- (예정) 거의 같은 예시 제거, 선별 기준별 남은 건수 보고

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pt_select` 에서 볼 수 있습니다.
