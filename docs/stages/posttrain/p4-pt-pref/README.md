# P4 · 선호 학습 (DPO 등) (Preference optimization)

**상태: ⬜ 예정** — 좋은 답 / 나쁜 답 쌍으로 모델이 좋은 쪽을 고르도록 학습한다

## 원리

DPO 는 같은 질문의 좋은 답 · 나쁜 답 쌍으로 보상 모델 없이 선호를 학습합니다. 쌍은 사람 판정 · 보상 함수 · Best-of-N 에서 만듭니다.

## 왜 하는가

'지어내지 말고 거절하기', '질문과 상관없는 조문 쓰지 않기'는 좋은 예시만으로는 잘 안 배워지고, 나쁜 예와 대비해야 배웁니다.

## 어떻게 (이 앱에서)

- (있음) 보상 함수 · Best-of-N · 선호 쌍 수집(자동 · 사람) · DPO 형식 JSONL 내보내기
- (예정) GPU 환경 DPO 학습, 보상-품질 일치 확인 후 학습

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pt_pref` 에서 볼 수 있습니다.

## 앞으로 할 일

- DPO 학습 (GPU)
- 보상-품질 일치 확인
