# P6 · 후학습 평가 · 안전성 (Post-training evaluation)

**상태: ⬜ 예정** — 학습 전후를 같은 평가 세트 · 같은 조건으로 비교하고, 안전성 회귀가 없는지 본다

## 원리

후학습은 목표한 능력을 올리면서 다른 능력 · 안전성을 떨어뜨릴 수 있습니다(망각). 도메인 평가 세트 · 일반 능력 · 레드팀 세트를 함께 다시 잽니다.

## 왜 하는가

학습 효과는 같은 조건의 비교로만 확인할 수 있습니다 — 파인튜닝 실측에서 작은 데이터 · 높은 학습률은 오히려 나빠졌습니다.

## 어떻게 (이 앱에서)

- (있음) 평가 세트 · 연결 비교 · 짝지은 통계, 임베딩 파인튜닝 전후 비교
- (예정) LLM 학습 전후 비교(품질 · 거절률 · 관련성 · 안전성)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pt_eval` 에서 볼 수 있습니다.
