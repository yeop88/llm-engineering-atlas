# P5 · 어댑터 (LoRA) · 모델 병합 (Adapters & merging)

**상태: ⬜ 예정** — 분야별 어댑터를 따로 학습해 갈아 끼우거나, 여러 모델을 합쳐 장점을 모은다

## 원리

LoRA 어댑터는 원래 모델을 두고 작은 추가 가중치만 학습해 분야별로 갈아 끼웁니다. 모델 병합은 여러 미세조정 모델의 가중치를 합쳐 하나로 만듭니다.

## 왜 하는가

분야(법률 · AS · 사내 규정)마다 전체 모델을 따로 두면 메모리가 모자랍니다. 어댑터는 서버 하나에서 분야별로 바꿔 쓸 수 있습니다.

## 어떻게 (이 앱에서)

- (예정) 분야별 LoRA, llama-server 어댑터 로드, 병합 실험

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pt_adapter` 에서 볼 수 있습니다.
