# RS4 · 검증기 · 과정 보상 (Verifiers & process rewards)

**상태: ✅ 구현됨** — 답 · 풀이 단계를 검증기로 채점해 고른다

## 원리

검증기는 답이 맞는지 판정하는 모델 · 규칙이고, 과정 보상 모델은 풀이의 각 단계를 채점합니다. 고르기의 품질은 검증기의 정확도를 넘지 못합니다.

## 왜 하는가

LLM 판정은 그 자체가 틀립니다(검증 보정 실측). 규칙으로 확인할 수 있는 것(조문 번호 · 숫자)은 규칙으로, 나머지는 판정의 정확도를 따로 잽니다.

## 어떻게 (이 앱에서)

- (기반) 검증 가능한 보상(RV3) · 검증 에이전트(MA7)
- 정답을 모르는 검증기: '정답:' 줄 · 답이 자료 · 그래프 집계(합)에 있나 · 생각의 각 문장의 조문 번호 · 수가 자료에서 왔나(과정 채점) · LLM 판정
- 검증기마다 맞은 · 틀린 풀이를 가르는 AUROC · 0.5 기준 정확도와 그 검증기로 골랐을 때의 정답률
