# RS1 · 생각 예산 (Thinking budget)

**상태: ⬜ 예정** — 생각 토큰 상한을 바꿔 가며 정답률 · 지연 · 비용 곡선을 잰다

## 원리

생각 예산은 답 전에 쓸 수 있는 생각 토큰의 상한입니다. 상한을 늘리면 어려운 문제의 정답률이 오르다가 평평해지고, 지연 · 비용은 계속 늡니다.

## 왜 하는가

어느 지점에서 정답률이 더 오르지 않는지 모르면 예산을 감으로 정하게 됩니다. 질문 유형마다 그 지점이 다릅니다.

## 어떻게 (이 앱에서)

- (기반) 비용 · 지연 예산(S7) · 생각 끄기 설정
- (예정) 생각 상한별 정답률 · 지연 곡선 · 유형별 꺾이는 점

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/rs_budget` 에서 볼 수 있습니다.
