# RS3 · 여러 번 풀고 고르기 (Self-consistency & Best-of-N)

**상태: ✅ 구현됨** — 같은 질문을 여러 번 풀어 다수결 · 점수로 고른다

## 원리

자기 일관성은 같은 문제를 여러 번 풀어 가장 많이 나온 답을 고르고, Best-of-N 은 점수 함수로 가장 좋은 답을 고릅니다. 연산을 더 써서 정확도를 사는 방법입니다.

## 왜 하는가

몇 번까지 풀어야 이득인지, 다수결과 점수 고르기 중 무엇이 나은지는 과제마다 다릅니다.

## 어떻게 (이 앱에서)

- (기반) Best-of-N · 보상 함수(8b)
- 온도를 두고 n 번 풀어 풀이 저장소에 쌓고, n = 1 … N 의 다수결(정규화한 답의 최빈값) · 검증기 고르기 · pass@n(상한) 곡선을 한 번에 — 앞 n 개만 써서 새로 부르지 않음
