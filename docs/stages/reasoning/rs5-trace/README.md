# RS5 · 생각 과정 검사 (Reasoning trace audit)

**상태: ✅ 구현됨** — 생각과 답이 맞는지, 생각에 근거 밖 사실 · 개인정보가 없는지 본다

## 원리

생각 과정 검사는 생각 글을 출력처럼 다루는 것입니다. 생각의 결론과 답이 다르거나, 생각에만 나온 근거 밖 사실 · 개인정보 · 숨은 지시 따르기를 찾습니다.

## 왜 하는가

생각 글을 사용자에게 보여 주거나 기록하면 그것도 출력입니다. 생각에서 한 계산과 답의 숫자가 다르면 답을 믿을 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 출력 검사 · 개인정보(G4 · G2) · 입력 방어(G1)
- 생각마다: 생각의 결론과 최종 답 불일치 · 자료에 없는 조문 번호 · 수 · 개인정보 · 인젝션 표현
- 표시마다 표시된 풀이와 나머지의 정답률 — 검사가 쓸모 있는 신호인지

## 화면
