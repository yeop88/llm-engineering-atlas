# RS5 · 생각 과정 검사 (Reasoning trace audit)

**상태: ⬜ 예정** — 생각과 답이 맞는지, 생각에 근거 밖 사실 · 개인정보가 없는지 본다

## 원리

생각 과정 검사는 생각 글을 출력처럼 다루는 것입니다. 생각의 결론과 답이 다르거나, 생각에만 나온 근거 밖 사실 · 개인정보 · 숨은 지시 따르기를 찾습니다.

## 왜 하는가

생각 글을 사용자에게 보여 주거나 기록하면 그것도 출력입니다. 생각에서 한 계산과 답의 숫자가 다르면 답을 믿을 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 출력 검사 · 개인정보(G4 · G2)
- (예정) 생각-답 일치 · 생각의 근거 밖 주장 · 개인정보 검사

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/rs_trace` 에서 볼 수 있습니다.

## 앞으로 할 일

- 생각-답 일치 · 생각의 근거 밖 주장 · 개인정보 검사
