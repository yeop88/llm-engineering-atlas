# RS6 · 추론 증류 (Reasoning distillation)

**상태: ⬜ 예정** — 큰 추론 모델의 풀이로 작은 모델을 학습해 싸게 생각하게 한다

## 원리

추론 증류는 큰 모델이 쓴 풀이(생각 + 답) 중 검증을 통과한 것만 모아 작은 모델을 SFT 하는 것입니다.

## 왜 하는가

큰 추론 모델은 비싸고 느립니다. 자주 나오는 유형의 풀이를 작은 모델에 옮기면 같은 정확도를 싸게 얻을 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 지식 증류(7a) · LoRA SFT(P3)
- (예정) 검증 통과 풀이 모으기 · 작은 모델 학습 · 정답률 · 길이 비교

## 화면
