# RS2 · 생각할지 말지 라우팅 (Adaptive reasoning)

**상태: ✅ 구현됨** — 질문 난이도를 보고 생각 모드 · 예산을 고른다

## 원리

적응형 추론은 쉬운 질문은 바로 답하고, 계산 · 여러 조문 결합 · 다단계 질문만 생각하게 하는 것입니다. 라우터가 난이도를 미리 판단합니다.

## 왜 하는가

모든 질문에 생각을 켜면 쉬운 질문까지 몇 배 느려집니다. 라우팅 실측처럼 질문을 나누면 같은 품질을 싸게 얻습니다.

## 어떻게 (이 앱에서)

- (기반) 규칙 · 확신도 · 학습 라우터(6)
- 질문 글만 보고 생각을 켤지: 규칙(계산 · 집계 · 결합 표현) 또는 LLM(생각 없이 한 낱말)
- 같은 과제의 끔 · 켬 풀이로 네 정책(늘 끔 · 늘 켬 · 라우터 · 이상적)의 정답률 · 평균 토큰 · 시간 · 유형별 켠 비율
