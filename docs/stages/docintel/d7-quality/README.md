# D7 · 데이터 품질 점검 (Data quality checks)

**상태: ✅ 구현됨** — 처리 단계별 건수 · 길이 분포 · 근거 보존을 점검하고 처리 기록을 남긴다

## 원리

데이터 품질 점검은 수집 · 정제 · 청킹 각 단계에서 남은 건수, 길이 분포, 이상한 글(반복 · 깨진 글자), 평가 근거의 보존을 확인하고 그 결과를 기록하는 것입니다.

## 왜 하는가

통계만 보면 문제를 못 찾고(법령 반복 행), 기록이 없으면 같은 실수를 반복합니다.

## 어떻게 (이 앱에서)

- 컬렉션 상태: 갱신이 필요한 청크 세트 · 문서 수
- 청크 품질 · 근거 보존 보고(D5)와 파싱 점검(D2)을 한 화면에

## 화면

- `/docintel/quality#chunks` — **근거 보존**: 평가 세트 근거가 한 청크에 남았는지

## 앞으로 할 일

- 품질 점수 추세
