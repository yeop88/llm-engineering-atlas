# D3 · 레이아웃 · 표 · 그림 추출 (Layout, tables & figures)

**상태: ✅ 구현됨** — 제목 · 단락 · 표 · 그림 영역을 나눠, 표는 구조로 · 그림은 이미지 청크로 남긴다

## 원리

레이아웃 분석은 페이지에서 제목 · 단락 · 표 · 그림 · 머리말 영역을 나누는 것입니다. 표는 행 · 열 구조로, 그림은 이미지로 따로 저장하면 글로 뭉개지지 않습니다.

## 왜 하는가

표를 글로 펴면 행 · 열 관계가 사라져 '3분기 매출' 같은 질문에 답할 수 없습니다. 법령 표의 행 반복 문제도 표 구조를 모르고 처리해서 생겼습니다.

## 어떻게 (이 앱에서)

- pdfplumber 로 표 → 마크다운 표(페이지 글에 '[표 p-n]'으로 넣어 검색 · 인용)
- 그림 → 미디어 청크(1장 = 1청크, 멀티모달 검색 · 답변에 첨부)
