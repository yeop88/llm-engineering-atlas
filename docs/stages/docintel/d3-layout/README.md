# D3 · 레이아웃 · 표 · 그림 추출 (Layout, tables & figures)

**상태: ⬜ 예정** — 제목 · 단락 · 표 · 그림 영역을 나눠, 표는 구조로 · 그림은 이미지 청크로 남긴다

## 원리

레이아웃 분석은 페이지에서 제목 · 단락 · 표 · 그림 · 머리말 영역을 나누는 것입니다. 표는 행 · 열 구조로, 그림은 이미지로 따로 저장하면 글로 뭉개지지 않습니다.

## 왜 하는가

표를 글로 펴면 행 · 열 관계가 사라져 '3분기 매출' 같은 질문에 답할 수 없습니다. 법령 표의 행 반복 문제도 표 구조를 모르고 처리해서 생겼습니다.

## 어떻게 (이 앱에서)

- (있음) 법령 조문 구조(조 · 항 · 호) 인식, 이미지 · 영상 프레임 청크
- (예정) PDF 표 추출(구조 보존), 그림 영역 → 이미지 청크(멀티모달 RAG 와 연결)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/doc_layout` 에서 볼 수 있습니다.

## 앞으로 할 일

- PDF 표 구조 추출
- 그림 영역 이미지 청크
