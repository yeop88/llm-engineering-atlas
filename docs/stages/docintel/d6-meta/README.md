# D6 · 메타데이터 · 증분 갱신 (Metadata & incremental updates)

**상태: ✅ 구현됨** — 문서 날짜 · 종류 · 권한 메타데이터를 붙이고, 바뀐 문서만 다시 색인한다

## 원리

메타데이터(작성일 · 시행일 · 종류 · 부서 · 권한)는 검색 필터와 최신성 판단에 쓰입니다. 증분 갱신은 문서가 바뀌면 그 문서의 청크만 다시 만들어 색인을 최신으로 유지하는 것입니다.

## 왜 하는가

전체 다시 색인은 이 PC 에서 법률 자료 하나에 44분이 걸렸습니다. 자주 바뀌는 사내 문서를 매번 전부 다시 할 수는 없습니다.

## 어떻게 (이 앱에서)

- 문서 메타(종류 · 부서 · 제품 모델 · 날짜 · 권한 · 판) 편집 · 모음, 검색 설정의 filters(종류 · 부서 · 제품 · 날짜 · 최신판만)
- 증분 갱신: 바뀐 시각(changed_at)이 청크 세트 갱신 시각보다 뒤인 문서만 다시 청크 · 임베딩
