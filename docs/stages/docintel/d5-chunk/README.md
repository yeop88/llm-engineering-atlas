# D5 · 청킹 (Chunking)

**상태: 🟡 기초 있음** — 문서를 검색 단위로 자르되 근거 문장이 경계에서 잘리지 않게 한다

## 원리

청킹은 문서를 임베딩 · 검색 단위로 자르는 것입니다. 크기 · 겹침 · 구조(조문 · 제목) 기준 · 짧은 청크 합치기를 정하고, 근거 문장이 청크 하나에 온전히 들어가는 비율로 평가합니다.

## 왜 하는가

청크가 너무 길면 질문과 무관한 글이 섞이고, 너무 짧거나 경계가 나쁘면 근거가 잘립니다. 법률 자료에서 짧은 청크가 35% 였고, 일부 근거는 경계에 걸쳐 어느 청크에도 온전히 없었습니다.

## 어떻게 (이 앱에서)

- (있음) 재귀 · 문장 · 법률 구조 청킹, 겹침, 최소 글자, 짧은 청크 합치기(−42% 청크 · 품질 동일), 청크 세트별 조합 평가
- (예정) '근거를 온전히 담은 청크 비율' 지표, 표 · 그림을 고려한 청킹
