# 정제 · 청크 품질 · 근거 보존 (D4 · D5 · D7)

화면은 `/docintel/quality`(정제 · 중복 · 판, 청크 품질 · 근거 보존)입니다.

## D4 정제 · 중복 · 판

- **머리말 · 꼬리말**: 3쪽 이상 문서에서 여러 쪽에 반복되는 줄과 쪽 번호 패턴(`- 3 -`, `3 / 35`)을 찾아 지웁니다. 반복 줄이 청크마다 섞이면 서로 다른 청크가 비슷해 보여 검색 순위가 흐려집니다.
- **거의 같은 문서**: 공백을 뺀 글자 5-gram 해시(1/4 표본) 집합의 Jaccard 유사도(기본 0.85 이상). 같은 내용을 HWP · PDF 로 두 번 올린 경우가 흔합니다.
- **판 묶기**: 파일 이름에서 확장자 · 판 표시(최종 · 수정본 · v2 · 날짜 등)를 뺀 제목이 같은 문서를 묶고, 날짜 · 올린 순서로 최신판만 남기고 나머지에 `superseded` 를 붙입니다(검색 필터 '최신판만').
- **판은 파일 이름으로만 묶습니다.** 처음에는 문서 첫 제목도 썼는데, 법률 컬렉션의 판례들이 모두 같은 머리('【전문】')로 시작해 서로 다른 판례 수십 개가 한 문서의 판으로 묶였습니다 — 적용했다면 대부분이 옛 판으로 숨겨질 뻔했습니다. 사건 번호 · 법령 이름이 다른 문서는 다른 문서입니다.

실측(2026-10-21): 공공문서 컬렉션 — `2022년 국립국어원 업무계획` HWP · PDF 가 거의 같은 문서(0.97)이자 판 묶음으로 잡힘, PDF 꼬리말 `- # -`(33쪽)과 편람의 반복 머리말을 찾음. 법률 컬렉션(170문서) — 판 묶음 0, 거의 같은 문서 0(고친 뒤).

## D5 청크 품질

청크 세트마다 길이 분포 · 너무 짧은 청크(<50자) · 똑같은 청크 · 깨진 글자가 섞인 청크 · 빈 문서 · 여러 청크에 반복되는 줄을 보고합니다.

| 청크 세트 | 청크 | 중앙 길이 | 짧은 청크 | 똑같은 청크 |
|---|---|---|---|---|
| 공공문서 #1 재귀 600/80 | 576 | 567 | 0.2% | 0 |
| 공공문서 #2 법률 구조 800/0 | 497 | 727 | 3.2% | 2 |
| 법률 #4 법률 구조 800/100 | 2,762 | 244 | **21.4%** | 86 |
| 법률 #5 법률 구조 800/100 + 짧은 청크 합치기 200 | 1,613 | 647 | **0.6%** | 1 |

#4 → #5 는 2 RAG 에서 '짧은 조문이 청크 하나가 돼 검색을 흐린다'를 보고 합치기를 넣은 변화인데, 이 보고가 같은 문제를 숫자로 바로 보여 줍니다(짧은 청크 21% → 0.6%, 똑같은 청크 86 → 1).
