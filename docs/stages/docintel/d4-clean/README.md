# D4 · 정제 · 중복 · 버전 (Cleaning, dedup & versions)

**상태: 🟡 기초 있음** — 머리말 · 반복 행 같은 잡음을 걷고, 거의 같은 문서 · 개정판을 정리한다

## 원리

정제는 검색을 방해하는 잡음(머리말 · 쪽 번호 · 반복 행 · 목차)을 걷는 것이고, 중복 정리는 같은 내용의 다른 파일 · 개정 전후판을 찾아 하나만 쓰거나 버전으로 묶는 것입니다.

## 왜 하는가

잡음 · 중복은 검색 결과 상위를 차지해 정답을 밀어냅니다. 개정판이 섞이면 옛 조항으로 답합니다.

## 어떻게 (이 앱에서)

- (있음) 법령 조 · 항 반복 제거(실제 텍스트를 열어 발견), 같은 파일 해시 건너뜀, 의미 응용의 중복 · 표절 검사
- (예정) 거의 같은 문서 자동 묶기, 개정판 버전 관리(최신만 검색 · 이전판 보관)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/doc_clean` 에서 볼 수 있습니다.

## 앞으로 할 일

- 거의 같은 문서 묶기
- 개정판 버전 관리
