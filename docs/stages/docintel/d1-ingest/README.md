# D1 · 수집 · 연결 (Ingestion & connectors)

**상태: 🟡 기초 있음** — 파일 업로드 · 공개 데이터 · 사내 시스템에서 원본을 가져오고 출처를 남긴다

## 원리

수집은 원본을 그대로 가져와 출처 · 시각 · 해시와 함께 저장하는 단계입니다. 같은 파일은 해시로 걸러 중복 색인을 막고, 원본을 남겨 처리 방법이 바뀌면 다시 처리할 수 있게 합니다.

## 왜 하는가

원본과 출처가 없으면 처리 실수를 고칠 수 없고, 답변의 근거를 원문으로 보여 줄 수 없습니다.

## 어떻게 (이 앱에서)

- (있음) 컬렉션 업로드(같은 파일 해시로 건너뜀), 공개 자료 프리셋(법령 · 판례, 원본 캐시 · 출처 · 라이선스)
- (예정) 사내 시스템 연결(공유 폴더 · 위키 · DB), 주기적 수집

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/doc_ingest` 에서 볼 수 있습니다.

## 앞으로 할 일

- 사내 시스템 연결
- 주기적 수집
