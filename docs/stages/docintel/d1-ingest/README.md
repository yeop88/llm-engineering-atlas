# D1 · 수집 · 연결 (Ingestion & connectors)

**상태: ✅ 구현됨** — 파일 업로드 · 공개 데이터 · 사내 시스템에서 원본을 가져오고 출처를 남긴다

## 원리

수집은 원본을 그대로 가져와 출처 · 시각 · 해시와 함께 저장하는 단계입니다. 같은 파일은 해시로 걸러 중복 색인을 막고, 원본을 남겨 처리 방법이 바뀌면 다시 처리할 수 있게 합니다.

## 왜 하는가

원본과 출처가 없으면 처리 실수를 고칠 수 없고, 답변의 근거를 원문으로 보여 줄 수 없습니다.

## 어떻게 (이 앱에서)

- 폴더 소스(INGEST_ROOTS 안만 — 서버의 아무 폴더나 읽지 못하게) · 파일 패턴 · 주기(분), 파일 sha 로 새 · 바뀜 · 지움 · 그대로 판단
- 주기 수집(앱 안 1분 주기 스레드) → 바뀐 문서만 증분 갱신
- 원본 파일을 sha 로 보관(다시 파싱 · OCR 할 때)

## 화면

- `/docintel/sources` — **수집 · 메타 · 증분 갱신**: 폴더 소스 동기화, 문서 메타데이터, 바뀐 문서만 다시 색인

## 앞으로 할 일

- 사내 시스템(그룹웨어 · 위키) 연결
