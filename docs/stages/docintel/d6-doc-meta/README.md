# D6 · 메타데이터 · 증분 갱신 (Metadata & incremental updates)

**상태: ⬜ 예정** — 문서 날짜 · 종류 · 권한 메타데이터를 붙이고, 바뀐 문서만 다시 색인한다

## 원리

메타데이터(작성일 · 시행일 · 종류 · 부서 · 권한)는 검색 필터와 최신성 판단에 쓰입니다. 증분 갱신은 문서가 바뀌면 그 문서의 청크만 다시 만들어 색인을 최신으로 유지하는 것입니다.

## 왜 하는가

전체 다시 색인은 이 PC 에서 법률 자료 하나에 44분이 걸렸습니다. 자주 바뀌는 사내 문서를 매번 전부 다시 할 수는 없습니다.

## 어떻게 (이 앱에서)

- (있음) 문서별 메타(출처 · 라이선스 · 사건번호), 청크 메타(조문 제목 · 페이지)
- (예정) 바뀐 문서 감지 → 그 문서 청크만 다시 색인, 메타데이터 필터 검색

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/doc_meta` 에서 볼 수 있습니다.

## 앞으로 할 일

- 바뀐 문서만 재색인
- 메타데이터 필터
