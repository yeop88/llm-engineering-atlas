# D7 · 데이터 품질 점검 (Data quality checks)

**상태: 🟡 기초 있음** — 처리 단계별 건수 · 길이 분포 · 근거 보존을 점검하고 처리 기록을 남긴다

## 원리

데이터 품질 점검은 수집 · 정제 · 청킹 각 단계에서 남은 건수, 길이 분포, 이상한 글(반복 · 깨진 글자), 평가 근거의 보존을 확인하고 그 결과를 기록하는 것입니다.

## 왜 하는가

통계만 보면 문제를 못 찾고(법령 반복 행), 기록이 없으면 같은 실수를 반복합니다.

## 어떻게 (이 앱에서)

- (있음) 데이터 처리 문서(단계별 건수 · 발견한 문제 · 점검 목록), 평가 근거의 원문 일치 검사(법률 6% 보정)
- (예정) 청크 세트별 자동 품질 보고(길이 분포 · 짧은 청크 · 반복 · 근거 보존)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/doc_quality` 에서 볼 수 있습니다.
