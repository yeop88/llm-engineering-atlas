# PF6 · 장애 대응 · 대체 모델 (Resilience & fallback)

**상태: ⬜ 예정** — 모델 서버 · 벡터 DB · 외부 API 가 멈추면 대체 경로로 넘어가고, 품질 차이를 알린다

## 원리

대체(fallback) 경로는 큰 모델 → 작은 모델, 로컬 → 클라우드 API, 벡터 검색 → 키워드 검색 처럼 미리 정해 둡니다. 재시도 · 시간 제한 · 차단기(실패가 계속되면 잠시 안 부름)를 함께 씁니다.

## 왜 하는가

단일 모델 서버는 단일 장애점입니다. 대체 경로의 품질을 미리 재 두지 않으면 장애 때 무엇을 잃는지 모릅니다(E2B 는 품질 −13).

## 어떻게 (이 앱에서)

- (있음) LLM 호출 재시도(429 · 5xx 지수 백오프), 검증 모델 실패 시 글자 검증으로 돌아가기, 모델별 서버 주소
- (예정) 대체 경로 정의 · 차단기, 대체 시 품질 표시

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pf_resilience` 에서 볼 수 있습니다.
