# PF2 · 멀티테넌트 격리 (Multi-tenant isolation)

**상태: ⬜ 예정** — 부서 · 고객사마다 자료 · 색인 · 설정 · 로그를 분리해 서로 보이지 않게 한다

## 원리

격리 수준은 같은 색인에 테넌트 필터(싸지만 실수 위험)부터 테넌트별 색인 · DB(안전하지만 비쌈)까지 있습니다. 자료의 민감도에 따라 고르고, 어느 경우든 데이터 단에서 강제합니다.

## 왜 하는가

한 테넌트의 문서가 다른 테넌트 답변의 근거로 나오면 가장 큰 사고입니다.

## 어떻게 (이 앱에서)

- (기반) 권한별 검색(G3) — 검색 문서 제한(doc_ids)
- (예정) 테넌트 단위 컬렉션 · 색인 분리, 격리 누출 테스트

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pf_tenancy` 에서 볼 수 있습니다.

## 앞으로 할 일

- 테넌트 단위 분리
- 격리 누출 테스트
