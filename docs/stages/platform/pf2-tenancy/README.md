# PF2 · 멀티테넌트 격리 (Multi-tenant isolation)

**상태: ✅ 구현됨** — 부서 · 고객사마다 자료 · 색인 · 설정 · 로그를 분리해 서로 보이지 않게 한다

## 원리

격리 수준은 같은 색인에 테넌트 필터(싸지만 실수 위험)부터 테넌트별 색인 · DB(안전하지만 비쌈)까지 있습니다. 자료의 민감도에 따라 고르고, 어느 경우든 데이터 단에서 강제합니다.

## 왜 하는가

한 테넌트의 문서가 다른 테넌트 답변의 근거로 나오면 가장 큰 사고입니다.

## 어떻게 (이 앱에서)

- 테넌트 = 사용자 그룹 'tenant:<이름>', 컬렉션을 테넌트에 묶음(pf_tenant_collections, 마이그레이션 0017)
- 연결 계층의 검색 제한(restrict)이 다른 테넌트의 컬렉션이면 결과를 비움 — 문서 권한(G3)과 같은 자리라 LLM 이 읽지도 않음
- 누출 시험: 테넌트마다 남의 컬렉션을 그 테넌트 그룹으로 검색해 결과 수 0 인지
