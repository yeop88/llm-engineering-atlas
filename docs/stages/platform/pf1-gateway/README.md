# PF1 · API 게이트웨이 (API gateway)

**상태: ✅ 구현됨** — 모든 요청이 들어오는 입구에서 인증 · 테넌트 구분 · 속도 제한 · 사용량 기록을 한다

## 원리

게이트웨이는 사용자 · 앱의 요청을 받아 인증하고, 어느 테넌트(부서 · 고객사)의 요청인지 정하고, 과도한 호출을 제한하고, 사용량을 기록한 뒤 뒤의 서비스로 넘깁니다.

## 왜 하는가

서비스마다 인증 · 제한을 따로 만들면 빠지는 곳이 생깁니다. 입구 하나에서 하면 정책을 한 곳에서 바꿀 수 있습니다.

## 어떻게 (이 앱에서)

- (있음) 선택형 접근 토큰(API_TOKEN · API_USERS) · 로그인
- 인증 미들웨어 안쪽에서 사용자 · 테넌트별 분당 요청 수(이동 창 60초, RATE_LIMIT_PER_MIN · 개별 상한), 넘으면 429 + Retry-After
- 사용량을 테넌트 · 사용자 · 경로 묶음별로 세어 화면에(서비스 비용 · 토큰은 요청 기록에서)
