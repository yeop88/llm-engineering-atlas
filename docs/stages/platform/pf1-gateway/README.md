# PF1 · API 게이트웨이 (API gateway)

**상태: 🟡 기초 있음** — 모든 요청이 들어오는 입구에서 인증 · 테넌트 구분 · 속도 제한 · 사용량 기록을 한다

## 원리

게이트웨이는 사용자 · 앱의 요청을 받아 인증하고, 어느 테넌트(부서 · 고객사)의 요청인지 정하고, 과도한 호출을 제한하고, 사용량을 기록한 뒤 뒤의 서비스로 넘깁니다.

## 왜 하는가

서비스마다 인증 · 제한을 따로 만들면 빠지는 곳이 생깁니다. 입구 하나에서 하면 정책을 한 곳에서 바꿀 수 있습니다.

## 어떻게 (이 앱에서)

- (있음) 선택형 접근 토큰(API_TOKEN) · 로그인 · 상태 확인(/api/health)
- (예정) 테넌트별 키 · 속도 제한 · 사용량 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pf_gateway` 에서 볼 수 있습니다.
