# PF4 · 설정 · 기능 플래그 (Config & feature flags)

**상태: ✅ 구현됨** — 테넌트 · 사용자 묶음별로 다른 설정을 켜고 끄며, 코드 배포 없이 동작을 바꾼다

## 원리

기능 플래그는 '고객센터 10% 에만 새 프롬프트', '법무팀만 에이전트 경로' 처럼 설정을 대상별로 켜는 스위치입니다. 단계적 배포 · A/B 의 실행 수단입니다.

## 왜 하는가

설정을 바꿀 때마다 코드를 배포하면 느리고 되돌리기 어렵습니다. 플래그로 켜고 끄면 문제가 생긴 대상만 바로 이전 설정으로 돌릴 수 있습니다.

## 어떻게 (이 앱에서)

- 플래그 = 기본값 + 대상 규칙(테넌트 · 그룹 · 사용자 · 비율 — 사용자 이름 해시라 같은 사용자는 같은 값), 첫 번째로 맞는 규칙
- 서비스 답변이 guard_mode · ai_notice · answer_relevance 플래그를 읽음(요청이 직접 고른 값 → 플래그 → 설정), 10초 기억, 바꾼 기록(누가 · 전후)
