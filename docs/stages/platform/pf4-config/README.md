# PF4 · 설정 · 기능 플래그 (Config & feature flags)

**상태: ⬜ 예정** — 테넌트 · 사용자 묶음별로 다른 설정을 켜고 끄며, 코드 배포 없이 동작을 바꾼다

## 원리

기능 플래그는 '고객센터 10% 에만 새 프롬프트', '법무팀만 에이전트 경로' 처럼 설정을 대상별로 켜는 스위치입니다. 단계적 배포 · A/B 의 실행 수단입니다.

## 왜 하는가

설정을 바꿀 때마다 코드를 배포하면 느리고 되돌리기 어렵습니다. 플래그로 켜고 끄면 문제가 생긴 대상만 바로 이전 설정으로 돌릴 수 있습니다.

## 어떻게 (이 앱에서)

- (있음) 경로별 설정(연결 실행 · 라우팅 경로 · 학습 라우터 선택)
- (예정) 대상별 플래그 · 변경 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pf_config` 에서 볼 수 있습니다.

## 앞으로 할 일
