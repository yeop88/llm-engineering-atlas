# PF7 · 비용 배분 · 사용량 보고 (Chargeback & usage reports)

**상태: ✅ 구현됨** — 테넌트 · 기능별 사용량과 비용을 집계해 배분하고, 예산을 넘기 전에 알린다

## 원리

비용 배분은 게이트웨이의 사용량 기록과 단계별 비용(토큰 · 시간 · GPU)을 테넌트 · 기능별로 나누는 것입니다.

## 왜 하는가

누가 얼마를 쓰는지 모르면 비싼 경로(에이전트 · 큰 모델)를 줄일 동기가 없습니다.

## 어떻게 (이 앱에서)

- 요청 기록(그룹 · 종류 · 토큰 · 비용)에서 이번 달 테넌트 · 기능별 요청 · 토큰 · 비용 · 지연을 집계 — 따로 세지 않아 숫자가 어긋나지 않음
- 테넌트 월 예산(pf_budgets) · 경보 비율, 닿으면 한 달에 한 번 ALERT_WEBHOOK
