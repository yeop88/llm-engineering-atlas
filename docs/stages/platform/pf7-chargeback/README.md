# PF7 · 비용 배분 · 사용량 보고 (Chargeback & usage reports)

**상태: ⬜ 예정** — 테넌트 · 기능별 사용량과 비용을 집계해 배분하고, 예산을 넘기 전에 알린다

## 원리

비용 배분은 게이트웨이의 사용량 기록과 단계별 비용(토큰 · 시간 · GPU)을 테넌트 · 기능별로 나누는 것입니다.

## 왜 하는가

누가 얼마를 쓰는지 모르면 비싼 경로(에이전트 · 큰 모델)를 줄일 동기가 없습니다.

## 어떻게 (이 앱에서)

- (기반) 비용 · 지연 대시보드(E4)
- (예정) 테넌트별 집계 · 예산 경보

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pf_chargeback` 에서 볼 수 있습니다.
