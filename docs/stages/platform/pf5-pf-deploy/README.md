# PF5 · 배포 · 단계적 출시 (Deployment)

**상태: 🟡 기초 있음** — 컨테이너로 배포하고, 버전 · 마이그레이션 · 릴리스 노트 규칙을 지킨다

## 원리

배포는 같은 이미지 · 같은 설정으로 어디서나 같은 동작을 보장하는 것입니다. 데이터베이스 변경은 마이그레이션으로, 버전은 의미 있는 번호(SemVer)로, 변경은 기록으로 남깁니다.

## 왜 하는가

로컬에서 되던 것이 서버에서 안 되는 문제(재부팅 뒤 실행 파일이 막힌 사례처럼)를 줄이려면 환경을 이미지로 고정해야 합니다.

## 어떻게 (이 앱에서)

- (있음) Dockerfile · compose app 프로필, Alembic 자동 마이그레이션, SemVer 릴리스 규칙 · CHANGELOG
- (예정) 스테이징 환경, 단계적 출시 연동(기능 플래그)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pf_deploy` 에서 볼 수 있습니다.
