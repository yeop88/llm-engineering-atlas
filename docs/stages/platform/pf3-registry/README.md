# PF3 · 모델 · 프롬프트 레지스트리 · 버전 (Model & prompt registry)

**상태: 🟡 기초 있음** — 모델 · 프롬프트 · 검색 설정을 버전으로 저장하고, 어느 답이 어느 버전에서 나왔는지 남긴다

## 원리

레지스트리는 바꿀 수 있는 모든 것(임베딩 모델 · LLM · 프롬프트 · 청킹 · 검색 설정)에 버전을 붙여 저장하는 곳입니다. 답변 기록에 버전을 남기면 품질 변화를 버전 변화와 연결할 수 있습니다.

## 왜 하는가

답변 규칙 하나를 바꿔도 같은 질문의 답이 바뀝니다(규칙 5번 추가로 답이 짧아짐). 버전 없이 기록하면 무엇 때문인지 알 수 없습니다.

## 어떻게 (이 앱에서)

- (있음) 모델 카탈로그(스펙 · 라이선스 · 캐시 상태), 호환성 점검, 저장된 라우터 · 분류기, 실행 이력의 설정 기록
- (예정) 프롬프트 버전 · 설정 묶음 버전, 답변 기록에 버전 연결

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/pf_registry` 에서 볼 수 있습니다.
