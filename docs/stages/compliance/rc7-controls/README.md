# RC7 · 규정 조항 ↔ 시스템 통제 매핑 (Control mapping (graph))

**상태: ✅ 구현됨** — 규정 조항과 시스템 통제(기능 · 설정 · 기록)를 그래프로 연결해 개정 영향을 바로 찾는다

## 원리

지식 그래프 맵의 방식으로 '통제 -근거→ 조항', '기능 -적용→ 통제', '기록 -증명→ 통제' 관계를 만듭니다. 조항이 개정되면 연결된 통제 · 기능을 바로 찾을 수 있습니다.

## 왜 하는가

규정과 시스템이 문서로만 연결되어 있으면 개정 때 무엇을 바꿔야 하는지 사람이 처음부터 찾아야 합니다.

## 어떻게 (이 앱에서)

- 법령 문서에서 조문 노드를 정형 추출(K3)하고 '통제 -근거→ 조항' · '기능 -적용→ 통제'를 그래프 저장소(K5)에, 시행령의 '법 제N조' 참조도 함께
- 자료의 판을 API 의 현행 · 시행예정 판과 조항별로 비교(개정 표시 · 띄어쓰기는 무시)해 바뀐 조항 → 영향받는 통제 · 기능
