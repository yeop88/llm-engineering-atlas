# RC4 · 설명 가능성 · 결정 기록 (Explainability & decision records)

**상태: ✅ 구현됨** — 답 · 결정마다 근거 문서 · 검증 결과 · 사용한 버전을 남겨 '왜 그렇게 답했나'를 설명할 수 있게 한다

## 원리

설명 가능성은 모델 내부를 설명하는 것이 아니라 결정의 근거를 보여 주는 것부터 시작합니다 — 어떤 문서의 어느 문장을 근거로, 어떤 검증을 통과했고, 어느 설정 버전이었는지.

## 왜 하는가

고객 · 감사인이 '왜 그 답이 나왔나'를 물을 때 근거 인용과 기록이 답입니다.

## 어떻게 (이 앱에서)

- 요청 기록에서 질문 · 답 · 근거 청크 본문 · 문장별 검증 · 조문 인용 검사 · 가드레일 조치 · 모델 · 단계를 한 장으로(새로 기록하지 않음)
- 그 행의 해시와 앞 행과의 이음을 다시 계산해 기록이 고쳐지지 않았음을 보이고, 남의 기록은 관리자만

## 화면

- `/compliance/records#decisions` — **결정 기록**: 답 하나의 근거 · 검증 · 조치 · 무결성
