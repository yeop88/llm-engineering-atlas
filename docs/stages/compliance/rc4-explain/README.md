# RC4 · 설명 가능성 · 결정 기록 (Explainability & decision records)

**상태: 🟡 기초 있음** — 답 · 결정마다 근거 문서 · 검증 결과 · 사용한 버전을 남겨 '왜 그렇게 답했나'를 설명할 수 있게 한다

## 원리

설명 가능성은 모델 내부를 설명하는 것이 아니라 결정의 근거를 보여 주는 것부터 시작합니다 — 어떤 문서의 어느 문장을 근거로, 어떤 검증을 통과했고, 어느 설정 버전이었는지.

## 왜 하는가

고객 · 감사인이 '왜 그 답이 나왔나'를 물을 때 근거 인용과 기록이 답입니다.

## 어떻게 (이 앱에서)

- (있음) 근거 번호 인용 · 문장별 근거 일치 · 질문 관련성 · 조문 번호 검사, 실행 이력
- (예정) 답변별 결정 기록(근거 · 검증 · 버전) 조회 화면

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/rc_explain` 에서 볼 수 있습니다.
