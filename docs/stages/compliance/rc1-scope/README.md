# RC1 · 적용 규제 식별 (Regulatory scoping)

**상태: ✅ 구현됨** — 서비스 · 자료 · 사용자에 따라 적용되는 법령 · 지침을 목록으로 만들고 근거 조항을 연결한다

## 원리

규제 식별은 서비스가 다루는 데이터(개인정보 · 신용 · 건강), 사용자(소비자 · 직원), 결정의 영향(안내 · 판단)을 보고 적용 법령 · 지침 · 업종 규정을 목록으로 만드는 것입니다. 각 항목에 근거 조항을 붙입니다.

## 왜 하는가

적용 규제를 모르면 무엇을 지켜야 할지 정할 수 없습니다. 법령 원문을 RAG 로 찾고 조항 번호로 연결하는 일은 이 프로젝트의 법률 자료 · 번호 조회가 이미 하는 일입니다.

## 어떻게 (이 앱에서)

- 국가법령정보 공동활용 API 로 법령의 시행일별 판을 받아 규제 자료 컬렉션에(법령마다 한 판, 출처에 시행일 · MST) — 데이터셋은 '제N조의M' 가지번호를 버려 개인정보 보호법 조항이 126 → 76개였다
- 기능 특성(생성형 AI · 개인정보 · 민감정보 · 자동화된 결정 · 고영향 영역) → 적용 규칙(조항 · 의무 요지 · 통제, presets/rules.json) — 조항 원문을 함께
- 검색은 규칙이 놓친 조항을 '검토할 후보'로만, 의무 질문 22개로 근거 조항 검색을 잰다(조항 단위 hit@k · MRR)
