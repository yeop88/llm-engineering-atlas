# RC5 · 영향 평가 (Impact assessment)

**상태: ⬜ 예정** — 출시 전에 정확도 · 편향 · 안전성 · 개인정보 영향을 측정해 기록하고 승인받는다

## 원리

영향 평가는 기능이 누구에게 어떤 영향을 줄 수 있는지 측정 결과(평가 세트 · 레드팀 · 질문 유형별 성능)와 함께 문서로 남기는 것입니다. 질문 유형 · 사용자 집단별 차이를 봅니다.

## 왜 하는가

평균 성능이 좋아도 특정 유형에서 크게 실패할 수 있습니다 — 법률 실측에서 여러 문서 질문은 nDCG 37, 답 없는 질문 거절은 13개 중 1개였습니다.

## 어떻게 (이 앱에서)

- (기반) 오프라인 평가 · 회귀(E2) · 레드팀(G7), 질문 유형별 지표
- (예정) 영향 평가 양식 · 승인 기록
