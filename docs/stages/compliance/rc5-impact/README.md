# RC5 · 영향 평가 (Impact assessment)

**상태: ✅ 구현됨** — 출시 전에 정확도 · 편향 · 안전성 · 개인정보 영향을 측정해 기록하고 승인받는다

## 원리

영향 평가는 기능이 누구에게 어떤 영향을 줄 수 있는지 측정 결과(평가 세트 · 레드팀 · 질문 유형별 성능)와 함께 문서로 남기는 것입니다. 질문 유형 · 사용자 집단별 차이를 봅니다.

## 왜 하는가

평균 성능이 좋아도 특정 유형에서 크게 실패할 수 있습니다 — 법률 실측에서 여러 문서 질문은 nDCG 37, 답 없는 질문 거절은 13개 중 1개였습니다.

## 어떻게 (이 앱에서)

- 최근 측정 기록(검색 평가 · 레드팀 · 대화 평가 · 드리프트)과 근거 자료 속 개인정보를 run 번호와 함께 모은다(새로 돌리지 않음)
- 전체보다 0.10 이상 낮은 질문 유형 · 통과 못 한 공격 유형을 약한 집단으로 짚고, 사람이 영향받는 사람 · 완화책 · 결론을 적어 승인

## 화면

- `/compliance/audit` — **영향 평가 · 통제 감사**: 측정 기록으로 영향 평가 초안 · 승인, 통제 감사

## 앞으로 할 일

- 사용자 집단(연령 · 지역)별 지표 — 평가 세트에 집단 표시가 필요
