# RC3 · 데이터 처리 근거 · 보관 (Data processing basis & retention)

**상태: 🟡 기초 있음** — 자료 · 로그마다 수집 근거 · 목적 · 보관 기한을 기록하고, 기한이 지나면 지운다

## 원리

데이터 처리 근거는 각 자료를 왜 · 어떤 근거(동의 · 계약 · 공개 자료 라이선스)로 수집했고, 무엇에 쓰며, 언제까지 보관하는지의 기록입니다.

## 왜 하는가

출처 · 근거가 없는 자료는 나중에 지울 수도, 쓸 수도 없게 됩니다. 공개 자료 가져오기가 문서마다 출처 · 라이선스를 남기는 것이 이 원칙의 시작입니다.

## 어떻게 (이 앱에서)

- (있음) 공개 자료의 문서별 출처 · 라이선스, 데이터 처리 문서(단계별 처리 기록)
- (예정) 목적 · 보관 기한 메타데이터 · 기한 만료 삭제

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/rc_data` 에서 볼 수 있습니다.
