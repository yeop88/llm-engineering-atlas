# RC3 · 데이터 처리 근거 · 보관 (Data processing basis & retention)

**상태: ✅ 구현됨** — 자료 · 로그마다 수집 근거 · 목적 · 보관 기한을 기록하고, 기한이 지나면 지운다

## 원리

데이터 처리 근거는 각 자료를 왜 · 어떤 근거(동의 · 계약 · 공개 자료 라이선스)로 수집했고, 무엇에 쓰며, 언제까지 보관하는지의 기록입니다.

## 왜 하는가

출처 · 근거가 없는 자료는 나중에 지울 수도, 쓸 수도 없게 됩니다. 공개 자료 가져오기가 문서마다 출처 · 라이선스를 남기는 것이 이 원칙의 시작입니다.

## 어떻게 (이 앱에서)

- 컬렉션 · 요청 기록 · 고객 프로필 · AS 대화를 한 처리 목록으로 — 문서 수 · 출처 · 라이선스 · 가장 오래된 기록 · 기한 지난 수
- 대상마다 처리 목적 · 근거 · 보관 일수 · 담당을 등록(개인정보 보호법 제30조 처리방침에 옮길 수 있는 모양)
- 기한이 지난 요청 기록 · 프로필 · 컬렉션 문서(청크 · 벡터까지)를 관리자 · confirm 으로 파기

## 화면

- `/compliance/records` — **처리 근거 · 결정 기록 · 검토 요청**: 처리 목록 · 보관 기한 · 결정 기록 · 사람 검토
