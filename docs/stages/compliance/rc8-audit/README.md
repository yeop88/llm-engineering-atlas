# RC8 · 정기 감사 · 증적 (Periodic audit & evidence)

**상태: ✅ 구현됨** — 통제가 실제로 동작했는지 로그 · 측정 기록 표본으로 정기 점검하고 증적을 남긴다

## 원리

정기 감사는 통제별로 증적(감사 로그 표본 · 측정 기록 · 설정 이력)을 모아 '실제로 지켜졌는가'를 확인하는 것입니다. 자동으로 모을 수 있는 증적은 자동으로 모읍니다.

## 왜 하는가

통제를 만들어 두는 것과 동작하는 것은 다릅니다. 증적이 없으면 감사에서 증명할 수 없습니다.

## 어떻게 (이 앱에서)

- 통제 15개마다 증적을 기록에서 모은다 — 최근 서비스 답 200건의 고지 · 개인정보 · 근거, 해시 사슬, 레드팀 최근 실행, 보관 기한, 사람 판단 기록
- 통과 · 실패 · 부분 · 없음(통제 자체가 없음) · 수동으로 나누고, WATCH_AUDIT_HOURS 마다 앱이 다시 돈다(LLM 없이)

## 화면
