# RC2 · 위험 등급 분류 (Risk classification)

**상태: ✅ 구현됨** — AI 기능마다 영향 · 자율성 · 데이터 민감도로 위험 등급을 정하고 등급별 통제를 고른다

## 원리

위험 등급은 기능이 사람에게 미치는 영향(안내 vs 결정), 사람이 개입하는지, 다루는 데이터의 민감도로 정합니다. 등급이 높을수록 설명 · 감사 · 사람 검토 같은 통제가 늘어납니다.

## 왜 하는가

모든 기능에 최고 수준 통제를 걸면 비용이 너무 크고, 반대면 위험합니다. 등급이 통제의 양을 정합니다.

## 어떻게 (이 앱에서)

- 기준표(결정의 영향 · 사람의 개입 · 데이터 민감도, 각 1~3) 점수 합으로 등급을 제안, 고영향 영역(인공지능 기본법 제2조제4호)은 점수와 상관없이 높음
- 등급별 필요한 통제와 아직 없는 통제를 보이고, 제안과 다르게 정하면 이유를 받아 초안 → 관리자 확정(누가 확정했는지 기록)
