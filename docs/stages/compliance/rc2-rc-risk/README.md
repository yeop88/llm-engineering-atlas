# RC2 · 위험 등급 분류 (Risk classification)

**상태: ⬜ 예정** — AI 기능마다 영향 · 자율성 · 데이터 민감도로 위험 등급을 정하고 등급별 통제를 고른다

## 원리

위험 등급은 기능이 사람에게 미치는 영향(안내 vs 결정), 사람이 개입하는지, 다루는 데이터의 민감도로 정합니다. 등급이 높을수록 설명 · 감사 · 사람 검토 같은 통제가 늘어납니다.

## 왜 하는가

모든 기능에 최고 수준 통제를 걸면 비용이 너무 크고, 반대면 위험합니다. 등급이 통제의 양을 정합니다.

## 어떻게 (이 앱에서)

- (기반) 의미 응용 분류기
- (예정) 등급 기준표 · 기능별 등급 기록(사람 검토로 확정)
