# RC6 · 사용자 고지 · 이의 제기 (Notice & contestation)

**상태: ⬜ 예정** — AI 가 답한다는 사실 · 한계를 알리고, 사람에게 다시 판단받을 길을 연다

## 원리

고지는 AI 응답임을 표시하고 한계(근거 자료 범위 · 법률 자문 아님)를 알리는 것이고, 이의 제기는 사용자가 사람 검토를 요청할 수 있는 경로입니다.

## 왜 하는가

AI 답을 사람이 한 판단으로 오해하면 위험합니다. 사람에게 넘기는 길(상담원 이관)이 이의 제기의 실제 수단입니다.

## 어떻게 (이 앱에서)

- (기반) 상담원 이관(C6)
- (예정) AI 응답 표시 · 한계 문구 · 사람 검토 요청 기록
