# RT3 · 부분 인식 (Partial recognition)

**상태: ✅ 구현됨** — 잠정 결과를 확정 규칙으로 굳혀 나간다

## 원리

부분 인식은 말하는 도중의 잠정 인식을 확정 규칙(연속 일치)으로 굳히는 것입니다. 확정된 부분만 다음 단계로 보냅니다.

## 왜 하는가

잠정 결과로 검색하면 고친 뒤에 다시 찾아야 하고, 끝까지 기다리면 늦습니다.

## 어떻게 (이 앱에서)

- (기반) 연속 일치 확정(OM2)
- 조각이 인식기를 지날 때마다 가설 → 연속 일치(agree) 확정, 확정 오류(확정 뒤 최종과 다른 낱말) · 깜빡임, 재전송 없는 손실은 못 들은 낱말로

## 화면
