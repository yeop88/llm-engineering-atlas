# RT5 · 점진 추론 (Incremental inference)

**상태: ⬜ 예정** — 문장 끝이 확정되면 검색 · 미리 채우기를 먼저 시작한다

## 원리

점진 추론은 말이 다 끝나기 전에 확정된 부분으로 검색 · 미리 채우기를 시작하고, 끝나면 나머지만 더하는 것입니다. 프롬프트 캐시가 앞부분을 다시 쓰게 합니다.

## 왜 하는가

끝점까지 기다렸다 시작하면 검색 · 미리 채우기 시간이 그대로 지연에 더해집니다.

## 어떻게 (이 앱에서)

- (기반) 짧은 지연 RAG(VC3) · 프롬프트 캐시(CX4)
- (예정) 미리 시작 · 캐시 적중 · 줄어든 지연

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/rt_incremental` 에서 볼 수 있습니다.
