# RT5 · 점진 추론 (Incremental inference)

**상태: ✅ 구현됨** — 문장 끝이 확정되면 검색 · 미리 채우기를 먼저 시작한다

## 원리

점진 추론은 말이 다 끝나기 전에 확정된 부분으로 검색 · 미리 채우기를 시작하고, 끝나면 나머지만 더하는 것입니다. 프롬프트 캐시가 앞부분을 다시 쓰게 합니다.

## 왜 하는가

끝점까지 기다렸다 시작하면 검색 · 미리 채우기 시간이 그대로 지연에 더해집니다.

## 어떻게 (이 앱에서)

- (기반) 짧은 지연 RAG(VC3) · 맥락 캐시(CX4)
- 확정 글이 문장 끝에 닿으면 검색을 끝점 전에 시작 — 끝점까지 남은 시간만큼(검색 몫 안에서) 줄인 시간

## 화면

- `/realtime/stream#run` — **점진 추론**: 문장 끝 확정 시 검색 미리 시작
