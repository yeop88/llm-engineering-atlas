# RT4 · 상태 갱신 (State update)

**상태: ✅ 구현됨** — 확정된 조각마다 대화 · 화면 상태를 갱신한다

## 원리

상태 갱신은 확정된 말 · 장면이 들어올 때마다 대화 상태(주제 · 제품 · 미해결 질문 · 지금 화면)를 고치는 것입니다. 상태는 서버에 두어 끊겨도 남게 합니다.

## 왜 하는가

상태가 화면(클라이언트)에만 있으면 연결이 잠깐만 끊겨도 대화가 처음으로 돌아가 고객이 다시 설명해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 대화 메모리(C3) · 옴니 융합(OM5)
- 확정된 글이 늘 때마다 대화 메모리 갱신(제품 · 오류 코드), 끝난 뒤 최종 글로 만든 상태와 같은지(상태 정확)

## 화면

- `/realtime/stream#run` — **상태 갱신**: 확정마다 제품 · 코드 상태, 최종과 일치
