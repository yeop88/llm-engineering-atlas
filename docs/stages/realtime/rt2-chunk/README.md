# RT2 · 조각 나누기 (Chunking)

**상태: ✅ 구현됨** — 조각 길이가 지연 · 인식 품질에 주는 영향을 잰다

## 원리

조각 나누기는 스트림을 처리 단위(소리 250ms · 프레임 1초)로 자르는 것입니다. 짧으면 빨리 반응하지만 처리 횟수와 오인식이 늘고, 길면 늦습니다.

## 왜 하는가

조각 길이 하나가 첫 소리까지의 시간과 인식 정확도를 함께 정합니다. 재 보고 골라야 합니다.

## 어떻게 (이 앱에서)

- (기반) 끝점 · 끼어들기(VC2)
- 조각 길이 · 지터 버퍼 · 망 조건을 훑어 첫 소리 p50 · p95 · p99, 1.2초 예산 초과 몫, 확정 오류 · 상태 정확
