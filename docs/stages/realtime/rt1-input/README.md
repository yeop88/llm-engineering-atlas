# RT1 · 스트림 입력 (Stream input)

**상태: ⬜ 예정** — 소리 · 영상 · 글 스트림을 시각 표시와 함께 받는다

## 원리

스트림 입력은 끝이 정해지지 않은 입력(마이크 · 카메라 · 타이핑)을 시각 표시와 함께 받는 단계입니다. 도착 시각과 보낸 시각을 함께 남겨 지터를 잽니다.

## 왜 하는가

보낸 시각이 없으면 지연이 네트워크에서 생겼는지 처리에서 생겼는지 나눌 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 음성 인식 · 실시간 음성(VC1 · OM2)
- (예정) 보낸 · 도착 시각 · 지터 · 순서 표시

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/rt_input` 에서 볼 수 있습니다.
