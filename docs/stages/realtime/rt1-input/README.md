# RT1 · 스트림 입력 (Stream input)

**상태: ✅ 구현됨** — 소리 · 영상 · 글 스트림을 시각 표시와 함께 받는다

## 원리

스트림 입력은 끝이 정해지지 않은 입력(마이크 · 카메라 · 타이핑)을 시각 표시와 함께 받는 단계입니다. 도착 시각과 보낸 시각을 함께 남겨 지터를 잽니다.

## 왜 하는가

보낸 시각이 없으면 지연이 네트워크에서 생겼는지 처리에서 생겼는지 나눌 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 음성 인식(VC4) · 실시간 음성(OM2)
- 조각마다 보낸 시각 → 망(기본 지연 + 오른쪽 꼬리가 긴 지터) · 손실 시 재전송(왕복 + 편도) 또는 포기 → 지터 버퍼 → 순서대로 내보냄, 망 조건 4개(유선 · 와이파이 · 이동 중 LTE · 재전송 없음)

## 화면

- `/realtime/stream` — **스트림 재생 · 꼬리 지연**: 망 · 조각 · 확정 · 첫 소리 p95 · p99 · 끼어들기 · 복구

## 앞으로 할 일
