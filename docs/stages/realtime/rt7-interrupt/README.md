# RT7 · 중단 처리 (Interruption handling)

**상태: ✅ 구현됨** — 끼어들면 생성 · 합성 · 전송을 함께 멈추고 들은 데까지 남긴다

## 원리

중단 처리는 사용자가 끼어들 때 LLM 생성 · 합성 · 전송을 모두 멈추고, 어디까지 들려줬는지 기록해 다음 턴의 맥락으로 쓰는 것입니다.

## 왜 하는가

소리만 멈추고 생성은 계속하면 비용이 들고, 들려주지 못한 내용을 들은 것으로 착각합니다.

## 어떻게 (이 앱에서)

- (기반) 끼어들기 감지(VC2)
- 답 재생 중 끼어들기 → 소리가 멈출 때까지: 서버가 감지해 취소(감지 + 조각 지연 + 망 왕복 + 재생 버퍼) vs 기기가 스스로 멈춤, 끝까지 들은 문장만 '들었다'로

## 화면

- `/realtime/stream#run` — **중단 처리**: 끼어들기 → 소리 멈춤, 서버 취소 vs 기기 멈춤
