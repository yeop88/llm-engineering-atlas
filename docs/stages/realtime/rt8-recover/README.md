# RT8 · 세션 복구 (Session recovery)

**상태: ⬜ 예정** — 끊겼다 다시 붙으면 마지막 확정 지점부터 이어 간다

## 원리

세션 복구는 네트워크가 끊겼다가 다시 연결되면 서버의 세션 상태로 마지막 확정 턴부터 이어 가는 것입니다. 이어지지 않으면 다른 채널로 넘깁니다.

## 왜 하는가

실시간 연결은 반드시 끊깁니다. 끊김을 예외가 아니라 흐름의 일부로 다뤄야 합니다.

## 어떻게 (이 앱에서)

- (기반) 체크포인트(LR3) · 채널 이어 가기(OM5)
- (예정) 끊김 흉내 · 복구율 · 복구까지 시간
