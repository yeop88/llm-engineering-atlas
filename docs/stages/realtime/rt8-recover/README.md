# RT8 · 세션 복구 (Session recovery)

**상태: ✅ 구현됨** — 끊겼다 다시 붙으면 마지막 확정 지점부터 이어 간다

## 원리

세션 복구는 네트워크가 끊겼다가 다시 연결되면 서버의 세션 상태로 마지막 확정 턴부터 이어 가는 것입니다. 이어지지 않으면 다른 채널로 넘깁니다.

## 왜 하는가

실시간 연결은 반드시 끊깁니다. 끊김을 예외가 아니라 흐름의 일부로 다뤄야 합니다.

## 어떻게 (이 앱에서)

- (기반) 장기 실행 상태(LR) · 옴니 이관(OM6)
- 말하는 도중 끊겼다 다시 붙을 때: 새 세션 · 서버가 확정분 보관 · 서버 보관 + 기기가 확인 못 받은 소리 다시 보냄 — 잃은 낱말 · 다시 보낸 낱말 · 순번 없이 겹칠 낱말
