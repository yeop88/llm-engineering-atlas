# AU5 · 시간 구간 추출 (Time segments)

**상태: ⬜ 예정** — 사건 · 발화를 시작 · 끝 시각으로 색인한다

## 원리

시간 구간 추출은 발화 · 사건마다 시작 · 끝 시각을 붙여 색인하는 것입니다. 영상 장면 색인(OM3)과 같은 시간축에 놓아 '그 소리가 날 때 화면' 을 찾게 합니다.

## 왜 하는가

'처음 그 소리가 난 때는?' 같은 질문은 시간 구간 없이는 답할 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 영상 장면 색인(OM3)
- (예정) 발화 · 사건 시간 색인 · 영상과 같은 시간축

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/au_segment` 에서 볼 수 있습니다.

## 앞으로 할 일

- 발화 · 사건 시간 색인 · 영상과 같은 시간축
