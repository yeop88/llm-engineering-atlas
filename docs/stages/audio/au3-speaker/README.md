# AU3 · 화자 · 언어 탐지 (Speaker & language ID)

**상태: ⬜ 예정** — 누가 말했는지(화자 분리)와 어떤 언어인지를 구간마다 붙인다

## 원리

화자 · 언어 탐지는 음성 구간마다 화자 번호(화자 분리)와 언어를 붙이는 것입니다. 상담에서는 고객 · 상담원, 회의에서는 참석자마다 나눕니다.

## 왜 하는가

누가 말했는지 모르면 '고객이 약속한 것'과 '상담원이 안내한 것'을 섞습니다.

## 어떻게 (이 앱에서)

- (기반) 목소리 특징(VC5)
- (예정) 화자 분리 · 언어 판별 · 화자 오류율

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/au_speaker` 에서 볼 수 있습니다.
