# AU7 · 검색 · 요약 (Search & summary)

**상태: ✅ 구현됨** — 회의 · 통화를 구간 근거와 함께 찾고 요약한다

## 원리

검색 · 요약은 '결정된 항목과 그 발언 구간', '이상음이 난 때' 같은 질문에 구간을 근거로 답하고, 요약 항목마다 구간을 붙이는 것입니다.

## 왜 하는가

근거 구간 없는 요약은 확인할 수 없습니다 — 다시 들어 볼 자리를 줘야 합니다.

## 어떻게 (이 앱에서)

- (기반) 통화 요약(VC7) · RAG
- 글자 2-gram 겹침 + 고객 소리 낱말(덜컹 · 웅웅 · 삐 · 음악)을 사건 종류로 바꾼 점수, 시간 순 요약, 합성 장면 평가(프레임 정확 · 사건 정밀 · 재현 · 화자 · 검색 적중)

## 화면
