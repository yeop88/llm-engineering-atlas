# AU2 · 음성 · 음악 · 환경음 분리 (Source separation)

**상태: ✅ 구현됨** — 구간마다 음성 · 음악 · 환경음 · 침묵을 나눈다

## 원리

분리는 소리 구간마다 음성 · 음악 · 환경음(기계음 · 경고음) · 침묵을 구분하는 것입니다. 간단히는 에너지 · 스펙트럼 특징으로, 정확히는 작은 분류 모델로 합니다.

## 왜 하는가

환경음 구간을 음성 인식에 넣으면 엉뚱한 글이 나오고, 기계음 증거는 버려집니다.

## 어떻게 (이 앱에서)

- (기반) 음원 입력(AU1)
- 프레임마다 침묵 · 말 · 음악 · 환경음 — 말은 음높이가 미끄러지고 음절 리듬으로 출렁임, 음악은 음높이가 머묾, 저역에 몰린 소리 · 평탄한 잡음은 환경음, 다수결로 매끄럽게 · 짧은 구간은 앞에 붙임

## 화면

- `/audio/scene#analyze` — **음성 · 음악 · 환경음 분리**: 프레임 종류 · 구간
