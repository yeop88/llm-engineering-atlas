# AU1 · 음원 입력 (Audio input)

**상태: ✅ 구현됨** — 녹음 · 통화 · 영상 소리를 같은 표본률 · 형식으로 맞춘다

## 원리

음원 입력은 녹음 파일 · 통화 · 영상의 소리를 같은 표본률(16kHz 등) · 채널 · 음량으로 맞추는 단계입니다. 원본은 개인정보라 보관 기한을 함께 정합니다.

## 왜 하는가

형식이 다르면 같은 모델도 결과가 흔들립니다. 소리는 개인정보라 받는 순간부터 정책이 필요합니다.

## 어떻게 (이 앱에서)

- (기반) 음성 신호 공통(VC1)
- 녹음 · 통화 파일(wav · mp3 · webm · m4a)을 16kHz 모노로 맞추고 20ms 간격 · 40ms 창 특징(크기 · 영교차 · 무게중심 · 평탄도 · 저역 몫 · 최대 성분 몫 · 주기성 · 음높이 · 대역 에너지)
