# AU6 · 의미 표현 (Semantic representation)

**상태: ✅ 구현됨** — 구간을 글 · 임베딩으로 바꿔 검색할 수 있게 한다

## 원리

의미 표현은 구간마다 전사 · 사건 이름 · 소리 임베딩을 만들어 글 질문으로 찾을 수 있게 하는 것입니다. 소리 · 글 공통 임베딩이면 소리로 소리를 찾을 수도 있습니다.

## 왜 하는가

전사만 색인하면 말이 없는 소리(기계음 · 경고음)는 글 질문으로 찾을 수 없어 증거가 묻힙니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달 입력(MM1)
- 구간 · 사건을 한 줄 글('3.6~9.3초 덜컹 반복(0.9초 간격 7번)')로, 말 구간에는 음성 인식 글(합성 장면은 만들 때 적은 글, 출처 표시)

## 화면

- `/audio/scene#search` — **의미 표현**: 구간을 한 줄 글로

## 앞으로 할 일

- 구간 소리 임베딩(소리-글 공통 공간)
