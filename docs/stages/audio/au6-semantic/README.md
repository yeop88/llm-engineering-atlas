# AU6 · 의미 표현 (Semantic representation)

**상태: 🔬 연구** — 구간을 글 · 임베딩으로 바꿔 검색할 수 있게 한다

## 원리

의미 표현은 구간마다 전사 · 사건 이름 · 소리 임베딩을 만들어 글 질문으로 찾을 수 있게 하는 것입니다. 소리 · 글 공통 임베딩이면 소리로 소리를 찾을 수도 있습니다.

## 왜 하는가

전사만 색인하면 말이 없는 소리(기계음 · 경고음)는 글 질문으로 찾을 수 없어 증거가 묻힙니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달 임베딩(MA1)
- (연구) 소리 임베딩 · 사건 이름 · 전사 색인
