# AU4 · 이벤트 인식 (Sound events)

**상태: ✅ 구현됨** — 기계 이상음 · 경고음 · 박수 같은 소리 사건을 알아본다

## 원리

이벤트 인식은 소리 안의 사건(덜컹 반복 · 삐 경고음 · 물 새는 소리 · 박수)을 이름 붙이는 것입니다. 제품 이상음은 사진 진단처럼 증상의 증거가 됩니다.

## 왜 하는가

고객은 소리를 말로 잘 설명하지 못합니다. 소리 자체를 알아보면 진단이 빨라집니다.

## 어떻게 (이 앱에서)

- (기반) 사진 진단(AS2)
- 덜컹 반복: 저역 시작점이 세 번 넘게 고른 간격(변동 계수 0.25 미만)으로, 경고음: 한 주파수에 몰린 1~5kHz 소리(되풀이는 하나로 묶음), 웅웅: 저역 순음이 1초 넘게
