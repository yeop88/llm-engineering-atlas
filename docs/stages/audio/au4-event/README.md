# AU4 · 이벤트 인식 (Sound events)

**상태: 🔬 연구** — 기계 이상음 · 경고음 · 박수 같은 소리 사건을 알아본다

## 원리

이벤트 인식은 소리 안의 사건(덜컹 반복 · 삐 경고음 · 물 새는 소리 · 박수)을 이름 붙이는 것입니다. 제품 이상음은 사진 진단처럼 증상의 증거가 됩니다.

## 왜 하는가

고객은 소리를 말로 잘 설명하지 못합니다. 소리 자체를 알아보면 진단이 빨라집니다.

## 어떻게 (이 앱에서)

- (기반) 사진 진단의 증거 흐름(AS4)
- (연구) 작은 소리 분류기 · 이상음 사건 · F1

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/au_event` 에서 볼 수 있습니다.

## 앞으로 할 일
