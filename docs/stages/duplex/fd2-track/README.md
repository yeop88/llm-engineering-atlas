# FD2 · 화자 · 시선 · 대상 추적 (Speaker, gaze & target tracking)

**상태: 🔬 연구** — 누가 말하는지, 어디를 보고 가리키는지 따라간다

## 원리

화자 · 시선 · 대상 추적은 지금 말하는 사람, 그 사람이 보는 곳 · 손으로 가리키는 대상을 계속 따라가는 것입니다. 가리킴 풀기(OM4)의 실시간판입니다.

## 왜 하는가

'이거' 는 말보다 손과 눈이 더 정확히 가리킵니다. 따라가지 않으면 장면 단위로만 풀 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 화자 분리(AU3) · 추적(VD4)
- (연구) 시선 · 손 방향 → 대상 영역

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/fd_track` 에서 볼 수 있습니다.
