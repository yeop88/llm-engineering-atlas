# FD7 · 전환 타이밍 조정 (Turn transition timing)

**상태: ✅ 구현됨** — 차례가 넘어가는 간격을 재고 사람 대화에 맞춘다

## 원리

전환 타이밍은 상대가 말을 맺은 뒤 응답을 시작하기까지의 간격(사람끼리 대략 0.2~0.5초)과 겹침을 재고 맞추는 것입니다.

## 왜 하는가

너무 빠르면 말을 자르고 너무 느리면 대화가 끊깁니다. 평균이 아니라 분포를 봐야 합니다.

## 어떻게 (이 앱에서)

- (기반) 실시간 첫 소리(RT6)
- 고객 말 끝 → 첫 소리 간격 p50 · p95, 끝날 것 같은 말끝이 들린 순간부터 답을 미리 준비하면 준비 시간을 숨김
