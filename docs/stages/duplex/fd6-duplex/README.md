# FD6 · 동시 듣기 · 보기 · 말하기 (Full-duplex generation)

**상태: ✅ 구현됨** — 말하는 동안에도 듣고 보며 응답을 고친다

## 원리

동시 처리는 에이전트가 말하는 동안에도 상대의 소리 · 화면을 계속 받아 응답을 고치거나 멈추는 것입니다. 통합 모델(Speech-to-Speech)이 이 방향이고, 파이프라인으로는 흉내만 냅니다.

## 왜 하는가

반이중 구조로는 '말하다가 상대 표정을 보고 고치기' 가 안 됩니다. 어디까지 흉내 낼 수 있는지 재야 통합 모델의 이득을 압니다.

## 어떻게 (이 앱에서)

- (기반) 끼어들기 감지(VC2)
- 우리가 말하는 중 고객 소리 — 길이만(250ms) 보는 정책과 길이 + 부분 인식 글('네' · '음'은 맞장구)로 거르는 정책의 잘못 멈춤 · 놓친 끼어들기

## 화면

- `/duplex/timing#evaluate` — **동시 듣기 · 말하기**: 말하는 중 고객 소리: 맞장구면 계속, 끼어들기면 멈춤

## 앞으로 할 일

- 말하는 중 들은 내용으로 답 고치기
