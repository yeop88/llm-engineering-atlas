# FD6 · 동시 듣기 · 보기 · 말하기 (Full-duplex generation)

**상태: 🔬 연구** — 말하는 동안에도 듣고 보며 응답을 고친다

## 원리

동시 처리는 에이전트가 말하는 동안에도 상대의 소리 · 화면을 계속 받아 응답을 고치거나 멈추는 것입니다. 통합 모델(Speech-to-Speech)이 이 방향이고, 파이프라인으로는 흉내만 냅니다.

## 왜 하는가

반이중 구조로는 '말하다가 상대 표정을 보고 고치기' 가 안 됩니다. 어디까지 흉내 낼 수 있는지 재야 통합 모델의 이득을 압니다.

## 어떻게 (이 앱에서)

- (기반) 스트리밍(RT6)
- (연구) 파이프라인 흉내 vs 통합 모델 비교 설계

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/fd_duplex` 에서 볼 수 있습니다.
