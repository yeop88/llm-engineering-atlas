# FD1 · 연속 오디오 · 비디오 입력 (Continuous AV input)

**상태: 🔬 연구** — 소리 · 영상을 끊지 않고 같은 시계로 받는다

## 원리

연속 입력은 소리와 영상을 턴으로 끊지 않고 같은 시계(타임스탬프)로 계속 받는 것입니다. 지연이 다른 두 스트림을 맞추는 것이 첫 문제입니다.

## 왜 하는가

소리와 화면이 0.5초만 어긋나도 '이거' 가 다른 장면을 가리켜, 맞는 말을 틀린 화면에 붙입니다.

## 어떻게 (이 앱에서)

- (기반) 스트림 입력(RT1)
- (연구) 소리 · 영상 같은 시계 · 어긋남 측정

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/fd_input` 에서 볼 수 있습니다.
