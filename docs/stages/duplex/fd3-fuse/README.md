# FD3 · 시간 상태 융합 (Temporal state fusion)

**상태: 🔬 연구** — 말 · 화면 · 사건을 하나의 대화 상태로 시간에 따라 합친다

## 원리

시간 상태 융합은 확정된 말 · 지금 화면 · 소리 사건을 하나의 대화 상태(주제 · 가리킨 대상 · 미해결 질문)로 시간에 따라 갱신하는 것입니다.

## 왜 하는가

말 · 화면을 따로 두면 매 턴 다시 합쳐야 해 늦고, 가리킨 대상이 턴 사이에 사라집니다.

## 어떻게 (이 앱에서)

- (기반) 턴 융합(OM4) · 상태 갱신(RT4)
- (연구) 연속 상태 융합 · 대상 유지

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/fd_fuse` 에서 볼 수 있습니다.
