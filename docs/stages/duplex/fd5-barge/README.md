# FD5 · 끼어들기 시점 · 정책 (Barge-in timing & policy)

**상태: ✅ 구현됨** — 언제 끼어들고 언제 맞장구만 칠지 정책으로 정한다

## 원리

끼어들기 시점 · 정책은 응답자(에이전트)가 상대 말 중에 끼어들 때를 정하는 것입니다. 안전 경고(전원을 뽑으세요)는 바로, 정보는 말이 끝난 뒤, 맞장구는 짧게.

## 왜 하는가

타이밍만 학습하면 무례하거나 위험을 놓칩니다. 끼어들기는 내용이 아니라 정책의 문제이기도 합니다.

## 어떻게 (이 앱에서)

- (기반) 실시간 끼어들기(RT7)
- 맞장구: 이어질 말끝 뒤 정해 둔 시간 동안 다음 어절이 없으면 '네'(그 순간 들은 것만으로) — 겹침, 안전: '타는 냄새 · 연기 · 감전'이 들리면 차례를 기다리지 않고 미리 합성해 둔 경고
