# FD4 · 발화 의도 예측 (Turn-taking intent)

**상태: 🔬 연구** — 상대가 말을 맺을지 · 이어 갈지 · 끼어들기를 원하는지 예측한다

## 원리

발화 의도 예측은 말끝 억양 · 쉼 · 글의 모양 · 시선으로 상대가 말을 맺으려는지, 생각 중인지, 끼어들려는지를 예측하는 것입니다. 끝점 규칙(VC2)의 확장입니다.

## 왜 하는가

침묵 길이만 보면 생각 중인 사람의 말을 자르거나, 말을 맺었는데 오래 기다립니다.

## 어떻게 (이 앱에서)

- (기반) 끝점 · 이어질 말 판정(VC2)
- (연구) 억양 · 쉼 · 글 모양 결합 · 예측 정확도
