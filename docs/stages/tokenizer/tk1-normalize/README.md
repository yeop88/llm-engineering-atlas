# TK1 · 원문 정규화 (Normalization)

**상태: ✅ 구현됨** — 유니코드 정규화 · 공백 · 전각 문자를 토크나이저 앞에서 맞춘다

## 원리

정규화는 같은 글자를 같은 바이트로 맞추는 것(NFC/NFKC · 전각 숫자 · 보이지 않는 문자 제거)입니다. 한글은 조합형 · 완성형 차이로 같은 글이 다른 토큰이 될 수 있습니다.

## 왜 하는가

정규화가 다르면 같은 질문이 다른 토큰이 되어 캐시가 맞지 않고, 검색 · 압축 보호 규칙이 빗나갑니다.

## 어떻게 (이 앱에서)

- (기반) 문서 정제(D4)
- 같은 글의 NFC · NFD(자모 분리) · 전각 숫자 · 보이지 않는 문자 형태별 토큰 수 — 토크나이저가 정규화하는지, 정제가 필요한지
