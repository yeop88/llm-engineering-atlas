# TK6 · 멀티모달 공통 공간 (Shared multimodal space)

**상태: ⬜ 예정** — 이미지 패치 · 오디오 토큰 · 영상 시공간 토큰이 글과 한 공간에 놓이는 방식

## 원리

멀티모달 공통 공간은 이미지 패치 · 오디오 코덱 토큰 · 영상 시공간 토큰을 투영기로 글 토큰과 같은 차원에 놓는 것입니다. 이미지 한 장이 글 몇백 토큰의 맥락을 씁니다.

## 왜 하는가

이미지 · 영상을 넣으면 맥락이 얼마나 쓰이는지 알아야 예산을 짭니다. 공통 공간이 약하면 사진으로 찾은 근거가 빗나갑니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달 임베딩(MA1)
- (예정) 이미지 · 소리당 토큰 수 · 교차 검색 정렬
