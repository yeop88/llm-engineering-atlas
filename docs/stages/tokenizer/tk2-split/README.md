# TK2 · 토큰 분할 (Token splitting)

**상태: ⬜ 예정** — 한국어 · 영어 · 코드 · 조문 번호의 글자당 토큰과 쪼개지는 모양을 모델별로 잰다

## 원리

토큰 분할은 BPE · 유니그램 같은 방식으로 글을 어휘의 조각으로 나누는 것입니다. 한국어 글자당 토큰, 코드의 들여쓰기, 'WM-200' · '제3조의2' 가 나뉘는 모양을 같은 글로 비교합니다.

## 왜 하는가

토큰 효율이 다른 두 모델을 '맥락 32K' 로 같다고 보면 실제로 넣을 수 있는 글이 다릅니다. 쪼개지는 모양은 압축 · 검색 규칙에도 쓰입니다.

## 어떻게 (이 앱에서)

- (기반) 작은 LM 도구(IP 맵 lm)
- (예정) 모델별 글 종류 × 글자당 토큰 · 코드 · 번호 쪼개짐 표
