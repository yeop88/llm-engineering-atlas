# TK4 · 임베딩 표현 (Embedding space)

**상태: ✅ 구현됨** — 토큰 · 문장 임베딩 공간의 비등방성 · 언어 간 정렬을 잰다

## 원리

임베딩 표현은 토큰이나 글을 벡터로 바꾼 공간입니다. 한쪽으로 몰린 정도(비등방성), 실제로 쓰는 차원, 같은 뜻의 한국어 · 영어가 가까운지(정렬)를 잽니다.

## 왜 하는가

검색 품질의 상한이 이 공간입니다. 언어 간 정렬이 약하면 한국어 질문으로 영어 문서를 못 찾습니다.

## 어떻게 (이 앱에서)

- (기반) 임베딩 공간 지표 · 언어 간 정렬(IP1)
- 어휘 × 은닉 = 임베딩 크기, 출력층과 같이 쓰는지(tied) — 공간의 성질(비등방성 · 정렬)은 해석 맵 IP1 에서
