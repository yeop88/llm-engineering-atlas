# TK3 · 어휘 (Vocabulary)

**상태: ✅ 구현됨** — 어휘 크기 · 언어별 몫 · 특수 토큰을 본다

## 원리

어휘는 토크나이저가 아는 조각 목록입니다. 크면 글자당 토큰이 줄지만 임베딩 · 출력층이 커집니다. 언어별로 어휘의 몇 % 를 차지하는지와 채팅 틀의 특수 토큰을 봅니다.

## 왜 하는가

어휘 크기는 토큰 효율과 메모리를 맞바꿉니다. 작은 모델일수록 출력층 비용이 커서 이 맞바꿈이 중요합니다.

## 어떻게 (이 앱에서)

- (기반) 토큰 분할(TK2)
- 어휘 크기 · 한글이 든 조각의 몫 · 한 글자(완성형) 조각 수 · 채팅 틀 특수 토큰
