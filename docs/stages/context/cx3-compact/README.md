# CX3 · 도구 결과 · 기록 압축 (Compaction)

**상태: ✅ 구현됨** — 오래된 도구 결과 · 대화를 지우거나 요약해 맥락을 비운다

## 원리

압축은 맥락이 차기 전에 오래된 도구 결과를 지우고, 대화 · 진행 기록을 요약으로 바꾸는 것입니다. 무엇을 남길지가 다음 단계의 품질을 정합니다.

## 왜 하는가

장기 실행 에이전트는 도구 결과가 쌓여 금방 한도에 닿습니다. 잘못 줄이면 이미 확인한 사실을 다시 찾거나 잊습니다.

## 어떻게 (이 앱에서)

- (기반) 대화 압축(C5) · 체크포인트(LR3)
- 하위 질문 검색 결과가 쌓인 기록 뒤 처음 단계의 사실을 묻는 시험 — 정답 단계 위치 · 남길 최근 단계 수를 바꿔
- 그대로 · 오래된 결과 지움 · LLM 요약 · 노트만(규칙) 의 정답률 · 맥락 글자 · 답 시간 · 압축 시간
