# CX5 · 외부 메모리 · 노트 (Agent memory & notes)

**상태: ✅ 구현됨** — 에이전트가 노트에 적어 두고 필요할 때 다시 읽는다

## 원리

외부 메모리는 맥락에 모두 넣는 대신 중간 결론 · 할 일 · 사실을 파일 · 표에 적고, 필요한 것만 다시 읽는 것입니다.

## 왜 하는가

맥락을 압축하면 잃는 것이 생깁니다. 노트에 남기면 맥락은 작게 유지하면서 긴 작업을 이어 갈 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 대화 메모리(C3)
- 세션별 노트(출처 · 시각과 함께) 쓰기 · 질문과 겹치는 노트만 읽기 · 지우기 API — 에이전트가 맥락 대신 노트에 적고 필요할 때 읽음
- 압축 시험의 '노트만' 방법과 같은 쓰기 규칙(단계 질문과 가장 겹치는 문장)
