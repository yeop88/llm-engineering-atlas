# CX5 · 외부 메모리 · 노트 (Agent memory & notes)

**상태: ⬜ 예정** — 에이전트가 노트에 적어 두고 필요할 때 다시 읽는다

## 원리

외부 메모리는 맥락에 모두 넣는 대신 중간 결론 · 할 일 · 사실을 파일 · 표에 적고, 필요한 것만 다시 읽는 것입니다.

## 왜 하는가

맥락을 압축하면 잃는 것이 생깁니다. 노트에 남기면 맥락은 작게 유지하면서 긴 작업을 이어 갈 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 대화 메모리(C3)
- (예정) 노트 쓰기 · 읽기 도구 · 노트 유무별 긴 작업 성공률
