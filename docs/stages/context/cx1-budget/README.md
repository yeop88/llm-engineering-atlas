# CX1 · 맥락 예산 · 배치 (Context budget & ordering)

**상태: ✅ 구현됨** — 시스템 · 대화 · 근거 · 도구 결과의 몫과 순서를 정하고 위치별 정답률을 잰다

## 원리

맥락 예산은 한 번의 호출에 넣을 토큰을 몫으로 나누는 것이고, 배치는 그 순서입니다. 같은 근거라도 앞 · 중간 · 끝 어디에 두느냐로 정답률이 달라집니다.

## 왜 하는가

근거를 많이 넣으면 좋아지는 것 같지만 읽기 시간이 늘고 중간 근거를 놓칩니다. 몫과 순서를 재야 합니다.

## 어떻게 (이 앱에서)

- (기반) 근거 길이 관리(S2) · 답변 채점(정답 근거 인용)
- 같은 근거를 관련도 순 · 역순(1위가 질문 앞) · 샌드위치(앞뒤)로 넣어 정답률 · 입력 토큰 · 시간
- 바늘 위치: 정답 근거 하나를 방해 근거 사이 위치별로 넣어 위치별 정답률(중간을 놓치는지)
