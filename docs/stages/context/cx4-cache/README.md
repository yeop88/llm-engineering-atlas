# CX4 · 프롬프트 캐시 (Prompt caching)

**상태: ✅ 구현됨** — 바뀌지 않는 앞부분을 캐시해 읽기 시간 · 비용을 줄인다

## 원리

프롬프트 캐시는 이전 호출과 같은 앞부분의 계산(KV)을 다시 쓰는 것입니다. 바뀌지 않는 시스템 · 도구 설명 · 문서를 앞에 두어야 적중합니다.

## 왜 하는가

근거 읽기가 시간의 대부분이므로 캐시 적중이 지연을 크게 줄입니다. 순서를 잘못 두면 매번 처음부터 읽습니다.

## 어떻게 (이 앱에서)

- (기반) 캐시(S1) · cache_prompt
- 같은 근거로 질문을 연달아: 근거 앞 · 질문 끝(고정 앞부분) vs 질문 앞 · 근거 뒤
- llama-server 단계별 시간으로 두 번째 질문부터 재사용 비율(1 − 다시 읽은 토큰 / 입력 토큰) · 읽기 시간

## 화면

- `/context/layout#cache` — **프롬프트 캐시**: 근거 앞 vs 질문 앞, 다시 읽은 토큰
