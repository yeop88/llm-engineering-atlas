# CX6 · 맥락 오염 방지 (Context hygiene)

**상태: ⬜ 예정** — 틀린 중간 결과 · 낡은 정보 · 숨은 지시가 맥락에 남지 않게 한다

## 원리

맥락 오염은 한 번 들어간 틀린 정보 · 숨은 지시가 이후의 모든 답에 영향을 주는 것입니다. 틀린 것으로 판정된 결과를 지우고, 출처와 시각을 붙여 넣습니다.

## 왜 하는가

에이전트는 자기가 쓴 틀린 결론을 다음 단계의 근거로 씁니다. 검증에서 떨어진 것은 맥락에서도 빼야 합니다.

## 어떻게 (이 앱에서)

- (기반) 입력 방어 · 근거 격리(G1)
- (예정) 판정 실패 결과 제거 · 출처 · 시각 표시 · 오염 주입 시험

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cx_hygiene` 에서 볼 수 있습니다.

## 앞으로 할 일

- 판정 실패 결과 제거 · 출처 · 시각 표시 · 오염 주입 시험
