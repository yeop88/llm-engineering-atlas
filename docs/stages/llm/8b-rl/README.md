# 8b · 강화학습 (Reinforcement learning)

**상태: ✅ 구현됨** — 보상 · 선호 신호로 답변 행동을 좋게 만든다

## 원리

'좋은 답'의 기준(근거로 뒷받침된 문장, 정답 근거 인용, 없는 근거 인용 · 근거가 있는데 거절은 감점)을 보상 함수로 만들고, 보상으로 답을 고르거나(Best-of-N) 좋은 답 / 나쁜 답 쌍으로 모델을 조정합니다(DPO 등 선호 학습).

## 왜 하는가

'근거를 정확히 인용하고 모르면 모른다고 하기'는 정답 문장만으로 가르치기 어렵습니다. 보상으로 그 기준을 직접 반영합니다.

## 어떻게 (이 앱에서)

- 설명 가능한 단순 합의 보상 함수 (학습된 보상 모델은 판단 근거 · 보상 해킹을 찾기 어려움)
- Best-of-N: 평소 답(후보 0)과 다양한 후보 중 보상 최고 — 학습 없이 효과 측정, 연결 실행 경로 옵션으로도 사용
- 선호 쌍: 보상 차가 큰 쌍 자동 저장 + 사람이 두 답 중 고르기, DPO 형식 JSONL 내보내기 (학습은 GPU 환경)

## 화면

- `/rl` — **강화학습 테스트**: 보상 · Best-of-N · 선호 쌍 · DPO 데이터

## 앞으로 할 일

- 사람 선호와 보상의 일치율로 보상 함수 고치기
