# 5 · 파인튜닝 (Fine-tuning)

**상태: ✅ 구현됨** — 임베딩 모델을 내 문서 분야에 맞게 추가 학습한다

## 원리

(질문, 정답 지문) 쌍을 보여 주며 질문과 자기 지문은 가깝게, 같은 배치의 다른 지문은 멀게 벡터를 조정합니다(대조 학습, MultipleNegativesRankingLoss).

## 왜 하는가

범용 모델이 분야 용어 · 문체에 약할 때, 모델 크기와 속도는 그대로 두고 검색 품질을 올리는 방법입니다. 단, 데이터가 적거나 나쁘면 효과가 없거나 오히려 떨어지므로 반드시 학습 전후를 측정합니다.

## 어떻게 (이 앱에서)

- 컬렉션 지문 → 학습 쌍(LLM 질문 또는 ICT), 평가 세트 근거가 든 지문은 제외(누수 방지)
- 학습 → 카탈로그 자동 등록 → 같은 평가 세트로 전후 짝지은 비교
- 실행마다 기록(모델 카드 README.md) — 실측 3건은 모두 '차이 불확실'

## 화면

- `/finetune` — **파인튜닝 테스트**: 학습 쌍 · 학습 · 전후 비교 · 기록

## 앞으로 할 일

- 학습 쌍 수천 개 규모 · 낮은 학습률 실험
