# 1 · 데이터 임베딩 (Embedding)

**상태: ✅ 구현됨** — 텍스트·이미지를 의미 벡터로 바꾸는 모델을 고르고 비교한다

## 원리

임베딩 모델은 텍스트(또는 이미지)를 고정 길이 벡터로 바꿔, 의미가 비슷하면 벡터가 가깝게(코사인 유사도가 높게) 놓이도록 학습된 모델입니다. 질문과 문서에 서로 다른 프롬프트를 붙이는 모델, 벡터 앞부분만 잘라 써도 되는 Matryoshka 모델이 있습니다.

## 왜 하는가

검색 · 분류 · 군집 · RAG 등 의미 기반 기능은 모두 임베딩에서 시작합니다. 모델마다 언어 · 분야 · 속도 · 크기 · 라이선스가 달라, 어떤 모델을 고르느냐가 이후 단계 품질의 절반을 정합니다.

## 어떻게 (이 앱에서)

- 카탈로그에서 모델을 받아 로드 (Hub 에서 새 모델 추가)
- 플레이그라운드에서 유사도 · 검색 결과를 모델끼리 나란히 비교
- 벤치마크(내장 · 공개 한국어 · 내 데이터셋)로 점수와 95% 신뢰구간을 보고 고르기

## 화면

- `/models` — **모델**: 카탈로그 · 다운로드 · 로드
- `/hub` — **Hub 검색**: 새 모델 찾아 가져오기
- `/playground` — **플레이그라운드**: 임베딩 · 유사도 · 검색 · 지도
- `/benchmark` — **벤치마크**: 데이터셋 · 공개 벤치마크 · 신뢰구간
