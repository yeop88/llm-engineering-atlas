# A · 의미 응용 (Semantic applications)

**상태: ✅ 구현됨** — 임베딩으로 추천 · 분류 · 군집 · 중복 · 이상 탐지 · 키워드를 만든다

## 원리

같은 임베딩 공간에서 거리 · 경계 · 군집 구조를 이용해 검색 외의 문제를 풉니다.

## 왜 하는가

고객 · AS 문의 분류와 라우팅, 스팸 · 이상 탐지, 중복 정리 등 실제 서비스의 많은 기능이 '의미가 가까운가'로 풀립니다.

## 어떻게 (이 앱에서)

- 추천(MMR) · 분류(제로샷 · 학습) · 군집 · 중복/표절 · 이상/신종 탐지 · 키워드/요약
- 학습한 분류기 · 탐지기를 저장해 API 로 사용

## 화면

- `/apps` — **응용 목록**: 추천 · 분류 · 군집 · 중복 · 이상 · 키워드
- `/apps/recommend` — **콘텐츠 추천**: 취향 벡터 · 다양성(MMR)
- `/apps/classify` — **텍스트 분류**: 제로샷 · 학습 분류기
- `/apps/cluster` — **클러스터링**: 주제 묶기 · 군집 이름
- `/apps/dedup` — **중복·표절 검사**: 중복 정리 · 문장 대조
- `/apps/anomaly` — **이상·신종 탐지**: 평소의 경계 밖 찾기
- `/apps/keywords` — **키워드·요약**: 대표 키워드 · 추출 요약
