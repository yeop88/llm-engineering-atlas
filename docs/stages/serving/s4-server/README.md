# S4 · 추론 서버 · 배치 · 스트리밍 (Inference serving)

**상태: ✅ 구현됨** — 모델별 서버 · 동시 처리 · 스트리밍으로 대기 시간과 처리량을 맞춘다

## 원리

추론 서버(llama.cpp · vLLM 등)는 여러 요청을 묶어 처리(배치)하고 결과를 글자 단위로 흘려(스트리밍) 첫 글자까지의 시간을 줄입니다. 모델마다 서버를 따로 띄워 경로별로 연결합니다.

## 왜 하는가

사용자는 전체 시간보다 첫 글자까지의 시간을 느낍니다. 동시 요청이 늘면 배치 · 슬롯 수가 처리량을 정합니다.

## 어떻게 (이 앱에서)

- (있음) llama-server(Vulkan) · 동시 슬롯, 답변 스트리밍(첫 글자 시간), 모델별 서버 주소, Docker
- 동시 요청 수(1 · 2 · 4 …)별로 두 배씩 보내 처리량(요청/초 · 출력 토큰/초) · p50 · p95 — 슬롯보다 많으면 줄을 섬
