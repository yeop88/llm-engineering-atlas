# S4 · 추론 서버 · 배치 · 스트리밍 (Inference serving)

**상태: 🟡 기초 있음** — 모델별 서버 · 동시 처리 · 스트리밍으로 대기 시간과 처리량을 맞춘다

## 원리

추론 서버(llama.cpp · vLLM 등)는 여러 요청을 묶어 처리(배치)하고 결과를 글자 단위로 흘려(스트리밍) 첫 글자까지의 시간을 줄입니다. 모델마다 서버를 따로 띄워 경로별로 연결합니다.

## 왜 하는가

사용자는 전체 시간보다 첫 글자까지의 시간을 느낍니다. 동시 요청이 늘면 배치 · 슬롯 수가 처리량을 정합니다.

## 어떻게 (이 앱에서)

- (있음) llama-server(Vulkan) · 동시 슬롯, 답변 스트리밍(첫 글자 시간 기록), 모델별 서버 주소(OPENAI_MODEL_URLS), Docker 배포
- (예정) 동시 요청 부하 측정(처리량 · p95), GPU 서버(vLLM) 비교

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/sv_server` 에서 볼 수 있습니다.
