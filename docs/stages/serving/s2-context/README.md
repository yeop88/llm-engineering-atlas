# S2 · 근거 길이 관리 (Context budgeting)

**상태: 🟡 기초 있음** — LLM 이 읽을 근거의 수 · 길이를 품질을 지키는 범위에서 줄인다

## 원리

답변 시간의 대부분은 근거를 읽는 시간입니다. 근거 수(context_top), 근거당 길이, 압축(관련 문장만)으로 읽을 양을 정하고, 정답 근거가 남는지 함께 잽니다.

## 왜 하는가

이 PC 실측에서 질문당 약 2,900토큰 읽기가 시간의 2/3 였습니다. 근거 압축은 지연 −19% 대신 품질 −10 이었습니다 — 줄이는 방법에 따라 품질이 갈립니다.

## 어떻게 (이 앱에서)

- (있음) 근거 수 · 최대 글자, 근거 압축(형태소 겹침) 실측, 짧은 청크 합치기
- (예정) 질문 유형별 근거 예산, 정답 근거 유지율을 보며 자동 조절

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/sv_context` 에서 볼 수 있습니다.
