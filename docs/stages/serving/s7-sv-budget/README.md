# S7 · 비용 · 지연 예산 (Cost & latency budgets)

**상태: ⬜ 예정** — 질문당 비용 · p95 지연 목표를 정하고 경로 · 모델 · 근거 설정을 그 안에 맞춘다

## 원리

예산은 '질문당 0.5초 안에 첫 글자, 평균 비용 얼마 이하' 같은 목표입니다. 라우팅 · 모델 · 근거 길이 설정을 예산 안에서 품질이 가장 높은 조합으로 고릅니다.

## 왜 하는가

최적화는 목표가 있어야 멈출 수 있습니다. 학습 라우터는 같은 품질로 지연 −25% 였는데, 이런 선택을 예산 기준으로 자동화합니다.

## 어떻게 (이 앱에서)

- (있음) 라우팅 평가의 비용-품질 곡선 · 오라클
- (예정) 예산 입력 → 설정 조합 탐색(품질 최대 · 예산 이내)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/sv_budget` 에서 볼 수 있습니다.
