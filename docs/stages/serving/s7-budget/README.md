# S7 · 비용 · 지연 예산 (Cost & latency budgets)

**상태: ✅ 구현됨** — 질문당 비용 · p95 지연 목표를 정하고 경로 · 모델 · 근거 설정을 그 안에 맞춘다

## 원리

예산은 '질문당 0.5초 안에 첫 글자, 평균 비용 얼마 이하' 같은 목표입니다. 라우팅 · 모델 · 근거 길이 설정을 예산 안에서 품질이 가장 높은 조합으로 고릅니다.

## 왜 하는가

최적화는 목표가 있어야 멈출 수 있습니다. 학습 라우터는 같은 품질로 지연 −25% 였는데, 이런 선택을 예산 기준으로 자동화합니다.

## 어떻게 (이 앱에서)

- 목표(p95 지연 · 질문당 비용 · 최저 품질) → 이미 잰 실측(연결 비교 · LLM 양자화 · 라우팅 평가)의 후보에서 평가 세트별로 목표 안 최고 품질 · 파레토 앞줄, 없으면 가장 가까운 것과 넘은 것
- 운영 요청 기록으로 경로 · 모델별 p95 · 질문당 비용 · 목표 넘은 비율

## 화면

- `/serving/budget` — **비용 · 지연 예산 · 자원**: 목표 안 최고 품질 · 파레토 · 운영 준수

## 앞으로 할 일

- 예산을 넘으면 경로를 자동으로 바꾸기(라우팅 · 플래그)
