# S3 · 경량 모델 (양자화 · 증류) (Lightweight models)

**상태: 🟡 기초 있음** — 가중치 · 벡터 비트를 낮추고 작은 모델에 지식을 옮겨 메모리 · 지연을 줄인다

## 원리

양자화는 가중치 · 벡터를 낮은 비트로, 증류는 큰 모델의 판단을 작은 모델에 옮기는 것입니다. 어느 쪽이든 품질 손실을 같은 조건으로 재야 합니다.

## 왜 하는가

작게 만들수록 싸지만 품질이 떨어질 수 있습니다 — QAT Q4_0 은 Q8_0 과 같은 품질로 빨랐지만, E2B 는 품질 −13(유의)이었습니다.

## 어떻게 (이 앱에서)

- (있음) 7b 양자화(벡터 int4 · binary 재점수 · LLM GGUF 비트), 7a 증류(임베딩 MarginMSE · LLM 증류 데이터)
- (예정) 서비스 경로별 모델 크기 선택을 비용 · 품질 예산으로

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/sv_light` 에서 볼 수 있습니다.
