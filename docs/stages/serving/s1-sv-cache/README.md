# S1 · 캐시 (의미 · 프롬프트 · 임베딩) (Caching)

**상태: 🟡 기초 있음** — 같거나 비슷한 계산을 다시 하지 않는다 — 임베딩 · LLM 변형 · 프롬프트 · 답변 캐시

## 원리

임베딩 캐시는 같은 글을 다시 인코딩하지 않고, 프롬프트 캐시(llama-server)는 앞부분이 같은 프롬프트의 읽기를 건너뛰며, 의미 캐시는 '비슷한 질문'에 저장해 둔 답을 돌려줍니다.

## 왜 하는가

같은 FAQ 질문이 반복되는 상담 서비스에서 가장 싸고 큰 절약입니다. 대신 비교 측정에서는 캐시가 결과를 왜곡합니다(Q4 가 캐시 때문에 6초로 보인 사례).

## 어떻게 (이 앱에서)

- (있음) 임베딩 캐시(의미 응용), 검색 향상의 LLM 변형 캐시, 비교 측정 때 프롬프트 캐시 끄기(no_cache)
- (예정) 의미 캐시(비슷한 질문 → 저장한 답, 근거 문서가 바뀌면 무효화)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/sv_cache` 에서 볼 수 있습니다.
