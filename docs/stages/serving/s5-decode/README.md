# S5 · KV 캐시 · 추측 디코딩 (KV cache & speculative decoding)

**상태: ✅ 구현됨** — KV 캐시 양자화로 긴 문맥 메모리를 줄이고, 추측 디코딩(MTP 등)으로 생성 속도를 올린다

## 원리

KV 캐시는 읽은 토큰의 중간 결과로 문맥이 길수록 커집니다(양자화로 줄임). 추측 디코딩은 작은 모델 · 추가 머리(MTP)가 여러 토큰을 미리 짐작하고 큰 모델이 한 번에 확인해 생성을 빠르게 합니다.

## 왜 하는가

긴 근거를 읽는 RAG 는 KV 캐시 메모리가 크고, 생성 속도(이 PC 13 토큰/초)도 체감 지연입니다. Gemma 4 는 MTP 파일이 공개되어 있어 바로 실험할 수 있습니다.

## 어떻게 (이 앱에서)

- 앱이 설정(KV f16 · q8_0 · q4_0 — V 는 flash attention, 초안 모델 추측 디코딩)마다 llama-server 를 빈 포트에 띄워 같은 질문 · 같은 근거로 양자화 비교(7b)와 같은 채점 — 첫 설정이 기준(짝 비교)
- 메모리: 서버 로그의 KV 캐시 크기(비트 효과) · 프로세스 RSS(GPU 메모리는 안 잡힘), 초안 수락률
