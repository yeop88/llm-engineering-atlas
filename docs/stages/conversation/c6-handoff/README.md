# C6 · 상담원 이관 · 인계 요약 (Human handoff)

**상태: ⬜ 예정** — 자동으로 풀 수 없거나 위험한 문의는 대화 요약과 함께 사람에게 넘긴다

## 원리

이관 기준(반복 실패 · 불만 · 안전 관련 · 고객 요청)을 정하고, 넘길 때는 대화 요약 · 시도한 조치 · 근거를 붙여 상담원이 처음부터 묻지 않게 합니다.

## 왜 하는가

자동 답변이 모든 것을 해결할 수는 없습니다. 이관이 늦거나 맥락 없이 넘어가면 고객 경험이 가장 나빠집니다.

## 어떻게 (이 앱에서)

- (있음) 의미 응용의 분류기(문의 유형 · 긴급도 학습 가능), 라우팅
- (예정) 이관 기준 · 인계 요약, 이관률 · 이관 후 해결 시간 지표

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cv_handoff` 에서 볼 수 있습니다.
