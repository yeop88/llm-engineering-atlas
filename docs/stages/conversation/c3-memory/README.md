# C3 · 대화 요약 메모리 (Conversation memory)

**상태: ✅ 구현됨** — 대화가 길어져도 중요한 사실(제품 · 증상 · 이미 해 본 조치)을 요약해 기억한다

## 원리

대화 메모리는 지난 대화를 통째로 넣는 대신 사실 목록 · 요약으로 줄여 다음 답변에 넣는 것입니다. 무엇을 기억할지(결정 · 조건 · 해 본 조치)를 정해 둡니다.

## 왜 하는가

대화를 통째로 넣으면 읽을 글이 계속 늘어 느려지고(근거 읽기가 이미 병목), 오래된 내용이 새 질문을 흐립니다.

## 어떻게 (이 앱에서)

- 규칙으로 사실 목록: 제품(컬렉션 문서 메타의 모델, 마지막에 말한 것) · 오류 코드(문서 제목 줄의 코드만) · 증상(개인정보 가림) · 답에서 안내한 번호 단계 · 대화 주제(첫 질문의 명사구)
- 저장하지 않고 대화 기록에서 매번 다시 계산 — 기록과 어긋나지 않음, LLM 요약이 사실을 바꾸는 위험 없음
