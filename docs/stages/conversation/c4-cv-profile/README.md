# C4 · 사용자 · 제품 프로필 (User & product profile)

**상태: ⬜ 예정** — 고객의 보유 제품 · 이전 문의 · 선호를 프로필로 두고 검색 · 답변에 쓴다

## 원리

프로필은 대화를 넘어 남는 정보(보유 모델 · 구매일 · 이전 문의)입니다. 검색 필터(그 모델의 매뉴얼만)와 답변 맞춤에 씁니다.

## 왜 하는가

같은 '배수가 안 돼요'도 모델마다 조치가 다릅니다. 매번 모델을 묻는 대신 프로필에서 가져오면 빠르고 정확합니다.

## 어떻게 (이 앱에서)

- (있음) 의미 응용의 추천 · 분류(관심 · 문의 유형)
- (예정) 프로필 저장 · 검색 필터 연결, 개인정보 보관 기간(보안 · 가드레일 맵)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cv_profile` 에서 볼 수 있습니다.

## 앞으로 할 일
