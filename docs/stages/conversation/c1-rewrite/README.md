# C1 · 대화 맥락 질의 재작성 (Contextual query rewriting)

**상태: ⬜ 예정** — '그거 말고 다른 모델은요?' 처럼 앞 대화를 가리키는 질문을 혼자 읽혀도 되는 질문으로 바꿔 검색한다

## 원리

검색은 앞 대화를 모르므로, 대화 기록을 보고 대명사 · 생략을 채워 독립된 질문으로 다시 씁니다(대화형 질의 재작성). 재작성한 질문으로 검색하고 원래 질문으로 답합니다.

## 왜 하는가

상담에서 두 번째 질문부터는 대부분 앞 대화에 기대 있습니다. 그대로 검색하면 엉뚱한 근거가 나옵니다.

## 어떻게 (이 앱에서)

- (있음) 4 검색 향상의 질의 재작성 · HyDE · 다중 질의(질문 하나 기준)
- (예정) 대화 기록을 받는 재작성, 대화형 평가 세트(앞 대화 + 질문 + 정답 근거)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cv_rewrite` 에서 볼 수 있습니다.

## 앞으로 할 일

- 대화형 재작성
- 대화형 평가 세트
