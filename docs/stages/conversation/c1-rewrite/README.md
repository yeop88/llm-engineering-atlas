# C1 · 대화 맥락 질의 재작성 (Contextual query rewriting)

**상태: ✅ 구현됨** — '그거 말고 다른 모델은요?' 처럼 앞 대화를 가리키는 질문을 혼자 읽혀도 되는 질문으로 바꿔 검색한다

## 원리

검색은 앞 대화를 모르므로, 대화 기록을 보고 대명사 · 생략을 채워 독립된 질문으로 다시 씁니다(대화형 질의 재작성). 재작성한 질문으로 검색하고 원래 질문으로 답합니다.

## 왜 하는가

상담에서 두 번째 질문부터는 대부분 앞 대화에 기대 있습니다. 그대로 검색하면 엉뚱한 근거가 나옵니다.

## 어떻게 (이 앱에서)

- 앞 대화에 기대는 질문 판단(가리키는 말 · 말을 줄인 끝맺음 · 대상이나 기억한 제품이 빠진 짧은 질문) — 독립 질문은 바꾸지 않음
- 풀어 쓰기 방법: 규칙(기억한 제품 · 대화 주제를 덧붙임, 지어내지 않음) · LLM(대화 기록 + 기억한 사실, 결과가 비거나 길면 규칙으로) · 앞 질문 이어 붙이기
- 대화 상담 화면 · AS 상담 창(두 번째 문의부터)에 연결, 대화 평가 세트(후속 질문 24개)로 방법별 검색 비교
