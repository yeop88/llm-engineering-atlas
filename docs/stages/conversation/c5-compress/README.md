# C5 · 긴 대화 압축 (Long conversation compression)

**상태: ✅ 구현됨** — 긴 대화 · 긴 근거를 품질을 지키며 줄여 문맥 한도 안에 넣는다

## 원리

긴 대화는 오래된 부분을 요약하고, 지금 질문과 관련된 부분만 남겨 문맥 한도 안에 넣습니다. 근거 압축과 같은 원리라 같은 위험(필요한 문장을 버림)이 있습니다.

## 왜 하는가

로컬 LLM 의 문맥(슬롯당 8K)과 읽기 시간 때문에 긴 상담은 압축이 필요합니다. 근거 압축 실측(품질 −10)처럼 무엇을 버렸는지 재야 합니다.

## 어떻게 (이 앱에서)

- 답변 프롬프트에 최근 몇 턴(기본 4)만 원문, 그 앞은 기억한 사실 목록으로(규칙으로 뽑은 사실이라 요약이 사실을 바꾸지 않음), 1,500자 한도

## 화면

- `/conversation/eval#retrieval` — **긴 대화 압축**: 최근 턴은 원문, 앞부분은 기억한 사실

## 앞으로 할 일

- 압축 전후 답변 품질 비교
