# C4 · 사용자 · 제품 프로필 (User & product profile)

**상태: ✅ 구현됨** — 고객의 보유 제품 · 이전 문의 · 선호를 프로필로 두고 검색 · 답변에 쓴다

## 원리

프로필은 대화를 넘어 남는 정보(보유 모델 · 구매일 · 이전 문의)입니다. 검색 필터(그 모델의 매뉴얼만)와 답변 맞춤에 씁니다.

## 왜 하는가

같은 '배수가 안 돼요'도 모델마다 조치가 다릅니다. 매번 모델을 묻는 대신 프로필에서 가져오면 빠르고 정확합니다.

## 어떻게 (이 앱에서)

- 고객 키별 보유 제품 · 지난 문의 요약(가린 글), 보유 제품이 하나면 다음 대화의 시작 기억으로
- 보관 기간(PROFILE_RETENTION_DAYS, 기본 90일)이 지나면 하루 한 번 지움, 화면에서 지우기

## 화면

- `/conversation/chat#profile` — **고객 프로필**: 보유 제품 · 지난 문의

## 앞으로 할 일

- 프로필로 검색 범위 · 추천 연결
