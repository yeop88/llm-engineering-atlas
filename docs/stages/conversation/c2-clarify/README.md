# C2 · 되묻기 (모호한 질문) (Clarifying questions)

**상태: ✅ 구현됨** — 질문이 모호하거나 정보가 모자라면 답하기 전에 필요한 것을 되묻는다

## 원리

되묻기는 '어느 모델인가요?', '언제 계약하셨나요?' 처럼 답에 필요한 조건이 빠졌을 때 짧게 묻는 것입니다. 모호함은 검색 확신도 · 조건 누락 · 분류기로 판단합니다.

## 왜 하는가

모호한 질문에 그럴듯하게 답하면 지어낸 답이 됩니다. 법률 실측에서 답 없는 질문을 거의 거절하지 못한 것과 같은 문제입니다.

## 어떻게 (이 앱에서)

- 필수 정보 빠짐: 제품별 매뉴얼 컬렉션에서 제품을 모르는 고장 문의 → '어느 모델인가요?'(코드가 한 모델에만 있으면 그 모델로 보고 묻지 않음)
- 검색이 헷갈림: 짧은 질문(명사 2개 이하)인데 검색 1 · 2위 차가 아주 작음 → 구체적으로 물음
- 한 대화에서 같은 이유로 두 번 묻지 않음(답하지 않으면 그대로 답함)
