# C2 · 되묻기 (모호한 질문) (Clarifying questions)

**상태: ⬜ 예정** — 질문이 모호하거나 정보가 모자라면 답하기 전에 필요한 것을 되묻는다

## 원리

되묻기는 '어느 모델인가요?', '언제 계약하셨나요?' 처럼 답에 필요한 조건이 빠졌을 때 짧게 묻는 것입니다. 모호함은 검색 확신도 · 조건 누락 · 분류기로 판단합니다.

## 왜 하는가

모호한 질문에 그럴듯하게 답하면 지어낸 답이 됩니다. 법률 실측에서 답 없는 질문을 거의 거절하지 못한 것과 같은 문제입니다.

## 어떻게 (이 앱에서)

- (있음) 라우팅의 검색 확신도 · LLM 판단(쉬움/어려움)
- (예정) '되묻기' 경로 추가, 되묻기가 필요한 질문 평가 세트

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cv_clarify` 에서 볼 수 있습니다.

## 앞으로 할 일

- 모호한 질문 평가 세트
