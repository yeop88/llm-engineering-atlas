# PV6 · 답 문장 (Answer sentences)

**상태: ⬜ 예정** — 답 문장 → 주장 → 근거를 요청 기록에 남긴다

## 원리

답 문장 계보는 답의 각 문장이 어떤 주장을 담고 어떤 근거에 기대는지입니다. 요청 기록(해시 사슬)과 함께 남겨 나중에 다시 볼 수 있게 합니다.

## 왜 하는가

운영에서 문제 답을 신고받으면 어느 문장이 어느 근거에서 왔는지 바로 봐야 고칠 곳(문서 · 청킹 · 검색 · LLM)을 고릅니다.
