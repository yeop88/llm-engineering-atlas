# PV2 · 수집 시각 · 판 (Ingestion time & version)

**상태: ✅ 구현됨** — 언제 받은 어느 판인지, 판이 바뀌면 무엇이 바뀌었나

## 원리

수집 시각과 판은 같은 원본의 시점별 상태입니다. 법령은 개정 판마다, 매뉴얼은 개정마다 내용이 바뀝니다. 판 사이의 바뀐 부분을 남깁니다.

## 왜 하는가

옛 판에서 나온 답은 지금 틀릴 수 있습니다. 판을 남겨야 '그때는 맞았다'와 '지금 틀리다'를 구분합니다.

## 어떻게 (이 앱에서)

- (기반) 증분 갱신(D6) · 데이터 근거(RC3)
- 같은 컬렉션에서 같은 원본(출처 키 · 파일 이름)인 문서를 받은 순서로 판을 세우고, 지금 판이 아닌 문서를 근거로 답했으면 '옛 판 근거'

## 화면
