# PV1 · 원본 소스 (Source)

**상태: ⬜ 예정** — 문서의 원본(파일 · URL · API)과 그 해시 · 권리를 남긴다

## 원리

원본 소스는 문서가 처음 온 곳(업로드 파일 · URL · 법령 API 등)과 그 내용 해시 · 라이선스입니다. 같은 이름이라도 해시가 다르면 다른 원본입니다.

## 왜 하는가

원본을 모르면 '이 근거가 믿을 만한가'와 '써도 되는가'를 판단할 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 수집(D1) · 라이선스(G6)
- (예정) 원본 노드 · 해시 · 권리 · URL
