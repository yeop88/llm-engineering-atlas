# PV7 · 인용 (Citations)

**상태: ⬜ 예정** — 인용 번호가 실제 근거를 가리키고, 근거가 주장을 뒷받침하는지 본다

## 원리

인용은 답의 [n] 이 가리키는 근거입니다. 번호가 없는 근거를 가리키거나, 가리킨 근거가 주장과 무관하면 틀린 인용입니다.

## 왜 하는가

인용이 있어도 틀린 근거를 가리키면 사용자는 확인했다고 믿어 버려, 인용이 없을 때보다 더 강하게 속습니다.

## 어떻게 (이 앱에서)

- (기반) 인용 검사(2) · 설명 가능성(RC4)
- (예정) 주장별 인용 일치 · 틀린 인용 표시
