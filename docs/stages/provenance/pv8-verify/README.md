# PV8 · 검증 결과 · 부딪힘 (Verification & contradictions)

**상태: ⬜ 예정** — 주장끼리 · 판끼리 부딪히는 것을 찾고 검증 결과를 남긴다

## 원리

검증 결과는 주장마다 '근거 있음 · 근거 약함 · 근거 없음'과, 같은 질문의 다른 답 · 다른 판의 근거와 부딪히는지(CONTRADICTS)입니다.

## 왜 하는가

같은 질문에 날마다 다른 답이 나오면 신뢰를 잃습니다. 부딪힘을 찾아야 어느 쪽이 맞는지 정할 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 엔티티 융합(K4) · 드리프트(E6)
- (예정) 주장 간 부딪힘 탐지 · 판 차이로 설명
