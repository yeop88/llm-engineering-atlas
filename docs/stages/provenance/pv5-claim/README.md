# PV5 · 주장 (Claims)

**상태: ✅ 구현됨** — 답을 확인 가능한 주장 단위로 나눈다

## 원리

주장은 답 안의 하나의 사실 진술('임금은 매월 1회 이상')입니다. 답 문장 하나에 주장이 여럿일 수 있어 주장 단위로 근거를 잇습니다.

## 왜 하는가

문장 단위로만 근거를 보면 한 문장 안의 맞는 주장과 틀린 주장이 섞여도 모릅니다.

## 어떻게 (이 앱에서)

- (기반) 근거 일치 검증(2)
- 답을 문장 → 주장(쉼표 · 접속 표현)으로 나누고, 주장마다 인용한 근거 · 가장 겹치는 근거(글자 3-gram) · 숫자 · 조문 · 코드 표시가 근거에 그대로 있는지 → 강함 · 약함 · 없음 · 인용 안 함
