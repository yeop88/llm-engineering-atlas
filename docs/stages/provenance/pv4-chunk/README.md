# PV4 · 청크 (Chunk)

**상태: ⬜ 예정** — 청크가 원본의 어디(쪽 · 조문 · 글자 범위)에서 왔는지 남긴다

## 원리

청크 계보는 청크마다 문서 · 판 · 쪽 · 조문 · 글자 범위입니다. 같은 문서를 다른 방식으로 나누면 다른 청크 세트가 됩니다.

## 왜 하는가

인용을 눌렀을 때 원본의 정확한 자리(쪽 · 조문)로 가야 사람이 답을 몇 초 안에 확인할 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 청킹(D5)
- (예정) 청크 → 문서 · 판 · 범위
