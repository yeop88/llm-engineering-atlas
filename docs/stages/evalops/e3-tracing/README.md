# E3 · 트레이싱 (Tracing)

**상태: ✅ 구현됨** — 질문마다 단계 · 시간 · 토큰 · 결정(라우팅 · 도구)을 기록해 한 요청을 끝까지 따라가 본다

## 원리

트레이스는 요청 하나가 거친 단계(검색 · 재정렬 · 라우팅 · 에이전트 행동 · 답변 · 검증)를 시간 순서로 남긴 기록입니다. 단계마다 입력 · 출력 요약 · 시간 · 토큰을 남기면 느리거나 틀린 원인을 찾을 수 있습니다.

## 왜 하는가

평균만 있으면 원인을 못 찾습니다 — 에이전트 측정에서 한 질문이 20분 걸린 이유를 질문별 기록이 없어 찾지 못했습니다.

## 어떻게 (이 앱에서)

- 모든 서비스 답변을 요청 기록으로: 단계별 시간(입력 검사 · 검색 · 근거 검사 · LLM · 검증 · 출력 검사) · 토큰 · 검색 신호(1위 점수 · 1 · 2위 차) · 근거 · 검증 · 가드레일 결과
- 기록 목록 · 상세, 느림 · 근거 약함 · 거절 · 차단 표시로 찾기

## 화면

- `/evalops/traces` — **요청 기록 · 비용**: 질문별 단계 · 시간 · 토큰 · 비용, 느린 · 근거 약한 답 찾기
