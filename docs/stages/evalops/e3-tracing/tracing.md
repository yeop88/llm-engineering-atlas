# 요청 기록 · 비용 · 지연 (E3 · E4)

화면은 `/evalops/traces`(대시보드 · 요청 목록 · 상세)입니다. 기록은 `app/core/tracing.py`, 쓰는 곳은 서비스 답변(`app/pipeline/serve.py`)입니다.

## E3 요청 기록

- 답변 화면 · AS 상담 · A/B 실험 · 레드팀의 답 하나 = 기록 하나(`traces`). 종류(`kind`) · 사용자 · 질문 · 답 · 경로 · 모델 · **단계별 시간**(입력 검사 · 검색 · 근거 검사 · LLM · 검증 · 출력 검사) · 토큰 · 비용 · **검색 신호**(결과 수 · 1위 점수 · 1 · 2위 차) · 근거 문서 · 검증 요약 · 가드레일 결과 · 실험 팔 · 피드백.
- 같은 표가 감사 로그(G5)입니다 — 따로 두면 '답한 기록'과 '감사 기록'이 어긋날 수 있어 하나로 두고 해시 체인을 붙였습니다.
- 목록의 표시: 느림(기간 p95 초과) · 실패 · 차단 · 근거 약함(근거 일치 < 0.5) · 관련 없음 · 거절 · 싫어요. 평균만 보면 '왜 나빠졌는지'를 못 찾습니다(에이전트 20분 질문 경험) — 그래서 질문 단위로 남기고 표시로 거릅니다.

## E4 비용 · 지연

- 전체 · 날짜 · 경로 · 모델 · 종류별 p50 · p95 지연, 토큰, 비용, 실패 · 차단 수. 단계별 시간 몫(어디서 시간을 쓰나).
- 비용 = 토큰 × `LLM_PRICES`(모델별 100만 토큰당 [입력, 출력]). 로컬 모델은 비워 두면 0 입니다.
