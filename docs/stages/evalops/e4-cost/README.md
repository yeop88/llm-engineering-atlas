# E4 · 비용 · 지연 대시보드 (Cost & latency dashboard)

**상태: ✅ 구현됨** — 질문당 토큰 · 시간 · 비용을 모아 단계별 · 경로별로 보여 준다

## 원리

답변 하나의 비용은 읽은 토큰 · 쓴 토큰 · 모델 단가 · 걸린 시간의 합입니다. 단계 · 경로 · 모델별로 나눠 모으면 어디에 돈과 시간이 쓰이는지 보입니다.

## 왜 하는가

라우팅 · 압축 · 소형 모델의 효과는 '얼마나 아꼈나'로 판단합니다. 지금은 측정 때만 시간을 보고, 서비스 중의 분포(p95)는 모릅니다.

## 어떻게 (이 앱에서)

- 기간 · 경로 · 모델 · 종류별 p50 · p95 지연, 토큰, 비용(LLM_PRICES: 1M 토큰당 가격), 단계별 시간 몫

## 화면

- `/evalops/traces#dashboard` — **비용 · 지연 대시보드**: p50 · p95 지연 · 토큰 · 비용
