# E1 · 평가 세트 · 정답 관리 (Eval datasets & ground truth)

**상태: ✅ 구현됨** — 질문 · 정답 근거 · 질문 유형을 세트로 관리하고, 생성 · 보정 · 보충 기록을 남긴다

## 원리

평가 세트는 '좋은 답'의 기준입니다. 질문마다 정답 문서 · 근거 문장 · 유형(사실 · 조건 · 여러 문서 · 답 없음 …)을 두고, 세트를 만든 방법 · 시드 · 보정 내역을 함께 남겨 같은 세트로 다시 잴 수 있게 합니다.

## 왜 하는가

기준이 흔들리면 모든 비교가 무의미합니다. 생성 LLM 이 근거를 고치거나(법률 6%) 특정 종류가 빠지는(법령 질문 0개) 문제는 세트를 열어 봐야 보입니다.

## 어떻게 (이 앱에서)

- 세트 버전 · 변경 이력(문항 추가 · 검토마다 버전 +1)
- 문항 검토 상태(검토 전 · 통과 · 제외) — 제외 문항은 평가에서 빠짐
- 회귀 세트 지정 · 기준선 저장
- (있음) LLM 질문 7유형 생성 · 직접 입력 · 문서 지정 보충, 근거 보정 기록
