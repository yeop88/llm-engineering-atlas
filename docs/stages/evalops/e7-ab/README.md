# E7 · A/B · 온라인 실험 (A/B & online experiments)

**상태: ⬜ 예정** — 실제 요청을 두 설정에 나눠 보내 품질 · 만족도 · 비용을 비교한다

## 원리

A/B 실험은 요청을 무작위로 나눠 두 설정에 보내고 결과를 비교합니다. 오프라인 평가가 '세트에서 좋은가'라면 A/B 는 '실제 사용자에게 좋은가'를 봅니다.

## 왜 하는가

오프라인 지표와 실제 만족도는 어긋날 수 있습니다(Best-of 는 보상이 유의하게 올랐지만 품질은 불확실). 출시 결정은 실제 요청으로 확인해야 합니다.

## 어떻게 (이 앱에서)

- (있음) 짝지은 비교 통계(부트스트랩 · 신뢰구간), 학습 라우터 · 경로 설정 저장
- (예정) 요청 분할 · 실험 기록, 피드백 · 비용 지표로 판정

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ev_ab` 에서 볼 수 있습니다.
