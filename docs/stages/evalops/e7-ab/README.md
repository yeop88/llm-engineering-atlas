# E7 · A/B · 온라인 실험 (A/B & online experiments)

**상태: ✅ 구현됨** — 실제 요청을 두 설정에 나눠 보내 품질 · 만족도 · 비용을 비교한다

## 원리

A/B 실험은 요청을 무작위로 나눠 두 설정에 보내고 결과를 비교합니다. 오프라인 평가가 '세트에서 좋은가'라면 A/B 는 '실제 사용자에게 좋은가'를 봅니다.

## 왜 하는가

오프라인 지표와 실제 만족도는 어긋날 수 있습니다(Best-of 는 보상이 유의하게 올랐지만 품질은 불확실). 출시 결정은 실제 요청으로 확인해야 합니다.

## 어떻게 (이 앱에서)

- 실험 = 두 설정(검색 · LLM). 사용자 해시로 고정 배정(같은 사용자는 늘 같은 쪽), 실험 답변도 서비스 답변으로 기록
- 기록 재생: 지난 질문을 두 설정으로 다시 답해 출시 전에 비교
- 판정: 근거 일치 · 좋아요 비율 · 지연 차이와 표본 수

## 화면

- `/evalops/experiments` — **A/B 실험**: 사용자를 나눠 두 설정 비교, 기록 재생으로 미리 재기
