# E6 · 드리프트 · 이상 감지 (Drift & anomaly detection)

**상태: ✅ 구현됨** — 들어오는 질문의 분포 · 검색 확신도 · 거절률이 평소와 달라지면 알린다

## 원리

드리프트는 시간이 지나며 질문 주제 · 말투가 바뀌거나 자료가 낡아 성능이 떨어지는 현상입니다. 질문 임베딩의 분포, 검색 확신도, 거절률 같은 신호를 기준 기간과 비교해 감지합니다.

## 왜 하는가

평가 세트는 만든 시점의 질문만 담습니다. 새 제품 · 새 법령이 나오면 세트에 없는 질문이 늘어 품질이 떨어지는데, 평가 세트로는 보이지 않습니다.

## 어떻게 (이 앱에서)

- 기준 기간 vs 최근: 질문 임베딩으로 새 유형 질문(가장 가까운 기준 질문 유사도 < 0.6) 비율 · 묶음
- 검색 신호(1위 점수 · 1 · 2위 차) 변화를 부트스트랩 구간으로 — 우연한 흔들림과 구분
- 정기 점검(WATCH_DRIFT_HOURS): 주기마다 최근 7일 vs 30일을 다시 재고, 경보가 나면 화면 · ALERT_WEBHOOK 으로
- 새 유형 질문 묶음을 평가 세트 후보(정답 문서 없이 검토 전)로 바로 보내기

## 화면

- `/evalops/drift` — **드리프트 감지**: 기준 기간과 최근 질문 분포 · 검색 신호 비교, 새 유형 질문

## 앞으로 할 일
