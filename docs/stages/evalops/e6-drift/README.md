# E6 · 드리프트 · 이상 감지 (Drift & anomaly detection)

**상태: ⬜ 예정** — 들어오는 질문의 분포 · 검색 확신도 · 거절률이 평소와 달라지면 알린다

## 원리

드리프트는 시간이 지나며 질문 주제 · 말투가 바뀌거나 자료가 낡아 성능이 떨어지는 현상입니다. 질문 임베딩의 분포, 검색 확신도, 거절률 같은 신호를 기준 기간과 비교해 감지합니다.

## 왜 하는가

평가 세트는 만든 시점의 질문만 담습니다. 새 제품 · 새 법령이 나오면 세트에 없는 질문이 늘어 품질이 떨어지는데, 평가 세트로는 보이지 않습니다.

## 어떻게 (이 앱에서)

- (있음) 의미 응용의 이상 · 신종 탐지(임베딩 기반), 라우팅의 검색 확신도
- (예정) 주간 질문 분포 · 확신도 · 거절률 비교, 신종 질문 묶음을 평가 세트 후보로

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ev_drift` 에서 볼 수 있습니다.

## 앞으로 할 일

- 질문 분포 · 확신도 감시
- 신종 질문 → 평가 세트 후보
