# E5 · 사용자 피드백 · 사람 판정 (User feedback & human labels)

**상태: 🟡 기초 있음** — 답변마다 좋아요 · 싫어요 · 이유를 받고, 사람 판정으로 자동 판정을 보정한다

## 원리

사용자 피드백은 가장 싼 정답 신호지만 시끄럽습니다. 이유(근거 없음 · 질문과 상관없음 · 틀린 숫자)를 고르게 하면 어느 단계를 고칠지 알 수 있고, 사람 판정과 자동 판정의 일치도로 자동 판정 기준을 맞춥니다.

## 왜 하는가

자동 판정만 믿으면 틀립니다 — 작은 LLM 판정은 사람 판정 28개를 모두 통과시켰고, 사람이 문제 삼은 것은 '질문과 상관없는 문장'이었습니다.

## 어떻게 (이 앱에서)

- (있음) 검증 보정 화면(근거 일치 · 질문 관련성 판정, 일치도 · 기준 탐색), 선호 쌍 수집(사람 · 자동)
- (예정) 답변 화면의 좋아요 · 싫어요 · 이유, 피드백을 판정 라벨 · 평가 세트 후보로 넘기기

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ev_feedback` 에서 볼 수 있습니다.

## 앞으로 할 일

- 답변 피드백 버튼 · 이유
- 피드백 → 라벨 · 평가 세트
