# E2 · 오프라인 평가 · 회귀 (Offline eval & regression)

**상태: 🟡 기초 있음** — 설정 · 모델 · 라이브러리를 바꿀 때마다 고정 세트로 다시 재서 기준선보다 나빠졌는지 확인한다

## 원리

회귀 평가는 같은 세트 · 같은 조건으로 '바꾸기 전'과 '바꾼 뒤'를 짝지어 비교하는 것입니다. 질문별 차이의 신뢰구간으로 우연인지 판단하고, 유의하게 나빠지면 경보를 냅니다.

## 왜 하는가

라이브러리 업그레이드 · 모델 교체 · 프롬프트 수정은 조용히 품질을 떨어뜨립니다. 사람이 매번 기억해서 재는 대신 정해진 세트를 자동으로 돌려야 합니다.

## 어떻게 (이 앱에서)

- (있음) 조합 평가 · 연결 비교 · 라우팅 평가 — 짝지은 차이와 95% 구간, 실행 이력, 모델 호환성 점검(라이브러리 버전 감지)
- (예정) 업그레이드 · 설정 변경 시 회귀 세트 자동 실행, 기준선 대비 유의한 하락이면 경보

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ev_offline` 에서 볼 수 있습니다.

## 앞으로 할 일

- 회귀 세트 자동 실행
- 하락 경보
