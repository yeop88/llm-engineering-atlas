# E2 · 오프라인 평가 · 회귀 (Offline eval & regression)

**상태: ✅ 구현됨** — 설정 · 모델 · 라이브러리를 바꿀 때마다 고정 세트로 다시 재서 기준선보다 나빠졌는지 확인한다

## 원리

회귀 평가는 같은 세트 · 같은 조건으로 '바꾸기 전'과 '바꾼 뒤'를 짝지어 비교하는 것입니다. 질문별 차이의 신뢰구간으로 우연인지 판단하고, 유의하게 나빠지면 경보를 냅니다.

## 왜 하는가

라이브러리 업그레이드 · 모델 교체 · 프롬프트 수정은 조용히 품질을 떨어뜨립니다. 사람이 매번 기억해서 재는 대신 정해진 세트를 자동으로 돌려야 합니다.

## 어떻게 (이 앱에서)

- 기준선 대비 질문별 짝지은 차이 · 95% 구간 → 유의하게 나빠지면 경보, 유형별 차이 · 가장 나빠진 질문
- 설정을 바꿔 돌리기 · 라이브러리 업그레이드 감지 때 자동 실행(REGRESSION_ON_UPGRADE)
- (있음) 조합 평가 · 연결 비교 · 라우팅 평가, 모델 호환성 점검
