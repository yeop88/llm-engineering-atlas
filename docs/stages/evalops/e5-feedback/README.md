# E5 · 사용자 피드백 · 사람 판정 (User feedback & human labels)

**상태: ✅ 구현됨** — 답변마다 좋아요 · 싫어요 · 이유를 받고, 사람 판정으로 자동 판정을 보정한다

## 원리

사용자 피드백은 가장 싼 정답 신호지만 시끄럽습니다. 이유(근거 없음 · 질문과 상관없음 · 틀린 숫자)를 고르게 하면 어느 단계를 고칠지 알 수 있고, 사람 판정과 자동 판정의 일치도로 자동 판정 기준을 맞춥니다.

## 왜 하는가

자동 판정만 믿으면 틀립니다 — 작은 LLM 판정은 사람 판정 28개를 모두 통과시켰고, 사람이 문제 삼은 것은 '질문과 상관없는 문장'이었습니다.

## 어떻게 (이 앱에서)

- 답변마다 좋아요 · 싫어요 + 이유 · 메모(답변 화면 · 기록 화면)
- 자동 판정(근거 일치)과 사람 판정의 일치율
- 싫어요 받은 기록 → 평가 세트 후보

## 화면

- `/evalops/feedback` — **피드백 · 개선 루프**: 좋아요 · 싫어요 · 이유, 실패 유형 분류 → 평가 세트 · 학습 데이터
