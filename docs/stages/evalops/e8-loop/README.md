# E8 · 개선 반영 루프 (Improvement loop)

**상태: ✅ 구현됨** — 실패 사례를 모아 평가 세트 · 학습 데이터 · 규칙으로 되돌려 다음 버전을 만든다

## 원리

개선 루프(데이터 플라이휠)는 서비스에서 나온 실패 사례를 분류해 평가 세트(재발 방지), 학습 데이터(파인튜닝 · 선호 학습), 규칙(라우팅 · 가드레일)으로 돌려보내는 과정입니다.

## 왜 하는가

같은 실수를 사람이 매번 찾지 않으려면 실패가 자동으로 다음 평가 · 학습의 재료가 되어야 합니다.

## 어떻게 (이 앱에서)

- 실패 유형 분류(검색 실패 · 인용 문제 · 질문과 다름 · 과잉 거절 · 정책) — 기록의 검증 · 피드백 신호로
- 평가 세트로 보내기 · 빈틈 목록 CSV(학습 데이터 후보)

## 화면

- `/evalops/feedback#loop` — **개선 루프**: 실패 유형 → 평가 세트 · 빈틈 CSV
