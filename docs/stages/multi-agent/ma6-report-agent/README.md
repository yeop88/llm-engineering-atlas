# MA6 · 보고서 작성 에이전트 (Writer agent (sLLM / LLM routing))

**상태: ⬜ 예정** — 모은 근거 · 분석 결과로 정해진 형식의 답 · 보고서를 쓴다 — 쉬운 작성은 소형 모델, 어려운 작성은 큰 모델

## 원리

작성 에이전트는 근거와 분석 결과를 받아 템플릿(보고서 · 안내문 · 요약)에 맞춰 씁니다. 짧은 요약 · 정형 안내는 소형 모델(sLLM)로, 긴 종합 · 추론은 큰 모델로 보냅니다.

## 왜 하는가

같은 품질이면 싼 모델을 써야 하지만, 작은 모델로 바꾸면 품질이 떨어질 수 있습니다. 이 PC 실측에서 Gemma 4 E2B 는 E4B 보다 지연 −21% 대신 품질 −13(유의)이라, 작성 난이도에 따라 나눠 써야 합니다.

## 어떻게 (이 앱에서)

- (있음) 6 라우팅의 경로별 답변 모델 지정, 7b 양자화 · 7a 증류 실측(소형 모델 후보), 답변 원칙(질문에 대한 답 + 관련된 부가 설명만)
- (예정) 출력 템플릿(보고서 · AS 안내 · 요약)과 템플릿별 검증 규칙
- (예정) 작성 난이도 라우팅: 템플릿 · 근거 길이 · 요구 형식으로 sLLM / LLM 선택, 품질 · 비용 실측
