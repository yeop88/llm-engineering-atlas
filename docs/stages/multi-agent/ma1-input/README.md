# MA1 · 멀티모달 입력 · 임베딩 (Multimodal input & embedding)

**상태: 🟡 기초 있음** — 텍스트 · 이미지 · 음성 · 문서를 공통 벡터 공간에 놓아, 사진으로 매뉴얼을 찾는 식의 교차 검색을 한다

## 원리

멀티모달 임베딩 모델(CLIP · SigLIP · ImageBind · 멀티모달 EmbeddingGemma 등)은 이미지와 텍스트(모델에 따라 음성까지)를 같은 벡터 공간에 놓습니다. 그래서 이미지 자체를 질의로 써서 비슷한 텍스트 · 이미지를 찾을 수 있습니다(예: 제품 사진 → 관련 매뉴얼).

## 왜 하는가

고객 · AS 문의는 '이 에러 화면' · '이 부품' 처럼 사진으로 들어오는 경우가 많습니다. 사진을 글로 옮겨 적게 하면 정보가 빠지고 사용자가 불편합니다.

## 어떻게 (이 앱에서)

- (있음) LLM 맵 M 멀티모달: 이미지 · 영상 장면을 텍스트와 같은 공간에서 검색 — 한국어 질의는 EmbeddingGemma 2 가 CLIP 보다 크게 나음(실측 nDCG 100 vs 67.4)
- (예정) 이미지로 이미지 · 문서 찾기(질의 이미지 업로드), 사진 + 질문을 함께 넣는 질의
- (예정) 음성 입력: 음성 인식(STT)으로 글로 바꾼 뒤 같은 파이프라인, 오디오 임베딩은 의존성 해결 후

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/mm_input` 에서 볼 수 있습니다.

## 앞으로 할 일

- 질의 이미지 업로드 검색
- 음성 입력(STT) 연결
