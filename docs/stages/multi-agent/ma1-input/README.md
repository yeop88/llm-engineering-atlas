# MA1 · 멀티모달 입력 · 임베딩 (Multimodal input & embedding)

**상태: ✅ 구현됨** — 텍스트 · 이미지 · 음성 · 문서를 공통 벡터 공간에 놓아, 사진으로 매뉴얼을 찾는 식의 교차 검색을 한다

## 원리

멀티모달 임베딩 모델(CLIP · SigLIP · ImageBind · 멀티모달 EmbeddingGemma 등)은 이미지와 텍스트(모델에 따라 음성까지)를 같은 벡터 공간에 놓습니다. 그래서 이미지 자체를 질의로 써서 비슷한 텍스트 · 이미지를 찾을 수 있습니다(예: 제품 사진 → 관련 매뉴얼).

## 왜 하는가

고객 · AS 문의는 '이 에러 화면' · '이 부품' 처럼 사진으로 들어오는 경우가 많습니다. 사진을 글로 옮겨 적게 하면 정보가 빠지고 사용자가 불편합니다.

## 어떻게 (이 앱에서)

- (있음) LLM 맵 M 멀티모달: 이미지 · 영상 장면을 텍스트와 같은 공간에서 검색
- 사진을 올려 컬렉션 인덱스의 멀티모달 모델로 임베딩해 그림 · 글 청크를 찾고, 질문 글을 함께 주면 그림 · 글 임베딩 평균으로 '이 사진 + 이 질문'
- 문서 권한(G3)은 그림 검색에도, 텍스트 전용 인덱스는 거절

## 화면

- `/multiagent/image-search` — **사진으로 찾기**: 사진 + 질문으로 멀티모달 인덱스 검색
