# MA7 · 품질 검증 에이전트 (Critic / reviewer agent)

**상태: ✅ 구현됨** — 최종 답이 원문과 맞는지(환각) · 질문에 답하는지 · 보안 규정을 어기지 않는지 검사해 반려하거나 통과시킨다

## 원리

검증 에이전트는 답을 만들지 않고 검사만 합니다. 문장마다 근거 일치 · 질문 관련성 · 인용 번호를 확인하고, 규정(개인정보 · 내부 정보 노출 등)을 점검해 통과 / 수정 요청 / 반려를 정합니다. 반려되면 작성 에이전트가 이유를 받아 다시 씁니다(교차 검증).

## 왜 하는가

에이전트가 많아질수록 앞 단계의 실수가 뒤로 전달됩니다. 마지막에 독립된 검사가 있어야 서비스로 내보낼 수 있습니다. 다만 이 PC 의 사람 판정에서 작은 LLM 판정은 근거 일치를 28개 모두 통과시켰습니다 — 검증 에이전트는 LLM 판단만이 아니라 측정으로 보정된 점수를 함께 써야 합니다.

## 어떻게 (이 앱에서)

- 문장별 근거 일치 · 질문 관련성(2 RAG), 출력 정책 · 개인정보(G4 · G2), 분석 숫자가 답에 있나를 보고 통과 · 수정 요청(지적과 함께) · 반려(규정 위반)
- 수정 요청이면 작성 에이전트가 다시(상한 2번), 상한에 닿으면 '검토 필요' 표시를 붙여 내보냄
