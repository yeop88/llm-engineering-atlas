# MA5 · 분석 · 코딩 에이전트 (Analysis / code agent)

**상태: ✅ 구현됨** — 검색된 표 · 수치를 파이썬 코드로 계산 · 검증하고 결과 차트를 만든다

## 원리

LLM 이 계산을 머릿속으로 하면 틀립니다. 분석 에이전트는 표 · 그래프 데이터를 파싱해 코드를 만들고, 격리된 실행기(코드 인터프리터)에서 실행한 결과로 통계 · 무결성 검증 · 차트를 냅니다.

## 왜 하는가

'분기별 매출 증감률', '보증금 반환 금액 계산' 같은 질문은 숫자를 정확히 계산해야 합니다. 실행 결과를 근거로 쓰면 계산 과정을 재현 · 검증할 수 있습니다.

## 어떻게 (이 앱에서)

- LLM 은 근거 글(SOURCES)에서 수치를 뽑아 계산하는 파이썬 코드만 쓰고, 계산은 샌드박스(IO2, 네트워크 없는 컨테이너)가 — 작은 모델의 암산 오류를 피하려고
- 결과는 JSON 한 줄(result · chart), 실패하면 오류를 보여 한 번 다시 쓰게

## 화면

- `/multiagent/console#timeline` — **분석 · 코딩**: 근거 수치를 코드로 계산 · 차트
