# MA5 · 분석 · 코딩 에이전트 (Analysis / code agent)

**상태: ⬜ 예정** — 검색된 표 · 수치를 파이썬 코드로 계산 · 검증하고 결과 차트를 만든다

## 원리

LLM 이 계산을 머릿속으로 하면 틀립니다. 분석 에이전트는 표 · 그래프 데이터를 파싱해 코드를 만들고, 격리된 실행기(코드 인터프리터)에서 실행한 결과로 통계 · 무결성 검증 · 차트를 냅니다.

## 왜 하는가

'분기별 매출 증감률', '보증금 반환 금액 계산' 같은 질문은 숫자를 정확히 계산해야 합니다. 실행 결과를 근거로 쓰면 계산 과정을 재현 · 검증할 수 있습니다.

## 어떻게 (이 앱에서)

- (있음) 8a 에이전트의 calc 도구 — 산술식만 계산(eval 없이, LLM 이 만든 코드를 실행하지 않음)
- (예정) 격리된 코드 실행기(시간 · 메모리 · 네트워크 제한, 허용 라이브러리만) — 임의 코드 실행 위험 때문에 격리가 먼저
- (예정) 표 파싱(PDF 표 · 이미지 표 → DataFrame), 결과 차트 생성(차트 색 규칙 · 색각이상 검증 그대로)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/analysis_agent` 에서 볼 수 있습니다.
