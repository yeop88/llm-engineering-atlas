# MA4 · 검색 전문가 에이전트 (Retrieval agent (Self-RAG))

**상태: 🟡 기초 있음** — 사내 문서 · 이미지 · 웹 검색만 맡고, 결과가 부실하면 스스로 질의를 고쳐 다시 찾는다(Self-RAG)

## 원리

검색 에이전트는 '정보 모으기'만 전담합니다. 찾은 결과가 질문에 충분한지 스스로 판단하고, 부족하면 질의를 바꾸거나 하위 질문으로 나눠 다시 검색합니다. 모은 근거는 번호를 붙여 다음 에이전트에게 넘깁니다.

## 왜 하는가

검색이 부실하면 뒤의 분석 · 작성이 아무리 좋아도 답이 틀립니다. 검색만 따로 두면 검색 품질을 기존 평가 세트(nDCG · 근거 검색률)로 따로 잴 수 있습니다.

## 어떻게 (이 앱에서)

- (있음) 8a 에이전트의 search · read · lookup(조문 · 사건번호) 도구, 4 검색 향상(질의 재작성 · HyDE · 다중 질의), 2 RAG 하이브리드 검색
- (예정) 결과 충분성 판단 → 재검색 루프(상한), 이미지 · 웹 검색 도구 추가
- (예정) 평가: 재검색 전후 근거 검색률 · 질문당 검색 횟수
