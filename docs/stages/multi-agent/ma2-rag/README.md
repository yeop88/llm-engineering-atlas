# MA2 · 멀티모달 RAG (Multimodal RAG)

**상태: ✅ 구현됨** — 표 · 그래프 · 설계도를 글로 바꾸지 않고 이미지 청크 그대로 저장 · 검색하고, 멀티모달로 다시 순위를 매긴다

## 원리

PDF 안의 복잡한 표 · 그래프 · 설계도는 글로 뽑으면 구조가 깨집니다. 페이지나 그림 영역을 이미지 청크로 그대로 저장해 멀티모달 임베딩으로 찾고, 찾은 이미지는 비전 LLM 이 직접 읽어 답합니다.

## 왜 하는가

사내 문서의 핵심 정보가 표 · 도면에 있는 경우가 많고, 텍스트 추출만으로는 '이 그래프의 추세'나 '도면의 부품 번호'를 답할 수 없습니다.

## 어떻게 (이 앱에서)

- (있음) 이미지 · 영상 프레임을 청크로 색인 · 검색, 그림 근거를 비전 LLM 에 첨부해 번호로 인용
- 검색 전문가가 그림 후보를 비전 LLM 에 질문과 함께 보여 0~3점을 받아 다시 줄 세움(글 임베딩이 놓친 그림 속 표 · 도면 보완), 실패하면 원래 순서

## 화면

- `/multiagent/console#timeline` — **멀티모달 RAG**: 그림 후보를 비전 LLM 으로 다시 줄 세움

## 앞으로 할 일

- PDF 표 · 그림 영역을 이미지 청크로
