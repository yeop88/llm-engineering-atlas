# MA2 · 멀티모달 RAG (Multimodal RAG)

**상태: 🟡 기초 있음** — 표 · 그래프 · 설계도를 글로 바꾸지 않고 이미지 청크 그대로 저장 · 검색하고, 멀티모달로 다시 순위를 매긴다

## 원리

PDF 안의 복잡한 표 · 그래프 · 설계도는 글로 뽑으면 구조가 깨집니다. 페이지나 그림 영역을 이미지 청크로 그대로 저장해 멀티모달 임베딩으로 찾고, 찾은 이미지는 비전 LLM 이 직접 읽어 답합니다.

## 왜 하는가

사내 문서의 핵심 정보가 표 · 도면에 있는 경우가 많고, 텍스트 추출만으로는 '이 그래프의 추세'나 '도면의 부품 번호'를 답할 수 없습니다.

## 어떻게 (이 앱에서)

- (있음) 이미지 · 영상 프레임을 RAG 컬렉션 문서로 올려 이미지 1장 = 청크 1개로 색인 · 검색, 근거 중 그림 청크를 비전 LLM(Gemma 4 + mmproj)에 첨부해 번호로 인용
- (예정) PDF 페이지 · 그림 영역을 이미지 청크로 함께 저장(텍스트 청크와 같은 문서에 묶어)
- (예정) 멀티모달 리랭킹: 질문과 이미지 후보를 함께 보는 리랭커 · 비전 LLM 목록형 재정렬

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/mm_rag` 에서 볼 수 있습니다.

## 앞으로 할 일

- PDF 표 · 그림을 이미지 청크로
- 멀티모달 리랭킹 실측
