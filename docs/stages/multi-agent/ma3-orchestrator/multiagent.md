# 멀티에이전트 · 멀티모달 — 오케스트레이터 · 전문가 에이전트 · 멀티모달 입출력 · 실측 (MA1~MA8)

화면은 `/multiagent/console`(에이전트 협업) · `/multiagent/image-search`(사진으로 찾기), 코드는 `app/stages/multiagent/` 입니다.

```
요청 ─ 오케스트레이터(규칙 계획) ─ 검색 전문가(Self-RAG: 검색 → 충분성 → 질의 고쳐 다시, 그림은 비전 LLM 으로 다시 줄 세움)
                               ├─ 분석 · 코딩(근거 수치 → 코드 → 샌드박스 실행 → 결과 · 차트)   ← 계산 · 비교 · 표를 물을 때만
                               ├─ 작성(쉬움 → 소형 모델, 어려움 → 기본 모델)
                               ├─ 품질 검증(통과 · 수정 요청 · 반려) ↺ 작성(상한 2번)
                               └─ 출력(글 + 차트 + 근거 그림 + 음성)
```

## 설계

- **계획은 규칙으로.** 에이전트가 다섯뿐이고 순서가 거의 정해져 있어(검색은 늘, 분석은 계산 · 비교 · 표를 물을 때, 작성 뒤엔 늘 검증), LLM 에게 계획을 맡기면 비용만 들고 '검증 빼기' 같은 실수가 생깁니다. 라우터(6)가 '어느 한 경로'를 고른다면 오케스트레이터는 '어떤 전문가를 어떤 순서로'를 정합니다. 에이전트끼리는 칠판(board)에 결과를 쌓아 주고받고, 모든 주고받음을 시간과 함께 남겨 화면이 흐름을 그대로 보입니다.
- **검색 전문가(Self-RAG).** 충분성은 규칙이 먼저입니다 — 질문 핵심 낱말이 근거에 나오는 비율이 0.85 이상이면 충분, 0.3 미만이면 부족, 그 사이에서만 LLM 판정(판정 자체가 LLM 한 번이라 매 질문에 부르면 검색보다 비쌈). 부족하면 '부족한 것'을 덧붙여 검색 향상(4)의 재작성으로 질의를 고쳐 다시 찾습니다(상한 3번).
- **멀티모달 리랭킹(MA2).** 그림 후보는 비전 LLM 에 질문과 함께 보여 0~3점을 받아 다시 줄 세웁니다 — 글 임베딩은 그림 속 표 · 도면의 정보를 놓치기 쉽습니다. 비전 모델이 아니거나 오류면 원래 순서 그대로입니다.
- **분석은 코드로, 계산은 샌드박스에서.** 작은 모델은 합계 · 비율 · 날짜 계산을 자주 틀리고, 틀린 숫자가 그럴듯한 문장에 섞이면 검증으로도 잡기 어렵습니다. LLM 은 근거 글(`SOURCES`)에서 수치를 뽑아 계산하는 코드만 쓰고, 계산은 상호운용 맵의 샌드박스(네트워크 없는 컨테이너)가 합니다. 숫자를 코드에 옮겨 적다 틀리지 않게 근거 글 자체를 입력으로 주고, 결과는 JSON 한 줄로 받습니다.
- **작성은 난이도별 모델.** 라우팅(6)의 규칙 라우터로 쉬움 · 어려움을 나눠, 쉬우면 소형 모델(`SMALL_LLM_MODEL`)에 맡깁니다. 분석 결과의 숫자는 그대로 쓰고 새로 계산하지 않게 합니다.
- **검증은 결정까지.** 문장별 근거 일치 · 질문 관련성(2 RAG), 출력 정책 · 개인정보(G4 · G2), 분석 결과의 숫자가 답에 있는지를 보고 통과 · 수정 요청(어느 문장이 왜 문제인지 지적과 함께) · 반려(규정 위반 — 고쳐 쓰게 두지 않음)를 정합니다. 재작성은 2번까지, 그래도 수정 요청이면 '검토 필요' 표시를 붙여 내보냅니다.
- **출력은 데이터로.** 차트는 데이터(labels · values)로 보내고 화면이 그립니다(Chart.js, 색은 `--series-*` 토큰, 표로 보기) — 서버가 그림을 만들면 다크 모드 · 접근성을 맞출 수 없습니다. 음성은 `TTS_URL`(OpenAI 호환 `/audio/speech`)이 있을 때만, 근거 번호는 읽지 않게 뺍니다.
- **사진으로 찾기(MA1).** 올린 사진을 컬렉션 인덱스의 멀티모달 모델로 임베딩해 같은 공간의 그림 · 글 청크를 찾고, 질문 글을 함께 주면 두 임베딩의 평균으로 찾습니다. 문서 권한(G3)은 그림 검색에도 같습니다.
- **기록.** 결과는 실행 기록(화면 · 실측)과 요청 기록(감사 · 규제 대응의 고지 · 근거 증적) 둘 다에 남깁니다.
