# 8a · 에이전틱 AI (LLM agents)

**상태: ✅ 구현됨** — LLM 이 도구를 여러 번 써서 어려운 질문을 푼다

## 원리

LLM 이 생각 → 도구 호출 → 관찰을 반복합니다(ReAct). 도구는 검색(다른 표현 · 하위 질문), 읽기(찾은 지문의 앞뒤), 계산이고, 모은 지문을 번호로 인용해 답합니다.

## 왜 하는가

여러 문서를 이어 봐야 하거나 청크 경계에서 잘린 표 · 조문, 계산이 필요한 어려운 질문은 한 번 검색하고 답하는 RAG 로 풀기 어렵습니다.

## 어떻게 (이 앱에서)

- JSON 한 객체로 행동 선택(작은 로컬 LLM 의 함수 호출 지원이 고르지 않아), 형식 오류 · 단계 상한이면 모은 근거로 답함
- 단계별 생각 · 행동 · 관찰 · 시간 기록(스트리밍), 답은 RAG 와 같은 문장별 근거 검증
- 연결 실행 · 라우팅의 어려운 경로에 '에이전트로 답하기'를 켜서 일반 RAG 와 같은 질문으로 비교

## 화면

- `/agent` — **에이전트 테스트**: 도구를 여러 번 쓰는 다단계 RAG
