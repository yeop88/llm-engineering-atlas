# 8a · 에이전틱 AI (LLM agents)

**상태: ⬜ 예정** — LLM 이 계획을 세우고 도구를 여러 번 써서 어려운 질문을 푼다

## 원리

LLM 이 질문을 나누고, 검색 · DB 조회 · 계산 같은 도구를 여러 번 호출하며 중간 결과를 보고 다음 행동을 정한 뒤 답을 종합합니다.

## 왜 하는가

여러 문서를 이어 봐야 하거나 조회 · 계산이 필요한 어려운 질문은 한 번 검색하고 답하는 RAG 로 풀기 어렵습니다.

## 어떻게 (이 앱에서)

- 질문 분해 → 여러 번 검색 → 근거 종합 (다단계 RAG)
- 도구 호출: 문서 필터 · 조문 조회 · 계산기
- 단계별 기록과 비용 · 시간 측정, 단일 RAG 와 정답률 비교

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/agent` 에서 볼 수 있습니다.
