# GM5 · 음성 · 음악 생성 (Voice & music)

**상태: 🔬 연구** — 대사 음성 · 배경 음악을 만들고 길이를 샷에 맞춘다

## 원리

음성 · 음악 생성은 대사를 합성하고 배경 음악을 붙여 샷 길이 · 입 모양에 맞추는 단계입니다. 음성 합성(VC4)의 읽기 규칙을 그대로 씁니다.

## 왜 하는가

음성 길이가 샷 길이와 어긋나면 편집 단계에서 음성이나 샷을 다시 만들어야 해 비용이 두 번 듭니다.

## 어떻게 (이 앱에서)

- (기반) 음성 합성 · 읽기 규칙(VC4)
- (연구) 샷 길이 맞춤 · 입 모양 정렬 기준

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gm_audio` 에서 볼 수 있습니다.
