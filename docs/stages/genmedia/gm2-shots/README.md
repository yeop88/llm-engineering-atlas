# GM2 · 장면 · 샷 분해 (Shot breakdown)

**상태: 🔬 연구** — 스크립트를 샷(구도 · 길이 · 카메라)으로 나눈다

## 원리

샷 분해는 장면을 샷마다 구도 · 길이 · 카메라 움직임 · 등장 요소로 나누는 것입니다. 생성 모델은 샷 단위로 지시해야 잘 따릅니다.

## 왜 하는가

긴 장면을 한 번에 생성하면 모델이 지시를 다 지키지 못하고 장면 안에서 캐릭터 · 배경 일관성이 깨집니다.

## 어떻게 (이 앱에서)

- (기반) 기획(GM1)
- (연구) 샷 목록 · 구도 · 카메라 지시 형식

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gm_shots` 에서 볼 수 있습니다.
