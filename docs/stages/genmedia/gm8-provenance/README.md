# GM8 · 출처 · 워터마크 기록 (Provenance & watermark)

**상태: ✅ 구현됨** — 생성 출처 메타 · AI 생성 표시 · 권리 확인을 남긴다

## 원리

출처 · 워터마크는 생성물에 '무엇으로 · 언제 · 어떤 지시로 만들었나' 메타데이터와 AI 생성 표시를 붙이고, 저작권 · 초상권 확인 결과를 남기는 단계입니다.

## 왜 하는가

AI 생성물 표시는 규제 의무가 되었고(고지 RC6), 출처가 없으면 권리 분쟁에 대응할 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 원본 계보(PV1) · 고지(RC6)
- 매니페스트(생성기 · 시각 · 지시문 해시 · 입력 · 권리 확인, 해시로 바뀜 확인)를 PNG 글 칸에, 보이는 'AI 생성' 표시, 열쇠로 만든 ±1 무늬를 밝기에 ±3 더한 워터마크(접어 더한 뒤 FFT 원형 상관으로 어긋남까지) — 다시 저장 · JPEG · 줄이기 · 자르기 뒤 남는지 · 거짓 검출

## 화면

- `/genmedia/check#provenance` — **출처 · 워터마크 기록**: 매니페스트 · AI 생성 표시 · 워터마크 · 남는지

## 앞으로 할 일

- C2PA 서명 매니페스트
- 크기 바뀜에 버티는 워터마크
