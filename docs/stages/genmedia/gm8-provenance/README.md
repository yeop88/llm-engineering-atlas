# GM8 · 출처 · 워터마크 기록 (Provenance & watermark)

**상태: ⬜ 예정** — 생성 출처 메타 · AI 생성 표시 · 권리 확인을 남긴다

## 원리

출처 · 워터마크는 생성물에 '무엇으로 · 언제 · 어떤 지시로 만들었나' 메타데이터와 AI 생성 표시를 붙이고, 저작권 · 초상권 확인 결과를 남기는 단계입니다.

## 왜 하는가

AI 생성물 표시는 규제 의무가 되었고(고지 RC6), 출처가 없으면 권리 분쟁에 대응할 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 원본 계보(PV1) · 고지(RC6)
- (예정) 생성 메타 · AI 생성 표시 · 권리 확인 기록
