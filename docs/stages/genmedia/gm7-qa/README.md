# GM7 · 품질 검사 (Quality checks)

**상태: ✅ 구현됨** — 프롬프트 준수 · 캐릭터 · 시간 일관성 · 입 모양 · 결함을 잰다

## 원리

품질 검사는 샷마다 지시를 지켰는지(VLM 판정), 캐릭터 · 스타일이 기준과 같은지(임베딩 거리), 프레임 사이가 튀지 않는지, 입 모양 · 결함(손가락 · 글자 깨짐)을 재는 단계입니다.

## 왜 하는가

생성물은 그럴듯해 보여도 결함이 많습니다. 사람 검토 전에 자동 검사로 걸러야 검토 비용이 줄어듭니다.

## 어떻게 (이 앱에서)

- (기반) 시각 질의응답(VL6) · 회귀 평가(E2)
- 지시 준수(지시의 물체가 있나 — 시험 샷은 색 탐지), 스타일 일관성(기준 샷과 색 분포 차 0.25 이하), 시간 일관성(이웃 프레임 차가 중앙값 4배 · 물체가 한 프레임에 폭 25% 넘게 뜀) — 결함을 넣은 시험 샷으로 잡기 · 거짓 경보

## 화면

- `/genmedia/check` — **생성물 검사 · 출처**: 자동 품질 검사 · 출처 · 워터마크

## 앞으로 할 일

- 비전 LLM 점검표로 실제 생성물의 지시 준수
- 입 모양 · 손가락 · 글자 깨짐 결함
