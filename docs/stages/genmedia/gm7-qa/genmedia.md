# 생성 미디어 — 생성물 자동 품질 검사(지시 · 스타일 · 시간) · 출처 매니페스트 · AI 생성 표시 · 보이지 않는 워터마크와 남는지 실측 (GM7 · GM8)

화면은 `/genmedia/check`(생성물 검사 · 출처), 코드는 `app/stages/genmedia/` 입니다. 이 PC 로는 이미지 · 영상 생성 모델을 돌리지 않습니다. 그래서 생성(GM1~GM6)은 바깥 서비스 · 공개 모델의 자리로 두고(연구), 생성물이 나온 뒤의 검사와 출처만 구현했습니다.

```
생성물(샷 = 연속 프레임) → 지시 준수: 지시의 물체가 있나 (시험 샷: 색 탐지)
                       → 스타일: 기준 샷과 색 분포 차(채널별 16칸) ≤ 0.25
                       → 시간: 이웃 프레임 차 > 중앙값 × 4 → 깜빡임, 물체가 한 프레임에 폭 25% 넘게 → 순간 이동  (GM7)
생성물 → 매니페스트(생성기 · 시각 · 지시문 해시 · 입력 · 권리 확인 + 해시)를 PNG 글 칸에
       → 보이는 'AI 생성' 표시 → 열쇠 무늬(64×64 ±1)를 밝기에 ±3                                     (GM8)
확인: 메타데이터 · 해시 / 고역 통과 → 64×64 로 접어 더함 → FFT 원형 상관(모든 어긋남) → z 점수
```

## 설계

- **사람 검토 전에 기계가 거릅니다(GM7).** 생성물은 그럴듯해 보여도 결함이 많습니다. 결함을 자동으로 먼저 걸러야 사람 검토 비용이 줄어듭니다. 검사는 셋입니다.
  - 지시 준수: 지시에 나온 물체가 샷에 있는가.
  - 스타일 일관성: 같은 장면 묶음의 기준 샷과 색감이 같은가.
  - 시간 일관성: 프레임 사이가 튀지 않는가(깜빡임 · 물체 순간 이동).
  - 시험 샷의 물체 찾기는 비디오 맵의 색 탐지를 씁니다. 실제 생성물에서는 비전 LLM 점검표(이미지 맵 VL6)로 바꿀 자리입니다.
- **샷 하나는 컷 없는 연속 장면입니다.** 처음에는 시험 샷을 고를 때 장면 전환을 보지 않았습니다. 그러자 결함 없는 샷의 20% 에 컷이 섞여, 시간 검사가 깜빡임으로 잘못 걸렀습니다. 지금은 컷을 피해 고릅니다. 실제 생성물에서도 검사 전에 샷 경계(VD2)를 먼저 나눠야 합니다.
- **출처는 세 겹입니다(GM8).** 겹마다 버티는 일이 달라서입니다.
  - 메타데이터(PNG 글 칸의 매니페스트)는 가장 많이 담지만, 다른 형식으로 다시 저장하면 사라집니다. 메신저 · 게시판은 보통 JPEG 로 다시 압축합니다.
  - 보이는 표시는 사람에게 바로 보이지만, 잘라 내면 사라집니다.
  - 보이지 않는 워터마크는 열쇠로 만든 ±1 무늬를 밝기에 ±3 더한 것입니다. 사람 눈에 띄지 않으면서 재압축 · 자르기를 버티게 하려는 것입니다.
- **지시문은 해시만 남깁니다.** 지시문에는 개인정보 · 영업 비밀이 들어갈 수 있습니다. 매니페스트에는 지시문의 SHA-256 만 넣고, 매니페스트 전체의 해시로 '바뀌었나'를 확인합니다. 해시는 서명이 아니라 위조를 막지 못합니다. 실서비스에서는 C2PA 서명 매니페스트로 바꿀 자리입니다.
- **워터마크 검출은 그림 내용을 빼고 무늬만 봅니다.**
  - 3×3 평균을 뺀 고역 성분만 남기고, 그림을 64×64 한 칸으로 접어 더해 무늬와 상관을 봅니다. 타일이라 잘린 그림의 남은 부분에서도 찾습니다.
  - 처음에는 잘린 그림의 어긋남(타일 시작점)을 8칸 간격으로 거칠게 찾았습니다. 상관 봉우리가 한 화소 폭이라 놓쳤고, 70% 로 자른 그림 18장 중 6장만 찾았습니다.
  - 지금은 접은 칸과 무늬의 원형 상관을 FFT 로 모든 어긋남(4,096개)에 대해 한 번에 구합니다. 모든 어긋남 중 최대는 무늬가 없어도 4 근처까지 오르므로, 그 값의 문턱은 6 으로 따로 둡니다(어긋남 0 의 문턱은 4).
- 워터마크는 '확산 스펙트럼'(널리 알려진 방법)의 설계를 참고해 새로 작성했습니다.

## 실측

2026-10-23.

**자동 품질 검사 (GM7)** — 비디오 맵 합성기의 8프레임 샷(씨앗 400~419), 결함 종류마다 20묶음 + 결함 없는 20묶음(85초)

| 넣은 결함 | 맞는 검사가 잡음 | 전체 판정이 걸러냄 |
| --- | --- | --- |
| 물체 빠짐 | 100% | 100% |
| 다른 색감(밝기 ×0.6~1.5 · 채도 ×0.2~2.2) | 100% | 100% |
| 깜빡임(한 프레임 밝기 ×0.4~1.8) | 100% | 100% |
| 순간 이동(한 프레임이 반 폭 밀림) | 100% | 100% |

결함 없는 샷의 통과는 100%(거짓 경보 지시 · 스타일 · 시간 모두 0%)입니다. 컷을 피해 고르기 전에는 시간 검사의 거짓 경보가 20% 였습니다.

**출처 · 워터마크가 남는지 (GM8)** — 시험 그림 18장(640×480, 이미지 맵 가전 앞판 12 + 비디오 프레임 6)

| 겪은 일 | 메타데이터 남음 | 워터마크 찾음 |
| --- | --- | --- |
| 그대로 | 100% | 100% |
| PNG 다시 저장 | 0% | 100% |
| JPEG 90 | 0% | 100% |
| JPEG 70 | 0% | 100% |
| JPEG 50 | 0% | 94.4% (17/18) |
| 반으로 줄이기 | 0% | **0%** |
| 70% 자르기 | 0% | 100% |

무늬 없는 그림 · 다른 열쇠로 찾은 거짓 검출은 0/36 이었습니다(모든 어긋남 중 최대 z 4.36, 문턱 6).

해석:

- **메타데이터만으로는 출처가 남지 않습니다.** 다른 도구로 다시 저장하기만 해도 사라집니다. 'AI 생성' 고지 의무(RC6)를 지키려면 보이는 표시나 워터마크가 함께 있어야 합니다.
- **이 워터마크는 재압축 · 자르기는 버티지만 크기 바뀜은 못 버팁니다.** 반으로 줄이면 무늬의 화소 간격이 바뀌어 상관이 사라집니다(0%). 크기를 바꿔 올리는 곳(썸네일 · 메신저 미리 보기)에서는 이 워터마크로 출처를 확인할 수 없습니다. 크기 변화에 버티는 방식(주파수 영역 · 학습형 워터마크)이 필요하고, 할 일로 남깁니다.
- **품질 검사의 100% 는 결함이 큰 탓입니다.** 시험 결함은 사람이 봐도 분명한 크기입니다(물체 통째로 빠짐, 밝기 1.8배). 실제 생성물의 결함(조금 다른 얼굴, 손가락 하나 더)은 이 검사로 잡히지 않습니다. 이 실측이 보이는 것은 '검사가 거짓 경보 없이 분명한 결함을 거른다'까지입니다.

한계: 시험 그림은 그린 그림이라 사진보다 고역 성분(잡음)이 적습니다. 사진에서는 워터마크 z 가 낮아질 수 있습니다.
