# GM4 · 이미지 · 비디오 생성 (Image & video generation)

**상태: 🔬 연구** — 외부 서비스 · 공개 모델로 샷을 생성하는 연결 자리

## 원리

생성은 샷 지시 · 기준 이미지로 이미지 · 영상을 만드는 단계입니다. 이 PC 로는 돌릴 수 없어 외부 서비스 · 공개 모델을 연결하는 자리로 두고, 요청 · 결과 · 비용을 기록합니다.

## 왜 하는가

생성 모델은 빠르게 바뀝니다. 연결 자리와 기록을 두어야 모델을 바꿔도 앞뒤 단계는 그대로 씁니다.

## 어떻게 (이 앱에서)

- (기반) 캐릭터 · 스타일(GM3)
- (연구) 생성 연결 인터페이스 · 요청 · 비용 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gm_generate` 에서 볼 수 있습니다.
