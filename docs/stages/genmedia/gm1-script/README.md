# GM1 · 기획 · 스크립트 (Planning & script)

**상태: 🔬 연구** — 목적 · 대상 · 길이 · 메시지로 스크립트를 쓴다

## 원리

기획 · 스크립트는 영상의 목적 · 대상 · 길이 · 핵심 메시지를 정하고 장면별 대사 · 자막을 쓰는 단계입니다. 사실 내용은 근거(매뉴얼)에서 가져옵니다.

## 왜 하는가

사실이 틀린 안내 영상은 글보다 퍼지기 쉽습니다. 스크립트 단계에서 근거 검증을 해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 작성 에이전트(MA6)
- (연구) 근거 기반 스크립트 · 사실 검증

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gm_script` 에서 볼 수 있습니다.
