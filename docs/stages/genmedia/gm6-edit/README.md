# GM6 · 편집 · 합성 (Editing & compositing)

**상태: 🔬 연구** — 샷 · 소리 · 자막을 이어 붙이고 전환을 넣는다

## 원리

편집 · 합성은 샷 · 음성 · 음악 · 자막을 시간축에 이어 붙이고 전환 · 글자를 넣는 단계입니다. 편집 결정(무엇을 왜 잘랐나)도 기록합니다.

## 왜 하는가

편집 결정(무엇을 왜 자르고 붙였나)이 기록되지 않으면 수정 요청이 올 때 처음부터 다시 해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 음성 · 음악(GM5)
- (연구) 편집 목록(EDL) · 자막 · 전환 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gm_edit` 에서 볼 수 있습니다.
