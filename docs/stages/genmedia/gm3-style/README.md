# GM3 · 캐릭터 · 스타일 정의 (Character & style)

**상태: 🔬 연구** — 캐릭터 · 색 · 글꼴 · 화풍을 고정할 기준을 정한다

## 원리

캐릭터 · 스타일 정의는 등장 캐릭터의 기준 이미지 · 색 · 글꼴 · 화풍을 정해 모든 샷이 같은 기준을 쓰게 하는 것입니다.

## 왜 하는가

샷마다 캐릭터 얼굴이 바뀌면 쓸 수 없습니다. 기준이 있어야 일관성을 잴 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 샷 분해(GM2)
- (연구) 기준 이미지 · 스타일 카드 · 일관성 기준

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gm_style` 에서 볼 수 있습니다.
