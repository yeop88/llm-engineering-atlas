# SD2 · 생성 전략 선택 (Generation strategy)

**상태: ✅ 구현됨** — 템플릿 · LLM 바꿔 쓰기 · 그래프 · 역번역 중 유형에 맞는 방법을 고른다

## 원리

생성 전략은 유형마다 맞는 방법(템플릿 + 지식 그래프 · 문서에서 LLM 질문 생성 · 바꿔 쓰기 · 정답이 계산되는 과제)을 고르는 것입니다. 정답을 확인할 수 있는 방법이 먼저입니다.

## 왜 하는가

정답 없이 LLM 이 질문 · 답을 다 만들면 틀린 답이 그대로 학습됩니다.

## 어떻게 (이 앱에서)

- (기반) 합성 거절 예시(P1) · 검증 가능한 과제(RV1)
- 형식이 유형을 정하는 것(조건 · 상황 · 여러 질문)은 틀, 말투가 정하는 것(바꿔 말하기)은 법률 용어 → 일상 말 바꿔 쓰기, 여러 질문은 둘을 이어 붙이기, 선택으로 LLM 바꿔 쓰기
