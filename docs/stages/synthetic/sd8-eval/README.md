# SD8 · 실제 데이터 평가 (Real-data evaluation)

**상태: ✅ 구현됨** — 합성이 아닌 실제 질문으로 나아졌는지 잰다

## 원리

실제 데이터 평가는 합성으로 만든 평가가 아니라 운영 · 사람이 만든 실제 질문으로 학습 전후를 짝지어 비교하는 것입니다.

## 왜 하는가

합성 데이터로 학습하고 합성 평가로 재면 같은 편향을 두 번 셉니다. 실제 질문에서 나아져야 의미가 있습니다.

## 어떻게 (이 앱에서)

- (기반) 학습 전후 평가(P6) · 오프라인 평가(E1)
- 시험용 실제 질문으로 정확 · 유형별 재현(씨앗 평균 · 범위), 같은 분류기를 합성 시험 질문으로도 재 합성 평가가 얼마나 부풀려지는지
