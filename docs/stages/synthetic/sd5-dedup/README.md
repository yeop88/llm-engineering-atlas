# SD5 · 중복 · 오염 제거 (Dedup & contamination)

**상태: ⬜ 예정** — 중복 · 평가 질문 누수 · 개인정보를 제거한다

## 원리

중복 · 오염 제거는 근사 중복, 평가 세트와 겹치는 예시(누수), 개인정보 · 저작권 문제를 빼는 것입니다. 단계별 남은 건수를 기록합니다.

## 왜 하는가

평가 질문이 합성 데이터에 섞이면 효과가 부풀려집니다. 누수 0 이 출발 조건입니다.

## 어떻게 (이 앱에서)

- (기반) 선별 · 누수(P2) · 자산화(FW4)
- (예정) 누수 0 확인 · 단계별 건수
