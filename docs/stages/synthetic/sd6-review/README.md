# SD6 · 인간 검토 (Human review)

**상태: ⬜ 예정** — 표본을 사람이 검토해 오류율을 재고 묶음을 통과 · 반려한다

## 원리

인간 검토는 생성 묶음에서 표본을 뽑아 사람이 정답 · 형식 · 안전을 검토하고, 오류율이 문턱을 넘는 묶음은 반려하는 것입니다.

## 왜 하는가

전수 검토는 못 해도 표본 오류율은 알아야 합니다. 오류율을 모르는 합성 데이터는 학습에 넣을 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 검토 우선순위(FW3)
- (예정) 표본 크기 · 오류율 · 통과 기준

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/sd_review` 에서 볼 수 있습니다.
