# SD1 · 데이터 부족 분석 (Gap analysis)

**상태: ✅ 구현됨** — 실패 유형 · 유형별 데이터 수에서 무엇이 부족한지 찾는다

## 원리

부족 분석은 실패 분류(FW2) · 유형별 정답률 · 유형별 학습 데이터 수를 겹쳐 '실패가 많고 데이터가 적은' 유형을 찾는 것입니다.

## 왜 하는가

부족한 곳을 모르고 만든 합성 데이터는 만들기 쉬운 유형, 즉 이미 잘하는 유형만 늘립니다.

## 어떻게 (이 앱에서)

- (기반) 실패 분류(FW1) · 드리프트(E5)
- 유형이 붙은 실제 질문을 학습용(적고 치우치게) · 시험용으로 나누고, 유형별 학습 수와 교차 검증 재현율로 부족 유형 · 이유 · 만들 수

## 화면

- `/synthetic/data` — **합성 데이터**: 부족 분석 · 생성 · 거르기 · 검토 · 효과 평가

## 앞으로 할 일

- 운영 실패 분류(FW1)의 유형별 실패율로 부족 분석
