# SD1 · 데이터 부족 분석 (Gap analysis)

**상태: ⬜ 예정** — 실패 유형 · 유형별 데이터 수에서 무엇이 부족한지 찾는다

## 원리

부족 분석은 실패 분류(FW2) · 유형별 정답률 · 유형별 학습 데이터 수를 겹쳐 '실패가 많고 데이터가 적은' 유형을 찾는 것입니다.

## 왜 하는가

부족한 곳을 모르고 만든 합성 데이터는 만들기 쉬운 유형, 즉 이미 잘하는 유형만 늘립니다.

## 어떻게 (이 앱에서)

- (기반) 실패 분류(FW2) · 드리프트(E6)
- (예정) 유형 × 실패율 × 데이터 수 표 · 우선순위
