# SD3 · 합성 데이터 생성 (Generation)

**상태: ⬜ 예정** — 고른 전략으로 만들고 만든 방법 · 원본을 남긴다

## 원리

생성은 고른 전략으로 예시를 만들고, 예시마다 만든 방법 · 원본 근거 · 생성 모델 · 시각을 남기는 것입니다.

## 왜 하는가

어떻게 만들었는지 모르면 나중에 문제(틀린 답 · 누수)가 있는 묶음만 골라 뺄 수 없고 전부 버려야 합니다.

## 어떻게 (이 앱에서)

- (기반) 합성 데이터(P1)
- (예정) 생성 메타 · 원본 근거 · 생성 모델
