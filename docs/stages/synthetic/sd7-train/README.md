# SD7 · 학습 (Training)

**상태: ✅ 구현됨** — 합성 · 실제 데이터 비율을 바꿔 학습한다

## 원리

학습은 합성 데이터를 실제 데이터와 정한 비율로 섞어 SFT 등에 넣는 것입니다. 비율별로 학습해 합성이 많아질 때 생기는 손해를 봅니다.

## 왜 하는가

합성 비율이 너무 높으면 합성 데이터의 말투 · 분포에 맞춰져 실제 질문에서는 오히려 나빠질 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) LoRA SFT(P3) · 재학습(FW)
- 질문 유형 분류기(글자 n-gram TF-IDF + 로지스틱 회귀, 유형 불균형 가중)를 조건마다 학습 — 가벼워서 씨앗 여러 개로 되풀이

## 화면

- `/synthetic/data#experiment` — **학습**: 실제만 · 실제 + 합성 · 합성만 · LLM 합성
