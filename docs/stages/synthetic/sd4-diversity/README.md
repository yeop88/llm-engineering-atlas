# SD4 · 다양성 검사 (Diversity check)

**상태: ⬜ 예정** — 임베딩 군집 · 표현 반복으로 다양성을 재고 비슷한 것을 줄인다

## 원리

다양성 검사는 생성 예시를 임베딩으로 군집해 한 군집에 몰렸는지, 같은 표현이 반복되는지 재고, 몰린 것을 줄이는 것입니다.

## 왜 하는가

LLM 이 만든 데이터는 비슷한 말투 · 구조로 몰립니다. 그대로 학습하면 그 말투만 배웁니다.

## 어떻게 (이 앱에서)

- (기반) 의미 응용(군집 · 중복, A)
- (예정) 군집 쏠림 · 반복 지표 · 줄인 뒤 건수

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/sd_diversity` 에서 볼 수 있습니다.
