# SD4 · 다양성 검사 (Diversity check)

**상태: ✅ 구현됨** — 임베딩 군집 · 표현 반복으로 다양성을 재고 비슷한 것을 줄인다

## 원리

다양성 검사는 생성 예시를 임베딩으로 군집해 한 군집에 몰렸는지, 같은 표현이 반복되는지 재고, 몰린 것을 줄이는 것입니다.

## 왜 하는가

LLM 이 만든 데이터는 비슷한 말투 · 구조로 몰립니다. 그대로 학습하면 그 말투만 배웁니다.

## 어떻게 (이 앱에서)

- (기반) 응용 임베딩 · 군집(APPS)
- 글자 n-gram TF-IDF 로 평균 쌍 유사도 · 서로 다른 2-gram 몫 · 첫 3어절 반복을 재고, 유형마다 가장 덜 비슷한 것부터 고름

## 화면

- `/synthetic/data#batch` — **다양성 검사**: 평균 쌍 유사도 · 2-gram · 첫 어절 반복 · 먼 점 고르기
