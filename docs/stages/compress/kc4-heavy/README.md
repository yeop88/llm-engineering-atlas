# KC4 · 중요 토큰 KV 남기기 (Heavy-hitter KV retention)

**상태: ✅ 구현됨** — 주의를 많이 받은 토큰의 KV 만 남겨 캐시를 줄인다

## 원리

중요 토큰 KV 남기기는 지금까지 주의를 많이 받은 토큰(또는 질문 끝 관찰 창이 주목하는 토큰)의 KV 만 남기고 나머지를 버리는 캐시 줄이기입니다.

## 왜 하는가

최근 창만 두면 앞쪽의 중요한 근거를 잃습니다. 주의 기록으로 무엇이 중요한지 고르면 같은 크기로 더 많이 기억합니다.

## 어떻게 (이 앱에서)

- (기반) 주의 싱크(KC3)
- 누적 주의(모든 질의가 준 주의 합) 또는 질문 쪽 관찰 창(프롬프트 끝 16토큰)이 주목하는 토큰을 첫 토큰 · 최근 일부와 함께 남김
- 충실도: 가득 찬 캐시의 탐욕 답을 기준으로 다음 토큰 1위 일치율 · 평균 KL · 처음 갈라지는 위치
