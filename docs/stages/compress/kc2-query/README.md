# KC2 · 질문을 아는 압축 (Question-aware compression)

**상태: ⬜ 예정** — 질문에 비춰 관계없는 문장은 통째로, 남은 문장은 토큰 단위로 줄인다

## 원리

질문을 아는 압축은 질문을 조건으로 했을 때 확률이 크게 바뀌는 문장 · 토큰(질문과 관계 깊은 것)을 남기는 방법입니다. 문장 단위로 먼저 거르고 토큰 단위로 다듬습니다.

## 왜 하는가

질문을 모르는 압축은 질문에 필요한 드문 정보를 '놀랍다'며 남기는 대신, 흔하지만 필요한 정보를 지울 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 토큰 압축(KC1) · 맥락 배치(CX1)
- (예정) 질문 조건 대비 확률 차 · 문장 → 토큰 2단계 · 질문 없는 압축과 비교

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/kc_query` 에서 볼 수 있습니다.
