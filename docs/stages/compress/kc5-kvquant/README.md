# KC5 · KV 양자화 (KV cache quantization)

**상태: ✅ 구현됨** — KV 캐시를 8 · 4비트로 저장해 같은 메모리에 더 긴 맥락을 둔다

## 원리

KV 양자화는 읽은 토큰의 키 · 값을 낮은 비트로 저장하는 것입니다. 가중치 양자화와 따로 정할 수 있고, 키와 값의 민감도가 다릅니다.

## 왜 하는가

긴 맥락에서는 KV 캐시가 가중치보다 커집니다. 몇 비트까지 품질이 버티는지 재야 합니다.

## 어떻게 (이 앱에서)

- (기반) 서빙 KV 캐시 설정 실측(S5) · 양자화(7b)
- 키 · 값을 따로 8 · 4 · 2비트 대칭 양자화(토큰마다 최댓값 눈금) 후 같은 충실도 — 어느 쪽이 더 민감한지
- 실제 서버의 KV 형식(q8_0 · q4_0)은 서빙 맵 디코딩 비교로
