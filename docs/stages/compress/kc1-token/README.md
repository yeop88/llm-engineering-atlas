# KC1 · 토큰 단위 프롬프트 압축 (Token-level prompt compression)

**상태: ✅ 구현됨** — 작은 모델이 쉽게 맞히는(정보가 적은) 토큰을 지워 근거를 줄인다

## 원리

토큰 단위 압축은 작은 언어 모델로 근거의 토큰마다 놀람 정도(음의 로그확률)를 재고, 낮은 것(예측하기 쉬운 것)부터 지워 목표 비율까지 줄이는 방법입니다.

## 왜 하는가

근거를 문장째 빼면 필요한 숫자 · 조항까지 빠집니다. 토큰 단위로 빼면 같은 길이에 더 많은 정보를 남길 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 근거 길이 관리(S2)
- 작은 공개 LM 으로 근거 토큰마다 놀람(-log p)을 재고, 낮은 토큰(쉽게 맞히는 조사 · 반복)부터 지워 목표 비율까지 — 남은 토큰은 원래 순서로
- 숫자 · 조문 번호 · 모델 · 오류 코드 토큰은 놀람과 상관없이 남김, 압축 뒤 숫자 · 조항 보존률
