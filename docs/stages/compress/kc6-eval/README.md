# KC6 · 압축 평가 (Compression evaluation)

**상태: ✅ 구현됨** — 압축률마다 같은 질문의 정답률 · 지연 · 남은 숫자 · 조항을 잰다

## 원리

압축 평가는 같은 평가 세트를 압축률별로 돌려 정답률 · 입력 토큰 · 지연과 함께, 정답 근거의 숫자 · 조문 번호가 압축 뒤에도 남았는지를 재는 것입니다.

## 왜 하는가

평균 정답률만 보면 숫자 하나가 사라져 틀린 답이 늘어난 것을 놓칩니다. 압축 방법마다 잃는 것이 다릅니다.

## 어떻게 (이 앱에서)

- (기반) 회귀 평가(E2)
- 같은 질문 · 같은 검색 근거를 방법(없음 · 토큰 · 질문을 아는 · 글자 겹침 · 무작위) × 압축률로 줄여 평소의 LLM 이 답 — 작은 모델로 줄이고 큰 모델이 읽는 구성
- 정답률 · 실제 남은 글자 · 정답 근거의 숫자 · 조항 보존률 · 압축 시간 · 답 시간
