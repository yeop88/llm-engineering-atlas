# KC3 · 주의 싱크 + 최근 창 (Attention sinks + sliding window)

**상태: ✅ 구현됨** — 첫 몇 토큰과 최근 창만 KV 에 남겨 끝없이 긴 대화를 고정 메모리로 돈다

## 원리

주의 싱크는 모델이 처음 몇 토큰에 주의를 몰아 두는 현상입니다. 그 토큰들과 최근 창만 KV 캐시에 남기면 메모리를 고정한 채 긴 흐름을 처리할 수 있습니다.

## 왜 하는가

창만 남기고 첫 토큰을 지우면 모델이 갑자기 무너집니다. 무엇을 남겨야 하는지 재 봐야 합니다.

## 어떻게 (이 앱에서)

- (기반) 어텐션 기여(IP2)
- 근거 + 질문을 읽은 KV 캐시에서 위치를 골라 남기고(키에 원래 위치의 RoPE 가 있어 이어지는 토큰도 원래 위치 번호로) 이어 읽기
- 최근 창만(첫 토큰도 버림 — 대조군) vs 첫 토큰(주의 싱크) + 최근 창, 남길 비율별
