# KC3 · 주의 싱크 + 최근 창 (Attention sinks + sliding window)

**상태: ⬜ 예정** — 첫 몇 토큰과 최근 창만 KV 에 남겨 끝없이 긴 대화를 고정 메모리로 돈다

## 원리

주의 싱크는 모델이 처음 몇 토큰에 주의를 몰아 두는 현상입니다. 그 토큰들과 최근 창만 KV 캐시에 남기면 메모리를 고정한 채 긴 흐름을 처리할 수 있습니다.

## 왜 하는가

창만 남기고 첫 토큰을 지우면 모델이 갑자기 무너집니다. 무엇을 남겨야 하는지 재 봐야 합니다.

## 어떻게 (이 앱에서)

- (기반) 어텐션 기여(IP2)
- (예정) 싱크 수 · 창 크기별 다음 토큰 정확도 · 첫 토큰 지움과 비교
