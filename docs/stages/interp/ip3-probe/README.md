# IP3 · 탐침 (Probing)

**상태: ✅ 구현됨** — 은닉 상태로 '근거에 답이 있나' · 주제 · 언어를 선형 분류한다

## 원리

탐침은 모델의 중간 은닉 상태에 작은 선형 분류기를 붙여, 모델이 안에서 무엇을 알고 있는지(답이 근거에 있는지 등)를 읽는 것입니다.

## 왜 하는가

모델이 '모른다'를 안에서 알면서도 답을 지어낸다면, 출력 전에 그 신호로 막을 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 의미 응용 분류기(A)
- 같은 질문을 정답 근거 있음 / 뺌 두 벌로, 층마다 프롬프트 마지막 토큰 은닉 상태를 선형 분류(교차 검증) — 모델이 어느 층에서 '답이 근거에 없다'를 아는가
- 은닉 상태를 파일로 남겨 조종 방향 · 탐침 점수가 같은 자료를 씀
