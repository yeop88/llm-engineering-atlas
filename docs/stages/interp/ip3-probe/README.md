# IP3 · 탐침 (Probing)

**상태: ⬜ 예정** — 은닉 상태로 '근거에 답이 있나' · 주제 · 언어를 선형 분류한다

## 원리

탐침은 모델의 중간 은닉 상태에 작은 선형 분류기를 붙여, 모델이 안에서 무엇을 알고 있는지(답이 근거에 있는지 등)를 읽는 것입니다.

## 왜 하는가

모델이 '모른다'를 안에서 알면서도 답을 지어낸다면, 출력 전에 그 신호로 막을 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 의미 응용 분류기(A)
- (예정) 층별 은닉 상태 추출 · 선형 탐침 · 층별 정확도

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ip_probe` 에서 볼 수 있습니다.
