# IP2 · 근거 기여 (Attribution)

**상태: ✅ 구현됨** — 어텐션 · 그래디언트 · 근거 지우기로 어느 문장이 답에 기여했는지 잰다

## 원리

근거 기여는 답의 각 부분이 맥락의 어느 문장에서 왔는지를 모델 안에서 재는 것입니다. 근거를 하나씩 지워 답이 바뀌는지가 가장 확실한 확인입니다.

## 왜 하는가

답이 인용한 근거와 실제로 기댄 근거가 다를 수 있습니다. 설명 가능성은 인용이 아니라 기여로 확인해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 설명 가능성(RC4)
- 작은 공개 LLM 이 쓴 답에 대해 근거를 하나씩 지웠을 때 같은 답의 로그확률 하락(지우기 기여) · 답 토큰이 근거마다 준 어텐션(마지막 4층)
- 기여 1위가 정답 근거 · 답이 인용한 번호와 같은지, 어텐션과 지우기 기여가 같은 근거를 가리키는지
