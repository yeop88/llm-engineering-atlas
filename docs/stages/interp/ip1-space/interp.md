# 해석 가능성 — 임베딩 공간 · 근거 기여 · 탐침 · 희소 특징 · 조종 · 내부 신호 환각 탐지 · 실측 (IP1~IP6)

화면은 `/interp/space`(임베딩 공간 · 희소 특징) · `/interp/attribution`(근거 기여) · `/interp/inside`(탐침 · 조종 · 내부 환각 탐지), 코드는 `app/stages/interp/` 입니다. 안을 보는 모델은 후학습 기본 모델(`POSTTRAIN_BASE_MODEL`, 기본 Qwen3-0.6B — 처음 쓸 때 내려받음)입니다.

```
임베딩 모델들 ─ 같은 청크 → 이방성 · 유효 차원 · 주성분 · 문서 군집 · 한-영 정렬 (IP1)
작은 공개 LLM(후학습과 같은 채팅 틀 · 생각 끔)
   ├ 한 층 토큰 은닉 상태 → 희소 오토인코더 → 특징 · 켜지는 글 조각 (IP4)
   ├ 답 + 근거 하나씩 지우기 → 로그확률 하락 · 어텐션 vs 인용 · 정답 근거 (IP2)
   └ 질문 × (정답 근거 있음 · 뺌)
        ├ 층별 은닉 상태 → 선형 탐침 '답이 근거에 있나' (IP3)
        ├ 거절 안 한 답 중 근거 없이 답한 것 → 내부 신호 vs 글자 근거율 AUROC (IP6)
        └ '뺌 − 있음' 방향을 생성 중 더하기 → 세기별 거절률 · 부작용 (IP5)
```

## 설계

- **작은 공개 모델로 안을, 큰 모델은 밖에서.** 서버 너머의 큰 모델은 은닉 상태를 볼 수 없습니다. 후학습 기본 모델을 직접 올려 재고, 큰 모델은 밖의 검증(근거 일치)으로 비교합니다. 프롬프트는 RAG 답변 · 후학습과 같은 틀(시스템 지시 + 번호 붙인 근거 + 질문, 생각 끔)이라, 같은 모델을 같은 모양의 입력으로 봅니다.
- **임베딩 공간(IP1).** 이방성(아무 두 글의 평균 코사인)이 높으면 벡터가 한쪽으로 몰려 점수 차이가 작아집니다. 유효 차원(특이값의 참여 비율)이 낮으면 차원 줄이기에 강하고, 주성분 상위 10 · 50 개의 설명력으로 그 정도를 봅니다. 문서 군집(같은 문서 청크끼리 − 다른 문서끼리 코사인)과 한국어-영어 번역 쌍 12개의 정렬(가장 가까운 영어 문장이 번역인 비율 · 번역 쌍 − 아무 쌍)을 함께 봅니다 — 같은 검색 점수의 모델이 양자화 · 차원 줄이기에서 다르게 무너지는 이유를 공간에서 찾으려는 것입니다.
- **설명은 기여로(IP2).** 답이 인용한 근거와 실제로 기댄 근거가 다를 수 있습니다. 작은 모델이 쓴 답을 고정하고, 근거를 하나씩 지운 프롬프트에서 같은 답의 평균 로그확률이 얼마나 떨어지는지 잽니다 — 지우면 답이 덜 그럴듯해지는 근거가 진짜 근거입니다. 어텐션(답 토큰이 근거 토큰 범위에 준 가중치, 마지막 4층 · 모든 머리 평균)은 값싼 대안이지만 기여와 다를 수 있어 둘이 같은 근거를 가리키는지도 셉니다. 어텐션 가중치를 돌려주지 않는 구현이면 비워 둡니다.
- **같은 질문 두 벌(IP3 · IP5 · IP6).** 답할 수 있는 질문마다 검색 근거를 '정답 근거 있음'(정답 근거를 담은 청크 포함, 상위 k)과 '정답 근거 뺌'(그 청크를 빼고 다음 순위로 채움)으로 만듭니다. 질문은 같고 답이 근거에 있고 없음만 달라, 안의 신호가 그 차이를 아는지 볼 수 있습니다. 정답 근거가 검색되지 않은 질문은 뺍니다.
- **탐침(IP3).** 층마다 프롬프트 마지막 토큰(답을 쓰기 직전)의 은닉 상태로 '있음 / 뺌'을 로지스틱 회귀로 분류해 교차 검증 정확도를 봅니다. 어느 층에서 정확도가 오르는지가 모델이 '답이 근거에 없다'를 알게 되는 곳입니다.
- **환각 탐지는 안과 밖을 같은 자료로(IP6).** 거절하지 않은 답 가운데 '근거 뺌' 쪽은 근거 없이 답한 것(환각)입니다. 이를 가려내는 AUROC 를 내부 신호(평균 토큰 엔트로피 · 최소 토큰 확률 · 탐침 점수)와 밖의 검증(답 문장의 글자 근거율)으로 비교합니다. 탐침 점수는 두 갈래로 나눠 서로 예측(교차 적합)해 자기 자신을 맞히지 않게 합니다. 내부 신호는 생성 중에, 밖의 검증은 답이 끝난 뒤에 얻습니다 — 같은 정확도면 더 일찍 막을 수 있습니다.
- **조종은 부작용과 함께(IP5).** 탐침이 가장 잘 맞힌 층의 '근거 뺌 평균 − 근거 있음 평균' 방향(길이 1)을 생성 중 그 층 블록 출력에 세기 α 로 더합니다(은닉 상태 n 번 = 블록 n-1 의 출력이라 같은 자리에). 근거가 없을 때 거절이 늘면 좋지만, 근거가 있을 때도 늘거나 근거율이 떨어지면 부작용입니다 — 학습 없이 행동을 바꾸는 값싼 방법인지 같은 자료로 판단합니다. 방향은 /inside 실행이 남긴 은닉 상태 파일에서 만듭니다(같은 모델 · 같은 자료).
- **희소 특징(IP4).** 은닉 상태의 한 차원에는 여러 뜻이 섞여 있습니다. 한 층의 토큰 은닉 상태를 표준화해 희소 오토인코더(특징 수 = 차원 × 배수, L1)를 학습하고, 디코더 방향 길이를 1 로 고정합니다(L1 을 피해 방향만 키우는 꼼수를 막음). 설명한 분산 · 평균 켜진 특징 수 · 안 켜진 특징 비율을 함께 보고 — 희소할수록 해석은 쉽지만 재구성이 나빠집니다 — 자주 · 세게 켜지는 특징마다 가장 세게 켜진 글 조각(켜진 토큰을 ⟦ ⟧ 로)을 보입니다. CPU 에서 돌도록 작게 시작합니다(글 200개 · 배수 4 · 400걸음).

## 실측

2026-10-23. 안의 신호는 Qwen3-0.6B(CPU), 평가 세트 eval_set 5(법률 7유형). 어텐션은 eager 로 바꿔 가중치를 받은 뒤 잼(KC 문서의 sdpa 정정 참고).

**임베딩 공간 (IP1, run #373)** — 컬렉션 3(법률 공개 자료) 청크 400개

| 모델 | 이방성 | 유효 차원 | 주성분 상위 10 · 50 설명력 | 문서 군집 | 한-영 번역 1위 · 쌍 − 아무 쌍 |
| --- | --- | --- | --- | --- | --- |
| KURE-v1 | 0.457 | 36.6 | 38.1% · 70.1% | **0.173** | 100% · **0.407** |
| bge-m3 | 0.522 | 36.9 | 38.1% · 70.6% | 0.157 | 100% · 0.388 |
| EmbeddingGemma | **0.712** | 33.0 | 41.6% · 74.5% | 0.078 | 100% · 0.209 |

- EmbeddingGemma 는 벡터가 한쪽으로 몰려(아무 두 글의 평균 코사인 0.71) 문서 사이 차이가 작습니다(문서 군집 0.078, KURE 의 절반). 번역 쌍도 1위는 다 맞히지만 '번역 쌍 − 아무 쌍' 간격이 0.21 로 좁습니다. 같은 검색 점수여도 점수 차이가 작으면 양자화 오차 · 문턱에 더 민감합니다.
- 세 모델 모두 1,024 · 768 차원 중 유효 차원은 33~37 이고, 상위 50 주성분이 분산의 70% 를 설명합니다. 차원 줄이기(MRL · PCA)에 여유가 크다는 뜻입니다.

**희소 특징 (IP4, run #374)** — 층 14 토큰 은닉 상태 25,425개, 특징 4,096(배수 4), 400걸음: 설명한 분산 84.7% · 토큰당 켜진 특징 1,055개 · 안 켜진 특징 0%. 켜진 특징이 많아(4,096 중 1/4) 아직 '희소'하지 않습니다. L1 을 키워 켜진 수를 수십 개로 줄여야 특징 하나에 뜻 하나가 대응합니다 — CPU 에서 짧게 학습한 첫 설정입니다.

**근거 기여 (IP2, run #375)** — 8문항, 작은 모델이 쓴 답을 고정하고 근거를 하나씩 지움

| | 값 |
| --- | --- |
| 지우면 답이 가장 덜 그럴듯해지는 근거 = 정답 근거 | 37.5% |
| 어텐션이 가장 많이 간 근거 = 정답 근거 | 50.0% |
| 어텐션 1위 = 지우기 1위 | 75.0% |
| 답이 인용한 근거 = 지우기 1위 (인용한 3문항) | 66.7% |
| 답이 인용한 근거 = 정답 근거 | 0% |

- 작은 모델은 정답 근거보다 다른 근거에 더 기대 답합니다(37.5%). 어텐션은 기여와 3/4 일치해 값싼 대안으로 쓸 만합니다. 인용 번호는 실제로 기댄 근거와 2/3 맞았지만, 정답 근거를 인용한 답은 없었습니다 — 인용이 '맞는 근거'를 보장하지 않습니다.

**탐침 · 환각 탐지 (IP3 · IP6, run #376)** — 같은 질문 두 벌(정답 근거 있음 · 뺌) 16쌍

| 층 | 4 | 8 | 12 | 16 | 20 | 24 | 28 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| '근거 있음 / 뺌' 탐침 정확 | 53% | 50% | 56% | **63%** | 60% | 59% | 63% |

| 환각(근거 뺀 쪽에서 거절 안 한 답, 15개 중 8개) 가려내기 | AUROC |
| --- | --- |
| 평균 토큰 엔트로피 | 0.54 |

- 0.6B 모델 안에는 '답이 근거에 없다'는 신호가 약합니다(최고 63%, 우연 50%). 거절도 근거가 있을 때 56% · 없을 때 50% 로 거의 같아, 이 모델은 근거 유무와 상관없이 답합니다. 환각 가려내기는 안 · 밖 모두 우연 수준(0.48~0.57)이었습니다. 작은 모델 · 16쌍이라 '안의 신호로 환각을 먼저 막는다'는 이 크기에서는 성립하지 않습니다.

**조종 (IP5, run #377)** — 층 16 '근거 뺌 − 있음' 방향을 세기 α 로 더함, 8쌍

| α | 근거 없을 때 거절 | 근거 있을 때 거절(부작용) | 답 근거율 |
| --- | --- | --- | --- |
| 0 | 50.0% | 75.0% | 12.5% |
| 4 | 62.5% | 87.5% | 12.5% |
| 8 | 62.5% | 75.0% | 12.5% |

- 방향을 더하면 근거가 없을 때 거절이 오르지만(50 → 62.5%) 근거가 있을 때도 같이 오릅니다(α 4 에서 75 → 87.5%). 탐침이 약한 층의 방향이라 '근거 없음'만 골라 바꾸지 못하고 거절 쪽으로 전체를 미는 것입니다. 8쌍이라 1문항이 12.5%p 입니다.

한계: 0.6B 한 모델 · 8~16문항이라 방향만 읽어야 합니다. 큰 모델(서버의 gemma-4)은 안을 볼 수 없어 비교하지 못했습니다.
