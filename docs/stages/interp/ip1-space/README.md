# IP1 · 임베딩 공간 분석 (Embedding space analysis)

**상태: ✅ 구현됨** — 차원 축소 · 군집 · 이방성 · 언어 간 정렬로 임베딩 공간을 본다

## 원리

임베딩 공간 분석은 벡터들이 어떻게 퍼져 있는지(한쪽으로 몰림 · 군집 · 한국어-영어 정렬)를 보는 것입니다. 검색 품질 차이의 원인을 공간에서 찾습니다.

## 왜 하는가

같은 점수의 두 모델도 공간 모양이 달라 양자화 · 차원 줄이기에서 다르게 무너집니다.

## 어떻게 (이 앱에서)

- (기반) 임베딩 투영 · 벤치마크(1)
- 같은 청크로 모델마다 이방성(아무 두 글의 평균 코사인) · 유효 차원(특이값 참여 비율) · 상위 10 · 50 주성분 설명력 · 문서 군집(같은 문서 − 다른 문서 코사인)
- 한국어-영어 번역 쌍 12개로 언어 간 정렬(가장 가까운 영어가 번역인 비율 · 번역 쌍 − 아무 쌍 코사인)
