# IP1 · 임베딩 공간 분석 (Embedding space analysis)

**상태: ⬜ 예정** — 차원 축소 · 군집 · 이방성 · 언어 간 정렬로 임베딩 공간을 본다

## 원리

임베딩 공간 분석은 벡터들이 어떻게 퍼져 있는지(한쪽으로 몰림 · 군집 · 한국어-영어 정렬)를 보는 것입니다. 검색 품질 차이의 원인을 공간에서 찾습니다.

## 왜 하는가
