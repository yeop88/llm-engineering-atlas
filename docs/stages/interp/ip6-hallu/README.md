# IP6 · 내부 신호 환각 탐지 (Internal uncertainty)

**상태: ✅ 구현됨** — 토큰 확률 · 엔트로피 · 탐침으로 근거 없는 답을 잡고 근거 일치 검증과 비교한다

## 원리

내부 신호 환각 탐지는 생성 중 토큰 확률 · 엔트로피 · 탐침 점수로 '모르면서 답하는' 부분을 찾는 것입니다.

## 왜 하는가

밖의 근거 일치 검증은 답이 끝난 뒤에야 판정합니다. 내부 신호가 같은 정확도로 더 일찍 잡는지, 둘을 합치면 나은지 잽니다.

## 어떻게 (이 앱에서)

- (기반) 근거 일치 검증(AS6)
- 거절하지 않은 답 중 근거 없이 답한 것(근거 뺌 쪽)을 가려내는 AUROC — 내부 신호(평균 엔트로피 · 최소 확률 · 탐침 점수, 교차 적합)와 밖의 검증(글자 근거율)
- 내부 신호는 생성 중에, 밖의 검증은 답이 끝난 뒤에 얻는다 — 같은 자료로 비교
