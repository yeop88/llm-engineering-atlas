# IP5 · 조종 · 편집 (Steering & editing)

**상태: ✅ 구현됨** — 특징 방향을 더해 말투 · 거절을 조종하고 부작용을 잰다

## 원리

조종은 생성 중 은닉 상태에 특정 방향(말투 · 거절 · 주제)을 더해 출력을 바꾸는 것이고, 편집은 특정 사실의 저장을 바꾸는 것입니다. 학습 없이 바꿀 수 있지만 부작용이 있습니다.

## 왜 하는가

후학습보다 싸게 행동을 바꿀 수 있는지, 그때 다른 능력 · 안전이 떨어지지 않는지를 같은 평가로 확인해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 어댑터 · 병합(P5)
- 탐침이 가장 잘 맞힌 층의 '근거 뺌 평균 − 근거 있음 평균' 방향을 그 층 블록 출력에 더해 생성
- 세기별 근거 뺌 거절률(오르면 좋음) · 근거 있음 거절률(오르면 부작용) · 근거 있음 답의 근거율
