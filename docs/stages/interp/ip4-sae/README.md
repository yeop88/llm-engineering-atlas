# IP4 · 희소 특징 (Sparse autoencoders)

**상태: ✅ 구현됨** — 은닉 상태를 사람이 읽을 수 있는 희소 특징으로 나눈다

## 원리

희소 오토인코더(SAE)는 은닉 상태를 수천 개의 희소한 특징으로 다시 표현해, 특징마다 어떤 글에서 켜지는지로 뜻을 붙이는 방법입니다.

## 왜 하는가

은닉 상태의 차원 하나는 뜻이 섞여 있습니다. 희소 특징은 '법 조문' · '거절' 같은 개념 단위로 볼 수 있게 합니다.

## 어떻게 (이 앱에서)

- (기반) 작은 공개 모델 · 학습기(P5)
- 한 층의 토큰 은닉 상태(표준화)로 희소 오토인코더(특징 배수 · L1) 학습, 특징 방향 길이 1 로 고정
- 설명한 분산 · 평균 켜진 특징 수(L0) · 안 켜진 특징 비율, 자주 · 세게 켜지는 특징의 글 조각
