# PS4 · 프로필 갱신 (Profile update)

**상태: ⬜ 예정** — 선호 · 숙련도 · 상황을 프로필로 갱신하고 오래된 추정은 낮춘다

## 원리

프로필 갱신은 명시 · 추정 선호를 합쳐 지금의 프로필(간결 선호 · 숙련 · 자주 쓰는 채널)을 만드는 것입니다. 오래된 추정은 확신도를 낮추고, 명시가 추정보다 앞섭니다.

## 왜 하는가

선호는 바뀝니다. 한 번 굳힌 프로필을 계속 쓰면 지금의 사용자와 어긋납니다.

## 어떻게 (이 앱에서)

- (기반) 기억 갱신 · 시점 기록(ME4)
- (예정) 명시 > 추정 · 감쇠 · 시점 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ps_profile` 에서 볼 수 있습니다.
