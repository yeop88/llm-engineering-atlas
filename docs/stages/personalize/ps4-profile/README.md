# PS4 · 프로필 갱신 (Profile update)

**상태: ✅ 구현됨** — 선호 · 숙련도 · 상황을 프로필로 갱신하고 오래된 추정은 낮춘다

## 원리

프로필 갱신은 명시 · 추정 선호를 합쳐 지금의 프로필(간결 선호 · 숙련 · 자주 쓰는 채널)을 만드는 것입니다. 오래된 추정은 확신도를 낮추고, 명시가 추정보다 앞섭니다.

## 왜 하는가

선호는 바뀝니다. 한 번 굳힌 프로필을 계속 쓰면 지금의 사용자와 어긋납니다.

## 어떻게 (이 앱에서)

- (기반) 메모리 갱신 · 망각(ME2)
- 명시 선호가 추정보다 우선, 행동 신호는 반감기 30일로 낮춰 길이 · 숙련도를 추정(근거가 신호 하나 몫도 안 되면 추정하지 않음), 동의가 없는 기록은 남아 있어도 쓰지 않음
