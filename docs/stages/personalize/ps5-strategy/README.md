# PS5 · 응답 전략 선택 (Response strategy)

**상태: ⬜ 예정** — 프로필로 길이 · 단계 수 · 설명 깊이 · 채널 형식을 고른다

## 원리

응답 전략은 프로필에 맞춰 답의 형식(길이 · 단계 수 · 설명 깊이 · 버튼 · 채널)을 고르는 것입니다. 사실 · 근거는 바꾸지 않고 모양만 바꿉니다.

## 왜 하는가

개인화가 내용까지 바꾸면 같은 질문에 사람마다 다른 사실을 답합니다 — 공정성 · 일관성 문제입니다.

## 어떻게 (이 앱에서)

- (기반) 라우팅(6) · 채널별 형식(OM7)
- (예정) 프로필 → 형식 규칙 · 내용 동일성 검사

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ps_strategy` 에서 볼 수 있습니다.
