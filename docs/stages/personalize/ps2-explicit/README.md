# PS2 · 명시적 선호 (Explicit preferences)

**상태: ⬜ 예정** — 사용자가 직접 고른 선호(길이 · 말투 · 채널 · 언어)를 받는다

## 원리

명시적 선호는 사용자가 직접 고른 것(짧게 · 자세히 · 존댓말 · 채널 · 언어)입니다. 가장 믿을 만한 신호이며 사용자가 언제든 고칠 수 있어야 합니다.

## 왜 하는가

추측한 선호보다 고른 선호가 먼저입니다. 고른 것을 무시하면 개인화가 오히려 불만이 됩니다.

## 어떻게 (이 앱에서)

- (기반) 고객 프로필(C4)
- (예정) 선호 항목 · 사용자 편집 · 출처(명시)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ps_explicit` 에서 볼 수 있습니다.
