# PS6 · 개인화 응답 (Personalized response)

**상태: ✅ 구현됨** — 이미 한 조치는 건너뛰고 숙련도에 맞춰 답한다

## 원리

개인화 응답은 메모리(이미 해 본 조치 · 보유 제품)와 전략(짧게 · 숙련)을 써서 답하는 것입니다. 개인화하지 않은 답과 근거 · 사실이 같은지 함께 검사합니다.

## 왜 하는가

같은 내용을 반복하면 시간이 아깝고, 맞춤이 지나치면 필요한 경고를 빠뜨립니다(안전 경고는 늘 남김).

## 어떻게 (이 앱에서)

- (기반) 서비스 답변(serve) · 질의 재작성(C2)
- 검증을 거친 기본 답을 단계 · 문장 단위로 고르기만(새로 쓰지 않음) — 해 본 단계 건너뛰기 · 더 보기, 숫자 · 코드 · 모델 표시와 문장이 기본 답에 있는지 검사

## 화면

- `/personalize/profile#respond` — **개인화 응답**: 기본 답의 문장 · 단계만 골라 줄이기 · 사실 보존 검사

## 앞으로 할 일

- LLM 으로 말투만 바꾸고 같은 사실 보존 검사로 거르기
