# PS7 · 사용자 피드백 (Feedback)

**상태: ⬜ 예정** — 개인화가 실제로 도움이 됐는지 A/B · 피드백으로 잰다

## 원리

피드백은 개인화한 답과 하지 않은 답을 나눠 해결률 · 만족 · 재질문을 비교하는 것입니다. 개인화를 끄는 버튼도 피드백입니다.

## 왜 하는가

개인화는 좋아 보이지만 해결률을 낮추기도 합니다. 재 보지 않은 개인화는 추측입니다.

## 어떻게 (이 앱에서)

- (기반) 피드백(AS8) · A/B 실험(E7)
- (예정) 개인화 A/B · 끄기 비율 · 해결률

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ps_feedback` 에서 볼 수 있습니다.
