# PS7 · 사용자 피드백 (Feedback)

**상태: ✅ 구현됨** — 개인화가 실제로 도움이 됐는지 A/B · 피드백으로 잰다

## 원리

피드백은 개인화한 답과 하지 않은 답을 나눠 해결률 · 만족 · 재질문을 비교하는 것입니다. 개인화를 끄는 버튼도 피드백입니다.

## 왜 하는가

개인화는 좋아 보이지만 해결률을 낮추기도 합니다. 재 보지 않은 개인화는 추측입니다.

## 어떻게 (이 앱에서)

- (기반) AS 피드백 · A/B(E6)
- 인물 7명(동의 없음 · 명시 · 행동 · 음성 · 오래된 신호 · 동의 철회) × 상담 3건으로 기대 형식 · 건너뛰기 · 사실 보존 · 길이, 개인화 없음 · 명시 선호만과 비교
