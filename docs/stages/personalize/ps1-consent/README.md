# PS1 · 사용자 동의 (Consent)

**상태: ✅ 구현됨** — 개인화 · 기록 보관 · 학습 사용 동의를 따로 받고 범위를 남긴다

## 원리

동의는 개인화(응답 맞춤) · 기록 보관 · 모델 학습 사용을 각각 따로 받는 것입니다. 하나에 동의했다고 다른 것에 동의한 것이 아닙니다.

## 왜 하는가

동의 범위 밖의 개인화는 법적 문제이자 신뢰 문제입니다. 범위가 기록되어야 쓰는 쪽이 검사할 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 고지 · 동의 관리(RC)
- 개인화 · 행동 신호 · 보관 · 학습 사용 동의를 범위마다 따로(언제 · 문안 판), 철회하면 그 범위로 모은 것을 바로 지움, 통째 지우기
