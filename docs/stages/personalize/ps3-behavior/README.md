# PS3 · 행동 신호 (Behavioral signals)

**상태: ✅ 구현됨** — 동의 범위 안에서 해결 단계 · 재질문 · 끊김 같은 행동 신호를 모은다

## 원리

행동 신호는 사용자가 한 일(몇 단계에서 해결했나 · 다시 물었나 · 상담원 연결을 눌렀나)에서 선호를 추정하는 것입니다. 추정이라 확신도를 함께 남깁니다.

## 왜 하는가

행동 신호는 많지만 틀릴 수 있습니다. 확신도 없이 쓰면 한 번의 우연을 선호로 굳힙니다.

## 어떻게 (이 앱에서)

- (기반) 사용자 피드백(E4) · 메모리 추출(ME1)
- 해결 단계 · 재질문 · 더 보기 · 끊김 · 연결 · 해 본 조치 — 동의가 없으면 버리고 버린 수만, 글은 개인정보를 가려서, 인증 정보는 버림
