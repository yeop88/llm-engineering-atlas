# RV6 · 일반화 · 안전성 평가 (Generalization & safety eval)

**상태: ⬜ 예정** — 학습에 없던 유형 · 자료에서도 나아졌는지, 안전성이 나빠지지 않았는지 확인한다

## 원리

일반화 평가는 학습 과제와 다른 유형(조문 질문으로 학습 → 판례 질문으로 평가)에서 효과를 봅니다. 레드팀 · 일반 능력 세트로 부작용을 확인합니다.

## 왜 하는가

검증 가능한 과제만 잘하고 실제 질문(검증하기 어려운 상황 설명형)은 그대로일 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 후학습 평가(P6) · 레드팀(G7), 질문 유형별 지표
- (예정) 학습 외 유형 평가 묶음

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/rv_eval` 에서 볼 수 있습니다.
