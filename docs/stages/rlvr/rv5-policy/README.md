# RV5 · 정책 학습 (GRPO · PPO) (Policy optimization)

**상태: ✅ 구현됨** — 같은 과제에 여러 답을 만들어 보상을 비교하며 모델이 더 나은 행동을 하도록 학습한다

## 원리

GRPO 는 같은 질문에 여러 답(그룹)을 만들고 그룹 안에서 상대적으로 보상이 높은 답 쪽으로 학습합니다(별도 가치 모델 없이). PPO 는 가치 모델을 함께 학습합니다. 둘 다 GPU 가 필요합니다.

## 왜 하는가

선호 학습(DPO)은 고정된 쌍으로 배우지만, 강화학습은 모델이 직접 행동해 보며 배워 도구 사용 같은 다단계 능력에 맞습니다.

## 어떻게 (이 앱에서)

- GRPO: 과제마다 답 G개(묶음) → 정규화한 이점 × 답 로그확률 + beta × KL(기준 = 어댑터를 끈 같은 모델) — 가치 모델 없이
- 묶음 보상이 모두 같으면 건너뜀(배울 것 없음), 걸음마다 보상 · 정답률 · 길이 · 여러 답, 정책은 후학습 끝점 pt-번호로
