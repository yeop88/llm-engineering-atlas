# RV3 · 보상 설계 (Reward design)

**상태: ✅ 구현됨** — 정답 확인 · 근거 일치 · 질문 관련성 · 비용을 합친 보상을 설명 가능하게 설계한다

## 원리

보상은 정답 확인(주된 신호)에 근거 일치 · 질문과 상관없는 문장 감점 · 단계 수 감점 같은 보조 신호를 더합니다. 항목별로 기록해 어떤 항목이 학습을 이끄는지 봅니다.

## 왜 하는가

보상이 곧 목표입니다. 보조 항목을 잘못 두면 모델이 그 항목만 올립니다(예: 길이 감점이 크면 너무 짧은 답).

## 어떻게 (이 앱에서)

- (있음) 설명 가능한 보상 함수(8b — 근거율 · 정답 인용 · 지어냄 · 상관없는 문장)
- 검증 보상 = 정답(1) + 형식(0.1, 마지막 '정답:' 줄) − 길이(300자 넘으면) − 여러 답(정답 줄에 후보를 늘어놓으면), 항목별 기여를 함께
