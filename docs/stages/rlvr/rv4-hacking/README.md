# RV4 · 보상 해킹 감시 (Reward hacking monitoring)

**상태: ✅ 구현됨** — 보상은 오르는데 실제 품질 · 사람 판정은 그대로인 경우를 찾아낸다

## 원리

보상 해킹은 모델이 의도와 다른 지름길로 보상을 올리는 것입니다(근거를 많이 인용만 하기 · 형식만 맞추기). 보상과 독립된 지표(사람 판정 · 다른 평가 세트)를 함께 보고, 둘이 벌어지면 경보를 냅니다.

## 왜 하는가

이 프로젝트의 Best-of 실측에서 보상은 유의하게 올랐지만 품질은 불확실했습니다 — 작은 규모에서도 보상과 품질이 어긋났습니다.

## 어떻게 (이 앱에서)

- (있음) Best-of 실측의 보상 · 품질 짝 비교, 사람 판정 보정 화면
- 학습 기록으로: 보상은 오르는데 정답률은 그대로 · 길이 부풀리기 · 여러 답 늘어놓기, 평가로: 학습 과제만 좋아지고 시험은 그대로(외움)

## 화면

- `/rlvr/train#hacking` — **보상 해킹 감시**: 보상 ↑ 정답률 그대로 · 길이 · 여러 답 · 외움
