# RV2 · 환경 · 도구 시뮬레이터 (Environment & tool simulator)

**상태: ✅ 구현됨** — 학습 중 에이전트가 쓸 도구 · 자료 환경을 실제와 같게, 빠르고 재현 가능하게 만든다

## 원리

환경은 에이전트가 행동하고 결과를 받는 곳입니다. 실제 도구(검색 · 번호 조회)를 그대로 쓰되, 결과를 캐시 · 고정해 같은 행동에 같은 결과가 나오게(재현) 하고 수천 번 돌릴 수 있게 합니다.

## 왜 하는가

시뮬레이터에서만 통하는 행동을 배우면 실제에서 실패합니다. 반대로 매번 실제 서비스를 부르면 느리고 비쌉니다.

## 어떻게 (이 앱에서)

- 도구 결과(검색 근거 · 그래프 집계)를 처음에 기록하고 다음부터 재생 — 학습이 빠르고 같은 과제의 보상이 흔들리지 않게
- 환경-실제 차이: 표본 과제를 다시 실제로 불러 근거 겹침 · 집계가 같은지
