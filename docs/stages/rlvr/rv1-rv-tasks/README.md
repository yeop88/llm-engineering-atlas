# RV1 · 검증 가능한 과제 설계 (Verifiable task design)

**상태: 🟡 기초 있음** — 정답을 자동으로 확인할 수 있는 과제(조문 조회 · 계산 · 쿼리 결과)를 모아 학습 과제로 만든다

## 원리

검증 가능한 과제는 모델의 답이 맞는지 프로그램으로 확인할 수 있는 과제입니다. 근거 조문이 정해진 질문, 정답 값이 있는 계산, 실행 결과를 비교할 수 있는 쿼리가 예입니다.

## 왜 하는가

사람 판정 없이 보상을 줄 수 있어야 대규모 학습이 가능합니다. 조문 번호 질문은 정답 조문이 있어 번호 조회의 효과(75% → 100%)를 정확히 잴 수 있었습니다.

## 어떻게 (이 앱에서)

- (있음) 조문 번호 질문 세트(정답 조문), 근거가 정해진 평가 세트, 에이전트 계산 도구
- (예정) 과제 유형 확장(계산 · 다단계 조회), 난이도 단계

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/rv_tasks` 에서 볼 수 있습니다.
