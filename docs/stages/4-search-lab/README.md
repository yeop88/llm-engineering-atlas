# 4 · 검색 향상 (Retrieval enhancement)

**상태: ⬜ 예정** — 모델을 바꾸지 않고 질의 · 문서를 다듬어 검색을 좋게 한다

## 원리

검색 전후에 질의나 문서를 손봅니다. 질의 재작성(구어체 질문 → 검색어), HyDE(LLM 이 쓴 가상 답변의 임베딩으로 검색), 문맥 청크(청크 앞에 문서 맥락 요약을 붙여 색인), 다중 질의(여러 표현으로 검색해 합치기) 등이 있습니다.

## 왜 하는가

사용자 질문은 짧고 구어체 · 상황 설명형이라 문서 표현과 어긋납니다. 모델 교체나 학습 없이도 검색 품질을 올릴 수 있는 가장 싼 방법입니다.

## 어떻게 (이 앱에서)

- 기법별로 켜고 끄며 같은 평가 세트 · 조합 평가로 비교
- LLM 호출 수 · 지연 · 비용을 함께 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/search_lab` 에서 볼 수 있습니다.

## 앞으로 할 일

- 질의 재작성 · HyDE · 다중 질의
- 문맥 청크(contextual chunk) 색인
- 기법 × 검색 방식 조합 평가
