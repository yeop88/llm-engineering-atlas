# K4 · 지식 융합 · 정제 (Knowledge fusion)

**상태: ⬜ 예정** — 다른 이름의 같은 개체를 하나로 묶고(개체 정규화) 중복 · 충돌을 정리해 그래프를 완성한다

## 원리

여러 문서에서 나온 '미국' · 'USA' · 'United States' 처럼 같은 대상을 가리키는 개체를 하나의 노드로 묶습니다(개체 정규화 · 연결). 이름 규칙 · 사전 · 임베딩 유사도 · LLM 판단을 섞어 후보를 찾고, 같은 관계의 중복과 서로 어긋나는 사실을 정리합니다.

## 왜 하는가

정규화하지 않으면 같은 조문이 '근로기준법 제23조' · '근기법 23조' · '같은 법 제23조 제1항' 처럼 여러 노드로 갈라져, 다단계 탐색이 중간에 끊기고 집계가 틀립니다. 그래프의 연결이 곧 답이므로 여기서의 오류가 그대로 오답이 됩니다.

## 어떻게 (이 앱에서)

- (예정) 조문 번호 정규화는 이미 있는 파서(`rag/legal.py` — 시행령 · '의2' · 띄어쓰기 처리)를 그대로 사용
- (예정) 이름이 다른 개체는 임베딩 유사도로 후보 → 규칙 · LLM 으로 확정, 합친 기록(어느 이름을 합쳤나)을 남김
- (예정) 정제 결과를 역량 질문(K1)으로 점검 — 합치기 전후 답이 달라지는 질문을 확인

## 화면
