# K8 · 글로벌 커뮤니티 요약 (Global community summaries (GraphRAG))

**상태: ⬜ 예정** — 그래프를 계층적 커뮤니티로 나눠 미리 요약해 두고, 전체 주제 · 추세 질문은 요약들을 모아 답한다

## 원리

그래프를 연결이 촘촘한 묶음(커뮤니티)으로 나누고(Leiden 등), 묶음마다 LLM 으로 요약을 미리 만들어 둡니다. 큰 묶음 안에 작은 묶음이 있는 계층 구조입니다. '이 자료 전체의 주요 쟁점은?' 같은 질문에는 특정 노드를 찾는 대신 관련 커뮤니티 요약들을 모아 답합니다(Microsoft GraphRAG 의 Global Search 방식).

## 왜 하는가

벡터 RAG 와 Text2Cypher 는 모두 '어딘가에 있는 특정 사실'을 찾는 방식이라, 책 한 권 분량 전체를 훑어야 하는 요약 · 추세 질문에는 약합니다. 대신 요약을 미리 만드는 비용이 크고(LLM 호출이 커뮤니티 수만큼), 자료가 바뀌면 다시 만들어야 합니다.

## 어떻게 (이 앱에서)

- (예정) 커뮤니티 탐지 → 계층별 요약 생성(로컬 LLM, 작업으로 백그라운드 실행) → 요약 저장 · 색인
- (예정) 전체 질문은 커뮤니티 요약에서 답을 모으는 map-reduce, 근거로는 요약과 그 요약의 원문 노드를 인용
- (예정) 평가: '전체 요약' 질문을 따로 만들어 벡터 RAG 와 비교, 요약 생성 비용(시간 · 토큰) 기록

## 화면
