# K7 · 그래프 하이브리드 검색 (Vector + graph retrieval)

**상태: ⬜ 예정** — 벡터 검색으로 찾은 청크에서 연결된 개체 · 관계(서브그래프)를 함께 가져와 답변 맥락을 넓힌다

## 원리

질문과 비슷한 문서 청크를 벡터로 먼저 찾고(LLM 맵의 2 RAG 검색과 같음), 그 청크와 연결된 개체 · 관계를 그래프에서 한두 단계 따라가 '이 판례는 이 조문을 인용했고, 그 조문은 이 시행령에 위임했다' 같은 맥락을 근거에 덧붙입니다.

## 왜 하는가

벡터 RAG 는 질문과 글이 비슷한 조각만 가져와, 답에 필요한 연결된 사실(다른 문서에 있는 관련 조문 · 판례)을 놓칩니다. 법률 재측정에서 여러 문서 질문의 검색 nDCG 가 37 로 가장 낮았던 것이 이 한계입니다.

## 어떻게 (이 앱에서)

- (예정) 1단계는 기존 RAG 검색(KURE · 하이브리드)을 그대로 쓰고, 결과 청크의 문서 노드에서 이웃(인용 조문 · 같은 쟁점 판례)을 확장
- (예정) 확장한 서브그래프를 근거에 '관계 요약' 으로 붙이고, 답변은 같은 인용 · 검증(근거 일치 · 질문 관련성) 규칙을 따름
- (예정) 평가: 여러 문서 질문 · 다단계 질문에서 벡터 RAG 와 짝지어 비교 — LLM 맵의 연결 비교에 경로로 추가
