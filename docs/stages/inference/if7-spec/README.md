# IF7 · 추측 디코딩 (Speculative decoding)

**상태: ⬜ 예정** — 작은 초안 모델이 미리 쓰고 큰 모델이 확인한다

## 원리

추측 디코딩은 작은 모델(또는 n-gram · MTP 머리)이 토큰 몇 개를 미리 쓰고 큰 모델이 한 번에 확인해 맞는 만큼 받는 것입니다. 받아들이는 비율이 이득을 정합니다.

## 왜 하는가

받아들이는 비율이 낮으면 오히려 느려집니다. 모델 짝 · 작업마다 재야 합니다.

## 어떻게 (이 앱에서)

- (기반) 디코딩 최적화(S5)
- (예정) 초안 방식별 수락률 · 속도 이득 · 동시 요청에서의 효과
