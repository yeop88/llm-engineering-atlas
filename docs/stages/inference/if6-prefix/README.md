# IF6 · 앞부분 캐시 (Prefix caching)

**상태: ⬜ 예정** — 같은 시스템 프롬프트 · 근거의 미리 채우기를 다시 쓴다

## 원리

앞부분 캐시는 요청 사이에 같은 앞부분(시스템 프롬프트 · 같은 근거)의 KV 를 다시 써 미리 채우기를 건너뛰는 것입니다. 앞부분을 같게 두는 프롬프트 배치가 먼저입니다.

## 왜 하는가

근거 읽기가 지연의 큰 몫이라, 같은 앞부분을 다시 쓰면 첫 토큰까지가 크게 줄어듭니다.

## 어떻게 (이 앱에서)

- (기반) 프롬프트 캐시(CX4) · 앞부분 공유(BM4)
- (예정) 캐시 적중률 · 미리 채우기 감소 · 배치 규칙

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/if_prefix` 에서 볼 수 있습니다.
