# IF3 · 양자화 (Quantization)

**상태: ⬜ 예정** — 가중치 비트를 모델 · 장치마다 품질과 함께 고른다

## 원리

양자화는 가중치를 8 · 4 · 2비트로 줄여 메모리와 생성 시간을 줄이는 것입니다. INT8 · FP8 · INT4 중 하나가 늘 맞지 않고, 장치 커널 · 맥락 길이 · 동시 수에 따라 결과가 다릅니다.

## 왜 하는가

비트를 줄이면 빨라지지만 품질 절벽이 있습니다. 같은 평가 · 같은 장치에서 p95 와 품질을 함께 봐야 고릅니다.

## 어떻게 (이 앱에서)

- (기반) LLM 양자화(7b) · 극저비트(BM6)
- (예정) 비트별 p95 · 품질 · 메모리를 한 표에
