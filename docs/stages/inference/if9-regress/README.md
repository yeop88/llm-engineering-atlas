# IF9 · 품질 회귀 · 카나리 (Quality regression & canary)

**상태: ✅ 구현됨** — 최적화마다 품질 회귀를 확인하고 일부 트래픽부터 넓힌다

## 원리

품질 회귀 · 카나리는 최적화한 설정을 기준 설정과 같은 평가로 비교하고(짝지은 차이), 통과하면 일부 트래픽에 먼저 넣어 운영 지표를 본 뒤 넓히는 것입니다.

## 왜 하는가

빠르지만 나빠진 설정이 조용히 배포되는 것이 가장 흔한 사고입니다. 순서의 마지막이 아니라 매 단계 확인입니다.

## 어떻게 (이 앱에서)

- (기반) 회귀 평가(E2) · 단계적 배포(FW7)
- 칸마다 바로 앞 통과 칸과 질문별 짝지은 품질 차이(신뢰 구간 하한 > −허용 하락) · p95 또는 처리량 3% 이상 이득일 때만 통과(누적), 끝에 카나리 비율 안내
