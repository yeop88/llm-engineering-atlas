# IF8 · 병렬화 (Parallelism)

**상태: ✅ 구현됨** — 텐서 · 파이프라인 · 전문가 병렬과 CPU-GPU 혼합을 고른다

## 원리

병렬화는 모델을 여러 장치에 나누는 방식(텐서 · 파이프라인 · 전문가 병렬)과 CPU-GPU 혼합입니다. 장치 사이 전송이 새 병목입니다.

## 왜 하는가

한 장치에 안 들어가거나 더 빠르게 하고 싶을 때 쓰지만, 링크가 느리면 나누는 것이 손해입니다.

## 어떻게 (이 앱에서)

- (기반) 여러 기기(BM7) · 혼합 오프로드(BM3)
- 한 PC 에서는 CPU-GPU 혼합(BM3 배치 실측)과 여러 기기 계획(BM7)으로 — 사다리 칸으로는 넣지 않음(기기가 하나)
