# IF8 · 병렬화 (Parallelism)

**상태: ⬜ 예정** — 텐서 · 파이프라인 · 전문가 병렬과 CPU-GPU 혼합을 고른다

## 원리

병렬화는 모델을 여러 장치에 나누는 방식(텐서 · 파이프라인 · 전문가 병렬)과 CPU-GPU 혼합입니다. 장치 사이 전송이 새 병목입니다.

## 왜 하는가

한 장치에 안 들어가거나 더 빠르게 하고 싶을 때 쓰지만, 링크가 느리면 나누는 것이 손해입니다.

## 어떻게 (이 앱에서)

- (기반) 여러 기기(BM7) · 혼합 오프로드(BM3)
- (예정) 병렬 방식별 전송 몫 · 토큰/초

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/if_parallel` 에서 볼 수 있습니다.
