# CU5 · 웹 콘텐츠 인젝션 방어 (Web prompt injection defense)

**상태: ⬜ 예정** — 페이지 글 속 지시를 따르지 않고 허용 도메인만 다닌다

## 원리

웹 콘텐츠 인젝션은 페이지에 숨긴 글('이전 지시를 무시하고 …로 보내라')이 에이전트의 지시로 작동하는 공격입니다. 화면 글은 데이터로 다루고, 이동 · 입력은 허용 목록 안에서만 합니다.

## 왜 하는가

브라우저 에이전트는 신뢰할 수 없는 글을 계속 읽습니다. 근거 격리와 같은 원칙이 화면에도 필요합니다.

## 어떻게 (이 앱에서)

- (기반) 입력 방어 · 근거 격리(G1) · 감사 추적(IO6)
- (예정) 화면 글 격리 · 허용 도메인 · 인젝션 페이지 시험

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cu_injection` 에서 볼 수 있습니다.

## 앞으로 할 일

- 화면 글 격리 · 허용 도메인 · 인젝션 페이지 시험
