# CU3 · 상태 확인 (State verification)

**상태: ⬜ 예정** — 행동 뒤 화면이 기대한 상태인지 확인한다

## 원리

상태 확인은 행동 전후 화면을 비교해 입력이 들어갔는지, 다음 화면으로 넘어갔는지, 오류 메시지가 떴는지 보는 것입니다.

## 왜 하는가

클릭이 됐다고 믿으면 실패한 입력 위에 다음 단계를 쌓습니다. 화면은 느리게 바뀌거나 오류를 조용히 띄웁니다.

## 어떻게 (이 앱에서)

- (기반) 완료 판정(LR6)
- (예정) 전후 화면 비교 · 기대 상태 검사 · 오류 메시지 감지

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cu_check` 에서 볼 수 있습니다.

## 앞으로 할 일

- 전후 화면 비교 · 기대 상태 검사 · 오류 메시지 감지
