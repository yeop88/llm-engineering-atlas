# CU1 · 화면 이해 (Screen understanding)

**상태: ✅ 구현됨** — 스크린샷 · 접근성 트리로 화면 요소를 찾는다

## 원리

화면 이해는 스크린샷(비전 LLM)과 접근성 트리(DOM)로 버튼 · 입력란 · 표를 찾아 좌표 · 이름을 얻는 것입니다.

## 왜 하는가

요소를 잘못 찾으면 엉뚱한 곳을 누릅니다. 그림만 보는 것과 구조(DOM)를 함께 보는 것의 정확도가 다릅니다.

## 어떻게 (이 앱에서)

- (기반) 사진 진단(AS4) · 멀티모달 임베딩(MA1)
- 시험용 사이트 HTML → 접근성 트리(역할 · 이름 · 값 · 요소 번호), 이름은 label · aria-label · 글자에서, 숨은 요소(display:none · hidden · aria-hidden)는 트리에서 빼 '숨은 글'로
- 사람의 설명('제출하는 버튼')으로 요소를 찾는 정확도(11개)

## 화면

- `/computer-use/screen` — **화면 이해**: 접근성 트리 · 숨은 글 · 요소 찾기 정확도
