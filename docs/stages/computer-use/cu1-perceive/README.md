# CU1 · 화면 이해 (Screen understanding)

**상태: ⬜ 예정** — 스크린샷 · 접근성 트리로 화면 요소를 찾는다

## 원리

화면 이해는 스크린샷(비전 LLM)과 접근성 트리(DOM)로 버튼 · 입력란 · 표를 찾아 좌표 · 이름을 얻는 것입니다.

## 왜 하는가

요소를 잘못 찾으면 엉뚱한 곳을 누릅니다. 그림만 보는 것과 구조(DOM)를 함께 보는 것의 정확도가 다릅니다.

## 어떻게 (이 앱에서)

- (기반) 사진 진단(AS4) · 멀티모달 임베딩(MA1)
- (예정) 스크린샷 + 접근성 트리 · 요소 찾기 정확도

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cu_perceive` 에서 볼 수 있습니다.

## 앞으로 할 일

- 스크린샷 + 접근성 트리 · 요소 찾기 정확도
