# CU4 · 위험 행동 승인 (Approval for risky actions)

**상태: ✅ 구현됨** — 제출 · 결제 · 삭제 같은 행동 전에 사람 승인을 받는다

## 원리

위험 행동 승인은 되돌릴 수 없는 행동(제출 · 결제 · 삭제 · 메일 보내기) 앞에서 멈추고 화면 · 입력값을 보여 승인을 받는 것입니다.

## 왜 하는가

화면 에이전트는 무엇이 되돌릴 수 없는지 모를 때가 많습니다. 버튼 이름 · 페이지로 규칙을 정해 멈춥니다.

## 어떻게 (이 앱에서)

- (기반) 승인 지점(LR4)
- 되돌릴 수 없는 행동: 사이트가 표시한 버튼(data-irreversible) 또는 이름 규칙(접수 · 삭제 · 결제 · 보내기 · 제출)
- 멈추고 승인 기다림(실행 기록 파일 · 이어 가기) · 자동 승인(기록만) · 거부(하지 않고 알림)
