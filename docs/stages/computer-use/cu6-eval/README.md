# CU6 · 재생 평가 (Replay evaluation)

**상태: ⬜ 예정** — 과제 세트를 녹화 · 재생해 성공률 · 걸음 수를 잰다

## 원리

재생 평가는 정해진 시작 화면 · 목표로 과제를 만들고, 에이전트의 성공률 · 걸음 수 · 위험 행동 시도를 재는 것입니다. 시험용 화면을 고정해 사이트가 바뀌어도 비교합니다.

## 왜 하는가

실제 사이트는 매번 달라 같은 조건으로 비교할 수 없습니다. 고정한 시험 화면이 필요합니다.

## 어떻게 (이 앱에서)

- (기반) 기록 → 재생 환경(RV2)
- (예정) 시험용 화면 · 과제 세트 · 성공률 · 걸음 · 위험 시도 수

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cu_eval` 에서 볼 수 있습니다.

## 앞으로 할 일

- 시험용 화면 · 과제 세트 · 성공률 · 걸음 · 위험 시도 수
