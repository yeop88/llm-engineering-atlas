# CU6 · 재생 평가 (Replay evaluation)

**상태: ✅ 구현됨** — 과제 세트를 녹화 · 재생해 성공률 · 걸음 수를 잰다

## 원리

재생 평가는 정해진 시작 화면 · 목표로 과제를 만들고, 에이전트의 성공률 · 걸음 수 · 위험 행동 시도를 재는 것입니다. 시험용 화면을 고정해 사이트가 바뀌어도 비교합니다.

## 왜 하는가

실제 사이트는 매번 달라 같은 조건으로 비교할 수 없습니다. 고정한 시험 화면이 필요합니다.

## 어떻게 (이 앱에서)

- (기반) 기록 → 재생 환경(RV2)
- 고정한 시험용 사이트(레거시 AS 접수 · 매뉴얼 · 관리자) × 과제 5개(로그인 · 접수 · 매뉴얼 요약 · 삭제 · 설정만)로 성공률 · 목표 달성 · 인젝션을 따른 비율 · 걸음
- 끝난 실행의 행동을 새 사이트에서 그대로 재생해 같은 최종 상태인지(결정적인 비교의 확인)
