# CU2 · 행동 계획 · 실행 (Action planning & execution)

**상태: ✅ 구현됨** — 클릭 · 입력 · 스크롤을 고르고 헤드리스 브라우저로 실행한다

## 원리

행동 계획은 목표와 지금 화면으로 다음 행동 하나를 고르는 것이고, 실행은 브라우저 자동화로 그 행동을 하는 것입니다.

## 왜 하는가

한 번에 여러 행동을 정하면 중간 화면 변화를 놓칩니다. 행동 하나 → 확인의 반복이 안전합니다.

## 어떻게 (이 앱에서)

- (기반) ReAct 에이전트(8a)
- 화면 하나 보고 행동 하나(click · type · select · check · navigate · back · done) JSON, 흉내 브라우저(표준 라이브러리 HTML 파서)가 폼 제출 · 링크를 사이트 상태 기계로 실행
- 성공은 에이전트의 말이 아니라 사이트 최종 상태로(티켓이 그 값으로 생겼나 · 지우면 안 되는 것이 남았나)

## 화면

- `/computer-use/run` — **화면 에이전트 실행**: 행동 · 상태 확인 · 승인 · 최종 상태 판정
