# CU2 · 행동 계획 · 실행 (Action planning & execution)

**상태: ⬜ 예정** — 클릭 · 입력 · 스크롤을 고르고 헤드리스 브라우저로 실행한다

## 원리

행동 계획은 목표와 지금 화면으로 다음 행동 하나를 고르는 것이고, 실행은 브라우저 자동화로 그 행동을 하는 것입니다.

## 왜 하는가

한 번에 여러 행동을 정하면 중간 화면 변화를 놓칩니다. 행동 하나 → 확인의 반복이 안전합니다.

## 어떻게 (이 앱에서)

- (기반) ReAct 에이전트(8a)
- (예정) 행동 도구(클릭 · 입력 · 스크롤 · 이동) · 헤드리스 브라우저

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cu_act` 에서 볼 수 있습니다.

## 앞으로 할 일
