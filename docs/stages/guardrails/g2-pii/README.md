# G2 · 개인정보 탐지 · 마스킹 (PII detection & masking)

**상태: ✅ 구현됨** — 주민번호 · 연락처 · 이름 같은 개인정보를 색인 전 · 답변 전에 찾아 가린다

## 원리

개인정보 탐지는 규칙(주민번호 · 전화번호 · 계좌 형식)과 개체명 인식(사람 이름 · 주소)을 섞어 찾고, 색인할 때(저장하지 않게) 또는 답변할 때(보여 주지 않게) 가립니다.

## 왜 하는가

사내 문서 · 상담 기록에는 개인정보가 섞여 있고, 한 번 벡터 DB 에 들어가면 어느 답변으로든 나올 수 있습니다. 판례처럼 이미 비식별된 공개본만 쓰는 것도 같은 이유입니다.

## 어떻게 (이 앱에서)

- 규칙 탐지: 주민 · 외국인등록번호(형식만 — 2020년 10월 이후 번호는 검증 숫자가 없음), 전화 · 이메일 · 카드(Luhn) · 계좌(앞뒤 문맥 낱말 필요) · 여권 · 운전면허 · 주소 · 이름(문맥 낱말 또는 '씨 · 님' 호칭 + 성씨)
- 답변 가리기: mask 이상에서 답의 개인정보를 가림. 스트리밍은 문장 단위로 모아 가림 — 번호가 조각(delta)으로 나뉘어 그대로 새지 않게
- 색인 전 점검: 컬렉션 문서별 개인정보 수, 원문 가리기(바뀐 문서로 표시 → 증분 갱신으로 벡터에서도 지움)

## 화면

- `/guardrails/check#pii` — **개인정보 점검**: 컬렉션 개인정보 수 · 가리기

## 앞으로 할 일

- NER 모델로 이름 · 주소 재현율 보강
- 사람 판정 표본으로 정밀도 재기
