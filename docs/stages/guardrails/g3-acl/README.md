# G3 · 권한별 검색 (ACL) (Access-controlled retrieval)

**상태: ✅ 구현됨** — 사용자가 볼 수 있는 문서만 검색 후보에 넣는다

## 원리

문서마다 볼 수 있는 부서 · 등급을 붙이고, 검색할 때 사용자의 권한으로 걸러 후보에서 뺍니다. 답변 후에 지우면 LLM 이 이미 읽은 뒤라 늦습니다.

## 왜 하는가

사내 RAG 의 가장 흔한 사고는 '권한 없는 문서가 근거로 나오는 것'입니다. 벡터 검색은 권한을 모르므로 따로 걸러야 합니다.

## 어떻게 (이 앱에서)

- 문서 메타 acl(그룹 목록, 비면 모두 공개)과 사용자 그룹(API_USERS) → 검색 전에 허용 문서만 남김(연결 계층 search.restrict, 메타 필터와 겹침)
- 허용 문서가 0개면 빈 결과 — '제한 없음'으로 읽지 않음
- 모든 문서를 보는 사용자(관리자)만 다른 그룹으로 검색해 볼 수 있음
- 유출 시험: 질문 세트를 그룹 권한으로 검색해 제한 문서가 후보에 나오는지

## 화면

- `/guardrails/access` — **권한 · 감사 · 라이선스**: 문서 권한 · 유출 시험, 감사 로그 · 무결성, 라이선스 점검
