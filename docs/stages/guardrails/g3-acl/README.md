# G3 · 권한별 검색 (ACL) (Access-controlled retrieval)

**상태: 🟡 기초 있음** — 사용자가 볼 수 있는 문서만 검색 후보에 넣는다

## 원리

문서마다 볼 수 있는 부서 · 등급을 붙이고, 검색할 때 사용자의 권한으로 걸러 후보에서 뺍니다. 답변 후에 지우면 LLM 이 이미 읽은 뒤라 늦습니다.

## 왜 하는가

사내 RAG 의 가장 흔한 사고는 '권한 없는 문서가 근거로 나오는 것'입니다. 벡터 검색은 권한을 모르므로 따로 걸러야 합니다.

## 어떻게 (이 앱에서)

- (있음) 검색 설정의 문서 제한(doc_ids) — 특정 문서들 안에서만 검색
- (예정) 문서 권한 메타데이터, 사용자 권한 → 검색 필터 자동 적용(벡터 DB 필터), 권한 누출 테스트

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gr_acl` 에서 볼 수 있습니다.

## 앞으로 할 일

- 문서 권한 메타데이터 · 필터
- 권한 누출 테스트
