# G4 · 출력 정책 검사 (Output policy checks)

**상태: 🟡 기초 있음** — 답변이 근거 · 질문 · 정책을 어기지 않는지 내보내기 전에 검사한다

## 원리

출력 검사는 답변을 사용자에게 보이기 전 마지막 관문입니다. 근거에 없는 내용, 질문과 상관없는 내용, 금지된 조언(의료 · 법률 단정), 내부 정보를 찾아 수정하거나 막습니다.

## 왜 하는가

법률 · 의료처럼 틀린 단정이 피해가 되는 분야는 '근거 인용'만으로 부족합니다 — 답 없는 질문을 13개 중 1개만 거절한 법률 실측이 그 예입니다.

## 어떻게 (이 앱에서)

- (있음) 답변 검증(근거 일치 · 질문 관련성 · 없는 인용 · 조문 · 판례 번호 검사), 근거에 없으면 거절 규칙
- (예정) 분야별 금지 정책(단정 · 개인 조언), 정책 위반 시 수정 · 거절, 정책 평가 세트

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gr_output` 에서 볼 수 있습니다.

## 앞으로 할 일

- 분야별 출력 정책
- 정책 평가 세트
