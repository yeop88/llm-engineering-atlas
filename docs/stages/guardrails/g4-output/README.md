# G4 · 출력 정책 검사 (Output policy checks)

**상태: ✅ 구현됨** — 답변이 근거 · 질문 · 정책을 어기지 않는지 내보내기 전에 검사한다

## 원리

출력 검사는 답변을 사용자에게 보이기 전 마지막 관문입니다. 근거에 없는 내용, 질문과 상관없는 내용, 금지된 조언(의료 · 법률 단정), 내부 정보를 찾아 수정하거나 막습니다.

## 왜 하는가

법률 · 의료처럼 틀린 단정이 피해가 되는 분야는 '근거 인용'만으로 부족합니다 — 답 없는 질문을 13개 중 1개만 거절한 법률 실측이 그 예입니다.

## 어떻게 (이 앱에서)

- 분야별 정책: 법률(결과 단정 → 고침) · 의료(진단 · 처방 단정) · 고객 지원(위험한 자가 조치 → 막음, 보증 · 환불 약속 → 고침) + 공통(내부 비밀)
- 근거 검증 결과와 함께 pass · fix · block 판정, enforce 에서 고친 글 · 막는 글로 바꿔 내보냄(검사 · 기록은 모든 모드)
- (있음) 답변 검증(근거 일치 · 질문 관련성 · 없는 인용 · 조문 · 판례 번호)

## 화면

- `/guardrails/check#policy` — **출력 정책**: 분야별 정책 규칙 · 즉석 검사
