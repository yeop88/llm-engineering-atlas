# G6 · 데이터 · 모델 라이선스 · 출처 (Data & model licensing)

**상태: ✅ 구현됨** — 자료 · 모델마다 출처 · 라이선스 · 사용 조건을 기록하고 상업 사용 가능 여부를 확인한다

## 원리

공개 데이터 · 모델은 라이선스(공공누리 · CC · openrail · 비상업)가 다르고, 학습 · 재배포 · 상업 사용 조건이 다릅니다. 수집할 때 출처와 라이선스를 문서마다 남겨야 나중에 걸러낼 수 있습니다.

## 왜 하는가

비상업 라이선스 모델 · 자료가 서비스에 섞이면 출시할 때 다시 만들어야 합니다.

## 어떻게 (이 앱에서)

- 문서 라이선스(공개 자료의 출처 정보) · 모델 카탈로그 라이선스 · LLM 이름으로 ok · warn(비상업 등) · unknown · block 판정
- 서비스 설정(컬렉션 · 인덱스 · 리랭커 · LLM)을 한 번에 점검

## 화면

- `/guardrails/access#license` — **라이선스 점검**: 자료 · 모델 라이선스 판정

## 앞으로 할 일

- 학습 데이터(미세조정 · 증류) 라이선스 추적
