# G6 · 데이터 · 모델 라이선스 · 출처 (Data & model licensing)

**상태: 🟡 기초 있음** — 자료 · 모델마다 출처 · 라이선스 · 사용 조건을 기록하고 상업 사용 가능 여부를 확인한다

## 원리

공개 데이터 · 모델은 라이선스(공공누리 · CC · openrail · 비상업)가 다르고, 학습 · 재배포 · 상업 사용 조건이 다릅니다. 수집할 때 출처와 라이선스를 문서마다 남겨야 나중에 걸러낼 수 있습니다.

## 왜 하는가

비상업 라이선스 모델 · 자료가 서비스에 섞이면 출시할 때 다시 만들어야 합니다.

## 어떻게 (이 앱에서)

- (있음) 공개 자료 가져오기의 문서별 출처 · 라이선스, 모델 카탈로그의 라이선스 · '비상업' 태그
- (예정) 서비스 설정의 라이선스 점검(비상업 자료 · 모델 사용 시 경고)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gr_license` 에서 볼 수 있습니다.
