# G5 · 접근 제어 · 감사 로그 (Access control & audit log)

**상태: 🟡 기초 있음** — 누가 언제 무엇을 묻고 어떤 문서를 근거로 받았는지 남기고, 접근을 토큰 · 권한으로 막는다

## 원리

감사 로그는 요청자 · 시각 · 질문 · 근거 문서 · 답변을 지울 수 없게 남긴 기록입니다. 사고가 났을 때 무엇이 나갔는지 확인하고, 접근 제어가 제대로 동작했는지 점검합니다.

## 왜 하는가

사내 · 법률 서비스는 '어떤 근거로 그렇게 답했나'를 나중에 설명해야 합니다. 실행 이력은 실험용이라 사용자 · 권한 정보가 없습니다.

## 어떻게 (이 앱에서)

- (있음) 선택형 접근 토큰(API_TOKEN) · 로그인, 실행 이력 · 작업 기록 저장
- (예정) 사용자 단위 인증 · 역할, 요청 감사 로그(질문 · 근거 문서 · 답변), 보관 기간

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/gr_audit` 에서 볼 수 있습니다.

## 앞으로 할 일

- 사용자 · 역할
- 요청 감사 로그
