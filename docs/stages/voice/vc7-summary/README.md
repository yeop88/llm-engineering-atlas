# VC7 · 통화 요약 · 후처리 (Call summary & wrap-up)

**상태: ✅ 구현됨** — 통화가 끝나면 요약 · 조치 · 다음 할 일을 정리해 티켓 · 고객 기록에 남긴다

## 원리

통화 후처리는 전사에서 문의 내용 · 진단 · 안내한 조치 · 약속(방문 일정)을 뽑아 정해진 양식으로 남기는 것입니다. 요약도 전사와 맞는지 검증합니다.

## 왜 하는가

상담원이 통화 후 정리에 쓰는 시간이 큽니다. 요약이 틀리면 다음 상담에서 잘못된 정보로 이어집니다.

## 어떻게 (이 앱에서)

- (기반) 대화 요약 메모리(C3) · 접수 티켓(AS7)
- 전사 → 양식(문의 · 제품 · 코드 · 진단 · 안내한 조치 · 해결 · 약속 · 다음 할 일), LLM 이 없으면 규칙 요약
- 항목마다 전사와 맞는지: 모델 · 코드 · 날짜는 표기 일치, 문장 항목은 글자 3-gram 겹침 — 맞지 않으면 '확인 필요', 해결 안 됐으면 요약을 담은 티켓, 전사는 개인정보를 가려 저장 · 보관 기간(VOICE_RETENTION_DAYS)
