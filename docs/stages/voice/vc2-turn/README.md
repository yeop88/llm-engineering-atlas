# VC2 · 말 끊기 · 끼어들기 (턴 관리) (Turn-taking & barge-in)

**상태: ✅ 구현됨** — 고객이 말을 끊거나 끼어들면 즉시 멈추고 듣고, 말이 끝나면 바로 응답한다

## 원리

턴 관리는 누가 말할 차례인지 정하는 것입니다. 고객이 말하는 동안 합성 음성을 멈추고(끼어들기 감지), 잠깐의 침묵이 말의 끝인지 생각 중인지 구분합니다.

## 왜 하는가

사람 상담원처럼 자연스럽지 않으면 고객이 같은 말을 반복하거나 끊습니다. 전화 상담 만족도의 큰 부분입니다.

## 어떻게 (이 앱에서)

- (기반) 되묻기(C2)
- 에너지 기반 말소리 감지(잡음 바닥을 따라가는 문턱) · 침묵 500ms 면 끝점 후보 → 인식한 글이 이어질 말('~는데' · '그리고')로 끝나면 1.4초까지 더 기다림
- 끼어들기: 소리가 나오는 동안 말소리가 200ms 이어지면 화면이 바로 멈추고(왕복 지연 없이) 몇 글자까지 읽었는지 기록
