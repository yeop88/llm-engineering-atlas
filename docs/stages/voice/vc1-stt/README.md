# VC1 · 스트리밍 음성 인식 (Streaming speech-to-text)

**상태: ✅ 구현됨** — 통화 음성을 말하는 도중에 글로 옮겨, 끝나기 전에 처리를 시작한다

## 원리

스트리밍 음성 인식(STT)은 음성을 작은 조각으로 받아 중간 결과를 계속 내놓습니다. 한국어 · 제품명 · 오류 코드를 잘 받아 적도록 용어 사전을 붙이고, 말이 끝났는지(끝점)를 판단합니다.

## 왜 하는가

통화가 끝난 뒤에 전사하면 응답이 늦습니다. 제품명 · 오류 코드를 잘못 받아 적으면 뒤의 검색이 모두 틀립니다.

## 어떻게 (이 앱에서)

- (기반) AS 상담의 음성 입력(STT_URL)
- 마이크 소리를 16kHz PCM 조각으로 받아 끝점 후보마다 그 조각만 인식(말하는 도중 처리 시작), 엔진은 OpenAI 호환 STT_URL 또는 로컬 Whisper
- 용어 사전(컬렉션의 제품 모델 · 오류 코드) 두 겹: 인식기 앞 문맥 + 받아 적은 소리의 표기 복원('이 사' → E4, '더블유엠 이백' → WM-200 — 짧은 코드는 코드를 말하는 문맥에서만)
- 평가: 녹음 + 정답 전사로 글자 오류율 · 용어 정확도 · 실시간 계수를 엔진 × (사전 없음 · 앞 문맥 · 앞 문맥 + 복원)으로
