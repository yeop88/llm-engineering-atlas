# VC4 · 스트리밍 음성 합성 (Streaming text-to-speech)

**상태: ⬜ 예정** — 생성되는 글을 문장 단위로 바로 음성으로 바꿔 들려준다

## 원리

스트리밍 음성 합성(TTS)은 LLM 이 문장을 다 쓰기 전에 앞 문장부터 소리로 바꿉니다. 숫자 · 단위 · 모델명을 읽는 규칙(예: 'E4' → '이 사')을 정합니다.

## 왜 하는가

글로는 괜찮은 답도 소리로는 길고 어렵습니다. 읽기 규칙이 틀리면 고객이 오류 코드를 잘못 알아듣습니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달 출력(MA8)의 음성 안내 계획
- (예정) 문장 단위 스트리밍 TTS · 숫자 · 코드 읽기 규칙

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/vc_tts` 에서 볼 수 있습니다.
