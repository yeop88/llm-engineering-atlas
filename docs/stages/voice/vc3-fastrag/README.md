# VC3 · 짧은 지연 RAG (Low-latency RAG)

**상태: ✅ 구현됨** — 음성에 맞게 1초 안팎으로 근거를 찾고 첫 문장을 낸다 — 캐시 · 짧은 근거 · 스트리밍

## 원리

짧은 지연 RAG 는 자주 묻는 질문은 캐시로, 나머지는 근거 수 · 길이를 줄이고 첫 문장을 먼저 생성해 흘려보냅니다. 긴 설명보다 짧은 단계 안내를 우선합니다.

## 왜 하는가

이 PC 에서 질문당 답변은 수십 초(근거 읽기 약 29초)였습니다. 음성은 그 수십 배 빨라야 하므로, 서빙 맵의 캐시 · 근거 길이 · 하드웨어 개선이 전제입니다.

## 어떻게 (이 앱에서)

- (기반) 캐시(S1) · 근거 길이 관리(S2) · 답변 스트리밍
- 지연 예산(VOICE_BUDGET_MS, 기본 1200ms)을 끝점 대기 · 인식 · 캐시 · 검색 · 첫 문장 · 첫 합성으로 나눠 턴마다 실측과 비교, 보고는 단계별 p50 · p95 · 예산 안 비율
- 음성용 설정: 의미 캐시 먼저 → 근거 2개 · 900자 · 2~3문장 · 첫 문장에 핵심 조치, 첫 문장부터 흘려보냄(서비스 답변 단계 그대로 — 입력 방어 · 검증 · 요청 기록)
