# VC6 · 상담원 실시간 보조 (Agent assist)

**상태: ⬜ 예정** — 자동 응답 대신 상담원 화면에 근거 · 추천 답 · 다음 질문을 실시간으로 띄운다

## 원리

상담원 보조는 통화 전사를 따라가며 관련 매뉴얼 근거 · 추천 답 · 확인할 질문을 띄우는 것입니다. 사람이 최종 판단을 하므로 자동 응답보다 위험이 낮습니다.

## 왜 하는가

완전 자동 음성 상담은 지연 · 정확도 모두 어렵습니다. 상담원 보조부터 시작하면 지금 기술로도 상담 시간을 줄일 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) FAQ · 매뉴얼 답변(AS3) · 상담원 이관(C6)
- (예정) 전사 따라가기 · 근거 띄우기 · 상담원 채택률 측정

## 화면
