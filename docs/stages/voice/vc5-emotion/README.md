# VC5 · 감정 · 불만 감지 (Emotion & escalation detection)

**상태: ✅ 구현됨** — 목소리와 말에서 불만 · 격앙을 감지해 말투를 바꾸거나 상담원에게 넘긴다

## 원리

감정 감지는 말의 내용(분류기)과 목소리의 특징(속도 · 높이)을 함께 봅니다. 불만이 커지면 사과 · 요약 · 상담원 연결을 먼저 제안합니다.

## 왜 하는가

화난 고객에게 같은 안내를 반복하면 상황이 나빠집니다. 이관 시점을 놓치지 않는 것이 핵심입니다.

## 어떻게 (이 앱에서)

- (기반) 의미 응용 분류기 · 이상 탐지
- 내용 점수(불만 표현 규칙) + 목소리 점수(같은 통화 첫 발화 대비 크기 · 높이 · 말 속도 변화)
- 이관 기준: 상담원 요청 · 강한 불만 · 불만 두 턴 이어짐 · 같은 문제 세 번 · 안전 문의 → 사과 + 상담원 연결 + 티켓, 그 전에도 불만이면 말투 지시(공감 · 사과 · 한 가지 조치)
