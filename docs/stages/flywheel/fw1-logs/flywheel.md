# 데이터 플라이휠 — 실패 분류 · 검토 · 분배 · 처방 · 게이트 · 단계적 배포 · 실측 (FW1~FW7)

화면은 `/flywheel/triage`(실패 분류 · 처방) · `/flywheel/review`(검토 · 자산 분배) · `/flywheel/release`(게이트 · 단계적 배포), 코드는 `app/stages/flywheel/` 입니다.

```
요청 기록 ─ 실패 분류(유형 · 추이) ─ 처방(싼 것부터) ─┐
    ↑                                               ├─ 사람 검토(우선순위 + 무작위) ─ 평가 세트 / 학습 데이터(누수 검사)
    │                                               └─ 고친 것 = 버전(검색 설정 · 방어 · LLM)
    │                                                      ↓
    └── 단계적 배포(5 → 25 → 50 → 100%, 기본 검색 설정에서) ← 게이트(회귀 짝 비교 + 레드팀) ← 감시 · 자동 롤백
```

## 설계

- **분류는 한 곳에서.** 실패 분류 규칙은 개선 루프(E8)의 것을 그대로 쓰고 두 유형만 더합니다 — 형식 오류(서비스 오류 · 빈 답), 확신도 낮은데 답함(검색 1 · 2위 차이 0.02 미만인데 거절하지 않음). 같은 실패를 두 화면이 다르게 세면 어느 숫자를 믿을지 모르게 됩니다.
- **처방은 싼 것부터.** 실패 유형 분포 → 설정 · 규칙(분 단위) → 사람 검토 · 평가 세트 → 자료 보강 · 재색인(수십 분) → 임베딩 재학습 · LLM 후학습(시간 · 일). 이 프로젝트의 실측에서 실패 대부분은 검색 설정 · 거절 기준 · 규칙으로 고쳐졌습니다.
- **검토 순서.** 사람의 시간을 가장 배울 것이 많은 사례에 먼저: 싫어요 > 근거 일치가 기준값 근처(0.5~0.7 — 자동으로 맞는지 틀리는지 가를 수 없음) > 실패 분류에 걸림 > 확신도 낮음. 그리고 20%는 무작위 표본입니다 — 규칙에 걸린 것만 보면 규칙 밖의 실패는 영영 보이지 않습니다. 같은 질문은 한 번만.
- **분배와 누수.** 평가로 보낸 사례(재발 방지)와 학습으로 보낸 사례(교정)가 섞이면 평가가 학습 데이터를 맞히는 셈입니다. 반대쪽에 같은 · 아주 비슷한 질문(글자 바이그램 겹침 0.8 이상)이 있으면 막고 이유를 남깁니다. 평가로 보낼 때는 정답 문서를 사람이 고릅니다 — 틀린 답의 근거를 정답으로 넣으면 안 됩니다.
- **버전과 게이트.** 바꾼 것(검색 설정 · 방어 모드 · LLM)을 버전 하나로 묶고(`fw_versions`, 마이그레이션 0016), 회귀 세트마다 저장한 기준선과 같은 질문으로 짝지어 비교합니다(nDCG@10 −0.02 · hit@5 −0.03 까지 허용, 짝 비교가 유의하게 나빠지면 막음). 레드팀은 후보의 방어 모드 · LLM 으로 같은 공격 문항을 돌려 같은 방어 모드의 최근 결과와 비교합니다. 평균이 올라도 한 세트 · 한 공격 유형이 떨어지면 통과하지 못합니다.
- **배포는 기본 검색 설정에서.** 서비스(AS · 대화 · 답변 · 업무)는 모두 연결 계층의 기본 검색 설정(`pipeline/search.default_config`)을 받으므로, 거기서 배포 중인 버전을 요청의 pct% 에 내보내면 한 곳에서 모두 바뀝니다. 요청 기록에 `signals.version` · `arm` 이 남아 두 팔을 비교합니다. 요청마다 무작위로 나눕니다 — 서비스마다 사용자 키가 달라 생긴 한계로, 같은 사용자도 두 버전을 볼 수 있습니다.
- **감시 · 자동 롤백.** 같은 기간 후보 팔과 나머지를 근거 일치(−0.05) · 거절률(+0.10) · 싫어요(+0.10)로 비교하고(후보 20건 이상부터), 나빠지면 되돌립니다. `FLYWHEEL_WATCH_HOURS` 를 정하면 주기 스레드가 사람을 기다리지 않고 롤백하고, 다음 비율로 올리는 것은 `FLYWHEEL_AUTO_ADVANCE` 일 때만입니다(기본은 사람이). 100% 다음은 현재 버전으로 승격, 이전 현재 버전은 물러납니다.
