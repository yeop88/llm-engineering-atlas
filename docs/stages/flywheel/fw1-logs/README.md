# FW1 · 서비스 로그 수집 (Production logs)

**상태: 🟡 기초 있음** — 질문 · 단계 · 근거 · 답변 · 검증 결과 · 피드백을 요청마다 남겨 순환의 원료로 쓴다

## 원리

플라이휠의 원료는 서비스 기록입니다. 요청마다 질문 · 사용한 설정 버전 · 근거 · 답변 · 검증 점수 · 사용자 피드백을 한 묶음으로 남겨야, 나중에 실패를 분류하고 다시 재현할 수 있습니다.

## 왜 하는가

기록이 측정 때만 있으면 실제 사용자 질문의 분포 · 실패를 모릅니다. 평가 세트가 실제와 멀어지는 원인입니다.

## 어떻게 (이 앱에서)

- (있음) 실행 이력 · 작업 기록(재시작해도 남음), 연결 비교의 질문별 기록, 답변 검증 결과
- (예정) 서비스 요청 단위 기록(설정 버전 포함) · 보관 기간 · 개인정보 마스킹

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/fw_logs` 에서 볼 수 있습니다.

## 앞으로 할 일

- 요청 단위 기록 · 설정 버전
- 보관 기간 · 마스킹
