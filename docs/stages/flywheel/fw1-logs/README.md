# FW1 · 서비스 로그 수집 (Production logs)

**상태: ✅ 구현됨** — 질문 · 단계 · 근거 · 답변 · 검증 결과 · 피드백을 요청마다 남겨 순환의 원료로 쓴다

## 원리

플라이휠의 원료는 서비스 기록입니다. 요청마다 질문 · 사용한 설정 버전 · 근거 · 답변 · 검증 점수 · 사용자 피드백을 한 묶음으로 남겨야, 나중에 실패를 분류하고 다시 재현할 수 있습니다.

## 왜 하는가

기록이 측정 때만 있으면 실제 사용자 질문의 분포 · 실패를 모릅니다. 평가 세트가 실제와 멀어지는 원인입니다.

## 어떻게 (이 앱에서)

- 서비스 답변(RAG · AS · 대화 · GraphRAG · A2A · 멀티에이전트 · 업무)의 요청 기록을 원료로 — 종류별 수 · 보관 기한까지 한 화면에
- 배포 중인 버전이 있으면 요청 기록 signals.version 으로 어느 버전의 답인지 남김
