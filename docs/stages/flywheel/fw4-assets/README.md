# FW4 · 평가 세트 · 학습 데이터로 변환 (Turn reviews into assets)

**상태: ✅ 구현됨** — 검토한 사례를 평가 세트(재발 방지)와 학습 데이터(교정)로 나눠 보내고, 둘이 섞이지 않게 한다

## 원리

같은 실패 사례를 평가 세트와 학습 데이터 양쪽에 넣으면 평가가 부풀려집니다. 사례를 나눠 보내고, 평가 세트에 들어간 사례의 근거 지문은 학습에서 뺍니다.

## 왜 하는가

순환에서는 누수가 쉽게 생깁니다 — 어제 학습한 사례로 오늘 평가하면 개선이 아니라 암기를 잽니다.

## 어떻게 (이 앱에서)

- 평가로: 컬렉션의 '플라이휠 회귀 후보' 평가 세트에 정답 문서와 함께(정답 없으면 막음), 학습으로: 학습 데이터 JSONL(질문 · 고친 답 · 정답 문서)
- 반대쪽에 같은 · 아주 비슷한 질문(글자 바이그램 겹침 0.8 이상)이 있으면 누수로 막고 이유를 남김
