# FW5 · 재학습 · 재색인 (Retrain & reindex)

**상태: 🟡 기초 있음** — 고칠 곳에 따라 임베딩 재학습 · 재색인 · 프롬프트 · LLM 후학습 중 가장 싼 것부터 한다

## 원리

실패 유형에 따라 처방이 다릅니다 — 검색 실패는 청킹 · 임베딩 파인튜닝 · 재색인, 인용 · 관련성 실패는 프롬프트 · LLM 후학습, 거절 실패는 선호 학습. 가장 싼 처방부터 시도합니다.

## 왜 하는가

모델 재학습은 비싸고 느립니다. 프롬프트 규칙 하나(답변 규칙 5번)나 규칙 기반 도구 선택(번호 조회)으로 해결되는 경우가 많았습니다.

## 어떻게 (이 앱에서)

- (있음) 임베딩 파인튜닝 · 증류, 청크 세트 · 인덱스 다시 만들기, 프롬프트 규칙 수정
- (예정) 실패 유형 → 처방 추천, LLM 후학습(GPU)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/fw_retrain` 에서 볼 수 있습니다.
