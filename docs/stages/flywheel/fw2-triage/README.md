# FW2 · 실패 자동 분류 (Failure triage)

**상태: ⬜ 예정** — 실패를 검색 실패 · 인용 실패 · 질문과 상관없는 답 · 거절 실패 · 형식 오류로 자동 분류한다

## 원리

검증 점수와 피드백으로 실패 유형을 나눕니다 — 정답 근거가 검색되지 않음(검색), 검색됐지만 인용 안 함(답변), 근거에 있지만 질문과 상관없음(관련성), 답 없는 질문에 답함(거절). 유형마다 고칠 곳이 다릅니다.

## 왜 하는가

실패를 한 덩어리로 보면 '모델을 바꾸자'로만 이어집니다. 법률 실측에서 RAG 의 실패는 검색(56%)이었고, 에이전트의 실패는 같은 검색 결과에서 인용을 덜 한 것이었습니다 — 원인이 달랐습니다.

## 어떻게 (이 앱에서)

- (기반) 개선 루프(E8)의 실패 분류 계획, 검증 에이전트(MA7)의 검사 점수
- (예정) 검증 점수 · 피드백 이유로 유형 자동 분류, 유형별 추이

## 화면

- 유형별 추이
