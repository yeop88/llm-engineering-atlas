# FW6 · 회귀 · 안전성 게이트 (Regression & safety gate)

**상태: ⬜ 예정** — 새 버전은 고정 회귀 세트 · 레드팀 세트를 같은 조건으로 통과해야 배포 후보가 된다

## 원리

게이트는 '나빠지지 않았음'을 확인하는 자동 관문입니다. 도메인 회귀 세트 · 일반 능력 · 공격 세트를 같은 조건(캐시 · 시드 · 세트 버전)으로 돌려, 유의한 하락이 없을 때만 통과시킵니다.

## 왜 하는가

순환이 빨라질수록 사람이 매번 확인할 수 없습니다. 게이트 없이 자동 재학습을 돌리면 조용한 품질 하락이 쌓입니다.

## 어떻게 (이 앱에서)

- (기반) 오프라인 평가 · 회귀(E2), 레드팀(G7)
- (예정) 게이트 기준(지표별 허용 하락폭) · 자동 실행 · 통과 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/fw_gate` 에서 볼 수 있습니다.
