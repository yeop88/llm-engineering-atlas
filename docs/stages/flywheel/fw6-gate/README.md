# FW6 · 회귀 · 안전성 게이트 (Regression & safety gate)

**상태: ✅ 구현됨** — 새 버전은 고정 회귀 세트 · 레드팀 세트를 같은 조건으로 통과해야 배포 후보가 된다

## 원리

게이트는 '나빠지지 않았음'을 확인하는 자동 관문입니다. 도메인 회귀 세트 · 일반 능력 · 공격 세트를 같은 조건(캐시 · 시드 · 세트 버전)으로 돌려, 유의한 하락이 없을 때만 통과시킵니다.

## 왜 하는가

순환이 빨라질수록 사람이 매번 확인할 수 없습니다. 게이트 없이 자동 재학습을 돌리면 조용한 품질 하락이 쌓입니다.

## 어떻게 (이 앱에서)

- 바꾼 것(검색 설정 · 방어 모드 · LLM)을 버전(fw_versions)으로, 게이트 = 회귀 세트마다 기준선과 같은 질문으로 짝 비교(nDCG −0.02 · hit@5 −0.03 까지 허용, 유의한 하락이면 막음) + 같은 공격의 레드팀(같은 방어 모드의 최근 결과보다 떨어지면 막음)
- 평균이 올라도 한 세트 · 한 공격 유형이 떨어지면 통과하지 못함
