# FW7 · 단계적 배포 · 롤백 (Staged rollout & rollback)

**상태: ✅ 구현됨** — 게이트를 통과한 버전을 일부 사용자부터 내보내고, 지표가 나빠지면 즉시 이전 버전으로 되돌린다

## 원리

단계적 배포(카나리)는 새 버전을 5% → 25% → 100% 로 넓히며 실제 지표(피드백 · 거절률 · 지연)를 비교하는 것입니다. 나빠지면 버전 하나만 바꿔 되돌립니다.

## 왜 하는가

오프라인 게이트를 통과해도 실제 사용자에게는 나쁠 수 있습니다(보상과 품질이 어긋난 Best-of 처럼).

## 어떻게 (이 앱에서)

- 연결 계층의 기본 검색 설정이 배포 중인 버전을 요청의 pct% 에 — AS · 대화 · 답변이 함께 바뀜(요청마다 무작위)
- 같은 기간 후보 팔 vs 나머지의 근거 일치 · 거절률 · 싫어요를 비교(후보 20건 이상), 나빠지면 롤백(FLYWHEEL_WATCH_HOURS 면 자동) · 좋으면 다음 비율, 100% 다음은 현재 버전으로 승격
