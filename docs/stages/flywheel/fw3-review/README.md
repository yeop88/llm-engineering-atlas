# FW3 · 사람 검토 우선순위 (Review prioritization (active learning))

**상태: 🟡 기초 있음** — 사람의 검토 시간을 가장 배울 것이 많은 사례(자동 판정이 애매한 것 · 새 유형)에 먼저 쓴다

## 원리

능동 학습은 모델이 가장 헷갈리는 사례(점수가 기준값 근처)와 대표성 있는 표본을 골라 사람에게 먼저 보여 주는 방법입니다. 같은 라벨 수로 더 많이 배웁니다.

## 왜 하는가

사람 판정은 비쌉니다 — 이 프로젝트에서 판정 28개로 검증 기준을 처음 맞췄습니다. 무작위로 고르면 쉬운 사례에 시간을 씁니다.

## 어떻게 (이 앱에서)

- (있음) 검증 보정 화면(근거 일치 · 질문 관련성 판정), 일치도 · 기준 탐색
- (예정) 기준값 근처 · 새 유형 · 무작위 표본을 섞어 검토 순서 정하기

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/fw_review` 에서 볼 수 있습니다.
