# FW4 · 평가 세트 · 학습 데이터로 변환 (Turn reviews into assets)

**상태: 🟡 기초 있음** — 검토한 사례를 평가 세트(재발 방지)와 학습 데이터(교정)로 나눠 보내고, 둘이 섞이지 않게 한다

## 원리

같은 실패 사례를 평가 세트와 학습 데이터 양쪽에 넣으면 평가가 부풀려집니다. 사례를 나눠 보내고, 평가 세트에 들어간 사례의 근거 지문은 학습에서 뺍니다.

## 왜 하는가

순환에서는 누수가 쉽게 생깁니다 — 어제 학습한 사례로 오늘 평가하면 개선이 아니라 암기를 잽니다.

## 어떻게 (이 앱에서)

- (있음) 평가 세트 근거 보정 · 보충, 학습 데이터의 평가 근거 제외(여러 근거 모두)
- (예정) 검토 사례 → 평가 / 학습 자동 분배 · 누수 검사

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/fw_assets` 에서 볼 수 있습니다.

## 앞으로 할 일
