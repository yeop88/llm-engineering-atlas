# TA1 · 토큰화 (Tokenization)

**상태: ⬜ 예정** — 글을 토큰으로 — 구조 맵에서는 토큰 수가 모든 비용의 단위

## 원리

토큰화는 글을 모델이 읽는 단위로 나누는 첫 단계입니다. 구조 맵에서는 '한국어 한 글자가 몇 토큰인가'가 맥락 · KV · 시간 비용을 모두 곱하는 계수라는 점만 봅니다(자세한 것은 토크나이저 맵).

## 왜 하는가

같은 글도 모델마다 토큰 수가 1.5 배까지 다릅니다. 이 계수를 빼고 구조를 비교하면 맥락 비용 비교가 틀립니다.

## 어떻게 (이 앱에서)

- (기반) 토크나이저 맵(TK2)
- (예정) 모델별 글자당 토큰 계수를 구조 비용 계산에 곱함

## 화면
