# TA6 · 출력 헤드 (Output head)

**상태: ✅ 구현됨** — 마지막 정규화 · 출력층 · 로짓 처리(소프트캡 등)가 비용 · 신호에 주는 영향

## 원리

출력 헤드는 마지막 은닉 상태를 어휘 크기의 로짓으로 바꾸는 층입니다. 어휘가 크면 토큰마다 읽는 양의 큰 몫이고, 로짓 소프트캡 같은 처리는 확신도 신호를 바꿉니다.

## 왜 하는가

작은 모델에서는 출력층이 토큰당 읽는 양의 1/4 을 넘기도 합니다. 확신도 기반 라우팅 · 환각 탐지도 이 층의 출력에 기대므로 처리 방식을 알아야 합니다.

## 어떻게 (이 앱에서)

- (기반) 내부 환각 탐지(IP6)
- 토큰마다 읽는 양에서 출력층(어휘 × 은닉)이 차지하는 몫 — 작은 모델일수록 크다
