# TA4 · FFN · 전문가 (FFN & experts)

**상태: ⬜ 예정** — 밀집 FFN 과 MoE 전문가(공용 전문가 포함)의 크기 · 쓰는 몫을 비교한다

## 원리

FFN 은 층마다 가장 큰 가중치입니다. MoE 는 FFN 을 전문가 여러 개로 나누고 토큰마다 몇 개만 씁니다. 공용 전문가는 모든 토큰이 씁니다.

## 왜 하는가

MoE 는 메모리(전부 올려야 함)는 그대로이고 토큰마다 읽는 양(속도)을 줄입니다. 이 차이가 '어디에 둘까'(BM3)를 정합니다.

## 어떻게 (이 앱에서)

- (기반) 전문가 오프로드 · 쓰임(BM3)
- (예정) 전체 · 활성 비율 · 공용 전문가 몫 · 메모리 대 연산 그림
