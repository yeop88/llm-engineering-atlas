# TA5 · 전문가 라우팅 (Expert routing)

**상태: ⬜ 예정** — 라우터가 토큰마다 전문가를 고르는 방식과 쓰임 치우침을 잰다

## 원리

전문가 라우팅은 라우터(작은 선형층)가 토큰마다 점수를 매겨 상위 k 전문가를 고르는 것입니다. 쓰임이 고르면 모든 전문가가 필요하고, 치우치면 일부만 빠른 곳에 둬도 됩니다.

## 왜 하는가

'MoE 는 언제 메모리보다 연산을 줄여 주나'의 답이 여기 있습니다 — 쓰임 분포를 재야 전문가 캐시가 의미 있는지 압니다.

## 어떻게 (이 앱에서)

- (기반) 전문가 쓰임 · 캐시 적중(BM3)
- (예정) 실제 작은 MoE 의 층별 쓰임 · 한국어 · 코드 · 영어 글별 차이
