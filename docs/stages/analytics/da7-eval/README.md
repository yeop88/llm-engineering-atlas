# DA7 · 실행 정확도 평가 (Execution accuracy)

**상태: ✅ 구현됨** — 정답 SQL 과 결과가 같은지(실행 정확도)를 질문 유형별로 잰다

## 원리

실행 정확도는 생성한 SQL 과 정답 SQL 의 실행 결과가 같은지로 채점하는 것입니다. SQL 글자가 달라도 결과가 같으면 맞습니다.

## 왜 하는가

글자 비교는 같은 뜻의 다른 SQL 을 틀렸다고 합니다. 유형(집계 · 조인 · 날짜 · 비율)별로 어디서 틀리는지 봐야 고칠 곳을 압니다.

## 어떻게 (이 앱에서)

- (기반) 평가 세트(E1)
- 예시 자료 질문 24개(집계 · 날짜 · 조인 · 비율 · 상위 · NULL)의 정답 SQL 결과와 비교 — 순서 있는 질문만 순서까지, 수 반올림, 설명 열을 더 붙여도 맞음
- 방식(연결 · 전체 스키마 · 의미 계층)별 정답률 · 유형별 · 연결 재현율 · 평균 시도 · 고쳐서 맞힌 수
