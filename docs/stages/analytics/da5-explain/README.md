# DA5 · 결과 해석 · 차트 (Answer & visualization)

**상태: ⬜ 예정** — 결과 표를 문장 · 차트로 바꾸고 숫자는 결과에서만 쓴다

## 원리

결과 해석은 표를 질문에 맞는 문장 · 차트로 바꾸는 것입니다. 숫자는 결과 표에서만 가져오고, 어떤 SQL 로 얻었는지 함께 보입니다.

## 왜 하는가

LLM 이 결과를 요약하며 숫자를 바꾸거나 지어낼 수 있습니다. 결과와 문장의 숫자가 같은지 검사합니다.

## 어떻게 (이 앱에서)

- (기반) 분석 에이전트(MA5) · 지어낸 숫자 검사(LR6)
- (예정) 결과 → 문장 · 차트, 숫자 일치 검사, SQL 함께 보이기

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/da_explain` 에서 볼 수 있습니다.
