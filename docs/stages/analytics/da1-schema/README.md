# DA1 · 스키마 연결 (Schema linking)

**상태: ⬜ 예정** — 표 · 열 설명 · 예시 값으로 질문과 관련된 표 · 열을 고른다

## 원리

스키마 연결은 질문의 낱말을 표 · 열에 잇는 것입니다. 열 이름만으로는 뜻을 모르므로 설명 · 예시 값 · 관계를 함께 줍니다.

## 왜 하는가

표가 많으면 전체 스키마를 맥락에 넣을 수 없고, 엉뚱한 표를 고르면 SQL 전체가 틀립니다.

## 어떻게 (이 앱에서)

- (기반) 온톨로지(K2)
- (예정) 표 · 열 설명 카드 · 질문-열 연결 · 연결 정확도

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/da_schema` 에서 볼 수 있습니다.
