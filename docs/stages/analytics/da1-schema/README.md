# DA1 · 스키마 연결 (Schema linking)

**상태: ✅ 구현됨** — 표 · 열 설명 · 예시 값으로 질문과 관련된 표 · 열을 고른다

## 원리

스키마 연결은 질문의 낱말을 표 · 열에 잇는 것입니다. 열 이름만으로는 뜻을 모르므로 설명 · 예시 값 · 관계를 함께 줍니다.

## 왜 하는가

표가 많으면 전체 스키마를 맥락에 넣을 수 없고, 엉뚱한 표를 고르면 SQL 전체가 틀립니다.

## 어떻게 (이 앱에서)

- (기반) 온톨로지(K2)
- 분석 자료는 앱 DB 가 아닌 별도 파일(예시 AS 자료 · 앱 기록의 분석용 열만), 표 · 열 설명 + 실제 예시 값(개인정보 열 제외) 스키마 카드
- 질문 낱말 → 동의어 · 열 설명 · 예시 값 겹침으로 표 · 열 점수, 고른 표 + 외래 키로 이어진 표만 맥락에 — 연결 재현율(정답 SQL 의 표를 모두 골랐나)
