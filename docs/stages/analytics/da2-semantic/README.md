# DA2 · 지표 정의 (의미 계층) (Semantic layer)

**상태: ✅ 구현됨** — '재방문 비율' 같은 업무 지표를 정의로 고정해 LLM 이 계산식을 만들지 않게 한다

## 원리

의미 계층은 업무 지표 · 차원을 미리 정의해 두고 LLM 은 정의를 고르기만 하게 하는 것입니다. 같은 지표가 사람 · 질문마다 다르게 계산되지 않습니다.

## 왜 하는가

LLM 이 '재방문'을 매번 다르게 해석하면 같은 질문에 다른 숫자가 나옵니다. 숫자의 정의는 사람이 정해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 요구사항 · 역량 질문(K1)
- 지표(접수 건수 · 해결률 · 평균 만족도 · 티켓 수 · 재방문율 · 상담원 처리 비율)를 SQL 식으로 고정
- LLM 은 {지표, 차원, 필터, 기간} JSON 만 고르고 SQL 은 정해진 규칙으로 — 정의에 없는 지표 · 차원은 SQL 을 만들지 않음, 직접 SQL 생성과 실행 정확도 비교
