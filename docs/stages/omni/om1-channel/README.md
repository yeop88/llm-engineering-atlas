# OM1 · 채널 통합 세션 (Unified omni-channel session)

**상태: ✅ 구현됨** — 채팅 · 메신저 · 이메일 · 전화 · 영상을 같은 메시지 봉투와 고객 세션으로 묶는다

## 원리

채널 통합은 채널마다 다른 메시지 모양을 하나의 봉투(누가 · 어느 채널 · 무엇을 · 첨부)로 바꾸고, 같은 고객이면 채널이 달라도 같은 세션에 잇는 것입니다.

## 왜 하는가

채널마다 따로 대화를 시작하면 고객이 같은 설명을 반복합니다. 고객 식별 · 세션 잇기가 옴니채널의 출발점입니다.

## 어떻게 (이 앱에서)

- (기반) 문의 접수(AS1) · 고객 프로필(C4)
- 채널 어댑터 7종(웹 채팅 · 메신저 · 카톡형 · 문자 · 이메일 · 전화 · 영상) → 봉투(누가 · 채널 · 글 · 첨부 · 보낸 시각 · 외부 id), 웹훅 /api/omni/webhook/{채널}
- 고객 식별: 같은 채널 주소 → 같은 고객, 전화번호(메신저 프로필 · 계정에 확인된 번호 포함)는 채널을 넘어 같은 고객 — 추측으로 묶지 않음, 열린 세션(72시간)에 이어 붙임

## 화면

- `/omni/inbox` — **통합 받은 편지함**: 채널 흉내 · 세션 · 넘김 요약 · 대기열 훈련
