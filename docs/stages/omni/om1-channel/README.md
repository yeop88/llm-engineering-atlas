# OM1 · 채널 통합 세션 (Unified omni-channel session)

**상태: ⬜ 예정** — 채팅 · 메신저 · 이메일 · 전화 · 영상을 같은 메시지 봉투와 고객 세션으로 묶는다

## 원리

채널 통합은 채널마다 다른 메시지 모양을 하나의 봉투(누가 · 어느 채널 · 무엇을 · 첨부)로 바꾸고, 같은 고객이면 채널이 달라도 같은 세션에 잇는 것입니다.

## 왜 하는가

채널마다 따로 대화를 시작하면 고객이 같은 설명을 반복합니다. 고객 식별 · 세션 잇기가 옴니채널의 출발점입니다.

## 어떻게 (이 앱에서)

- (기반) 문의 접수(AS1) · 고객 프로필(C4)
- (예정) 메시지 봉투 · 채널 어댑터(웹훅) · 고객 식별 · 세션 잇기

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/om_channel` 에서 볼 수 있습니다.

## 앞으로 할 일

- 메시지 봉투 · 채널 어댑터(웹훅) · 고객 식별 · 세션 잇기
