# OM8 · 옴니 평가 (Omni-channel evaluation)

**상태: ✅ 구현됨** — 채널을 바꾸는 시나리오로 맥락 이어짐 · 채널별 지연 · 답의 일관성을 잰다

## 원리

옴니 평가는 '채팅 → 영상 → 메신저' 같은 시나리오를 돌려, 앞 채널에서 말한 것을 기억하는지 · 채널마다 지연이 예산 안인지 · 같은 질문에 채널마다 같은 내용을 답하는지를 재는 것입니다.

## 왜 하는가

채널마다 따로 재면 채널을 넘나들 때 생기는 문제(맥락 잃음 · 중복 답)를 놓칩니다.

## 어떻게 (이 앱에서)

- (기반) 평가 세트(E1)
- 채널 바꿈 시나리오 6개(채팅 → 영상, 카톡형 재전송 → 문자, 전화 끊김 → 메신저, 이메일 → 채팅, 영상 앞 장면, 문자 개인정보)를 실제 웹훅 모양으로
- 답에 필요한 표기 · 넘김 요약의 사실 · 같은 세션 · 재전송 한 번만 · 형식 준수 · 채널별 지연 예산 · 같은 질문의 채널 간 핵심 표기 일치
