# OM5 · 채널 간 이어 가기 (Cross-channel continuity)

**상태: ⬜ 예정** — 채팅에서 전화로, 통화가 끊기면 메신저로 — 같은 맥락을 이어 간다

## 원리

채널 간 이어 가기는 채널을 바꿀 때 세션 요약 · 미해결 질문 · 다음 할 일을 넘겨, 새 채널에서 처음부터 다시 묻지 않게 하는 것입니다.

## 왜 하는가

전화로 바꿨더니 상담원이 처음부터 다시 묻는 것이 가장 큰 불만입니다. 넘길 것을 정해 두어야 합니다.

## 어떻게 (이 앱에서)

- (기반) 상담원 이관(C6)
- (예정) 넘김 요약 · 미해결 질문 · 채널 바꿈 시험
