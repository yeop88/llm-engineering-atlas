# OM4 · 멀티모달 턴 융합 (Multimodal turn fusion)

**상태: ✅ 구현됨** — 음성 · 지금 프레임 · 첨부를 한 턴으로 합치고 '이거' 같은 가리킴을 푼다

## 원리

턴 융합은 같은 순간의 말 · 화면 · 첨부를 하나의 질문으로 합치는 것입니다. '이거 뭐예요?' 의 '이거'를 지금 프레임의 물체로, '아까 그거'를 앞 장면으로 풉니다.

## 왜 하는가

말만 보면 '이거'가 무엇인지 모르고, 화면만 보면 무엇을 묻는지 모릅니다.

## 어떻게 (이 앱에서)

- (기반) 맥락 재작성(C1) · 영상 장면 색인(OM3)
- '이거 · 여기 · 이 표시' → 말한 순간의 장면, '아까 · 처음' → 앞 장면(낱말이 겹치는 장면 먼저), 장면의 코드 · 앞 채널의 제품을 검색 질문에
- LLM 에는 원래 질문 + 장면 설명(시스템) + 그 프레임 사진 — 바꿔 쓴 질문이 틀려도 사진으로 바로잡게

## 화면

- `/omni/live#fuse` — **말 + 화면으로 묻기**: 가리킴 풀기 · 장면 프레임 함께
