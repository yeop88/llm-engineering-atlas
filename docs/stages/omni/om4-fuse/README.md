# OM4 · 멀티모달 턴 융합 (Multimodal turn fusion)

**상태: ⬜ 예정** — 음성 · 지금 프레임 · 첨부를 한 턴으로 합치고 '이거' 같은 가리킴을 푼다

## 원리

턴 융합은 같은 순간의 말 · 화면 · 첨부를 하나의 질문으로 합치는 것입니다. '이거 뭐예요?' 의 '이거'를 지금 프레임의 물체로, '아까 그거'를 앞 장면으로 풉니다.

## 왜 하는가

말만 보면 '이거'가 무엇인지 모르고, 화면만 보면 무엇을 묻는지 모릅니다.

## 어떻게 (이 앱에서)

- (기반) 맥락 재작성(C1)
- (예정) 말 · 프레임 · 첨부 묶기 · 가리킴 풀기 · 융합 전후 정답률

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/om_fuse` 에서 볼 수 있습니다.

## 앞으로 할 일

- 말 · 프레임 · 첨부 묶기 · 가리킴 풀기 · 융합 전후 정답률
