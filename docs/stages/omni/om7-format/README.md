# OM7 · 채널별 응답 형식 (Channel-specific rendering)

**상태: ⬜ 예정** — 같은 답을 음성은 짧게 · 채팅은 단계로 · 문자는 글자 수 안에 바꾼다

## 원리

채널별 응답 형식은 같은 내용을 채널의 제약(음성 길이 · 메신저 버튼 · 문자 글자 수 · 이메일 형식)과 정책(채널별 개인정보 표시)에 맞게 바꾸는 것입니다.

## 왜 하는가

채팅용 번호 목록을 그대로 읽어 주거나, 문자에 링크 · 표를 보내면 쓸 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 읽기 규칙(VC4) · 출력 검사(G4)
- (예정) 채널별 형식 규칙 · 길이 · 버튼 · 채널별 개인정보 정책

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/om_format` 에서 볼 수 있습니다.

## 앞으로 할 일

- 채널별 형식 규칙 · 길이 · 버튼 · 채널별 개인정보 정책
