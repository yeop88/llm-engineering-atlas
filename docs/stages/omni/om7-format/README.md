# OM7 · 채널별 응답 형식 (Channel-specific rendering)

**상태: ✅ 구현됨** — 같은 답을 음성은 짧게 · 채팅은 단계로 · 문자는 글자 수 안에 바꾼다

## 원리

채널별 응답 형식은 같은 내용을 채널의 제약(음성 길이 · 메신저 버튼 · 문자 글자 수 · 이메일 형식)과 정책(채널별 개인정보 표시)에 맞게 바꾸는 것입니다.

## 왜 하는가

채팅용 번호 목록을 그대로 읽어 주거나, 문자에 링크 · 표를 보내면 쓸 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 읽기 규칙(VC4) · 출력 검사 · 개인정보 탐지(G2 · G4)
- 음성 두 문장 · 읽는 글 + '문자로 보내 드릴까요', 문자 70자 · 링크 · 마크다운 · 근거 번호 없음, 메신저 단계 줄 + 빠른 답장 버튼, 이메일 인사 · 각주, 채팅 마크다운
- 채널별 개인정보 정책(문자 · 메신저 · 음성은 연락처까지 가림), 형식 위반 검사(render.check)

## 화면
