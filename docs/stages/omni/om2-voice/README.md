# OM2 · 실시간 음성 대화 (Real-time voice conversation)

**상태: ⬜ 예정** — 말하는 도중 인식 · 끼어들기 · 문장 단위 합성으로 사람처럼 주고받는다

## 원리

실시간 음성 대화는 인식 결과를 말하는 도중 확정해 나가고(앞부분이 두 번 같게 나오면 확정), 끼어들면 멈추며, 답을 문장 단위로 합성해 들려주는 양방향 대화입니다.

## 왜 하는가

통화가 끝나야 인식하면 늦고, 확정하지 않은 인식으로 검색하면 틀린 근거를 찾습니다.

## 어떻게 (이 앱에서)

- (기반) 음성 인식 · 턴 관리 · 합성(VC1 · VC2 · VC4)
- (예정) 인식 확정 규칙(연속 일치) · 양방향 흐름 · 채널 세션과 잇기

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/om_voice` 에서 볼 수 있습니다.

## 앞으로 할 일

- 인식 확정 규칙(연속 일치) · 양방향 흐름 · 채널 세션과 잇기
