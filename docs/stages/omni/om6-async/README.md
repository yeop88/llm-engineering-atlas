# OM6 · 비동기 메시지 처리 (Async messaging)

**상태: ⬜ 예정** — 늦게 · 두 번 · 순서가 바뀌어 오는 메시지를 대기열 · 멱등 키로 한 번만 처리한다

## 원리

비동기 메시지 처리는 메신저 · 웹훅처럼 재전송되고 순서가 바뀌는 메시지를 대기열에 넣고, 멱등 키로 같은 메시지를 한 번만 처리하며, 실패하면 다시 시도하는 것입니다.

## 왜 하는가

웹훅은 타임아웃이면 다시 보냅니다. 같은 문의에 답을 두 번 보내거나 티켓을 두 개 만들면 안 됩니다.

## 어떻게 (이 앱에서)

- (기반) A2A 위임(멱등 · 재시도, IO3) · 체크포인트(LR3)
- (예정) 메시지 대기열 · 멱등 키 · 순서 · 재시도 · 전달 확인

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/om_async` 에서 볼 수 있습니다.
