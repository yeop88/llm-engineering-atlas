# OM6 · 비동기 메시지 처리 (Async messaging)

**상태: ✅ 구현됨** — 늦게 · 두 번 · 순서가 바뀌어 오는 메시지를 대기열 · 멱등 키로 한 번만 처리한다

## 원리

비동기 메시지 처리는 메신저 · 웹훅처럼 재전송되고 순서가 바뀌는 메시지를 대기열에 넣고, 멱등 키로 같은 메시지를 한 번만 처리하며, 실패하면 다시 시도하는 것입니다.

## 왜 하는가

웹훅은 타임아웃이면 다시 보냅니다. 같은 문의에 답을 두 번 보내거나 티켓을 두 개 만들면 안 됩니다.

## 어떻게 (이 앱에서)

- (기반) A2A 위임(멱등 · 재시도, IO3) · 체크포인트(LR3)
- 받기와 처리를 나눔: (채널, 외부 id) 멱등 키 → 중복은 기록만, 보낸 시각 순서로 처리, 앞 메시지가 실패하면 세션의 뒤 메시지를 멈춤, 3번 실패하면 사람에게
- 나가는 답도 멱등 키(reply:받은 메시지) — 다시 처리해도 한 번만, 먼저 보냈는데 늦게 온 메시지는 '늦게 도착' 표시
