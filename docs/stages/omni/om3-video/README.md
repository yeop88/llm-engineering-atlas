# OM3 · 영상 스트림 분석 (Video stream analysis)

**상태: ⬜ 예정** — 장면이 바뀐 프레임만 골라 읽고 사건 · 시간 색인을 만든다

## 원리

영상 스트림 분석은 프레임을 일정 간격으로 받아 장면이 바뀐 순간만 비전 모델로 읽고(표시창 코드 · 물건 · 동작), 시간과 함께 색인해 '아까 그 장면'을 찾을 수 있게 하는 것입니다.

## 왜 하는가

영상의 모든 프레임을 비전 모델로 읽으면 느리고 비쌉니다. 바뀐 순간만 읽어야 실시간이 됩니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달 임베딩(MA1) · 사진 진단(AS4) · 같은 장면 제외
- (예정) 장면 변화 감지 · 키프레임 읽기 · 사건 · 시간 색인 · 영상 질문

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/om_video` 에서 볼 수 있습니다.

## 앞으로 할 일

- 장면 변화 감지 · 키프레임 읽기 · 사건 · 시간 색인 · 영상 질문
