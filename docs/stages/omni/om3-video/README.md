# OM3 · 영상 스트림 분석 (Video stream analysis)

**상태: ✅ 구현됨** — 장면이 바뀐 프레임만 골라 읽고 사건 · 시간 색인을 만든다

## 원리

영상 스트림 분석은 프레임을 일정 간격으로 받아 장면이 바뀐 순간만 비전 모델로 읽고(표시창 코드 · 물건 · 동작), 시간과 함께 색인해 '아까 그 장면'을 찾을 수 있게 하는 것입니다.

## 왜 하는가

영상의 모든 프레임을 비전 모델로 읽으면 느리고 비쌉니다. 바뀐 순간만 읽어야 실시간이 됩니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달 프레임 추출(같은 장면 제외) · 사진 진단(AS4)
- 장면 변화: 전체(16×16 평균 밝기 차) 또는 국소(48×48 에서 크게 바뀐 칸 0.8% 이상 — 같은 표시창에서 코드만 바뀜), 최소 간격
- 키프레임 → 비전 LLM JSON(설명 · 표시창 · 코드 · 물체) → 알려진 코드에 맞춤 → 세션 시간축 색인, 카메라 · 녹화 영상 · 시험 영상 채점

## 화면

- `/omni/live#video` — **영상 장면 색인**: 장면이 바뀐 프레임만 비전으로
- `/omni/live#keyframes` — **키프레임 채점**: 놓친 장면 · 더 남긴 프레임 · 절약
