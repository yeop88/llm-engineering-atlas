# MR5 · 모델 후보 생성 (Candidate generation)

**상태: ✅ 구현됨** — 모달리티 · 품질 · 지연을 만족하는 모델 · 경로 후보를 만든다

## 원리

후보 생성은 모달리티를 지원하고(LN5), 품질 하한 · 지연 예산을 넘는 모델과 실행 경로(RAG · GraphRAG · SQL · 에이전트 · 로컬)를 조합해 후보를 만드는 것입니다.

## 왜 하는가

후보를 사람이 목록으로 고정하면 새 모델 · 새 경로가 들어와도 쓰이지 않고, 낡은 모델이 계속 선택됩니다.

## 어떻게 (이 앱에서)

- (기반) 모달리티(LN5) · 온디바이스(ED)
- 설정의 모델(기본 · 모델별 주소 · 소형 · 대체 · Claude)을 후보로 자동 생성, 보정이 잰 유형별 품질 · p95 · 호출당 비용 · 성공률을 덧씌움(잰 날 표시), 안 잰 후보는 종류별 추정
