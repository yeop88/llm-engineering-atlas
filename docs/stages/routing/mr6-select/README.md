# MR6 · 모델 선택 (Model selection)

**상태: ⬜ 예정** — 점수(품질 · 근거 · 지연 · 비용 · 신뢰성 가중합)로 고른다

## 원리

모델 선택은 후보마다 점수 = 0.35 × 품질 + 0.20 × 근거 + 0.15 × 지연 + 0.15 × 비용 + 0.15 × 신뢰성(가중치는 바꿀 수 있음)을 계산해 가장 높은 것을 고르는 것입니다.

## 왜 하는가

가중치가 명시되어야 '왜 이 모델인가' 를 설명하고, 업무마다 다르게 조정할 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 라우터(6)
- (예정) 점수 계산 · 가중치 설정 · 고른 이유
