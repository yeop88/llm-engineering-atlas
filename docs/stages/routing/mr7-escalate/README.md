# MR7 · 실패 시 승격 (Escalation)

**상태: ⬜ 예정** — 검증에 떨어지거나 실패하면 다음 모델 · 사람으로 올린다

## 원리

승격은 고른 모델의 답이 검증(인용 · 관련성 · 형식)에 떨어지거나 오류가 나면 더 강한 모델, 그래도 안 되면 사람에게 넘기는 것입니다.

## 왜 하는가

싼 모델을 먼저 쓰는 라우팅은 승격이 있어야 품질을 지킵니다. 승격률이 높으면 라우터가 틀린 것입니다.

## 어떻게 (이 앱에서)

- (기반) 대체 모델 사슬(PF6) · 검증(AS6)
- (예정) 검증 실패 → 승격 사슬 · 승격률
