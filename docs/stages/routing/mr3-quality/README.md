# MR3 · 품질 요구 계산 (Quality requirement)

**상태: ⬜ 예정** — 작업 유형 · 위험도로 필요한 품질 수준을 정한다

## 원리

품질 요구는 작업마다 '이 정도면 된다' 를 정하는 것입니다(간단 요약은 0.7, 법률 근거 답은 인용 정확 0.95). 평가 세트의 유형별 점수로 모델이 그 수준을 넘는지 압니다.

## 왜 하는가

모든 요청에 최고 품질을 요구하면 비용이 끝없이 늘고, 낮게 잡으면 중요한 질문을 놓칩니다.

## 어떻게 (이 앱에서)

- (기반) 평가 세트 · 유형별 점수(E1)
- (예정) 유형 × 위험 → 품질 하한 표

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/mr_quality` 에서 볼 수 있습니다.
