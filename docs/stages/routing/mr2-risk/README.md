# MR2 · 위험도 판정 (Risk assessment)

**상태: ⬜ 예정** — 법률 · 의료 · 금전 · 외부 행동 같은 고위험을 먼저 가른다

## 원리

위험도 판정은 요청이 법률 · 의료 · 금전 · 개인정보 · 외부 행동(결제 · 발송)에 닿는지, 인젝션 신호가 있는지를 보는 것입니다. 고위험은 비용 최적화보다 먼저입니다.

## 왜 하는가

고위험 요청을 싼 모델로 보내 아낀 비용은 잘못된 법률 · 금전 안내 사고 한 번이면 모두 사라집니다.

## 어떻게 (이 앱에서)

- (기반) 위험 등급(RC2) · 입력 방어(G1)
- (예정) 위험 규칙 · 고위험 → 고성능 + 사람 승인 강제

## 화면
