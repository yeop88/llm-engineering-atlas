# MR1 · 요청 분류 (Request classification)

**상태: ✅ 구현됨** — 모달리티 · 작업 유형(요약 · 추론 · 이미지 · 음성 · 관계 · 코드)을 판정한다

## 원리

요청 분류는 입력 모달리티와 작업 유형(간단 요약 · 사실 검색 · 집계 · 관계 · 깊은 추론 · 코드 · 이미지 · 음성)을 판정하는 것입니다. 규칙 → 작은 분류기 → LLM 순으로 싸게 먼저 시도합니다.

## 왜 하는가

분류가 틀리면 뒤의 모든 선택이 틀립니다. 분류 자체의 비용도 작아야 라우팅이 이득입니다.

## 어떻게 (이 앱에서)

- (기반) 라우터(6) · 생각 라우터(RS2)
- 모달리티(사진 · 음성 채널)를 먼저, 그다음 규칙(도구 실행 · 코드 · 집계 · 관계 · 추세 · 요약 · 추론 표현), 규칙이 못 찾은 긴 질문만 LLM — 분류 비용이 이득을 먹지 않게

## 화면

- `/model-routing/decide` — **라우팅 결정**: 분류 · 위험 · 후보 점수 · 승격 사슬
