# MR1 · 요청 분류 (Request classification)

**상태: ⬜ 예정** — 모달리티 · 작업 유형(요약 · 추론 · 이미지 · 음성 · 관계 · 코드)을 판정한다

## 원리

요청 분류는 입력 모달리티와 작업 유형(간단 요약 · 사실 검색 · 집계 · 관계 · 깊은 추론 · 코드 · 이미지 · 음성)을 판정하는 것입니다. 규칙 → 작은 분류기 → LLM 순으로 싸게 먼저 시도합니다.

## 왜 하는가

분류가 틀리면 뒤의 모든 선택이 틀립니다. 분류 자체의 비용도 작아야 라우팅이 이득입니다.

## 어떻게 (이 앱에서)

- (기반) 라우터(6) · 생각 라우터(RS2)
- (예정) 작업 유형 체계 · 규칙 → 분류기 → LLM 단계 분류 · 정확도

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/mr_classify` 에서 볼 수 있습니다.
