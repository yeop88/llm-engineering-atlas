# 모델 라우팅 · 비용 최적화 — 분류 · 위험 · 품질 하한 · 예산 · 후보 점수 · 승격 · 보정 · 채점 · 실측 (MR1~MR8)

화면은 `/model-routing/decide`(라우팅 결정) · `/model-routing/eval`(라우터 채점), 코드는 `app/stages/model_routing/` 입니다. LLM 맵의 라우터(6)가 고르던 '쉬움 · 어려움' 두 갈래를, 설정에 있는 여러 모델 · 실행 경로 · 사람 승인 사이의 선택으로 넓힙니다.

```
요청 → 분류(모달리티 → 규칙 → 필요할 때만 LLM) (MR1) → 위험도(영역 규칙 + 인젝션) (MR2)
     → 품질 하한(위험 × 유형) (MR3) → 채널 지연 예산 · 비용 상한 (MR4)
     → 후보(설정에서 자동 + 보정 값) 거르기 (MR5) → 점수 = 0.35 품질 + 0.20 근거 + 0.15 지연 + 0.15 비용 + 0.15 신뢰성 (MR6)
     → 사슬대로 답 · 실행 중 판정에 떨어지면 다음 후보 · 끝은 사람 (MR7) → 요청 기록 · 채점 (MR8)
```

## 설계

- **분류는 싼 것부터(MR1).** 사진이 붙었거나 음성 · 영상 채널이면 모달리티가 먼저 정합니다. 그다음 규칙 — 도구 실행('보내 줘' · '예약해') · 코드 · 집계('몇 건' · '평균') · 관계 · 추세 · 요약 · 깊은 추론('왜' · '비교' · '판단') 순서로, 앞의 것이 더 구체적이라 먼저 봅니다. 규칙이 아무것도 못 찾은 긴 질문만 LLM 에 묻습니다 — 분류 비용이 라우팅으로 아낀 비용을 먹지 않게. 유형마다 실행 경로(RAG · GraphRAG · SQL · 커뮤니티 요약 · 에이전트)를 추천하되, 이 맵의 답은 서비스 답변(RAG)으로 하고 경로는 기록으로 남겨 채점합니다.
- **위험이 비용보다 먼저(MR2).** 법률 · 의료 · 금전 · 개인정보 · 외부 행동 영역 규칙과 인젝션 탐지(G1)로 낮음 · 중간 · 높음을 정합니다. 높음이면 작은 모델을 후보에서 빼고, 외부 행동 · 인젝션 의심은 답을 만들되 '사람 승인 대기'로 둡니다 — 싼 모델로 아낀 비용은 사고 한 번이면 사라집니다.
- **하한을 넘는 후보가 먼저(MR3 · MR6).** 품질 하한은 위험도(0.6 · 0.75 · 0.9)에 깊은 추론 · 집계는 0.05 를 더합니다(틀리면 숫자가 틀림). 하한을 넘는 후보를 앞에 두고 그 안에서 점수 순으로 정렬하며, 넘는 후보가 없으면 점수 순 사슬로 두고 승격으로 보완합니다. 지연 · 비용은 후보들 안에서 0~1 로 바꿔(가장 좋은 것 1) 가중합합니다. 가중치는 요청마다 바꿀 수 있고 고른 이유(후보마다 품질 · p95 · 비용 · 점수 · 제외 이유)를 표로 보여 줍니다.
- **후보는 설정에서 자동으로(MR5).** 후보를 사람이 고정하면 새 모델이 들어와도 쓰이지 않습니다. 기본 모델 · 모델별 주소 · 소형 · 대체 사슬 · Claude 를 후보로 만들고, 종류(소형 · 로컬 · 추론 · API)는 이름으로 추정합니다. 품질 · p95 · 비용은 보정이 같은 평가 세트로 잰 값을 덧씌우고 잰 날을 남깁니다. 안 잰 후보는 종류별 추정값을 쓰고 '추정'으로 표시합니다.
- **실행 중 판정으로 승격(MR7).** 실행 중에는 정답을 모르므로 답의 성질로 판정합니다: 거절 · 없는 근거 인용 · 근거 일치 0.5 미만 · 질문과 무관하면 떨어짐. 떨어지면 사슬의 다음 후보, 끝은 사람입니다. 후보 서버가 꺼져 있어도 다음 후보로 넘어갑니다(대체 사슬 PF6 과 같은 생각).
- **강한 · 싼 후보와 같은 질문으로 채점(MR8).** 라우팅의 목적은 품질을 지키며 비용을 줄이는 것이라, 늘 가장 강한 후보(품질 상한) · 늘 가장 싼 후보(비용 하한)를 같은 질문 · 같은 근거(검색은 한 번)로 함께 답하게 합니다. 라우터가 '싼 → 강한' 품질 차이의 몇 % 를 지켰는지, 강한 후보 대비 비용을 몇 % 아꼈는지, 승격률(첫 선택이 틀린 비율)을 봅니다. 같은 후보 · 같은 질문은 한 번만 부릅니다. 비용 단위는 단가가 있으면 돈(LLM_PRICES), 없으면(로컬) 장치 초입니다.
