# MR8 · 비용 · 품질 기록 (Cost & quality log)

**상태: ⬜ 예정** — 고른 이유 · 비용 · 품질을 남겨 라우터를 다시 채점한다

## 원리

비용 · 품질 기록은 요청마다 분류 · 위험 · 후보 · 점수 · 고른 모델 · 승격 · 결과 품질 · 비용을 남기는 것입니다. 이 기록으로 라우터를 다시 채점하고 가중치를 고칩니다.

## 왜 하는가

기록 없는 라우터는 개선할 수 없습니다. 두 경로를 함께 돌린 기록으로 채점하는 방법(6)을 그대로 씁니다.

## 어떻게 (이 앱에서)

- (기반) 트레이싱(E3) · 개선 루프(E8)
- (예정) 라우팅 기록 · 오프라인 재채점 · 가중치 조정

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/mr_log` 에서 볼 수 있습니다.
