# MR4 · 지연 · 예산 계산 (Latency & budget)

**상태: ✅ 구현됨** — 채널의 지연 예산과 테넌트 예산 안에서 쓸 수 있는 몫을 계산한다

## 원리

지연 · 예산은 채널(음성 1.5초 · 채팅 4초 · 이메일 분 단위)의 지연 예산과 테넌트 · 사용자 예산의 남은 몫을 계산해 후보를 거르는 것입니다.

## 왜 하는가

지연 예산을 넘는 모델은 답이 좋아도 음성 채널에서는 쓸 수 없습니다 — 고객은 그 사이 전화를 끊습니다.

## 어떻게 (이 앱에서)

- (기반) 예산(S7) · 채널 지연 예산(OM8)
- 채널별 지연 예산(음성 1.5초 · 영상 2초 · 채팅 4초 · 이메일 10분)과 호출 비용 상한으로 후보 거르기
