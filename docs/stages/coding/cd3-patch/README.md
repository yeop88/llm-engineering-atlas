# CD3 · 수정 · 패치 (Code editing)

**상태: ✅ 구현됨** — 정확한 문자열 교체 · diff 로 고치고 형식 검사를 통과시킨다

## 원리

패치는 파일 전체를 다시 쓰는 대신 바꿀 부분만 정확히 교체하는 것입니다. 교체할 글이 파일에 정확히 한 번 있어야 합니다.

## 왜 하는가

전체를 다시 쓰면 고치지 않은 부분이 바뀌거나 사라집니다. 작은 패치가 리뷰 · 되돌리기도 쉽습니다.

## 어떻게 (이 앱에서)

- (기반) 에이전트 도구(8a)
- 한 걸음에 도구 하나(찾기 · 읽기 · 교체 · 테스트 · 끝) JSON, 교체는 파일에 정확히 한 번 있는 글만 — 전체를 다시 쓰지 않음
- 문법이 깨진 패치는 되돌리고, tests/ 는 고칠 수 없음, 모든 일은 저장소 복사본(작업 공간)에서
