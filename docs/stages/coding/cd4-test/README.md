# CD4 · 테스트 실행 · 고치기 (Test-driven repair)

**상태: ⬜ 예정** — 샌드박스에서 테스트를 돌려 실패 출력으로 다시 고친다

## 원리

테스트 주도 수정은 패치 뒤 관련 테스트를 실행하고, 실패 메시지를 다음 수정의 입력으로 쓰는 반복입니다.

## 왜 하는가

테스트를 돌리지 않은 패치는 맞는지 모릅니다. 실패 출력이 가장 정확한 피드백입니다.

## 어떻게 (이 앱에서)

- (기반) 샌드박스(IO2)
- (예정) 관련 테스트 고르기 · 실행 · 실패 피드백 · 재시도 상한

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cd_test` 에서 볼 수 있습니다.

## 앞으로 할 일

- 관련 테스트 고르기 · 실행 · 실패 피드백 · 재시도 상한
