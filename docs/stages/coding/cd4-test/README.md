# CD4 · 테스트 실행 · 고치기 (Test-driven repair)

**상태: ✅ 구현됨** — 샌드박스에서 테스트를 돌려 실패 출력으로 다시 고친다

## 원리

테스트 주도 수정은 패치 뒤 관련 테스트를 실행하고, 실패 메시지를 다음 수정의 입력으로 쓰는 반복입니다.

## 왜 하는가

테스트를 돌리지 않은 패치는 맞는지 모릅니다. 실패 출력이 가장 정확한 피드백입니다.

## 어떻게 (이 앱에서)

- (기반) 샌드박스(IO2)
- 교체할 때마다 그 과제의 테스트를 작업 공간에서 같은 파이썬으로 실행(시간 상한) → 실패 출력을 다음 걸음에
- 끝나면 테스트 결과 · 원본과의 diff · 테스트 파일을 건드렸는지(건드리면 무효)
