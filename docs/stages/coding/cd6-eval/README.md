# CD6 · 해결률 평가 (Issue resolution benchmark)

**상태: ⬜ 예정** — 일부러 깬 코드와 테스트로 과제를 만들어 해결률 · 걸음 · 토큰을 잰다

## 원리

해결률 평가는 실제 이슈(또는 일부러 깬 코드)와 그것을 확인하는 테스트로 과제를 만들고, 에이전트가 테스트를 통과시킨 비율을 재는 것입니다.

## 왜 하는가

공개 벤치마크는 학습 데이터에 섞였을 수 있습니다. 이 저장소에서 만든 과제는 오염이 없고 실제 코드와 같습니다.

## 어떻게 (이 앱에서)

- (기반) 검증 가능한 과제(RV1) · 회귀 평가(E2)
- (예정) 깬 코드 과제 세트 · 해결률 · 걸음 · 토큰 · 모델 비교

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cd_eval` 에서 볼 수 있습니다.

## 앞으로 할 일

- 깬 코드 과제 세트 · 해결률 · 걸음 · 토큰 · 모델 비교
