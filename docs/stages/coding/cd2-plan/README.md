# CD2 · 작업 계획 (Task planning)

**상태: ✅ 구현됨** — 이슈를 바꿀 파일 · 단계 · 확인할 테스트로 나눈다

## 원리

작업 계획은 이슈 설명을 바꿀 파일 · 순서 · 완료 조건(통과할 테스트)으로 바꾸는 것입니다.

## 왜 하는가

계획 없이 고치기 시작하면 관련 파일 · 문서 갱신을 빠뜨립니다(이 저장소의 문서 동기화 규칙처럼).

## 어떻게 (이 앱에서)

- (기반) 목표 분해(LR1)
- 실패한 테스트 출력 + 코드 검색 상위로 고칠 파일 · 함수 후보와 이유 · 확인할 테스트를 JSON 계획으로, 첫 걸음의 맥락에 넣음
