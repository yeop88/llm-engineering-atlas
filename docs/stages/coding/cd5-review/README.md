# CD5 · 리뷰 · 보안 검사 (Code review & security)

**상태: ✅ 구현됨** — 비밀 · 위험 함수 · 구조 규칙을 검사하고 LLM 이 리뷰한다

## 원리

리뷰는 테스트가 보지 못하는 것(비밀 값 · 위험 함수 · 의존 방향 위반 · 문서 누락)을 규칙과 LLM 으로 보는 것입니다.

## 왜 하는가

테스트를 통과해도 보안 · 구조 문제를 넣을 수 있습니다. 에이전트가 쓴 코드도 사람이 쓴 코드와 같은 리뷰를 받아야 합니다.

## 어떻게 (이 앱에서)

- (기반) 출력 검사(G4) · 검증 에이전트(MA7)
- 규칙: 비밀 값 · 위험 함수(eval · 셸 실행 · pickle) · 테스트 약화(assert 감소 · skip) · 의존 방향 · 넓은 예외 삼키기
- 선택: LLM 리뷰, 좋은 · 나쁜 diff 12개로 규칙 · LLM 의 정밀도 · 재현율, 에이전트 diff 마다 리뷰 지적

## 화면

- `/coding/review` — **코드 리뷰**: 규칙 · LLM 리뷰 정밀도 · 재현율, diff 검사
