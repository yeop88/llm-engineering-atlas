# CD1 · 코드 검색 · 저장소 이해 (Code retrieval)

**상태: ⬜ 예정** — 함수 · 파일 단위로 나누고 기호 · 호출 관계로 관련 코드를 찾는다

## 원리

코드 검색은 문서 검색과 달리 함수 · 클래스 단위 청킹, 기호(이름) 일치, 호출 · 가져오기 관계가 중요합니다.

## 왜 하는가

고칠 곳을 못 찾으면 에이전트가 엉뚱한 파일을 고칩니다. 코드에서는 의미 검색보다 이름 · 관계가 더 정확할 때가 많습니다.

## 어떻게 (이 앱에서)

- (기반) RAG 검색 · BM25 혼합(2) · 관계 추출(K3)
- (예정) 함수 단위 청킹 · 기호 색인 · 호출 그래프 · 검색 정확도

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/cd_index` 에서 볼 수 있습니다.
