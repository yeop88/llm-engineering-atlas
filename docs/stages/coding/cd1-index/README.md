# CD1 · 코드 검색 · 저장소 이해 (Code retrieval)

**상태: ✅ 구현됨** — 함수 · 파일 단위로 나누고 기호 · 호출 관계로 관련 코드를 찾는다

## 원리

코드 검색은 문서 검색과 달리 함수 · 클래스 단위 청킹, 기호(이름) 일치, 호출 · 가져오기 관계가 중요합니다.

## 왜 하는가

고칠 곳을 못 찾으면 에이전트가 엉뚱한 파일을 고칩니다. 코드에서는 의미 검색보다 이름 · 관계가 더 정확할 때가 많습니다.

## 어떻게 (이 앱에서)

- (기반) RAG 검색 · BM25(2) · 관계 추출(K3)
- 저장소 복사본을 ast 로 함수 · 클래스(메서드) 단위로 나누고 호출하는 이름 · 줄 범위를 함께, 식별자를 snake_case · CamelCase 로 쪼갠 BM25
- 기호 일치(질문의 함수 이름 · 파일 경로) · 호출 그래프(실패한 테스트가 부른 함수 → 그 함수가 부르는 함수) 가산 — 깬 코드 과제로 방법별 hit@k · MRR

## 화면

- `/coding/search` — **코드 검색**: 함수 단위 BM25 · 기호 · 호출 그래프, 방법별 hit@k
