# 7a · 지식 증류 (Distillation)

**상태: ⬜ 예정** — 큰 모델의 판단을 작은 모델이 따라 하도록 학습한다

## 원리

큰 교사 모델의 출력(임베딩 벡터 · 리랭커 점수 · LLM 답변)을 작은 학생 모델이 흉내 내도록 학습합니다.

## 왜 하는가

작은 모델로 큰 모델에 가까운 품질을 내면, 쉬운 질문을 맡을 소형 모델의 비용과 지연이 크게 줄어듭니다.

## 어떻게 (이 앱에서)

- 임베딩: 큰 모델 → 작은 모델 벡터 증류
- 리랭커: 크로스 인코더 점수 → 임베딩 모델
- LLM: 큰 LLM 답변 → 소형 LLM 학습 데이터

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/distill` 에서 볼 수 있습니다.

## 앞으로 할 일

- 크기 · 속도 · 정확도 3축 비교표
