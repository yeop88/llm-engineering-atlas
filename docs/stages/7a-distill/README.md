# 7a · 지식 증류 (Distillation)

**상태: ✅ 구현됨** — 큰 모델의 판단을 작은 모델이 따라 하도록 학습한다

## 원리

큰 교사 모델의 출력(임베딩 점수 · 리랭커 점수 · LLM 답변)을 작은 학생 모델이 흉내 내도록 학습합니다. 임베딩은 교사가 매긴 '정답 − 오답' 점수 차를 학생이 배우는 MarginMSE 를 씁니다 — 점수 차이를 배우므로 교사 · 학생의 차원이 달라도 되고 교사가 리랭커여도 됩니다.

## 왜 하는가

작은 모델로 큰 모델에 가까운 품질을 내면, 쉬운 질문을 맡을 소형 모델(라우팅의 빠른 경로)의 비용과 지연이 크게 줄어듭니다.

## 어떻게 (이 앱에서)

- 임베딩 증류: 학습 질문(LLM · ICT) → 교사가 어려운 오답 고르기 · 점수 차 → 학생 학습(MarginMSE) → 카탈로그 등록 → 교사 · 학생 전 · 후 비교와 격차 회복률 · 인코딩 속도
- LLM 증류 데이터: 컬렉션 지문으로 새 질문 → 교사 LLM 이 서비스와 같은 형식으로 답 → 검증 통과한 답만 대화형 JSONL (학습은 GPU 환경)
- 평가 세트 근거가 든 지문은 학습에서 제외(누수 방지), 실행 기록은 파인튜닝과 함께 관리

## 화면

- `/distill` — **지식 증류 테스트**: 임베딩 증류 · LLM 증류 데이터

## 앞으로 할 일

- 증류한 소형 LLM 을 라우팅의 빠른 경로 모델로 연결
- 리랭커 → 임베딩 증류 실측
