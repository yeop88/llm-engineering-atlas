# VD6 · 시공간 추론 (Spatio-temporal reasoning)

**상태: ⬜ 예정** — '처음 · 마지막 · 몇 번 · 무엇 다음' 을 색인 위에서 계산한다

## 원리

시공간 추론은 '처음 일어난 때', '몇 번', 'X 다음에 일어난 일' 같은 질문을 사건 색인 위에서 계산(조회 · 집계)으로 푸는 것입니다. LLM 은 질문을 계산으로 바꾸는 데 씁니다.

## 왜 하는가

긴 영상 전체를 LLM 에 넣어 시간 질문을 물으면 틀리기 쉽습니다. 색인 위의 계산이 정확합니다.

## 어떻게 (이 앱에서)

- (기반) 추론 맵(RS)
- (예정) 시간 질문 → 색인 조회 · 집계 · 정답률
