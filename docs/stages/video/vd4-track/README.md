# VD4 · 객체 · 행동 추적 (Object & action tracking)

**상태: 🔬 연구** — 물체 · 사람을 프레임에 걸쳐 따라가고 행동을 붙인다

## 원리

추적은 같은 물체 · 사람을 프레임마다 이어(트랙) 언제 나타나고 무엇을 했는지(집다 · 열다)를 붙이는 것입니다.

## 왜 하는가

'A 가 B 와 상호작용한 장면' 은 장면 설명만으로는 답할 수 없고 트랙이 필요합니다.

## 어떻게 (이 앱에서)

- (기반) 영역 탐지(VL3)
- (연구) 탐지 + 트랙 잇기 · 행동 이름 · 트랙 정확도

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/vd_track` 에서 볼 수 있습니다.
