# VD4 · 객체 · 행동 추적 (Object & action tracking)

**상태: ✅ 구현됨** — 물체 · 사람을 프레임에 걸쳐 따라가고 행동을 붙인다

## 원리

추적은 같은 물체 · 사람을 프레임마다 이어(트랙) 언제 나타나고 무엇을 했는지(집다 · 열다)를 붙이는 것입니다.

## 왜 하는가

'A 가 B 와 상호작용한 장면' 은 장면 설명만으로는 답할 수 없고 트랙이 필요합니다.

## 어떻게 (이 앱에서)

- (기반) 영역 찾기(VL3)
- 물체 찾기(시험 영상: 알려진 색의 연결 성분) → 같은 이름의 가장 가까운 덩어리로 잇기, 1초 넘게 안 보이면 사라짐, 중심 34px 안이면 닿음(처음 닿은 때만)
