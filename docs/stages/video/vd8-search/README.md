# VD8 · 검색 · 요약 (Video search & summary)

**상태: ✅ 구현됨** — 질문에 근거 클립과 함께 답하고 영상을 구간 근거로 요약한다

## 원리

검색 · 요약은 질문에 맞는 구간을 찾아 클립 · 전사 · 대표 프레임을 근거로 답하고, 요약 항목마다 구간을 붙이는 것입니다.

## 왜 하는가

영상 답은 확인이 어렵습니다. 근거 클립이 있어야 사람이 몇 초만 보고 확인합니다.

## 어떻게 (이 앱에서)

- (기반) RAG · 통화 요약(VC7)
- 답에 근거 사건과 앞 1초 · 뒤 2초 클립 구간, 시간 순 사건 기록을 요약으로, 합성 영상 평가(컷 · 사건 찾기 · 질문 종류별 정답률)
