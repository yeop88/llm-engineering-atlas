# VD5 · 음성 · 자막 정렬 (Speech & subtitle alignment)

**상태: ⬜ 예정** — 전사 · 자막 · 화자를 영상 시간축에 맞춘다

## 원리

음성 · 자막 정렬은 소리 전사 · 자막 · 화자 구간을 프레임 시간에 맞추는 것입니다. 말과 화면이 같은 초에 있어야 '그 말을 할 때 화면' 을 찾습니다.

## 왜 하는가

회의 · 강의 영상은 정보의 대부분이 말에 있습니다. 정렬이 어긋나면 근거 구간이 틀립니다.

## 어떻게 (이 앱에서)

- (기반) 오디오 시간 구간(AU5) · 음성 인식(VC1)
- (예정) 전사 · 자막 · 화자 정렬 · 어긋남 측정

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/vd_align` 에서 볼 수 있습니다.
