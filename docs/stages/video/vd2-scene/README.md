# VD2 · 장면 분할 (Shot & scene detection)

**상태: ⬜ 예정** — 컷(샷)과 장면 경계를 찾는다

## 원리

장면 분할은 영상을 샷(카메라가 끊기지 않은 구간)과 장면(같은 장소 · 사건)으로 나누는 것입니다. 전체 · 국소 밝기 변화로 컷을, 내용 유사도로 장면을 묶습니다.

## 왜 하는가

장면 경계가 틀리면 '그 장면' 질문의 범위가 틀려, 맞는 장면을 찾고도 근거 구간이 어긋납니다.

## 어떻게 (이 앱에서)

- (기반) 장면 변화 게이트(OM3)
- (예정) 샷 · 장면 경계 · 경계 정확도

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/vd_scene` 에서 볼 수 있습니다.
