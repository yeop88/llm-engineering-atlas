# VD3 · 대표 프레임 선택 (Keyframe selection)

**상태: ✅ 구현됨** — 장면마다 대표 프레임을 골라 비전 모델로 읽는다

## 원리

대표 프레임 선택은 장면마다 가장 정보가 많은 프레임(흐리지 않고 가운데 있는 것)을 골라 비전 모델로 설명 · OCR 하는 것입니다.

## 왜 하는가

모든 프레임을 읽으면 비싸고 느립니다. 대표 프레임만 읽어도 대부분의 질문에 답합니다.

## 어떻게 (이 앱에서)

- (기반) 영상 장면 읽기(OM3)
- 장면마다 가운데 프레임 한 장만 비전 LLM 으로 읽음(설명 · 표시창 · 코드 · 물체) — 장면이 바뀐 곳만 읽어 비용을 장면 수로

## 화면
