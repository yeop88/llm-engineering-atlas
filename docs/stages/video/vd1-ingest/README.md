# VD1 · 영상 수집 (Video ingest)

**상태: ⬜ 예정** — 영상 파일 · 스트림을 받고 길이 · 형식 · 소리 트랙을 확인한다

## 원리

영상 수집은 파일 · 스트림을 받아 길이 · 해상도 · 프레임률 · 소리 트랙을 확인하고, 디코딩 오류를 이유와 함께 알리는 단계입니다.

## 왜 하는가

긴 영상을 통째로 처리하면 비용이 큽니다. 형식 · 길이를 먼저 알아야 나눠 처리할 계획을 세웁니다.

## 어떻게 (이 앱에서)

- (기반) 영상 프레임 추출(멀티모달 수집)
- (예정) 메타 · 소리 트랙 분리 · 처리 계획

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/vd_ingest` 에서 볼 수 있습니다.
