# VD7 · 이벤트 색인 (Event index)

**상태: ✅ 구현됨** — 장면 · 트랙 · 말 · 사건을 시간 · 관계로 색인한다

## 원리

이벤트 색인은 장면 · 트랙 · 발화 · 소리 사건을 시각과 관계(누가 · 무엇을 · 어디서)로 저장하는 것입니다. 그래프로 두면 관계 질문도 됩니다.

## 왜 하는가

색인이 있어야 같은 영상에 여러 질문을 해도 매번 비전 모델로 다시 보지 않아 시간 · 비용이 들지 않습니다.

## 어떻게 (이 앱에서)

- (기반) 영상 색인(OM3) · 그래프 저장소
- 사건(종류 · 시각 · 끝 · 대상 · 상대 · 출처: 영상 · 추적 · 소리)을 시간 순으로, 장면마다 대표 프레임 구간
