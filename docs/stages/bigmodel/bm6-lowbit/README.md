# BM6 · 극저비트 (Extreme low-bit weights)

**상태: ✅ 구현됨** — 2비트 이하 · 1.58비트 가중치로 메모리를 줄이고 품질 손실을 잰다

## 원리

극저비트는 가중치를 2비트 이하(삼진 1.58비트 등)로 줄이는 것입니다. 일반 모델을 그대로 줄이면 품질이 크게 떨어지고, 처음부터 저비트로 학습한 모델은 버팁니다.

## 왜 하는가

메모리가 가장 크게 줄지만 품질 절벽이 있습니다. 어느 비트에서 무너지는지 같은 평가로 봐야 합니다.

## 어떻게 (이 앱에서)

- (기반) 양자화(7b) · 극단 경량화(ED2)
- 작은 공개 LM 선형층을 학습 없이 64개 묶음 반올림 8 · 4 · 3 · 2비트(칸 가운데 값) · 삼진(평균 절댓값 눈금)으로 — 혼란도 · 원래와 1위 일치 · KL
- 가진 GGUF 의 실제 가중치당 비트(파일 바이트 × 8 ÷ 파라미터)와 형식 구성, 품질은 양자화 맵의 LLM 비트 수 비교로
