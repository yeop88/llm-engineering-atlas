# BM1 · 메모리 계획 (Memory planning)

**상태: ⬜ 예정** — 가중치 · KV · 활성값을 계산해 GPU · CPU · 디스크 어디에 둘지 정한다

## 원리

메모리 계획은 모델 크기(층 수 · 차원 · 전문가 수 · 비트)와 맥락 길이 · 동시 요청 수로 필요한 메모리를 계산하고, 장치별 남은 메모리에 층을 배치하는 것입니다.

## 왜 하는가

올려 보고 실패하면 몇 분씩 버립니다. 미리 계산하면 어떤 설정이 올라갈지, 무엇을 내보내야 할지 압니다.

## 어떻게 (이 앱에서)

- (기반) 기기별 모델 선택(ED1) · 하드웨어(S6)
- (예정) 모델 설정 읽기 · 층별 크기 · KV 계산 · 장치 배치 계획

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/bm_plan` 에서 볼 수 있습니다.
