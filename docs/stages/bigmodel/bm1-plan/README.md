# BM1 · 메모리 계획 (Memory planning)

**상태: ✅ 구현됨** — 가중치 · KV · 활성값을 계산해 GPU · CPU · 디스크 어디에 둘지 정한다

## 원리

메모리 계획은 모델 크기(층 수 · 차원 · 전문가 수 · 비트)와 맥락 길이 · 동시 요청 수로 필요한 메모리를 계산하고, 장치별 남은 메모리에 층을 배치하는 것입니다.

## 왜 하는가

올려 보고 실패하면 몇 분씩 버립니다. 미리 계산하면 어떤 설정이 올라갈지, 무엇을 내보내야 할지 압니다.

## 어떻게 (이 앱에서)

- (기반) 기기별 모델 선택(ED1) · 하드웨어(S6)
- GGUF 머리말만 읽어 텐서별 정확한 바이트(종류: 임베딩 · 출력 · 어텐션 · FFN · 전문가), HF 는 config.json × 비트 어림, 층별 실제 K · V 차원으로 KV(슬라이딩 창 · KV 공유 층 · 선형 어텐션 고정 상태 반영)
- 배치 후보(전부 GPU · 층 N 개만 GPU · 전문가만 CPU · 앞 N 층 전문가만 CPU · 전부 CPU · 디스크 스트리밍)마다 장치별 메모리 · 들어가나 · 지붕선 토큰/초 어림 · llama-server 인자
