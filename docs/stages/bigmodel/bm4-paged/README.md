# BM4 · 페이지 KV 캐시 (Paged KV cache)

**상태: ⬜ 예정** — KV 캐시를 작은 블록으로 나눠 요청끼리 나눠 쓰고 같은 앞부분은 공유한다

## 원리

페이지 KV 캐시는 요청마다 최대 길이만큼 KV 를 미리 잡지 않고, 작은 블록을 필요할 때 붙이는 방식입니다. 같은 시스템 프롬프트 · 근거는 블록을 공유합니다.

## 왜 하는가

최대 길이로 미리 잡으면 실제로는 메모리가 남는데도 새 요청을 받지 못합니다(조각 낭비).

## 어떻게 (이 앱에서)

- (기반) KV 양자화(KC5)
- (예정) 블록 할당기 · 앞부분 공유 · 실제 요청 기록으로 낭비 · 동시 수 비교
