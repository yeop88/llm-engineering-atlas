# BM2 · 층 단위 스트리밍 (Layer-wise streaming)

**상태: ⬜ 예정** — 층을 디스크에서 하나씩 불러 돌리고 버려 메모리보다 큰 모델을 돌린다

## 원리

층 단위 스트리밍은 모델 전체를 올리지 않고 층 하나의 가중치만 불러 계산한 뒤 내리는 방식입니다. 최대 메모리는 층 하나 + 활성값 정도로 줄고, 대신 매 토큰 디스크를 읽습니다.

## 왜 하는가

메모리가 모자라 아예 못 돌리는 것과, 느리지만 돌리는 것은 다릅니다. 얼마나 느린지 · 언제 쓸 만한지(한 번에 긴 글 읽기 등)를 재야 합니다.

## 어떻게 (이 앱에서)

- (기반) 작은 공개 모델(P5)
- (예정) 층별 가중치 파일 · 하나씩 불러 계산 · 최대 메모리 · 토큰/초 · 미리 읽기
