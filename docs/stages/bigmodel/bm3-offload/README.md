# BM3 · CPU-GPU 혼합 · 전문가 오프로드 (Hybrid CPU-GPU & expert offload)

**상태: ⬜ 예정** — 자주 쓰는 층은 GPU, MoE 전문가처럼 드물게 쓰는 부분은 CPU 에 둔다

## 원리

혼합 실행은 모델을 나눠 일부 층(또는 MoE 의 전문가 가중치)만 CPU 메모리에 두고 계산하는 것입니다. MoE 는 토큰마다 전문가 일부만 쓰므로 전문가를 CPU 에 둬도 손해가 작습니다.

## 왜 하는가

GPU 메모리가 모델보다 작아도 자주 쓰는 부분만 GPU 에 두면 전부 CPU 보다 훨씬 빠릅니다. 어디까지 내보낼지가 속도를 정합니다.

## 어떻게 (이 앱에서)

- (기반) llama-server 설정별 실행(S4)
- (예정) GPU 층 수 · 전문가 CPU 오프로드 설정별 토큰/초 · 메모리 · 전문가 쓰임 통계
