# BM7 · 여러 기기 나눠 돌리기 (Multi-device split)

**상태: ✅ 구현됨** — 층(파이프라인)이나 텐서를 여러 기기에 나눠 한 기기에 안 들어가는 모델을 돌린다

## 원리

여러 기기 나눠 돌리기는 층을 기기마다 나눠 차례로 넘기거나(파이프라인), 한 층의 행렬을 나눠 동시에 계산하는(텐서) 방식입니다. 기기 사이 전송이 새 병목이 됩니다.

## 왜 하는가

기기 하나로는 안 되지만 노트북 두 대 · PC + 서버라면 될 수 있습니다. 전송 비용이 이득을 넘지 않는지 잽니다.

## 어떻게 (이 앱에서)

- (기반) 혼합 · 오프로드(BM3)
- 파이프라인: 메모리 비율로 층을 이어 나눔 — 기기별 층 · 가중치 · KV · 들어가나, 토큰당 기기 시간 + 경계마다 (지연 + 은닉 벡터 ÷ 링크)
- 텐서: 대역폭 비율로 층을 나눠 동시에 읽기 + 층마다 두 번 결과 모으기 — 이더넷 지연이 이득을 먹는 지점, 실측은 rpc-server 주소를 --rpc 로(BM3 과 같은 길)
