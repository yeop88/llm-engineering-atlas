# 8b · 강화학습 (Reinforcement learning)

**상태: ⬜ 예정** — 보상 · 선호 신호로 모델의 행동을 최적화한다

## 원리

정답 근거 인용 · 환각 없음 · 사용자 선호 같은 보상 신호로 모델 행동을 조정합니다. 좋은 답 / 나쁜 답 쌍으로 학습하는 선호 학습(DPO 등)이 대표적입니다.

## 왜 하는가

'좋은 답'의 기준(근거를 정확히 인용, 모르면 모른다고 하기)은 정답 문장만으로 가르치기 어렵습니다. 보상으로 그 기준을 직접 반영합니다.

## 어떻게 (이 앱에서)

- 보상 설계: 근거 인용 정확도 · 환각 없음 · 답변 길이
- 선호 데이터(좋은 답 / 나쁜 답) 수집
- DPO 등으로 소형 LLM 조정 후 답변 평가 비교

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/rl` 에서 볼 수 있습니다.
