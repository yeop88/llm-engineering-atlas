# VL3 · 객체 · 영역 인식 (Object & region detection)

**상태: ⬜ 예정** — 관심 물체 · 영역(표시창 · 버튼 · 부품)의 위치를 찾는다

## 원리

객체 · 영역 인식은 이미지 안의 관심 물체(표시창 · 배수 필터 · 호스)의 위치 상자를 찾는 것입니다. 작은 탐지 모델이나 VLM 의 위치 출력으로 합니다.

## 왜 하는가

어디를 봐야 하는지 먼저 찾아야 OCR · 판단이 그 영역에 집중하고, 배경의 다른 글자에 속지 않습니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달 임베딩(MA1)
- (예정) 영역 탐지(VLM 위치 출력) · 위치 정확도

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/vl_detect` 에서 볼 수 있습니다.
