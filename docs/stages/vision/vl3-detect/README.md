# VL3 · 객체 · 영역 인식 (Object & region detection)

**상태: ✅ 구현됨** — 관심 물체 · 영역(표시창 · 버튼 · 부품)의 위치를 찾는다

## 원리

객체 · 영역 인식은 이미지 안의 관심 물체(표시창 · 배수 필터 · 호스)의 위치 상자를 찾는 것입니다. 작은 탐지 모델이나 VLM 의 위치 출력으로 합니다.

## 왜 하는가

어디를 봐야 하는지 먼저 찾아야 OCR · 판단이 그 영역에 집중하고, 배경의 다른 글자에 속지 않습니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달 입력(MM1)
- 표시창: 사진마다 정한 어둠 기준 · 구멍 메우기 · 주축 상자의 채움과 가로세로 비, 호스: 채도 낮은 중간 회색의 가늘고 긴 덩어리 — 시험 사진(가전 앞판)용 규칙

## 화면

- `/vision/look#look` — **객체 · 영역**: 표시창 · 배수 호스 영역

## 앞으로 할 일
