# VL1 · 이미지 입력 (Image input)

**상태: ⬜ 예정** — 사진 · 스크린샷 · 스캔을 받고 크기 · 형식 · 개인정보를 확인한다

## 원리

이미지 입력은 사진 · 스크린샷 · 스캔을 받아 형식 · 크기를 맞추고, 얼굴 · 문서 같은 개인정보가 있는지 확인하는 단계입니다.

## 왜 하는가

큰 이미지는 비전 토큰을 많이 써 느리고, 개인정보가 든 사진은 그대로 LLM 에 보내면 안 됩니다.

## 어떻게 (이 앱에서)

- (기반) 사진 진단 입력(AS4)
- (예정) 형식 · 크기 · 개인정보(얼굴 · 신분증) 확인

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/vl_input` 에서 볼 수 있습니다.

- 형식 · 크기 · 개인정보(얼굴 · 신분증) 확인
