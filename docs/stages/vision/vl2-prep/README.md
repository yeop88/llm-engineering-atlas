# VL2 · 전처리 (Preprocessing)

**상태: ✅ 구현됨** — 기울기 · 밝기 · 반사 · 잘라내기로 읽기 좋게 만든다

## 원리

전처리는 기울기 보정 · 밝기 맞추기 · 반사 줄이기 · 관심 영역 잘라내기입니다. 표시창처럼 작은 영역은 잘라 키워야 읽힙니다.

## 왜 하는가

같은 VLM 도 전처리에 따라 코드 읽기 정확도가 크게 다릅니다(사진 진단 실측의 흐림 · 반사 조건).

## 어떻게 (이 앱에서)

- (기반) 문서 파싱(D2)
- 표시창 덩어리 주축으로 기울기를 재 사진을 되돌리고 영역을 다시 찾음, 반사 누르기(밝은 곳 감마) · 선명하게(언샤프)는 읽을 영역(잘라 낸 표시창)에만 — 모양을 재는 규칙은 보정 전 그림으로
