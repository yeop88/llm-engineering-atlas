# VL7 · 근거 영역 표시 (Visual grounding)

**상태: ✅ 구현됨** — 답의 각 주장이 이미지의 어느 영역에 기대는지 표시한다

## 원리

근거 영역 표시는 답의 주장마다 이미지의 영역 상자를 붙여 보여 주는 것입니다. 사람이 확인할 자리를 주고, 영역이 틀리면 답도 의심합니다.

## 왜 하는가

'사진을 보니 꺾였네요' 가 사진의 어디를 본 것인지 모르면 확인할 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 인용 근거(PV)
- 답 문장이 코드를 말하면 표시창, 호스 · 배수 · 꺾임을 말하면 호스 영역 번호를 붙이고, 영역 상자를 그린 그림 — 영역이 없는 문장은 매뉴얼 근거에만 기댄 것
