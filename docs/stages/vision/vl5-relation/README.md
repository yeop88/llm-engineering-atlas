# VL5 · 관계 추론 (Relation reasoning)

**상태: ⬜ 예정** — 물체 사이의 관계(꺾임 · 연결 · 위치)를 판단한다

## 원리

관계 추론은 '호스가 꺾여 있다', '필터 덮개가 열려 있다' 처럼 물체 사이 · 상태를 판단하는 것입니다. 규칙으로 판단할 수 있는 것은 규칙 엔진에 둡니다.

## 왜 하는가

관계 판단은 VLM 이 가장 자주 틀리는 부분입니다. 규칙으로 가능한 것은 규칙으로 해야 일관됩니다.

## 어떻게 (이 앱에서)

- (기반) 관계 추출(K3)
- (예정) 관계 판단(VLM) · 규칙 엔진 분리 · 정확도
