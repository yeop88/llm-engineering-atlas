# VL6 · 시각 질의응답 (Visual QA)

**상태: ✅ 구현됨** — 사진 + 질문 + 매뉴얼 근거로 답한다

## 원리

시각 질의응답은 사진 · 질문 · 검색 근거를 함께 넣어 답하는 것입니다. 사진에서 읽은 사실(코드 · 상태)과 근거(매뉴얼)를 나눠 인용합니다.

## 왜 하는가

사진만 보고 답하면 근거가 없고, 근거만 보면 사진이 보여 주는 지금 상태를 무시해 엉뚱한 조치를 안내합니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달 RAG · 검색 에이전트
- 사진에서 읽은 코드 · 호스 상태를 질문에 붙여 서비스 답변(입력 방어 → 검색 → 근거 검증)으로 — 사진을 LLM 에 다시 주지 않음

## 화면

- `/vision/look#answer` — **시각 질의응답**: 사진에서 읽은 것을 붙인 매뉴얼 근거 답
