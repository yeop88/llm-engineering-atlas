# 7b · 양자화 (Quantization)

**상태: ✅ 구현됨** — 가중치 · 벡터를 낮은 비트로 바꿔 메모리와 지연을 줄이고, 정확도 손실을 잰다

## 원리

32비트 실수 가중치 · 벡터를 int8 · 4bit · binary 처럼 낮은 정밀도로 표현합니다. 벡터는 이진화해 해밍 거리로 후보를 넉넉히 뽑은 뒤 더 정밀한 값으로 다시 점수 매기는(재점수) 방식이 흔합니다.

## 왜 하는가

메모리 · 디스크 · 지연을 몇 배에서 수십 배 줄일 수 있습니다. 대신 정확도가 떨어질 수 있어, 손실을 측정해 허용 범위의 설정을 고릅니다. 라우팅의 빠른 경로에 쓸 작고 빠른 모델을 고르는 근거가 됩니다.

## 어떻게 (이 앱에서)

- 2026-10 기준 기술 카탈로그(원리 · 장단점 · 언제)에서 골라 실행 — 벡터(float16 · int8 · int4 · binary · 재점수 · PQ), 차원(MRL), 모델 가중치(bf16 · int8 동적), LLM(GGUF legacy · K · I · 동적 혼합 · QAT · KV 캐시)
- 여러 양자화를 동시에: 가중치 × 차원 × 벡터 정밀도의 모든 조합을 공개 벤치마크로 채점, 기준과 짝지은 비교 · 기준 상위 10 유지율 · 메모리, 파레토 최적 표시
- LLM: GGUF 가중치 × KV 캐시 양자화를 함께 적용한 서버 명령을 만들고, 같은 질문 · 같은 근거로 근거 인용 · 속도 비교 (모델별 서버 주소 OPENAI_MODEL_URLS)

## 화면

- `/quant` — **양자화 테스트**: 벡터 정밀도 · LLM 비트 수 비교

## 앞으로 할 일
