# 7b · 양자화 (Quantization)

**상태: ⬜ 예정** — 가중치 · 벡터를 낮은 비트로 바꿔 메모리와 지연을 줄인다

## 원리

32비트 실수 가중치 · 벡터를 int8 · 4bit · binary 처럼 낮은 정밀도로 표현합니다. 벡터는 이진화 후 원래 벡터로 다시 점수 매기는(rescoring) 방식이 흔합니다.

## 왜 하는가

메모리 · 디스크 · 지연을 몇 배에서 수십 배 줄일 수 있습니다. 대신 정확도가 떨어질 수 있어, 손실을 측정해 허용 범위의 설정을 고릅니다.

## 어떻게 (이 앱에서)

- 임베딩 벡터 int8 · binary + 재점수
- 모델 양자화: ONNX · OpenVINO · int8 인코딩 속도
- LLM GGUF 비트 수(4 · 5 · 8bit)별 답변 품질 · 속도

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/quant` 에서 볼 수 있습니다.
