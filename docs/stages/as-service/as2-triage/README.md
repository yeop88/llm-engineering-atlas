# AS2 · 의도 · 긴급도 분류 (Intent & urgency triage)

**상태: 🟡 기초 있음** — 문의 유형(고장 · 사용법 · 배송 · 환불)과 긴급도(안전 관련)를 나눠 처리 경로를 정한다

## 원리

분류기로 의도 · 긴급도를 정하고, 안전 관련(감전 · 화재 · 가스 냄새)은 즉시 사람에게, 쉬운 사용법은 FAQ 로, 고장은 진단 경로로 보냅니다.

## 왜 하는가

모든 문의를 같은 경로로 처리하면 비싸고(에이전트), 위험한 문의를 자동 답변할 수 있습니다.

## 어떻게 (이 앱에서)

- (있음) 의미 응용 분류기(제로샷 · 학습, 저장 · API), 라우팅(규칙 · 확신도 · 학습 라우터)
- (예정) AS 의도 · 긴급도 라벨 세트, 안전 키워드 규칙 우선

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/as_triage` 에서 볼 수 있습니다.

## 앞으로 할 일

- AS 의도 라벨 세트
- 안전 문의 규칙
