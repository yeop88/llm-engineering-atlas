# AS2 · 의도 · 긴급도 분류 (Intent & urgency triage)

**상태: ✅ 구현됨** — 문의 유형(고장 · 사용법 · 배송 · 환불)과 긴급도(안전 관련)를 나눠 처리 경로를 정한다

## 원리

분류기로 의도 · 긴급도를 정하고, 안전 관련(감전 · 화재 · 가스 냄새)은 즉시 사람에게, 쉬운 사용법은 FAQ 로, 고장은 진단 경로로 보냅니다.

## 왜 하는가

모든 문의를 같은 경로로 처리하면 비싸고(에이전트), 위험한 문의를 자동 답변할 수 있습니다.

## 어떻게 (이 앱에서)

- 안전(감전 · 화재 · 연기 · 가스)은 규칙으로 먼저 — 분류기 오답 한 번이 위험한 자동 답변이 되므로
- 의도: 임베딩 제로샷(라벨 설명 유사도) 기본, 라벨 문의 48개로 학습 분류기(5겹 교차검증)와 비교
- 오류 코드 추출(알려진 코드만 — '5G' · 'A4' 같은 낱말 제외)

## 화면

- `/as/eval` — **분류 · 사진 · 종단 실측**: 의도 · 긴급도 정확도, 사진 코드 읽기, 문의 세트 종단 평가

## 앞으로 할 일

- 대화 중 의도 바뀜 처리
