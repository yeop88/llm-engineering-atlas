# AS5 · 수리 · 조치 안내 (Repair guidance)

**상태: ✅ 구현됨** — 고객이 따라 할 수 있는 단계별 조치를 쓰고, 그림 · 음성으로도 낸다

## 원리

조치 안내는 진단 결과와 매뉴얼 근거로 '1. 전원을 끄고 2. 필터를 …' 같은 단계별 안내를 템플릿에 맞춰 씁니다. 필요하면 그림 · 음성 안내를 함께 냅니다.

## 왜 하는가

긴 설명보다 단계별 안내가 실제 해결률을 올립니다. 위험한 조치는 안내하지 않고 방문 접수로 돌립니다.

## 어떻게 (이 앱에서)

- 고장 의도면 '번호 단계로, 위험 조치는 방문 수리' 지시를 시스템 프롬프트에(질문에 붙이지 않음 — 검색 · 검증이 지시문을 질문으로 읽지 않게)
- 위험한 자가 조치 안내는 출력 정책(고객 지원)이 막고 상담원 연결

## 화면

- `/as/console#c-head` — **조치 안내**: 상담 창의 단계 표시

## 앞으로 할 일
