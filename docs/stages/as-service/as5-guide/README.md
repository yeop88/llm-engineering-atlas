# AS5 · 수리 · 조치 안내 (Repair guidance)

**상태: ⬜ 예정** — 고객이 따라 할 수 있는 단계별 조치를 쓰고, 그림 · 음성으로도 낸다

## 원리

조치 안내는 진단 결과와 매뉴얼 근거로 '1. 전원을 끄고 2. 필터를 …' 같은 단계별 안내를 템플릿에 맞춰 씁니다. 필요하면 그림 · 음성 안내를 함께 냅니다.

## 왜 하는가

긴 설명보다 단계별 안내가 실제 해결률을 올립니다. 위험한 조치는 안내하지 않고 방문 접수로 돌립니다.

## 어떻게 (이 앱에서)

- (기반) 보고서 작성 에이전트(MA6) · 멀티모달 출력(MA8)
- (예정) 조치 안내 템플릿, 위험 조치 금지 목록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/as_guide` 에서 볼 수 있습니다.

## 앞으로 할 일

- 조치 안내 템플릿
- 위험 조치 금지 목록
