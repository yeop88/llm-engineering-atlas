# AS8 · 피드백 · 개선 (Feedback & improvement)

**상태: ⬜ 예정** — 해결 여부 · 만족도를 받아 실패 사례를 평가 세트 · 매뉴얼 보강으로 되돌린다

## 원리

상담 끝에 해결 여부를 묻고, 미해결 · 불만 사례를 분류해 평가 세트(재발 방지) · 매뉴얼 보강(자료 부족) · 분류기 재학습(경로 오류)으로 돌려보냅니다.

## 왜 하는가

AS 상담의 품질 지표는 '해결률'입니다. 측정과 되돌리기가 없으면 같은 문의에서 계속 실패합니다.

## 어떻게 (이 앱에서)

- (기반) 사용자 피드백(E5) · 개선 루프(E8)
- (예정) 해결률 · 이관률 지표, 미해결 사례 분류

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/as_feedback` 에서 볼 수 있습니다.

## 앞으로 할 일

- 해결률 · 이관률 지표
