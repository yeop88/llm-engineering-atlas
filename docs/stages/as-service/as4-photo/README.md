# AS4 · 오류 사진 진단 (Photo diagnosis)

**상태: 🟡 기초 있음** — 오류 화면 · 부품 사진에서 오류 코드 · 증상을 읽고 매뉴얼의 해당 항목을 찾는다

## 원리

비전 LLM 으로 사진의 오류 코드 · 표시등 · 부품 상태를 읽고, 그 정보와 사진 자체로 매뉴얼 · 사례를 검색합니다(멀티모달 RAG).

## 왜 하는가

고객은 오류 코드를 정확히 옮겨 적지 못하는 경우가 많습니다. 사진에서 바로 읽으면 진단이 빨라집니다.

## 어떻게 (이 앱에서)

- (있음) 그림 근거를 비전 LLM(Gemma 4 + mmproj)에 첨부해 답하기, 이미지 컬렉션 검색
- (예정) 오류 코드 읽기 → 매뉴얼 항목 검색, 사진 진단 평가 세트

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/as_photo` 에서 볼 수 있습니다.

## 앞으로 할 일

- 오류 코드 읽기 · 검색
- 사진 진단 평가 세트
