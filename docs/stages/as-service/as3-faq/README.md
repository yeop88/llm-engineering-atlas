# AS3 · FAQ · 매뉴얼 답변 (FAQ & manual answers)

**상태: 🟡 기초 있음** — 매뉴얼 · FAQ 에서 근거를 찾아 인용하며 답한다 — 쉬운 문의는 RAG 한 번

## 원리

사용법 · 간단한 고장은 매뉴얼 · FAQ 컬렉션을 RAG 로 검색해 근거 번호를 달아 답합니다. 반복 질문은 캐시로 바로 답합니다.

## 왜 하는가

가장 많은 문의가 여기서 끝나야 비용이 맞습니다. 근거 인용으로 상담원이 답을 확인할 수 있습니다.
