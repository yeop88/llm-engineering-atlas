# AS3 · FAQ · 매뉴얼 답변 (FAQ & manual answers)

**상태: ✅ 구현됨** — 매뉴얼 · FAQ 에서 근거를 찾아 인용하며 답한다 — 쉬운 문의는 RAG 한 번

## 원리

사용법 · 간단한 고장은 매뉴얼 · FAQ 컬렉션을 RAG 로 검색해 근거 번호를 달아 답합니다. 반복 질문은 캐시로 바로 답합니다.

## 왜 하는가

가장 많은 문의가 여기서 끝나야 비용이 맞습니다. 근거 인용으로 상담원이 답을 확인할 수 있습니다.

## 어떻게 (이 앱에서)

- 검색 범위 = 고객 제품의 문서 + 모델 구분 없는 공통 문서(FAQ) — 다른 모델 매뉴얼은 후보에서 뺌
- 혼합 검색(BM25 + 의미) — 오류 코드 같은 낱말은 BM25 가 잘 잡음
- 의미 캐시: 같은 제품 범위에서 유사도 0.93 이상이고 검증을 통과한 답만 재사용, 컬렉션 문서가 바뀌거나 근거 문서가 지워지면 앞선 캐시를 버림

## 화면
