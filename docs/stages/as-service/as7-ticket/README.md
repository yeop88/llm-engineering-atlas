# AS7 · 접수 티켓 · 상담원 이관 (Ticket & handoff)

**상태: ✅ 구현됨** — 해결되지 않으면 방문 · 수리 접수 티켓을 만들고 대화 요약과 함께 상담원에게 넘긴다

## 원리

미해결 · 안전 관련 · 고객 요청이면 티켓(고객 · 모델 · 증상 · 사진 · 시도한 조치)을 만들어 상담원 · 수리 기사에게 넘깁니다.

## 왜 하는가

티켓에 맥락이 없으면 상담원이 처음부터 다시 묻습니다. 자동 상담의 가치는 이관 품질에서도 나옵니다.

## 어떻게 (이 앱에서)

- 티켓: 고객 · 모델 · 증상 · 코드 · 시도한 조치 · 사진 수(상담원이 다시 묻지 않게)
- 안전 · 거절 · 위험 조치 · 미해결이면 자동 이관, AS_TICKET_WEBHOOK 으로 외부 접수 시스템에 보냄
- 티켓 상태(접수 · 처리 중 · 완료) · 메모
