# 티켓 · 상담원 이관 · 지표 (AS7 · AS8)

화면은 `/as/tickets`(지표 · 티켓 목록 · 상세 · 상태 바꾸기)입니다.

## AS7 티켓 · 이관

- **이관하는 경우**: 안전 문의(검색 없이 바로), 자료에서 답을 찾지 못함(거절), 출력 정책이 막은 위험 조치 요청, 고객이 '해결 안 됨'으로 답함.
- **티켓 내용**: 고객 · 제품 모델 · 의도 · 긴급도 · 증상(고객 말 최근 5개) · 오류 코드 · 이미 안내한 조치(답의 번호 단계) · 사진 수. 상담원이 처음부터 다시 묻지 않게 대화에서 뽑습니다. 고객의 피드백 문구('해결 안 됨')는 증상에서 뺍니다.
- **외부 접수 연동**: `AS_TICKET_WEBHOOK` 이 있으면 티켓 JSON 을 POST 하고 결과(상태 코드 · 오류)를 티켓에 남깁니다. 없으면 이 앱의 티켓 화면에만 남습니다.
- 상태: 접수 → 처리 중 → 완료(완료하면 상담을 닫음 — 화면이 한 번 확인을 받음).

## AS8 피드백 · 지표

- 답 끝의 '해결되셨나요?'에 해결됨 / 해결 안 됨 + 만족도(1~5) + 한마디. 해결 안 됨이면 티켓을 만듭니다.
- **해결률** = 해결됨 / 해결 여부를 답한 상담, **이관률** = 상담원에게 넘긴 상담 / 전체(기간 안), 만족도 평균, 의도별 건수 · 해결 · 이관.
- 해결률의 분모를 '답한 상담'으로 둔 이유: 답하지 않고 떠난 상담을 미해결로 세면 해결률이 실제보다 낮게, 해결로 세면 높게 나옵니다. 답한 수(`n_feedback`)를 함께 보여 줍니다.
- 상담 답변은 요청 기록(E3)에도 `kind=as` 로 남아 피드백(E5) · 개선 루프(E8) · 드리프트(E6)에서 함께 봅니다. 종단 평가로 만든 상담은 지표에 섞이지 않게 바로 지웁니다.
