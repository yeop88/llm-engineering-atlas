# AS7 · 접수 티켓 · 상담원 이관 (Ticket & handoff)

**상태: ⬜ 예정** — 해결되지 않으면 방문 · 수리 접수 티켓을 만들고 대화 요약과 함께 상담원에게 넘긴다

## 원리

미해결 · 안전 관련 · 고객 요청이면 티켓(고객 · 모델 · 증상 · 사진 · 시도한 조치)을 만들어 상담원 · 수리 기사에게 넘깁니다.

## 왜 하는가

티켓에 맥락이 없으면 상담원이 처음부터 다시 묻습니다. 자동 상담의 가치는 이관 품질에서도 나옵니다.

## 어떻게 (이 앱에서)

- (기반) 상담원 이관(C6) · 오케스트레이터(MA3)
- (예정) 티켓 형식 · 외부 시스템 연동(가짜 접수 API 로 시험)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/as_ticket` 에서 볼 수 있습니다.
