# AS1 · 문의 접수 (텍스트 · 사진 · 음성) (Intake)

**상태: ✅ 구현됨** — 채팅 · 사진 · 음성 문의를 한 형식으로 받아 대화로 이어 간다

## 원리

접수 단계는 여러 경로(웹 채팅 · 사진 업로드 · 전화 음성)의 문의를 같은 형식(텍스트 + 첨부 + 고객 정보)으로 바꿉니다. 음성은 글로 옮기고, 사진은 그대로 붙입니다.

## 왜 하는가

AS 문의의 상당수가 '이 화면 좀 보세요' 같은 사진 · 음성입니다. 접수에서 형식이 갈리면 뒤 단계가 경로마다 따로 필요해집니다.

## 어떻게 (이 앱에서)

- 상담 한 건 = 세션(고객 · 제품 모델 · 경로 · 대화 · 분류 · 티켓)
- 글 · 사진(최대 3장) · 음성 — 음성은 STT_URL(OpenAI 호환 받아 적기, 예: whisper.cpp server)이 있을 때

## 화면

- `/as/console` — **상담 창**: 글 · 사진 · 음성 문의 → 분류 · 답변 · 조치 안내 · 검증
