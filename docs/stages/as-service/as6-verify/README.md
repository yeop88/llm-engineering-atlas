# AS6 · 품질 검증 (Verification)

**상태: ✅ 구현됨** — 안내가 매뉴얼과 맞는지 · 질문에 답하는지 · 안전 정책을 지키는지 확인한다

## 원리

답변 검증(근거 일치 · 질문 관련성)에 AS 정책(위험 조치 · 보증 범위 약속 금지)을 더해 통과 · 수정 · 이관을 정합니다.

## 왜 하는가

잘못된 수리 안내는 고장을 키우거나 사고가 됩니다. 근거에 있어도 다른 모델의 조치면 틀린 답입니다.

## 어떻게 (이 앱에서)

- 근거 일치 + 코드 일치(조치 안내는 문장 관련성 대신 — 단계 문장은 질문과 의미가 멀어 늘 낮게 나옴) + 출력 정책
- 다른 모델 근거 경고 · 고객 제품 자료에 없는 코드 알림

## 화면

- `/as/console#c-fb` — **검증 · 해결 여부**: 근거 · 코드 일치 · 정책
