# AS6 · 품질 검증 (Verification)

**상태: 🟡 기초 있음** — 안내가 매뉴얼과 맞는지 · 질문에 답하는지 · 안전 정책을 지키는지 확인한다

## 원리

답변 검증(근거 일치 · 질문 관련성)에 AS 정책(위험 조치 · 보증 범위 약속 금지)을 더해 통과 · 수정 · 이관을 정합니다.

## 왜 하는가

잘못된 수리 안내는 고장을 키우거나 사고가 됩니다. 근거에 있어도 다른 모델의 조치면 틀린 답입니다.

## 어떻게 (이 앱에서)

- (있음) 근거 일치 · 질문 관련성 검증, 사람 판정 보정
- (예정) AS 정책 검사, 모델 불일치 검사(프로필의 모델 vs 근거 문서의 모델)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/as_verify` 에서 볼 수 있습니다.

## 앞으로 할 일

- AS 정책 검사
- 모델 불일치 검사
