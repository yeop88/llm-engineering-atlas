# ME4 · 갱신 · 충돌 해결 (Update & conflict resolution)

**상태: ⬜ 예정** — 새 기억이 기존 기억과 같은지 · 바꾸는지 · 부딪히는지 판단해 고친다

## 원리

갱신은 새 기억마다 추가 · 고치기 · 무효화 · 그대로 중 하나를 고르는 것입니다. 덮어쓰지 않고 예전 기억에 '언제까지 맞았다'를 남깁니다(시점 기록).

## 왜 하는가

고객이 이사했는데 예전 주소로 기사를 보내면 안 됩니다. 반대로 지운 기억 때문에 '예전엔 어디 살았나'에 답하지 못해도 안 됩니다.

## 어떻게 (이 앱에서)

- (기반) 엔티티 융합 · 정제(K4)
- (예정) 추가 · 고치기 · 무효화 · 그대로 판단 · 시점 기록 · 충돌 시험
