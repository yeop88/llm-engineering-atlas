# ME4 · 갱신 · 충돌 해결 (Update & conflict resolution)

**상태: ✅ 구현됨** — 새 기억이 기존 기억과 같은지 · 바꾸는지 · 부딪히는지 판단해 고친다

## 원리

갱신은 새 기억마다 추가 · 고치기 · 무효화 · 그대로 중 하나를 고르는 것입니다. 덮어쓰지 않고 예전 기억에 '언제까지 맞았다'를 남깁니다(시점 기록).

## 왜 하는가

고객이 이사했는데 예전 주소로 기사를 보내면 안 됩니다. 반대로 지운 기억 때문에 '예전엔 어디 살았나'에 답하지 못해도 안 됩니다.

## 어떻게 (이 앱에서)

- (기반) 엔티티 융합 · 정제(K4)
- 하나만 맞는 key(이름 · 주소 · 연락처 · 선호)에 다른 값 → 예전 기억에 valid_to · superseded_by 를 남기고 새 기억(덮어쓰지 않음)
- 여럿이 쌓이는 key(보유 제품 · 수리 이력)는 추가, 같은 값 · 아주 비슷한 문장(0.92)은 그대로(쓰임만 갱신)
