# ME3 · 기억 검색 (Memory retrieval)

**상태: ⬜ 예정** — 질문과 비슷함 · 최근 · 중요도 · 연결을 합쳐 기억을 고른다

## 원리

기억 검색은 질문과 비슷한 기억을 찾되, 최근 것 · 중요한 것에 가산하고 연결된 기억을 함께 꺼내 맥락에 넣을 몇 개를 고르는 것입니다.

## 왜 하는가

비슷함만 보면 몇 달 전 낡은 기억이 오늘 기억보다 먼저 나옵니다. 시간과 중요도를 함께 봐야 합니다.

## 어떻게 (이 앱에서)

- (기반) RAG 혼합 검색(2) · 그래프 확장(K7)
- (예정) 비슷함 × 최근 × 중요도 점수 · 연결 확장 · 가중치별 정답률
