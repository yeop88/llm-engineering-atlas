# ME6 · 메모리 계층 (Memory tiers)

**상태: ✅ 구현됨** — 항상 넣는 핵심 기억 · 꺼내 쓰는 기억 · 보관 기억으로 나눠 맥락 예산을 지킨다

## 원리

메모리 계층은 늘 맥락에 두는 작은 핵심 기억(이름 · 보유 제품 · 선호)과 질문할 때만 꺼내는 기억, 거의 쓰지 않는 보관 기억을 나눠 맥락 예산 안에서 운영하는 것입니다.

## 왜 하는가

모든 기억을 같은 방식으로 다루면 핵심 정보가 검색에서 빠지거나 맥락이 넘칩니다.

## 어떻게 (이 앱에서)

- (기반) 맥락 예산 · 배치(CX1)
- 핵심(core): 지금 맞는 이름 · 주소 · 연락처 · 선호 · 보유 제품 — 질문과 상관없이 맥락 맨 앞에 짧게(400자)
- 꺼내 쓰기(recall): 점수 상위 k, 보관(archive): 무효 이력 · 합쳐진 사건 — 과거 질문일 때만, 계층별 글자 수

## 화면

- `/memory/recall#retrieve` — **메모리 계층**: 핵심 · 꺼내 쓰기 · 보관, 계층별 글자 수
