# ME5 · 통합 · 망각 (Consolidation & forgetting)

**상태: ✅ 구현됨** — 비슷한 기억을 합치고 낡고 안 쓰는 기억은 요약하거나 지운다

## 원리

통합은 여러 사건 기억을 하나의 요약 사실로 합치는 것이고, 망각은 오래 쓰이지 않고 중요도가 낮은 기억을 지우는 것입니다.

## 왜 하는가

기억이 끝없이 쌓이면 검색이 흐려지고 저장 비용이 늡니다. 무엇을 남길지가 품질을 정합니다.

## 어떻게 (이 앱에서)

- (기반) 대화 압축(C5)
- 같은 key 의 오래된 사건이 많으면 요약 기억 하나로 합치고 원래 기억은 보관(검색에서만 뺌)
- 중요도 × 쓰임 감쇠가 문턱보다 낮은 보관 · key 없는 기억을 지움 — 핵심 · 지금 맞는 단일 key 기억은 잊지 않음, 미리 보기 먼저

## 화면

- `/memory/recall#consolidate` — **통합 · 망각**: 오래된 사건 요약 · 쓰임 감쇠 망각
