# ME2 · 메모리 DB 저장 · 연결 (Memory store & links)

**상태: ⬜ 예정** — 기억을 DB 에 벡터 · 낱말 · 연결과 함께 저장한다

## 원리

메모리 DB 는 기억마다 벡터 · 키워드 · 태그 · 다른 기억과의 연결(같은 제품 · 같은 사건)을 저장해, 하나를 찾으면 이어진 기억도 따라오게 하는 저장소입니다.

## 왜 하는가

기억이 서로 떨어져 있으면 '그때 그 수리' 같은 질문에 필요한 기억을 한 번에 모을 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 세션 노트(CX5) · 그래프 융합(K4)
- (예정) 기억 표 · 벡터 · 키워드 · 연결 표, 저장할 때 비슷한 기억과 연결

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/me_store` 에서 볼 수 있습니다.

## 앞으로 할 일

- 기억 표 · 벡터 · 키워드 · 연결 표, 저장할 때 비슷한 기억과 연결
