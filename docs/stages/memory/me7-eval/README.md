# ME7 · 여러 세션 평가 (Long-term memory evaluation)

**상태: ✅ 구현됨** — 여러 세션에 걸친 대화로 기억 · 갱신 · 시간 질문을 묻고 전체 기록 넣기와 비교한다

## 원리

장기 메모리 평가는 몇 세션에 걸친 대화를 만든 뒤 '지금 주소는?' · '처음 산 제품은?' · '지난번 수리는 언제?' 같은 질문으로 기억 · 갱신 · 시간 추론을 채점하는 것입니다.

## 왜 하는가

메모리가 전체 기록을 넣는 것보다 정말 나은지, 얼마나 싸고 정확한지는 같은 질문으로 비교해야 압니다.

## 어떻게 (이 앱에서)

- (기반) 평가 세트(E1)
- 정해진 씨앗의 고객별 세션 4개(이사 · 제품 추가 · 선호 변경 · 수리 날짜, 잡담 섞음)와 질문 6유형(갱신 둘 · 과거 · 누적 · 시간 · 없는 기억)
- 방식(전체 기록 · 메모리 · 없음)별 정답률 · 유형별 · 맥락 글자 — 정답 값 포함 · 예전 값이 먼저 나오면 틀림 · 없는 기억은 거절해야 맞음(LLM 판정 없음)
