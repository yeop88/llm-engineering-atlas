# ME1 · 기억 추출 (Memory extraction)

**상태: ✅ 구현됨** — 대화에서 기억할 사실 · 선호 · 사건을 한 문장 단위로 뽑는다

## 원리

기억 추출은 대화 원문 대신 '고객은 WM-200 을 쓴다', '오후 방문을 선호한다' 같은 사실 단위를 뽑아 누가 · 언제 말했는지와 함께 남기는 것입니다.

## 왜 하는가

원문을 그대로 쌓으면 찾기도 어렵고 맥락도 금방 찹니다. 사실 단위여야 갱신 · 충돌 판단을 할 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 대화 메모리 · 제품 · 코드 추출(C3)
- 규칙(이름 · 주소 · 보유 제품 · 선호 시간 · 수리 이력 · 연락처) + LLM(규칙 밖 사실) — 같은 key 목록, 연락처는 가려서
- 사건은 '일어난 날'(3월 20일 · 어제 · 지난주)을 말한 날 기준으로 풀어 함께
