# TL6 · 안전 정렬 (Safety alignment)

**상태: ⬜ 예정** — 학습 전후 레드팀 · 거절 균형을 같은 문항으로 확인한다

## 원리

안전 정렬은 해로운 요청을 거절하고 인젝션에 덜 흔들리게 하는 단계입니다. 학습 전후 같은 레드팀 문항으로 차단율과 과한 거절(정상 질문 거절)을 함께 잽니다.

## 왜 하는가

정렬 학습이 지시를 더 잘 따르게 만들면 인젝션에도 더 잘 따를 수 있습니다. 안전은 학습마다 다시 재야 합니다.

## 어떻게 (이 앱에서)

- (기반) 레드팀(G7) · 보상 해킹 감시(RV4)
- (예정) 학습 단계마다 레드팀 회귀 · 과한 거절률

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/tl_safety` 에서 볼 수 있습니다.
