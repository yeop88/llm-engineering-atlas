# TL7 · 평가 (Evaluation)

**상태: ⬜ 예정** — 기본 모델 대비 업무 · 일반 · 안전을 짝지은 질문으로 비교한다

## 원리

평가는 학습한 모델을 기본 모델과 같은 질문으로 비교해 업무 정답률 · 일반 능력 · 안전을 함께 보는 단계입니다. 질문마다 짝지어 차이의 신뢰 구간을 냅니다.

## 왜 하는가

평균 점수만 보면 표본 오차를 개선으로 착각합니다. 짝지은 비교여야 작은 차이를 믿을 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 후학습 평가(P6) · 회귀 평가(E2)
- (예정) 생애주기 전 단계의 평가 결과를 한 줄로

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/tl_eval` 에서 볼 수 있습니다.
