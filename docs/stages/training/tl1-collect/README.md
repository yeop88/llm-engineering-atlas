# TL1 · 데이터 수집 (Data collection)

**상태: ⬜ 예정** — 학습 데이터의 출처(운영 기록 · 합성 · 공개)를 모으고 출처를 남긴다

## 원리

데이터 수집은 학습에 쓸 예시를 모으는 단계입니다. 이 앱에서는 운영 요청 기록 · 검토된 피드백 · 합성 데이터 · 공개 말뭉치가 출처이고, 예시마다 출처 · 날짜 · 동의를 남깁니다.

## 왜 하는가

출처를 잃으면 나중에 문제 예시(개인정보 · 저작권 · 평가 누수)를 찾아 뺄 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 운영 로그(FW1) · 합성 데이터(P1)
- (예정) 출처 · 동의 · 날짜가 붙은 학습 데이터 목록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/tl_collect` 에서 볼 수 있습니다.

## 앞으로 할 일
