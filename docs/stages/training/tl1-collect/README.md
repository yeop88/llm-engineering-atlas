# TL1 · 데이터 수집 (Data collection)

**상태: ✅ 구현됨** — 학습 데이터의 출처(운영 기록 · 합성 · 공개)를 모으고 출처를 남긴다

## 원리

데이터 수집은 학습에 쓸 예시를 모으는 단계입니다. 이 앱에서는 운영 요청 기록 · 검토된 피드백 · 합성 데이터 · 공개 말뭉치가 출처이고, 예시마다 출처 · 날짜 · 동의를 남깁니다.

## 왜 하는가

출처를 잃으면 나중에 문제 예시(개인정보 · 저작권 · 평가 누수)를 찾아 뺄 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 플라이휠 기록(FW1) · 후학습 데이터 모으기(P1)
- 모델에서 거꾸로 어댑터 → 학습 데이터 → 메타의 출처별 건수(증류 · 플라이휠 · 거절 합성 · 선호 쌍), GRPO 는 과제 이름 · 개수
