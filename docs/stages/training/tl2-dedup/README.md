# TL2 · 전처리 · 중복 제거 (Preprocessing & dedup)

**상태: ⬜ 예정** — 중복 · 저품질 · 평가와 겹치는 예시를 거른다

## 원리

전처리는 형식을 맞추고 중복(정확 · 근사), 저품질, 개인정보, 평가 질문과 겹치는 예시를 거르는 단계입니다. 남은 건수를 단계별로 기록합니다.

## 왜 하는가

평가 질문이 학습에 섞이면 점수가 오른 것처럼 보입니다. 중복은 특정 답을 외우게 합니다.

## 어떻게 (이 앱에서)

- (기반) 선별 · 누수 검사(P2) · 정제(D4)
- (예정) 단계별 남은 건수 · 누수 0 확인

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/tl_dedup` 에서 볼 수 있습니다.
