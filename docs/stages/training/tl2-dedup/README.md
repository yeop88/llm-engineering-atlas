# TL2 · 전처리 · 중복 제거 (Preprocessing & dedup)

**상태: ✅ 구현됨** — 중복 · 저품질 · 평가와 겹치는 예시를 거른다

## 원리

전처리는 형식을 맞추고 중복(정확 · 근사), 저품질, 개인정보, 평가 질문과 겹치는 예시를 거르는 단계입니다. 남은 건수를 단계별로 기록합니다.

## 왜 하는가

평가 질문이 학습에 섞이면 점수가 오른 것처럼 보입니다. 중복은 특정 답을 외우게 합니다.

## 어떻게 (이 앱에서)

- (기반) 선별 · 누수(P2) · 문서 정제(D4)
- 만들 때의 보고(입력 → 형식 → 중복 → 누수)와 누수 검사에 쓴 평가 세트 유무
- 만든 뒤 다시 읽어 비슷한 질문 쌍 · 같은 답 반복 · 짧은 답 · 거절 몫 · 채팅 틀 조각 · 선호 쌍 길이 치우침을 센다
