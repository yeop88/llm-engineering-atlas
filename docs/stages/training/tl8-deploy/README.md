# TL8 · 배포 (Deployment)

**상태: ⬜ 예정** — GGUF 로 내보내 게이트 · 단계적 배포로 운영에 넣는다

## 원리

배포는 학습한 가중치를 서빙 형식(GGUF 등)으로 바꿔 품질 게이트를 통과시키고, 일부 트래픽부터 단계적으로 넣는 것입니다. 생애주기 기록에 '어느 판이 언제 몇 % 에' 를 남깁니다.

## 왜 하는가

배포한 모델이 어떤 데이터 · 학습으로 만들어졌는지 모르면 문제가 생겼을 때 되돌릴 판을 고를 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 배포 변환(P7) · 단계적 배포(FW7)
- (예정) 판 · 데이터 · 학습 · 평가 · 배포를 잇는 생애주기 기록

## 화면
