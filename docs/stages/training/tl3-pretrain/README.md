# TL3 · 사전학습 (Pretraining)

**상태: 🔬 연구** — 사전학습은 하지 않고, 쓰는 공개 모델의 사전학습 정보(데이터 · 토큰 수)를 기록만 한다

## 원리

사전학습은 큰 말뭉치로 다음 토큰을 예측하게 하는 단계입니다. 이 PC 로는 할 수 없어, 쓰는 공개 모델의 사전학습 데이터 규모 · 언어 비율 · 컷오프를 모델 카드에서 기록해 생애주기의 출발점으로 둡니다.

## 왜 하는가

같은 후학습도 출발 모델의 사전학습(한국어 비율 등)에 따라 결과가 다릅니다. 출발점을 적어야 비교가 됩니다.

## 어떻게 (이 앱에서)

- (기반) 모델 계보(LN1)
- (연구) 공개 모델의 사전학습 정보 기록 · 작은 모델의 계속 사전학습 흉내

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/tl_pretrain` 에서 볼 수 있습니다.
