# LN6 · 라이선스 · 배포 조건 (License & terms)

**상태: ✅ 구현됨** — 라이선스 · 사용 제한 · 재배포 조건을 모델 카드에서 확인해 남긴다

## 원리

라이선스는 상업 사용 · 재배포 · 사용자 수 제한 · 금지 용도 같은 조건입니다. 가중치 공개와 자유 사용은 다르며, 파생 모델은 원 모델의 조건을 따릅니다.

## 왜 하는가

성능이 좋아도 쓸 수 없는 모델이 있습니다. 배포 직전에 알면 비용이 큽니다 — 고를 때부터 조건이 보여야 합니다.

## 어떻게 (이 앱에서)

- (기반) 라이선스 점검(G6)
- GGUF general.license · 링크 · 이름, HF 모델 카드 메타 — id 와 링크가 다른 라이선스를 가리키면 '확인 필요', 기반 모델 저장소 · 양자화한 곳(QUANTIZED_FROM · DERIVED_FROM)
