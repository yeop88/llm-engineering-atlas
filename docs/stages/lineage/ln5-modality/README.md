# LN5 · 입력 · 출력 모달리티 (Modalities)

**상태: ⬜ 예정** — 글 · 이미지 · 소리 · 영상 입력과 출력을 모델별로 적는다

## 원리

모달리티는 모델이 받는 것(글 · 이미지 · 소리 · 영상)과 내는 것(글 · 소리 · 이미지)입니다. 같은 모델도 투영기(mmproj) 파일이 있어야 이미지를 봅니다.

## 왜 하는가

'이미지 질문' 을 글 전용 모델로 보내면 조용히 틀립니다. 라우팅(M29)이 고를 수 있으려면 모달리티가 사실로 있어야 합니다.

## 어떻게 (이 앱에서)

- (기반) 멀티모달(M) · 음성 인식(VC1)
- (예정) SUPPORTS_MODALITY · 투영기 파일 · 모달리티별 실측 연결

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ln_modality` 에서 볼 수 있습니다.
