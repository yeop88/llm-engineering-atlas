# LN1 · 모델 계열 (Model family)

**상태: ⬜ 예정** — 모델을 계열(만든 곳 · 구조 흐름)로 묶는다

## 원리

모델 계열은 같은 곳에서 같은 구조 흐름으로 만든 모델 묶음(Qwen · Gemma · Llama · EXAONE 등)입니다. 계열이 같으면 토크나이저 · 채팅 틀 · 약점이 비슷합니다.

## 왜 하는가

계열을 알면 처음 보는 모델의 채팅 틀 · 토크나이저 · 양자화 호환을 짐작할 수 있습니다. 모델이 늘수록 하나씩 따로 볼 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 임베딩 카탈로그(1) · GGUF 머리말(BM1)
- (예정) 계열 · 제작사 · 모델 노드 · BELONGS_TO 관계
