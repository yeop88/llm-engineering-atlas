# 기반 모델 계보 — GGUF 머리말 · HF 설정 · 모델 카드 · 계열 · 세대 · 구조 · 맥락 · 모달리티 · 라이선스 확인 · 실측 (LN1~LN6)

화면은 `/lineage/models`(모델 계보) · `/lineage/graph`(계보 관계 · 세대 비교), 코드는 `app/stages/lineage/` 입니다. 읽은 모델은 `data/lineage/models.json` 에 쌓입니다.

```
GGUF 머리말(general.* · 구조 · 텐서) ─┐
HF config.json + 모델 카드 메타 ──────┴→ 계열 · 세대(이름 규칙, 추정 표시) · 구조 숫자 · 맥락 · 모달리티 · 라이선스 · 기반 모델
                                        → 관계: BELONGS_TO · MADE_BY · SUCCEEDS · QUANTIZED_FROM · DERIVED_FROM ·
                                                HAS_ARCHITECTURE · SUPPORTS_MODALITY · LICENSED_UNDER
```

## 설계

- **이름보다 설정 파일.** 카드의 말보다 config · GGUF 머리말의 숫자를 믿습니다. GGUF 는 기반 모델 저장소(`general.base_model.*`) · 제작사 · 양자화한 곳 · 크기 표시 · 라이선스 id · 링크를, HF 는 config.json 에 층 · 차원 · 전문가 · 맥락 · 위치 확장을, 모델 카드 메타에 라이선스 · 기반 모델 · 용도 태그를 둡니다. 가중치는 받지 않습니다.
- **계열은 이름이 먼저.** 계열 · 제작사는 모델 · 파일 이름 규칙으로 정하고 구조 이름(`general.architecture`)은 마지막에만 봅니다 — 처음에는 구조 이름까지 같이 봐서 kanana-2(구조는 qwen3)가 Qwen 계열로 잡히고, 그 결과 Qwen3.5 가 kanana 의 다음 세대로 이어지는 잘못된 관계가 생겼습니다. 계열 · 세대는 이름에서 추정한 값이라 화면에 그렇게 표시합니다.
- **라이선스는 id · 링크 · 이름을 맞춰 본다(LN6).** id 와 링크가 서로 다른 라이선스를 가리키면 '확인 필요' 입니다. 가진 gemma-4 GGUF 4개는 id 가 `apache-2.0` 인데 링크는 Gemma 전용 라이선스 문서였습니다 — 어느 쪽이 맞는지는 원 저장소의 라이선스로 확인해야 하고, 확인하기 전에는 배포 조건을 정할 수 없습니다. id 가 `other` 인데 이름이 없어도 확인 필요입니다.
- **할 수 있는 것과 이 PC 에서 쓸 수 있는 것(LN5).** 모달리티는 모델이 받는 것(태그 · vision/audio 설정)이고, 이 PC 에서 이미지를 쓰려면 같은 폴더에 투영기(mmproj) 파일이 있어야 합니다. Qwen3.5-4B 는 이미지 모델이지만 투영기 파일이 없어 '투영기 파일 없음' 으로 표시됩니다.
- **같은 모델의 다른 비트를 묶는다(LN1 · LN2).** 같은 기반 모델 저장소를 가리키는 GGUF 들을 QUANTIZED_FROM 으로 기반에 묶어 양자화 비교(7b · IF3)의 후보가 한눈에 보이게 합니다. 세대(SUCCEEDS)는 같은 계열 안에서 세대 번호 순으로만 잇고, 두 모델을 골라 구조 숫자 · 맥락 · 모달리티 · 라이선스의 바뀐 점을 봅니다.

해석:

- **Gemma 4 는 모두 '확인 필요'입니다.** HF 저장소 · GGUF 4개 · unsloth 의 GGUF 저장소 모두 라이선스 id 는 apache-2.0 인데 링크는 Gemma 4 라이선스 문서입니다. 원 저장소의 라이선스 문서로 확인하기 전에는 배포 조건을 정할 수 없습니다. 학습 생애주기(TL3)가 이 기록을 원장 앞에 두는 이유입니다.
- **양자화 관계 6개가 묶였습니다.** 가진 GGUF 6개가 모두 기반 저장소를 가리켜, 같은 기반의 다른 비트(gemma-4-E4B q4_0 · Q8_0 · UD-Q2_K_XL)가 한 기반 아래 모입니다(7b 양자화 비교 후보).
- **처음에는 A.X 가 '기타' 계열로 나왔습니다.** 이름에 점이 들어간 'A.X' 를 계열 규칙이 몰라서입니다. 규칙을 더해 A.X(SKT) 4.0 으로 고쳤습니다. 계열은 이름 규칙으로 추정한 값이라, 새 제작사가 나오면 규칙을 늘려야 합니다.
- **같은 모델이라도 HF 어림과 GGUF 의 파라미터 수가 다릅니다.** Qwen3.5-4B 는 HF config 어림 3.74B · GGUF 4.21B 입니다. HF 어림은 글 모델 부분만 세고, GGUF 는 실제 텐서(시각 부분 일부 포함)를 셉니다.
