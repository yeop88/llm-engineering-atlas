# LN4 · 컨텍스트 길이 (Context length)

**상태: ⬜ 예정** — 학습 · 확장 맥락 길이와 실제로 쓸 수 있는 길이를 나눠 적는다

## 원리

컨텍스트 길이는 모델 카드의 최대 길이, 학습할 때의 길이, 위치 확장(YaRN 등)으로 늘린 길이가 다릅니다. 실제로 쓸 수 있는 길이는 긴 맥락 실측(CX2)으로 확인합니다.

## 왜 하는가

카드의 128K 를 믿고 넣었다가 중간 근거를 놓치는 일이 흔합니다. 적힌 길이와 잰 길이를 함께 둬야 고를 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 긴 맥락 vs RAG(CX2)
- (예정) 학습 · 확장 · 실측 길이 · 위치 부호 방식
