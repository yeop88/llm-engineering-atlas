# LN2 · 모델 세대 (Generations)

**상태: ⬜ 예정** — 같은 계열 안의 세대 차이(무엇이 바뀌었나)를 잇는다

## 원리

세대는 같은 계열의 다음 판(Qwen2 → Qwen3 → Qwen3.5)입니다. 세대마다 맥락 길이 · 어텐션 구조 · 생각 모드 · 모달리티가 바뀌어, SUCCEEDS 관계와 바뀐 점을 함께 남깁니다.

## 왜 하는가

새 세대가 나오면 '바꿔야 하나'를 판단해야 합니다. 무엇이 바뀌었는지 표로 있어야 같은 평가로 비교할 대상을 고릅니다.

## 어떻게 (이 앱에서)

- (기반) 모델 계열(LN1)
- (예정) 세대 노드 · SUCCEEDS · 바뀐 점(맥락 · 구조 · 모드) 표
