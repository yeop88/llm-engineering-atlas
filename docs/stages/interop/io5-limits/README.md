# IO5 · 호출 · 비용 상한 (Call & cost limits)

**상태: ✅ 구현됨** — 요청 하나가 쓸 수 있는 도구 호출 수 · 시간 · 비용에 상한을 두고, 넘으면 멈추고 알린다

## 원리

에이전트는 도구를 반복 호출하다 끝나지 않을 수 있습니다. 단계 수 · 총 시간 · 토큰 · 외부 API 비용에 상한을 두고, 상한에 닿으면 모은 결과로 답하거나 사람에게 넘깁니다.

## 왜 하는가

에이전트 측정에서 한 질문이 20분 걸렸습니다. 외부 유료 도구가 연결되면 같은 일이 비용으로 바로 나타납니다.

## 어떻게 (이 앱에서)

- MCP 세션 · 위임 작업마다 호출 수 · 시간 · 비용 상한(INTEROP_MAX_CALLS · INTEROP_MAX_SECONDS · INTEROP_MAX_COST)
- 상한에 닿으면 호출을 막고 '모은 결과로 답하거나 사람에게 넘기라'는 도구 오류로 돌려주며 감사 기록에 상한으로 남김

## 화면

- `/interop/audit#limits` — **호출 · 비용 상한**: 세션 · 위임별 호출 수 · 시간 · 비용
