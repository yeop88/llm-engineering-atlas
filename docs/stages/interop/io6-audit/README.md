# IO6 · 감사 추적 · 신뢰 경계 (Audit trail & trust boundaries)

**상태: ✅ 구현됨** — 어느 도구 · 에이전트가 무엇을 받아 무엇을 했는지 추적 id 로 남기고, 신뢰 경계를 넘은 입력을 표시한다

## 원리

감사 추적은 요청 하나에 엮인 모든 도구 호출 · 위임 · 결과를 같은 추적 id 로 연결한 기록입니다. 외부에서 온 결과(신뢰 경계 밖)는 표시해 검증 대상으로 둡니다.

## 왜 하는가

여러 에이전트 · 도구가 얽히면 문제가 생겼을 때 어디서 잘못된 정보가 들어왔는지 찾기 어렵습니다.

## 어떻게 (이 앱에서)

- 도구 호출 · 위임을 tool_calls 에 추적 id 로(통로 · 부른 쪽 · 대상 · 범위 · 입력 · 결과 요약 · 결과 · 시간)
- 신뢰 경계 밖 결과(외부 MCP · 외부 에이전트 · 샌드박스)는 '외부 결과'로 표시하고 지시 문장을 문장 단위로 빼 남김(가드레일 G1 의 정리)

## 화면

- `/interop/audit` — **호출 상한 · 감사 추적**: 추적 id 로 이은 호출 · 위임, 외부 결과 표시

## 앞으로 할 일

- 서비스 요청 기록(traces)과 추적 id 잇기
