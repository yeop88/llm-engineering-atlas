# IO1 · 도구 정의 · 검색 (MCP 서버) (Tool definitions (MCP))

**상태: ✅ 구현됨** — 검색 · 조회 · 계산 같은 도구를 MCP 서버로 표준화해 어느 에이전트 · 앱에서나 쓰게 한다

## 원리

MCP(Model Context Protocol)는 LLM 앱이 외부 도구 · 자료에 접근하는 표준 방식입니다. 도구마다 이름 · 설명 · 입력 형식을 정의한 서버를 두면, 에이전트는 표준 방식으로 도구 목록을 받고 호출합니다.

## 왜 하는가

도구를 앱마다 따로 붙이면 같은 도구를 여러 번 만들게 됩니다. 이 프로젝트의 검색 · 번호 조회 · 계산 도구를 MCP 로 내보내면 다른 에이전트 환경에서도 쓸 수 있습니다.

## 어떻게 (이 앱에서)

- 이 앱의 검색 · 조문 번호 조회 · 청크 읽기 · 계산 · 그래프 조회 · 코드 실행 · 사람 검토 요청 도구 8개를 MCP 서버(/mcp, Streamable HTTP · JSON-RPC 2.0, 규격 2025-06-18)로
- 도구 설명에 '언제 쓰는가'(번호가 있으면 조회 먼저)를 적고, 입력 형식(JSON Schema)을 호출 전에 검사 · 도구 오류는 isError 결과로 돌려 LLM 이 고치게
- 다른 MCP 서버에 붙어 도구 목록 · 호출(클라이언트) — 외부 도구 설명 · 결과의 지시 문장을 표시
