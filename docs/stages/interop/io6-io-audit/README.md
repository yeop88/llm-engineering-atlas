# IO6 · 감사 추적 · 신뢰 경계 (Audit trail & trust boundaries)

**상태: ⬜ 예정** — 어느 도구 · 에이전트가 무엇을 받아 무엇을 했는지 추적 id 로 남기고, 신뢰 경계를 넘은 입력을 표시한다

## 원리

감사 추적은 요청 하나에 엮인 모든 도구 호출 · 위임 · 결과를 같은 추적 id 로 연결한 기록입니다. 외부에서 온 결과(신뢰 경계 밖)는 표시해 검증 대상으로 둡니다.

## 왜 하는가

여러 에이전트 · 도구가 얽히면 문제가 생겼을 때 어디서 잘못된 정보가 들어왔는지 찾기 어렵습니다.

## 어떻게 (이 앱에서)

- (기반) 감사 로그(G5) · 트레이싱(E3)
- (예정) 도구 · 위임 단위 추적, 외부 입력 표시
