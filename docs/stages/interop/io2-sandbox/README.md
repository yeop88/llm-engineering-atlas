# IO2 · 권한 · 샌드박스 (Permissions & sandboxing)

**상태: ✅ 구현됨** — 도구마다 할 수 있는 일(읽기 · 쓰기 · 네트워크)을 제한하고, 실행형 도구는 격리된 곳에서 돌린다

## 원리

도구 권한은 최소한으로 줍니다 — 검색은 읽기만, 발송은 승인 후에만. 코드 실행 · 브라우저 같은 도구는 파일 · 네트워크 · 시간을 제한한 샌드박스에서 돌립니다.

## 왜 하는가

도구가 늘수록 프롬프트 인젝션의 피해가 커집니다. 읽기 도구만 있으면 정보가 새지만, 쓰기 도구가 있으면 시스템이 바뀝니다.

## 어떻게 (이 앱에서)

- 도구마다 범위(읽기 · 쓰기 · 실행), 역할별 허용(관리자 = 셋 다, 사용자 = 읽기 · 쓰기) — 쓸 수 없는 도구는 목록에서 빼 헛걸음을 줄임
- 코드 실행은 Docker 컨테이너(네트워크 없음 · 읽기 전용 · 메모리 256MB · CPU 1 · 프로세스 64 · 권한 없는 사용자 · 시간 상한), Docker 가 없으면 격리가 약한 별도 프로세스로 하고 그렇게 표시
- 검색 도구도 문서 권한(G3)을 그대로 적용
