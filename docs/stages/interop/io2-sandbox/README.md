# IO2 · 권한 · 샌드박스 (Permissions & sandboxing)

**상태: ⬜ 예정** — 도구마다 할 수 있는 일(읽기 · 쓰기 · 네트워크)을 제한하고, 실행형 도구는 격리된 곳에서 돌린다

## 원리

도구 권한은 최소한으로 줍니다 — 검색은 읽기만, 발송은 승인 후에만. 코드 실행 · 브라우저 같은 도구는 파일 · 네트워크 · 시간을 제한한 샌드박스에서 돌립니다.

## 왜 하는가

도구가 늘수록 프롬프트 인젝션의 피해가 커집니다. 읽기 도구만 있으면 정보가 새지만, 쓰기 도구가 있으면 시스템이 바뀝니다.

## 어떻게 (이 앱에서)

- (있음) 계산 도구는 eval 없이 산술식만, Text2Cypher(예정)는 읽기 전용 설계
- (예정) 도구별 권한 표, 실행형 도구 샌드박스(분석 에이전트와 공유)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/io_sandbox` 에서 볼 수 있습니다.

## 앞으로 할 일

- 도구별 권한 표
- 샌드박스
