# IO4 · 장기 작업 · 재시도 · 복구 (Long-running tasks)

**상태: ✅ 구현됨** — 오래 걸리는 도구 · 위임 작업을 비동기로 돌리고, 끊기면 재시도 · 이어 하기를 한다

## 원리

도구 · 위임 작업은 몇 분~몇 시간 걸릴 수 있습니다. 작업 id 로 비동기 실행 · 진행률 · 결과 조회를 하고, 실패하면 정해진 횟수만 재시도하며, 같은 작업이 두 번 실행돼도 안전하게(멱등) 만듭니다.

## 왜 하는가

동기 호출로 기다리면 연결이 끊길 때 결과를 잃습니다. 이 프로젝트의 측정 작업도 재시작하면 결과가 사라지던 문제를 작업 기록으로 고쳤습니다.

## 어떻게 (이 앱에서)

- 위임 작업을 DB(interop_tasks, 마이그레이션 0014)에 — 서버가 다시 떠도 상태 · 결과가 남음
- 같은 상대 · 같은 messageId 는 같은 작업(멱등), 받은 작업은 실패하면 1 · 2초 간격으로 두 번 더, 맡긴 작업은 보내기 3번 · 확인은 간격을 늘리며(1 → 10초)
- 끝나지 않은 위임은 상한에 닿으면 상대에게 취소를 보내고 멈춤

## 화면

- `/interop/a2a#tasks` — **작업 · 재시도**: 작업 상태 · 시도 · 멱등

## 앞으로 할 일

- 재시작 뒤 '진행' 상태로 남은 받은 작업 다시 띄우기
