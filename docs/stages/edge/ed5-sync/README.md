# ED5 · 서버와 동기화 · 업데이트 (Sync & updates)

**상태: ✅ 구현됨** — 바뀐 자료 · 모델만 기기로 보내고, 기기의 기록 · 피드백은 서버로 모은다

## 원리

동기화는 증분 갱신(바뀐 문서의 청크 · 벡터만)과 모델 업데이트, 기기에서 서버로 가는 피드백 · 사용 기록을 다룹니다. 버전이 맞지 않는 기기를 찾습니다.

## 왜 하는가

기기마다 자료 버전이 다르면 같은 질문에 다른 답이 나옵니다. 전체를 매번 내려받을 수는 없습니다.

## 어떻게 (이 앱에서)

- (기반) 메타데이터 · 증분 갱신(D6)
- 증분: 두 판의 문서별 sha256 비교 → 바뀐 · 새 문서의 청크만 + 지울 청크 번호, 모델 · 정밀도 · 청크 세트가 바뀌면 전체, 적용 결과 지문 = 서버 최신 판 지문인지 계산으로 확인
- 기기 버전 관리: 받은 팩 · 판 · 마지막 동기화로 판 뒤처짐 · 오래 연결 안 됨(EDGE_STALE_HOURS)을 표시, 대기열 수
