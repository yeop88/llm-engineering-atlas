# ED1 · 기기별 모델 선택 (Device-aware model selection)

**상태: 🟡 기초 있음** — 기기의 메모리 · 연산 능력에 맞는 임베딩 · LLM 크기를 고르고 품질 손실을 잰다

## 원리

기기마다 쓸 수 있는 메모리와 연산(CPU · NPU · 내장 GPU)이 다릅니다. 모델 크기 · 비트 수 · 차원을 기기 예산에 맞춰 고르고, 같은 평가 세트로 손실을 잽니다.

## 왜 하는가

가장 작은 모델이 답이 아닙니다 — E2B 는 E4B 보다 지연 −21% 대신 품질 −13 이었습니다.

## 어떻게 (이 앱에서)

- (있음) 카탈로그의 파라미터 · 차원 · 크기, 소형 LLM 비교, 양자화 실측
- (예정) 기기 프로필 → 후보 모델 추천

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ed_select` 에서 볼 수 있습니다.
