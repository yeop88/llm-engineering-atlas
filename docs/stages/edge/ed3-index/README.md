# ED3 · 기기 내 검색 (작은 색인) (On-device retrieval)

**상태: ✅ 구현됨** — 필요한 자료만 압축 색인으로 기기에 담아 서버 없이 검색한다

## 원리

기기 내 검색은 담당 범위의 자료만 골라 binary + 재점수 같은 압축 색인으로 담습니다. 작은 색인은 정확 검색이 가능해 근사 검색의 재현율 문제도 피합니다.

## 왜 하는가

자료 전체를 기기에 넣을 수 없습니다. 무엇을 담을지(담당 제품군 · 최근 자료)가 품질만큼 중요합니다.

## 어떻게 (이 앱에서)

- (있음) 벡터 int4 · binary + 재점수(메모리 1/8 · 1/32), 작은 인덱스 정확 검색
- 담당 범위(제품 모델 · 문서 종류 · 최근 n일 · 문서 번호)의 청크만 압축 벡터로 담은 팩(폴더 하나 — manifest · chunks · vectors · 자주 묻는 답), 벡터 DB 없이 정확 검색
- 판을 올릴 때 바뀌지 않은 문서의 벡터는 앞 판에서 가져옴(같은 눈금), 평가 세트로 팩 vs 서버 — 정답이 범위 밖인 질문을 따로 세어 압축 손실과 '안 담아서 못 찾음'을 나눔
