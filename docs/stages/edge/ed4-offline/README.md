# ED4 · 오프라인 동작 (Offline operation)

**상태: ✅ 구현됨** — 연결이 끊겨도 검색 · 답변이 되고, 할 수 없는 일(사진 진단 등)은 연결될 때로 미룬다

## 원리

오프라인 동작은 기기 안의 모델 · 색인 · 캐시로 처리하고, 서버가 필요한 작업은 대기열에 넣었다가 연결되면 보내는 것입니다.

## 왜 하는가

현장 · 지하 · 보안 구역에서는 연결이 없습니다. 오프라인에서 무엇이 되고 안 되는지 사용자에게 분명해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 캐시(S1)
- 기능 범위: 검색 · 자주 묻는 답 · 답변 생성 · 사진 진단 · 법령 조회 · 지식 그래프 · 최신 자료를 기기에서 / 연결될 때 / 안 됨과 이유로
- 기기에서 묻기: 자주 묻는 답(근거가 모두 팩 안) → 팩 검색 → 기기 LLM 또는 근거만, 서버가 필요한 일은 거절하지 않고 미룬 요청으로 대기열에 → 연결되면 올려 서비스 답변으로 처리
