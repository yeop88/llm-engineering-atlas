# ED4 · 오프라인 동작 (Offline operation)

**상태: ⬜ 예정** — 연결이 끊겨도 검색 · 답변이 되고, 할 수 없는 일(사진 진단 등)은 연결될 때로 미룬다

## 원리

오프라인 동작은 기기 안의 모델 · 색인 · 캐시로 처리하고, 서버가 필요한 작업은 대기열에 넣었다가 연결되면 보내는 것입니다.

## 왜 하는가

현장 · 지하 · 보안 구역에서는 연결이 없습니다. 오프라인에서 무엇이 되고 안 되는지 사용자에게 분명해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 캐시(S1)
- (예정) 오프라인 기능 범위 · 대기열 · 연결 시 동기 전송

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ed_offline` 에서 볼 수 있습니다.
