# ED3 · 기기 내 검색 (작은 색인) (On-device retrieval)

**상태: 🟡 기초 있음** — 필요한 자료만 압축 색인으로 기기에 담아 서버 없이 검색한다

## 원리

기기 내 검색은 담당 범위의 자료만 골라 binary + 재점수 같은 압축 색인으로 담습니다. 작은 색인은 정확 검색이 가능해 근사 검색의 재현율 문제도 피합니다.

## 왜 하는가

자료 전체를 기기에 넣을 수 없습니다. 무엇을 담을지(담당 제품군 · 최근 자료)가 품질만큼 중요합니다.

## 어떻게 (이 앱에서)

- (있음) 벡터 int4 · binary + 재점수(메모리 1/8 · 1/32), 작은 인덱스 정확 검색
- (예정) 담당 범위 선택 · 기기용 색인 내보내기

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ed_index` 에서 볼 수 있습니다.
