# ED6 · 개인정보 국소 처리 (On-device privacy)

**상태: ⬜ 예정** — 고객 정보 · 사진 · 음성은 기기 안에서 처리하고 서버로는 가린 결과 · 통계만 보낸다

## 원리

국소 처리는 개인정보가 기기를 떠나지 않게 하는 설계입니다. 서버에 보내야 하면 마스킹 · 요약 · 집계 후에 보냅니다.

## 왜 하는가

기기에서 돌리는 큰 이유 중 하나가 개인정보입니다. 동기화 · 피드백 수집이 그 장점을 깨지 않게 해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 개인정보 탐지 · 마스킹(G2)
- (예정) 기기 → 서버 전송 정책 · 마스킹

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ed_privacy` 에서 볼 수 있습니다.
