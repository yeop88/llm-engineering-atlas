# ED2 · 극단적 양자화 · 증류 (Extreme quantization & distillation)

**상태: ✅ 구현됨** — 4비트 이하 · 이진 벡터 · 작은 학생 모델로 줄이고, 손실이 겹치는지 잰다

## 원리

극단적 경량화는 LLM 가중치 2~4비트, 벡터 int4 · binary, 큰 모델의 판단을 배운 작은 학생 모델을 함께 씁니다. 여러 압축이 겹칠 때 손실이 더해지는지 조합으로 잽니다.

## 왜 하는가

기기에 올리려면 여러 압축을 동시에 써야 하는데, 실측에서 압축은 겹치면 손실이 누적됐습니다.

## 어떻게 (이 앱에서)

- (있음) 양자화 조합 실측(가중치 × 차원 × 벡터 정밀도, 파레토), 임베딩 증류(학생 6배 빠름)
- 조합 점수 = 검색 recall × 답변 품질(압축 손실이 함께 깎이게), 손실은 압축별 실측의 합으로 추정, 같은 메모리에서 더 나은 조합이 없는 것만 파레토 앞줄
- 품질을 재지 않은 LLM 은 점수를 매기지 않고 '재야 할 후보'로
