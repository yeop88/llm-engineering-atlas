# LR7 · 권한 · 비용 상한 (Permission & cost limits)

**상태: ⬜ 예정** — 작업이 쓸 수 있는 권한 · 자료 · 비용 · 기간을 미리 정하고 넘으면 멈춘다

## 원리

장기 작업은 시작할 때 범위(접근 가능한 자료 · 쓸 수 있는 도구 · 최대 비용 · 마감)를 정합니다. 범위를 넘는 행동은 승인 지점으로 보냅니다.

## 왜 하는가

오래 도는 에이전트일수록 범위를 넘는 행동을 할 기회가 많습니다. 시작할 때 범위를 정해 두지 않으면 어디까지 허락했는지 나중에 확인할 수도 없습니다.

## 어떻게 (이 앱에서)

- (기반) 호출 · 비용 상한(IO5) · 권한별 검색(G3)
- (예정) 작업 범위 정의 · 초과 시 승인

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/lr_limits` 에서 볼 수 있습니다.
