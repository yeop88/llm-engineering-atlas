# LR4 · 사람 승인 지점 (Human approval points)

**상태: ⬜ 예정** — 되돌릴 수 없는 행동(발송 · 결제 · 삭제) 전에 사람의 승인을 받고, 기다리는 동안 상태를 유지한다

## 원리

승인 지점은 계획에 표시된 단계에서 실행을 멈추고 사람에게 결과 · 다음 행동을 보여 주는 것입니다. 승인 · 수정 · 거절을 기록하고, 기다리는 동안 다른 작업은 계속합니다.

## 왜 하는가

자동화의 사고는 대부분 되돌릴 수 없는 행동에서 납니다. 검증 에이전트가 있어도 최종 책임은 사람이 집니다.

## 어떻게 (이 앱에서)

- (기반) 검증 에이전트(MA7)
- (예정) 승인 대기 · 알림 · 승인 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/lr_approval` 에서 볼 수 있습니다.

## 앞으로 할 일
