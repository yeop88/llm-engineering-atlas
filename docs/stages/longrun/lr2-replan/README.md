# LR2 · 실행 · 재계획 (Execution & replanning)

**상태: ⬜ 예정** — 계획대로 실행하다 막히면 상황을 보고 계획을 고친다

## 원리

재계획은 작업 결과가 예상과 다를 때(자료 없음 · 도구 실패 · 조건 변경) 남은 계획을 다시 세우는 것입니다. 무한 재계획을 막는 횟수 상한을 둡니다.

## 왜 하는가

실제 업무는 계획대로 가지 않습니다. 하지만 작은 모델은 재계획을 반복하다 비용만 늘리기 쉽습니다(에이전트 20분 사례).

## 어떻게 (이 앱에서)

- (있음) 에이전트의 ReAct 반복 · 단계 상한
- (예정) 계획 수준 재계획 · 상한 · 변경 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/lr_replan` 에서 볼 수 있습니다.
