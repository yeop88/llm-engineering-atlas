# LR6 · 결과 검증 · 완료 판정 (Result verification)

**상태: 🟡 기초 있음** — 작업 결과를 완료 조건 · 근거 · 형식으로 검사해 '정말 끝났는지' 판정한다

## 원리

완료 판정은 에이전트의 '다 했다'가 아니라 검사로 합니다 — 체크리스트, 근거 일치 · 질문 관련성, 형식 검사, 숫자 재계산.

## 왜 하는가

작은 LLM 의 자기 판정은 믿기 어렵습니다(사람 판정 28개를 모두 통과시킨 LLM 판정).

## 어떻게 (이 앱에서)

- (있음) 답변 검증(근거 일치 · 질문 관련성 · 번호 검사), 회귀 평가
- (예정) 작업 완료 조건 검사기

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/lr_verify` 에서 볼 수 있습니다.
