# LR6 · 결과 검증 · 완료 판정 (Result verification)

**상태: ✅ 구현됨** — 작업 결과를 완료 조건 · 근거 · 형식으로 검사해 '정말 끝났는지' 판정한다

## 원리

완료 판정은 에이전트의 '다 했다'가 아니라 검사로 합니다 — 체크리스트, 근거 일치 · 질문 관련성, 형식 검사, 숫자 재계산.

## 왜 하는가

작은 LLM 의 자기 판정은 믿기 어렵습니다(사람 판정 28개를 모두 통과시킨 LLM 판정).

## 어떻게 (이 앱에서)

- 완료 조건: 필수 절 · 보고서의 숫자가 모두 집계 · 자료에 있나(지어낸 숫자) · 인용 번호 범위 · 근거 일치 0.6 이상 · 승인 · 발송
- 하나라도 미달이면 '완료'가 아니라 '검토 필요'
