# LR3 · 상태 저장 · 체크포인트 (State & checkpoints)

**상태: ✅ 구현됨** — 작업마다 상태 · 중간 결과를 저장해 서버가 재시작돼도 마지막 체크포인트부터 이어 간다

## 원리

체크포인트는 작업이 끝날 때마다 상태(완료한 작업 · 중간 결과 · 다음 할 일)를 저장하는 것입니다. 재시작하면 저장된 상태를 읽어 이어 갑니다.

## 왜 하는가

며칠짜리 작업은 중간에 반드시 끊깁니다. 지금 백그라운드 작업은 재시작하면 '중단됨'으로 표시만 되고 이어 하지는 못합니다.

## 어떻게 (이 앱에서)

- 업무 · 단계를 DB(lr_runs · lr_steps, 마이그레이션 0015)에 — 단계가 끝날 때마다 결과를 저장(체크포인트)
- 서버가 다시 뜨면 돌던 업무는 '중단됨', 돌던 단계는 다시 할 단계로 → '이어 하기'가 마지막 체크포인트 다음부터

## 화면
