# LR5 · 실패 복구 · 되돌리기 (Failure recovery & rollback)

**상태: ✅ 구현됨** — 실패한 작업을 재시도 · 대체 · 되돌리기 중에서 고르고, 이미 한 행동의 부작용을 정리한다

## 원리

복구는 실패 유형에 따라 재시도(일시적 오류), 대체 경로(도구 장애), 되돌리기(잘못된 결과)를 고르는 것입니다. 되돌릴 수 있도록 행동마다 반대 행동(보상 작업)을 정의합니다.

## 왜 하는가

중간에 실패한 업무는 '반쯤 된 상태'가 가장 위험합니다(메일 일부만 발송).

## 어떻게 (이 앱에서)

- 행동마다 보상 작업(발송 → 파일 삭제 · 웹훅 철회 알림), '되돌리기'는 끝난 단계를 나중 것부터
- 되돌릴 수 없는 행동은 단계 멱등 키로 두 번 하지 않음(재시도 · 이어 하기에서 다시 와도 같은 파일 · Idempotency-Key)
