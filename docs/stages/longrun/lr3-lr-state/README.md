# LR3 · 상태 저장 · 체크포인트 (State & checkpoints)

**상태: ⬜ 예정** — 작업마다 상태 · 중간 결과를 저장해 서버가 재시작돼도 마지막 체크포인트부터 이어 간다

## 원리

체크포인트는 작업이 끝날 때마다 상태(완료한 작업 · 중간 결과 · 다음 할 일)를 저장하는 것입니다. 재시작하면 저장된 상태를 읽어 이어 갑니다.

## 왜 하는가

며칠짜리 작업은 중간에 반드시 끊깁니다. 지금 백그라운드 작업은 재시작하면 '중단됨'으로 표시만 되고 이어 하지는 못합니다.

## 어떻게 (이 앱에서)

- (있음) 작업 기록(상태 · 진행률 · 결과 DB 저장, 재시작 시 중단 표시)
- (예정) 작업 단위 체크포인트 · 이어 하기
