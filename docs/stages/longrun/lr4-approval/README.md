# LR4 · 사람 승인 지점 (Human approval points)

**상태: ✅ 구현됨** — 되돌릴 수 없는 행동(발송 · 결제 · 삭제) 전에 사람의 승인을 받고, 기다리는 동안 상태를 유지한다

## 원리

승인 지점은 계획에 표시된 단계에서 실행을 멈추고 사람에게 결과 · 다음 행동을 보여 주는 것입니다. 승인 · 수정 · 거절을 기록하고, 기다리는 동안 다른 작업은 계속합니다.

## 왜 하는가

자동화의 사고는 대부분 되돌릴 수 없는 행동에서 납니다. 검증 에이전트가 있어도 최종 책임은 사람이 집니다.

## 어떻게 (이 앱에서)

- 승인 단계에서 업무는 상태만 남기고 멈춤(스레드가 기다리지 않음) — ALERT_WEBHOOK 으로 알림
- 승인 화면에 초안과 완료 조건 검사를 함께, 승인 · 반려한 사람 · 메모를 남김(관리자)

## 화면

- `/longrun/approvals` — **승인 · 완료 판정**: 승인 대기 · 반려 · 완료 조건
