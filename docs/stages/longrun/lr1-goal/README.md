# LR1 · 목표 분해 · 계획 (Goal decomposition & planning)

**상태: ⬜ 예정** — 큰 목표를 하위 작업 · 의존 관계 · 완료 조건이 있는 계획으로 나눈다

## 원리

계획은 작업 목록과 순서(의존), 작업별 완료 조건, 필요한 승인 지점을 담은 구조입니다. 계획 자체를 사람이 검토할 수 있게 저장합니다.

## 왜 하는가

며칠짜리 업무를 즉흥적으로 진행하면 중간에 길을 잃습니다. 완료 조건이 없으면 '끝났다'를 판단할 수 없습니다.

## 어떻게 (이 앱에서)

- (기반) 오케스트레이터(MA3)의 작업 계획(JSON) 계획
- (예정) 완료 조건 · 승인 지점을 포함한 계획 형식

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/lr_goal` 에서 볼 수 있습니다.

## 앞으로 할 일
