# LR1 · 목표 분해 · 계획 (Goal decomposition & planning)

**상태: ✅ 구현됨** — 큰 목표를 하위 작업 · 의존 관계 · 완료 조건이 있는 계획으로 나눈다

## 원리

계획은 작업 목록과 순서(의존), 작업별 완료 조건, 필요한 승인 지점을 담은 구조입니다. 계획 자체를 사람이 검토할 수 있게 저장합니다.

## 왜 하는가

며칠짜리 업무를 즉흥적으로 진행하면 중간에 길을 잃습니다. 완료 조건이 없으면 '끝났다'를 판단할 수 없습니다.

## 어떻게 (이 앱에서)

- 목표 → 단계 계획(행동 · 의존 · 완료 조건): 템플릿(AS 문의 동향 보고서 · 질문 일괄 답변) 또는 LLM 계획(등록된 행동 10개만 · JSON)
- 계획 검사: 모르는 행동은 거절, 의존은 앞 단계만, 되돌릴 수 없는 행동 앞에는 승인 단계를 자동으로 끼움

## 화면

- `/longrun/runs` — **업무 계획 · 실행**: 계획 · 체크포인트 · 이어 하기 · 되돌리기

## 앞으로 할 일

- 계획 품질 평가(목표 → 필요한 단계를 빠뜨리지 않았나)
