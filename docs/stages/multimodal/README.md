# M · 멀티모달 (Multimodal)

**상태: 🟡 기초 있음** — 이미지 · 텍스트를 같은 벡터 공간에서 다룬다

## 원리

멀티모달 임베딩 모델은 이미지와 텍스트를 같은 공간에 놓아, 텍스트로 이미지를 찾거나 이미지끼리 비교할 수 있게 합니다.

## 왜 하는가

제품 이미지 검색, 도면 · 스캔 문서, 영상 장면 검색처럼 텍스트만으로 풀 수 없는 사용 사례가 많습니다.

## 어떻게 (이 앱에서)

- 멀티모달 모델로 이미지 임베딩, 텍스트 → 이미지 교차 검색

## 화면

- `/multimodal` — **이미지 · 텍스트**: 이미지 임베딩 · 교차 검색

## 앞으로 할 일

- 이미지 컬렉션 색인 · 검색
- 영상 프레임 추출 · 장면 검색
