# M · 멀티모달 (Multimodal)

**상태: ✅ 구현됨** — 이미지 · 영상 장면을 텍스트와 같은 벡터 공간에서 찾는다

## 원리

멀티모달 임베딩 모델은 이미지와 텍스트를 같은 공간에 놓아, 텍스트로 이미지를 찾거나 이미지끼리 비교할 수 있게 합니다. 영상은 일정 간격의 프레임(장면)으로 나눠 이미지처럼 다룹니다.

## 왜 하는가

제품 이미지 검색, 도면 · 스캔 문서, 영상 장면 검색처럼 텍스트만으로 풀 수 없는 사용 사례가 많습니다. 한국어 질의로 그림을 찾으려면 다국어 멀티모달 모델이 필요합니다(CLIP 은 한국어에 약함).

## 어떻게 (이 앱에서)

- 이미지 · 영상을 RAG 컬렉션 문서로 올림 — 영상은 일정 간격 프레임을 뽑고 같은 장면은 버림, 이미지 · 프레임 1장 = 청크 1개
- 멀티모달 모델로 인덱스를 만들면 그림으로 인코딩 → 검색 비교 · 평가 세트 · 검색 향상을 그대로 사용
- 결과 썸네일, 영상은 그 장면 시각부터 재생 — 실측: EmbeddingGemma 2 nDCG 100 vs CLIP 67.4(한국어 단일 정답 5문항 모두 실패)

## 화면

- `/multimodal` — **이미지 · 영상**: 즉석 교차 검색 · 컬렉션 갤러리 검색

## 앞으로 할 일

- 이미지로 이미지 찾기(질의 이미지 업로드)
- 실제 영상(움직임 · 자막)과 대량 이미지로 재측정, GPU 색인
- 오디오 임베딩(의존성 해결 후)
