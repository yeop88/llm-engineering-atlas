# EC6 · 결과 검증 (Result verification)

**상태: ✅ 구현됨** — 산 결과가 조건에 맞는지 검사한다

## 원리

결과 검증은 받은 결과(번역 · 보고서 · 데이터)가 주문 조건(형식 · 품질 · 납기)에 맞는지 자동 검사 · 검증 에이전트로 확인하는 단계입니다.

## 왜 하는가

확인 없이 정산하면 에스크로가 의미 없습니다. 검증 기준은 주문할 때 정해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 장기 실행 검증(LR)
- 납품됐나 · 받기 기준을 넘나(흉내 판매자는 신뢰도 · 품질 확률로 납품 · 결과)

## 화면

- `/economy/ledger#simulate` — **결과 검증**: 납품 · 받기 기준

## 앞으로 할 일

- 번역 표본 검사 · OCR 정확 · 배송 접수 번호 확인
