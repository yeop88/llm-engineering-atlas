# EC6 · 결과 검증 (Result verification)

**상태: 🔬 연구** — 산 결과가 조건에 맞는지 검사한다

## 원리

결과 검증은 받은 결과(번역 · 보고서 · 데이터)가 주문 조건(형식 · 품질 · 납기)에 맞는지 자동 검사 · 검증 에이전트로 확인하는 단계입니다.

## 왜 하는가

확인 없이 정산하면 에스크로가 의미 없습니다. 검증 기준은 주문할 때 정해야 합니다.

## 어떻게 (이 앱에서)

- (기반) 완료 판정(LR6) · 검증 에이전트(MA7)
- (연구) 주문 조건 → 검사 · 통과 · 불합격 판정

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ec_verify` 에서 볼 수 있습니다.
