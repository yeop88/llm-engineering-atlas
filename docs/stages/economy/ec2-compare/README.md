# EC2 · 가격 · 조건 비교 (Price & terms comparison)

**상태: 🔬 연구** — 같은 기능의 가격 · 품질 · 납기 · 환불 조건을 비교한다

## 원리

가격 · 조건 비교는 같은 기능의 서비스들을 가격 · 품질(과거 결과) · 납기 · 환불 조건으로 점수 매기는 것입니다. 가장 싼 것이 늘 맞지 않습니다.

## 왜 하는가

조건을 읽지 않고 가격만 보고 고르면 결과가 나빠도 환불이 안 되는 서비스에 돈이 묶입니다.

## 어떻게 (이 앱에서)

- (기반) 예산 · 비용 선택(S7)
- (연구) 서비스 점수(가격 · 품질 · 납기 · 환불)

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ec_compare` 에서 볼 수 있습니다.
