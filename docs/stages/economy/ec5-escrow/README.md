# EC5 · 결제 · 에스크로 (Payment & escrow)

**상태: 🔬 연구** — 흉내 장부에서 돈을 묶어 두고 결과 확인 뒤 푼다

## 원리

에스크로는 돈을 바로 보내지 않고 묶어 두었다가 결과가 확인되면 보내는 방식입니다. 이 맵은 실제 결제 대신 흉내 장부(잔액 · 묶음 · 이동)로 흐름을 시험합니다.

## 왜 하는가

결과를 받기 전에 다 내면 분쟁 때 되찾기 어렵습니다. 묶어 두는 단계가 있어야 검증이 의미가 있습니다.

## 어떻게 (이 앱에서)

- (기반) 장기 작업(IO4)
- (연구) 흉내 장부 · 묶음 · 해제 · 멱등 결제

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ec_escrow` 에서 볼 수 있습니다.
