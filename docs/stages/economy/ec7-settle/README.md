# EC7 · 정산 · 영수증 (Settlement & receipts)

**상태: 🔬 연구** — 통과하면 정산하고 영수증 · 감사 기록을 남긴다

## 원리

정산은 검증을 통과한 거래의 묶인 돈을 보내고 영수증(누가 · 무엇을 · 얼마에 · 근거)을 남기는 것입니다. 영수증은 감사 기록 사슬에 묶습니다.

## 왜 하는가

영수증이 없으면 누가 무엇에 얼마를 썼는지 알 수 없어 비용 배분 · 감사 · 세무가 모두 막힙니다.

## 어떻게 (이 앱에서)

- (기반) 감사 로그(G5)
- (연구) 영수증 · 감사 사슬 · 비용 배분 연결

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ec_settle` 에서 볼 수 있습니다.
