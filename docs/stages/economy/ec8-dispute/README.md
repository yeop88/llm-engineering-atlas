# EC8 · 분쟁 처리 (Dispute handling)

**상태: ✅ 구현됨** — 불합격 · 미이행이면 환불 · 분쟁 · 책임을 정한다

## 원리

분쟁 처리는 결과가 불합격이거나 상대가 이행하지 않을 때 환불을 요청하고, 책임(우리 · 상대 · 에이전트 오류)을 정해 사람에게 넘기는 단계입니다.

## 왜 하는가

에이전트 오류로 산 것과 상대의 잘못을 나눠야 책임과 재발 방지를 정할 수 있습니다.

## 어떻게 (이 앱에서)

- (기반) 고지 · 이의(RC6)
- 불합격이면 판매자 환불 조건대로(전액 · 50% · 없음), 납품 자체가 없으면 전액 — 공격 시나리오로 규칙 있는 · 없는 에이전트를 같은 씨앗으로 비교

## 화면
