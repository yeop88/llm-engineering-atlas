# EC4 · 거래 승인 (Transaction approval)

**상태: 🔬 연구** — 금액 · 위험에 따라 사람 승인을 요구한다

## 원리

거래 승인은 위임 안이어도 금액 · 처음 보는 상대 · 위험 신호가 있으면 사람 승인을 받는 단계입니다. 승인 기록(누가 · 언제 · 무엇을)을 남깁니다.

## 왜 하는가

되돌리기 어려운 행동은 사람이 보고 결정해야 합니다. 승인 없는 거래 0 이 이 맵의 첫 지표입니다.

## 어떻게 (이 앱에서)

- (기반) 승인 지점(LR4) · 위험 승인(CU4)
- (연구) 금액 · 상대 · 위험 기반 승인 규칙 · 승인 기록

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ec_approve` 에서 볼 수 있습니다.
