# EC4 · 거래 승인 (Transaction approval)

**상태: ✅ 구현됨** — 금액 · 위험에 따라 사람 승인을 요구한다

## 원리

거래 승인은 위임 안이어도 금액 · 처음 보는 상대 · 위험 신호가 있으면 사람 승인을 받는 단계입니다. 승인 기록(누가 · 언제 · 무엇을)을 남깁니다.

## 왜 하는가

되돌리기 어려운 행동은 사람이 보고 결정해야 합니다. 승인 없는 거래 0 이 이 맵의 첫 지표입니다.

## 어떻게 (이 앱에서)

- (기반) 장기 실행 승인(LR)
- 금액이 기준(5,000원)을 넘거나 처음 거래하는 상대면 사람 승인, 승인한 금액과 결제 금액이 다르면(승인 뒤 값 바꾸기) 막음

## 화면

- `/economy/ledger#quote` — **거래 승인**: 금액 · 처음 상대 → 사람 승인, 승인 금액 ≠ 결제 금액이면 막음
