# EC3 · 예산 정책 · 위임 (Budget & mandate)

**상태: 🔬 연구** — 누가 · 무엇에 · 얼마까지 쓰게 할지 위임 범위를 정하고 검사한다

## 원리

예산 정책은 에이전트에게 준 위임(mandate) — 쓸 수 있는 금액 · 기간 · 상대 · 용도 — 입니다. 거래마다 위임 안인지 검사하고 남은 예산을 갱신합니다.

## 왜 하는가

에이전트가 반복 실행하면 작은 금액도 쌓여 큰돈이 됩니다. 상한은 실행하는 쪽에서 막아야 합니다.

## 어떻게 (이 앱에서)

- (기반) 비용 배분(PF7) · 장기 실행 상한(LR7)
- (연구) 위임 객체 · 금액 · 기간 · 상대 · 용도 검사
