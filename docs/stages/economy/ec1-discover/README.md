# EC1 · 서비스 발견 (Service discovery)

**상태: ✅ 구현됨** — 에이전트 카드 · 도구 목록에서 살 수 있는 서비스를 찾는다

## 원리

서비스 발견은 에이전트 카드(A2A) · 도구 목록(MCP)에서 기능 · 가격 · 조건이 적힌 서비스를 찾는 것입니다. 상대의 신원(누가 운영하나)을 함께 확인합니다.

## 왜 하는가

기능만 맞는다고 아무 상대에게 돈을 보낼 수 없습니다. 신원 확인 없는 발견은 사기에 열려 있습니다.

## 어떻게 (이 앱에서)

- (기반) 에이전트 카드(IO A2A)
- 흉내 시장(번역 · OCR · 배송 접수 7곳)에서 기능(skill)으로 찾기 — 에이전트 카드의 기술 목록 자리

## 화면

- `/economy/ledger` — **거래 규칙 · 흉내 장부**: 견적 · 일 처리 흉내 · 규칙 있음 vs 없음

## 앞으로 할 일

- 실제 에이전트 카드 · 도구 목록에서 찾기
