# EC1 · 서비스 발견 (Service discovery)

**상태: 🔬 연구** — 에이전트 카드 · 도구 목록에서 살 수 있는 서비스를 찾는다

## 원리

서비스 발견은 에이전트 카드(A2A) · 도구 목록(MCP)에서 기능 · 가격 · 조건이 적힌 서비스를 찾는 것입니다. 상대의 신원(누가 운영하나)을 함께 확인합니다.

## 왜 하는가

기능만 맞는다고 아무 상대에게 돈을 보낼 수 없습니다. 신원 확인 없는 발견은 사기에 열려 있습니다.

## 어떻게 (이 앱에서)

- (기반) A2A 위임 · 에이전트 카드(IO3)
- (연구) 카드의 가격 · 조건 필드 · 상대 신원 확인

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/ec_discover` 에서 볼 수 있습니다.

## 앞으로 할 일

- 카드의 가격 · 조건 필드 · 상대 신원 확인
