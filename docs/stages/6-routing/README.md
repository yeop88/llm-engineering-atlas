# 6 · 라우팅 (Model routing)

**상태: ⬜ 예정** — 질문의 난이도 · 종류를 먼저 분류해 처리할 모델을 고른다

## 원리

질문을 먼저 분류(난이도 · 의도 · 분야)해, 쉬운 질문은 작고 빠른 모델로, 어려운 질문은 크고 정확한 모델(에이전트)로 보내는 단계입니다.

## 왜 하는가

모든 질문을 가장 큰 모델로 처리하면 비싸고 느립니다. 대부분의 쉬운 질문은 작은 모델로 충분하므로, 나눠 처리하면 비용과 지연을 크게 줄이면서 품질을 지킬 수 있습니다.

## 어떻게 (이 앱에서)

- 규칙 · 임베딩 분류기(의미 응용의 분류기 재사용) · LLM 판단 라우터 비교
- 모델별 비용 · 지연 · 정답률을 함께 보고 배분

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/routing` 에서 볼 수 있습니다.

## 앞으로 할 일

- 질문 난이도 · 의도 분류기
- 라우팅 전후 평균 비용과 품질 비교
