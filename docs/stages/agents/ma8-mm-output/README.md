# MA8 · 멀티모달 출력 (Multimodal output)

**상태: ⬜ 예정** — 텍스트 답에 더해 차트 · 이미지 · 음성으로 결과를 낸다

## 원리

수집한 이미지 · 표 근거와 분석 결과를 함께 써서, 글 답변 외에 새 차트 · 요약 이미지 · 음성(TTS) 안내를 만듭니다. 출력도 근거 번호와 검증을 따릅니다.

## 왜 하는가

'그래프로 보여 줘', '현장에서 들을 수 있게' 같은 요구는 글만으로 채울 수 없습니다. AS 수리 안내는 단계별 그림 · 음성이 더 쓸모 있습니다.

## 어떻게 (이 앱에서)

- (있음) 그림 근거를 읽고 글로 답하기(비전 입력) — 출력은 아직 글만
- (예정) 분석 에이전트(MA5) 결과로 차트 출력, 음성 안내(TTS)
- (예정) 출력물에도 근거 번호를 달고 검증 에이전트(MA7)를 거침

## 화면

- 아직 테스트 화면이 없습니다. 단계 소개는 앱의 `/stages/mm_output` 에서 볼 수 있습니다.

## 앞으로 할 일

- 차트 출력
- 음성 안내(TTS)
