# K1 · 요구사항 정의 (Competency questions)

**상태: ⬜ 예정** — 지식 그래프가 답해야 할 업무 질문 10~15개로 그래프의 범위를 정한다

## 원리

역량 질문(Competency Questions)은 '이 그래프로 무엇에 답할 수 있어야 하는가'를 질문 목록으로 적은 것입니다. 어떤 개념 · 관계 · 속성이 필요한지는 이 질문들에서 거꾸로 정해지고, 완성된 그래프가 질문에 실제로 답하는지가 검수 기준이 됩니다.

## 왜 하는가

범위를 정하지 않고 '문서에 있는 것을 전부' 그래프로 만들면 개념이 끝없이 늘고 관계 이름이 제각각이 되어 쿼리할 수 없는 그래프가 됩니다. 질문이 먼저 있어야 온톨로지를 작게 시작해 필요할 때 넓힐 수 있습니다.

## 어떻게 (이 앱에서)

- (예정) 도메인별 역량 질문 목록과 기대 답(쿼리 결과)을 평가 세트처럼 저장 — 예: '근로기준법 제23조를 인용한 대법원 판례 중 해고가 무효로 판단된 사건은?'
- (예정) 질문마다 필요한 개념 · 관계를 표시해 온톨로지 설계(K2)의 입력으로 사용
- (예정) 벡터 RAG 로 답하기 어려운 질문(다단계 · 집계 · 전체 요약)을 따로 표시 — GraphRAG(K6~K8)의 효과를 잴 대상
