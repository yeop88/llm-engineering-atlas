텍스트 분류

감성분석, 고객·AS 문의 라우팅, 스팸 판별처럼 텍스트를 정해진 라벨로 나눕니다. 라벨 설명만으로 바로 분류(제로샷)하거나, 라벨 붙은 예시로 분류기를 학습해 저장하고 API 로 씁니다.

라벨 붙은 예시

학습 설정

로지스틱 회귀는 예시가 수십 개 이상일 때 가장 정확합니다. 중심점은 예시가 아주 적거나(라벨당 2~5개) 라벨이 자주 바뀔 때, kNN 은 한 라벨 안에 여러 유형이 섞여 있을 때 유리합니다. 정확도는 5겹 교차검증(라벨 비율 유지)으로 잽니다.

분류할 텍스트

라벨 정의

텍스트와 "라벨: 설명" 문장의 유사도로 고릅니다. 학습 데이터 없이 바로 쓸 수 있지만 보통 학습한 분류기보다 정확도가 낮습니다. 입력에 정답 라벨([라벨] 텍스트)이 있으면 정확도도 계산합니다.
