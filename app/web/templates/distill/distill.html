지식 증류 테스트

큰 모델(교사)의 판단을 작은 모델(학생)이 따라 하게 학습합니다. 임베딩은 교사가 매긴 '정답 − 오답' 점수 차를 학생이 배우고(MarginMSE, 교사는 큰 임베딩 모델 또는 리랭커), LLM 은 교사 답변 중 검증을 통과한 것만 모아 작은 LLM 학습 데이터로 내보냅니다.

임베딩 증류

학습 질문은 파인튜닝과 같은 방법(LLM 질문 · ICT)으로 만들고, 평가 세트의 근거가 든 지문은 학습에서 뺍니다. 학습한 학생은 카탈로그에 등록되고, 교사 · 학생(전) · 학생(후)를 같은 평가 세트로 비교합니다. 학습 기록은 파인튜닝 화면에도 함께 보입니다.

LLM 증류 데이터

컬렉션 지문으로 새 질문을 만들고(평가 세트는 쓰지 않음 — 나중에 그 세트로 학생을 재야 하므로), 교사 LLM 이 서비스와 똑같은 형식(근거 번호 + 질문)으로 답한 것 중 문장 근거율 · 인용 검증을 통과한 것만 대화 형식 JSONL 로 저장합니다. 작은 LLM 학습(SFT)은 GPU 환경의 TRL · Unsloth · LLaMA-Factory 등에서 이 파일로 합니다.
